## 微信视频号发布指南

### 封面设计
- 尺寸：1080x1920 (竖屏)
- 主标题：「JetBrains 放弃 Fleet」或「全新 Air IDE」
- 副标题：震撼感文字
- 建议色系：深色背景 + 霓虹/渐变文字

### 文案模板
```
🔥 JetBrains 史诗级转型！

Fleet 停止开发，全新 Air IDE 发布
VS Code、Cursor、Air 三国争霸
AI 编程时代开启

你怎么看？评论区告诉我 👇
#JetBrains #AirIDE #AI编程 #开发者工具 #程序员
```

### 发布时间
- **最佳时间**：20:00-22:00（用户活跃高峰）
- **备选时间**：12:00-14:00（午休时间）

### 互动引导
- 结尾提问：「你最看好谁？」
- 引导评论：「评论区见」
- 引导分享：「转发给你身边的程序员」

## 小红书发布指南

### 封面设计
- 尺寸：1080x1920 (竖屏) 或 1440x1920 (3:4)
- 标题文字要大：60-80px
- emoji 装饰：🚀🔥💫
- 话题标签显眼

### 文案模板
```
JetBrains 放弃 Fleet 了！全新 Air IDE 来了 🚀

就在昨天，JetBrains 宣布了一个重磅消息：

🔥 停止开发 Fleet
🔥 全新 Agentic IDE "Air" 即将登场

这意味着什么？
VS Code 和 Cursor 的对手换人了！

从「舰队 Fleet」到「空气 Air」
这改名也太有诗意了 😂

你怎么看？评论区告诉我！

#JetBrains #AirIDE #Fleet #VSCode #Cursor 
#AI编程 #开发者工具 #编程IDE #程序员
```

### 发布时间
- **最佳时间**：12:00-14:00（午休刷手机高峰）
- **次佳时间**：20:00-22:00（晚上刷笔记高峰）

### 标签策略
- 必带：#JetBrains #AI编程 #程序员
- 选带：#代码编辑器 #技术新闻 #编程入门
- 蹭热点：#VSCode #Cursor

## 抖音发布指南

### 短视频脚本（15-30秒）

**[0-3秒] 开场**
- 画面：Fleet logo 快速闪过
- 配音：「Fleet，要停用了？」
- 字幕：震惊效果

**[3-8秒] 转折**
- 画面：问号动画 + 紧张音效
- 配音：「但是！JetBrains 推出了全新 Air IDE！」
- 字幕：重磅！

**[8-20秒] 亮点**
- 画面：Air logo 渐显 + 科技感背景
- 配音：「面向 AI 编程，Agentic 开发环境」
- 字幕：Air = 空气

**[20-30秒] 收尾**
- 画面：VS Code / Cursor / Air 三分天下
- 配音：「三国争霸，你 pick 谁？」
- 字幕：评论区见

```
程序员重磅消息！

全新 Air IDE 即将登场 👇

VS Code、Cursor、Air 三国争霸
你看好谁？

#程序员 #JetBrains #AI编程 #IDE #VSCode #Cursor #Air
```

### 发布时间
- **最佳时间**：18:00-20:00（下班刷抖音高峰）
- **次佳时间**：21:00-23:00（睡前刷抖音高峰）

## 知乎发布指南

### 文章结构

**1. 开头（Hook）**
- 开门见山抛出核心事件
- 「2026年，JetBrains 做出了一个艰难的决定」

**2. 背景铺垫**
- Fleet 的历史（2021年发布，一直预览）
- 市场竞争格局（VS Code、Copilot 的崛起）

**3. 核心分析**
- 为什么是现在？（AI 时代的到来）
- Air 的定位（Agentic IDE）
- JetBrains 的优势

**4. 未来展望**
- 能否成功？
- 行业影响

**5. 互动结尾**
- 「你怎么看？」
- 引导评论讨论

### 发布时间
- **最佳时间**：工作日 10:00-12:00
- **备选时间**：工作日 20:00-22:00

## 通用发布 Checklist

### 发布前检查
- [ ] 视频/文章内容准确无误
- [ ] 标题吸引眼球
- [ ] 封面图清晰、高质量
- [ ] 话题标签已添加
- [ ] 互动引导已设置
- [ ] 原文链接已添加（如有）

### 发布后维护
- [ ] 第一时间回复评论
- [ ] 引导讨论方向
- [ ] 收集用户反馈
- [ ] 如有错误，及时修正
