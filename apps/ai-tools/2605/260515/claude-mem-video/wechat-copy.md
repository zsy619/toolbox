# Claude Code 终于能"记住"项目了！这个开源插件太强了

用 Claude Code 编程，最痛苦的是什么？

每次新建会话，AI 就像失忆了一样，什么都不记得。

你得重新解释项目结构、之前的决策、遇到的坑...

**Claude-Mem** 来了。

## 它解决了什么问题？

自动记录你在编程过程中的：
- 关键决策和原因
- Bug 修复方案
- 功能实现思路
- 项目特定知识

下次新建会话，直接继承这些上下文。

## 自然语言搜索

不需要手动整理记录，直接问：

> "上次我们是怎么实现这个功能的？"
> "之前修复过这个 bug 吗？"
> "我们对 auth 模块做了什么改动？"

它能理解并回答你。

## 隐私保护

使用 `<private>` 标签，可以排除敏感内容的存储。

## 安装方式

在 Claude Code 中输入：

```
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```

重启即可使用。

## 完全免费开源

AGPL-3.0 开源协议，代码完全透明。
