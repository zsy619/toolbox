### 发布规范

- **帧率**: 60fps
- **时长**: 约47秒（符合15-60秒规范）
- **文件格式**: MP4 (H.264编码)

> 让 AI 真正掌控浏览器！这个开源工具太牛了

还在为 AI 无法操作网页而烦恼？Agent Browser 让 AI 像人类一样操作浏览器 —— 可访问性树快照 + 引用定位元素，双核心告别 XPath 脆弱问题。支持主流浏览器和多种 AI 框架，免费开源！

### 推荐话题
`#AI工具` `#无头浏览器` `#自动化` `#开源项目` `#AI Agent`

### 发布步骤
1. 打开微信视频号后台
2. 上传视频文件
3. 填写标题和描述
4. 添加话题标签
5. 发布

## YouTube

### 发布规范
- **分辨率**: 1080×1920 (Shorts) 或 1920×1080 (横屏)
- **帧率**: 60fps
- **时长**: Shorts 60秒以内最佳
- **文件格式**: MP4

### 推荐标题
> Agent Browser: AI Agent Headless Browser Automation | Open Source

### 推荐描述
```
Is your AI agent struggling to interact with websites? Agent Browser solves this problem with two powerful features:

1. Accessibility Tree Snapshot - AI reads page structure directly
2. Reference-based Element Location - No more fragile XPath

Supports major browser drivers and multiple AI Agent frameworks.

Perfect for: Automated Testing | Data Collection | AI Agent Workflows

Free & Open Source!

🔗 GitHub: github.com/matrixy/agent-browser-clawdbot
🔗 Skill: cn.clawhub-mirror.com/matrixy/agent-browser-clawdbot
```

### 推荐标签
`AI Agent` `headless browser` `automation` `open source` `web scraping` `automated testing`

### 发布步骤
1. 打开 YouTube Studio
2. 点击「创建」→ 上传视频
3. 填写标题、描述和标签
4. 选择「Shorts」或普通视频
5. 设置缩略图（可使用 docs/assets/cover.png）
6. 发布
