## 小红书正文

最近 GitHub 上有个项目让我震撼了。

用 AI 写代码已经很强了，但 UI 风格每次都像随机抽奖——

同一句"按钮用蓝色"，每次生成的颜色都不一样。

直到我看到了 awesome-design-md 这个项目：

它把 Linear、Vercel、Stripe 这些大厂的设计规范整理成 Markdown 文件。

AI 编程时直接读取，生成的 UI 风格瞬间稳定了 10 倍！

同一个需求，换一套 DESIGN.md，就像换了一套皮肤。

AI 前端开发的正确打开方式找到了。

## 视频号描述

awesome-design-md 项目收集了 Linear、Vercel、Stripe 等知名产品的设计规范文件，用 Markdown 格式让 AI 直接读取。生成的 UI 风格统一、美观，效率提升明显。

---

## 产品亮点

1. **简单直接** - 只需一个 Markdown 文件
2. **风格多样** - 收录 Linear、Vercel、Stripe 等多种风格
3. **AI 友好** - Markdown 是大模型擅长的格式
4. **效果明显** - UI 一致性提升显著
5. **免费开源** - 任何人都可使用和贡献

---

## 适用场景

- AI 编程助手（Claude Code、Cursor、Codex）
- 前端开发快速原型
- 设计规范统一
- 团队协作
