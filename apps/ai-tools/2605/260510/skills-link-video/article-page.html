Skills-Link

一个文件夹，所有AI应用共享skills

41+ AI Agent 支持 · 符号链接方案
跨设备同步 · 一条命令搞定

问题：每个AI工具都要单独配置skills？

Claude Code一套skills，Cursor另一套，Windsurf又一套……改一次要同步41个地方。每次更新都要手动同步，效率太低。

Skills-Link的解决思路：用符号链接方案，让所有AI应用的skills共享同一个Master目录。

41个AI应用，每个都有自己独立的skills配置

×

解决方案：符号链接

Claude Code
←
~/AISkills/
→
Cursor
所有app的skills链接到同一个Master目录

每个app的~/.xxx/skills变成指向~/AISkills/的符号链接。新增或编辑一个skill，所有应用立即可见。

支持的功能

🔗 符号链接

~/AISkills/ 作为唯一数据源，所有app链接到这里

🔄 跨设备同步

skills-link sync 推送到GitHub，另一台机器自动拉取

📋 rules-link

同时支持rules同步

🌐 universal fallback

任何未列出的agent也能用

命令

  • skills-link — 主命令，同步skills到所有应用
  • skills-link add <repo> — 从GitHub安装skill
  • skills-link list — 列出本地skills
  • skills-link sync — 推送变更到GitHub
  • skills-link app — 管理启用的应用
  • rules-link — 同步rules

安装使用

npm i -g skills-link
skills-link

首次运行自动引导：检测应用、导入skills、创建链接。随时再运行一次即可同步变更和检查状态。
