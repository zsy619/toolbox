## 视频文案 (配音脚本)

```
大家好，今天推荐一款 AI 字幕编辑神器：FlyCut Caption。

做视频最怕什么？观众看一半就划走。很大原因是没字幕。

FlyCut Caption 帮你解决这个问题。上传视频，Whisper AI 自动识别语音，生成精确的时间戳字幕。

全程在浏览器本地运行，不需要上传到服务器，保护你的隐私。

支持的可视化编辑：选择删除片段、批量操作、实时预览效果。

最后，一键导出 SRT、JSON 字幕，或者直接把字幕烧录到视频里。

技术栈是 React 19 加 Transformers.js，用 Web Workers 后台处理，不卡顿。

完全开源免费，开箱即用。访问 flycut.dev 试试吧。
```
