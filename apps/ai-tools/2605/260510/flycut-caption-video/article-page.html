FlyCut Caption - 基于 Whisper 的视频字幕编辑工具

AI 字幕 开源免费 本地处理

做视频最怕什么？

观众看一半就划走。

很大一个原因是——没有字幕。

今天推荐一款 AI 字幕编辑神器：FlyCut Caption。

它能做什么？

1. 上传视频，AI 自动识别语音

基于 OpenAI Whisper 模型，高精度语音转文字，支持多语言识别。

2. 全程本地运行

使用 Hugging Face Transformers.js，数据不上传服务器，保护隐私。

3. 可视化编辑

直观选择要删除的字幕片段，批量操作，实时预览效果。

4. 一键导出

支持 SRT、JSON 字幕格式，或者直接把字幕烧录到视频里。

技术亮点

  • React 19 + TypeScript + Vite
  • Web Workers 后台处理，不卡顿
  • 完全免费，开源可商用

使用方式

访问 flycut.dev，直接上手，无需注册。

总结：做视频字幕，有这一款工具就够了。免费、开源、本地处理、保护隐私。
