# FlyCut Caption Video Project

## 项目信息
- **项目名称**: flycut-caption-video
- **来源**: GitHub x007xyz/flycut-caption
- **主题**: AI 视频字幕编辑工具
- **开始时间**: 2026-04-27

## 核心内容
FlyCut Caption 是一款 AI 驱动的视频字幕编辑工具，专注于智能字幕生成、编辑和视频剪辑。

**官网**: https://flycut.dev
**GitHub**: https://github.com/x007xyz/flycut-caption

## 核心亮点
- 🎤 **Whisper 语音识别** - 基于 AI 的高精度语音转文字
- ✂️ **可视化字幕编辑** - 直观的字幕片段选择和删除
- 🎬 **实时视频预览** - 与字幕同步的视频播放
- 📤 **多格式导出** - SRT、JSON 字幕格式和视频文件
- 🎨 **字幕样式定制** - 字体、颜色、位置自定义
- 🌐 **国际化支持** - 中英文、日语等多语言

## 技术栈
- React 19 + TypeScript + Vite + Tailwind CSS
- Hugging Face Transformers.js（本地 AI 处理）
- Web Workers（后台线程处理）
- WebAV（视频处理）
