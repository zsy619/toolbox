# FlyCut Caption - 发布指南

## 平台发布参数

### 微信视频号
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 时长 | 15-60 秒（建议 30-45 秒） |
| 文件大小 | ≤ 200MB |
| 格式 | MP4 (H.264) |
| 封面 | 1080×1920 (竖屏) |
| 标题 | 简洁有力，不超过 20 字 |
| 描述 | 包含核心亮点和关键词 |

**标题参考**:
- "AI 字幕神器！上传视频自动生成"
- "这个开源工具，让字幕制作快 10 倍"

**话题标签**:
\#AI字幕 \#视频工具 \#效率神器 \#开源免费

### 小红书
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 或 1440×1920 |
| 封面 | 1440×2560 |
| 时长 | 15 秒 - 5 分钟 |
| 格式 | MP4 |

**标题** (8-20 字，带 emoji):
- "🔥 AI 字幕神器 | 免费开源"
- "这个工具让我做字幕效率提升 10 倍"

**正文** (100-500 字):
- 开头：痛点引入
- 中间：功能介绍
- 结尾：行动号召

**标签** (不少于 5 个):
\#AI字幕 \#视频剪辑 \#效率工具 \#开源免费 #whisper #工具推荐
