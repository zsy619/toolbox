## 正文

**【正文】**

🔥 GitHub 7.6K Stars！让 AI 编程「可追溯」的工具！

今天给大家介绍一个最近很火的开源项目——**h5i**。

## 它解决了什么问题？

AI 编程时代，Git 只能记录「是什么变化」，但它无法回答：

❌ **谁触发了这个变更？**
❌ **AI 当时在想什么？**
❌ **能否从上次停止的地方继续？**

**h5i**——AI 时代的 Git，作为 Git 的副驾驶，集成 Claude Code 和 Codex，记录 AI 生成代码时的完整推理过程。

## 四大核心功能

### 1️⃣ h5i context — 记录每一步推理

记录目标、里程碑、每个 OBSERVE/THINK/ACT 步骤，不丢失任何推理线索！

### 2️⃣ h5i claims — 减少 69% Token 消耗

为文件附加内容寻址的事实，AI 首次推导后下次直接复用！

### 3️⃣ h5i notes — 记录探索足迹

标记最需要人工 review 的提交，不确定时刻、盲改一目了然！

### 4️⃣ h5i vibe — 5秒审计

AI 足迹分析、提示注入检测、风险文件识别！

## 实测数据 (N=10 实验)

| 指标 | 变化 |
|------|------|
| Cache-read tokens | **−68.6%** |
| Read tool calls | **−80.8%** |
| Wall time | **−55.6%** |
