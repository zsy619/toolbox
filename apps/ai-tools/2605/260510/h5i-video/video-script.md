# h5i 视频脚本

## 基本信息

- **项目**: h5i
- **来源**: GitHub h5i-dev/h5i
- **风格**: 赛博朋克
- **总时长**: 约50秒
- **帧率**: 60fps

## 分镜脚本

### 场景1: 封面 (0-3秒)

**视觉**:
- 深紫黑背景 (#0D0221)
- 霓虹青色大标题 "h5i"
- 霓虹品红副标题 "AI 时代的 Git"
- 底部: github.com/h5i-dev/h5i

**动画**:
- 标题从中心放大出现 (spring动画)
- 文字带霓虹发光效果

**配音**: 无

---

### 场景2: 问题引入 (3-8秒)

**视觉**:
- 深紫黑背景
- 大字 "Git 只能记录代码变化"
- 小字列出 Git 无法回答的问题

**问题列表**:
- 谁触发了这个变更？
- AI 跳过了什么？
- AI 当时在想什么？

**动画**:
- 文字依次出现
- 问号带闪烁效果

**配音**: AI 编程时代，Git 只能记录「是什么变化」。但它无法回答：谁触发了这个变更？AI 当时在想什么？

---

### 场景3: h5i context (8-16秒)

**视觉**:

## 字幕设计

- **字体**: PingFang SC
- **大小**: 72px (竖屏必须≥72px)
- **颜色**: #00FFFF (霓虹青色)
- **对齐**: 底部居中 (Alignment 2 + \an2)
- **距底边**: 120px (MarginV)
- **描边**: 2px黑色

## 技术规格

| 参数 | 值 |
|------|-----|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 总帧数 | 3000帧 (50秒×60) |
| 字幕规格 | 72px, PingFang SC, 霓虹青色, 底部居中 |
