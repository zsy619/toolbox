# h5i 视频项目

## 项目信息

- **项目名称**: h5i-video
- **来源**: https://github.com/h5i-dev/h5i
- **主题**: AI 时代的版本控制 — 记录 AI 编程的思考过程
- **安装命令**: `curl -fsSL https://raw.githubusercontent.com/Koukyosyumei/h5i/main/install.sh | sh`
- **协议**: Apache-2.0

## 视频规格

- **分辨率**: 1080×1920 (9:16 竖屏)
- **帧率**: 60fps
- **时长**: 约50秒
- **风格**: 赛博朋克 (Cyberpunk)
- **主题色**: 深紫黑背景 + 霓虹青/品红发光

## 核心内容

1. **一句话介绍**: AI 时代的 Git — 记录 AI 编程的思考过程，不丢失任何推理线索

2. **核心亮点**:
   - **h5i context** - 记录目标、里程碑、每一步的 OBSERVE/THINK/ACT 推理过程
   - **h5i claims** - 为文件附加内容寻址的事实，证据变化时自动失效，**减少69%缓存读取 Token**
   - **h5i notes** - 记录探索足迹、不确定时刻、盲改
   - **h5i vibe** - 5秒审计：AI 足迹、风险文件、提示注入检测

3. **适用人群**: 使用 Claude Code / Codex 的开发者

4. **实测数据** (N=10实验):
   - Cache-read tokens: **−68.6%** (528K → 166K)
   - Read tool calls: **−80.8%** (5.2 → 1.0)
   - Wall time: **−55.6%** (46s → 20s)
