Maigret - 输入用户名，查遍全网

OSINT 开源免费 3000+网站

想查一个人在网上有哪些账号？

今天推荐一款 OSINT 神器：Maigret。

把用户名丢进去，3000+ 网站同时开扫，账号、ID、昵称全给你扒出来。

它能做什么？

1. 3000+ 网站同时扫描

默认扫描 500 个高流量站点，加 -a 参数扫描全部。

2. 递归扩散

发现新的用户名或线索？自动继续搜，把一个人的数字足迹串成网。

3. Tor / I2P 支持

支持暗网站点 (.onion)，可以查到更隐蔽的网络痕迹。

4. 多格式报告

  • HTML 报告 - 完整网页版
  • PDF 报告 - 方便分享
  • JSON / CSV - 机器可读
  • XMind 脑图 - 可视化关联

快速开始

pip install maigret
maigret YOUR_USERNAME

不想安装？试试 Telegram Bot：@maigret_search_bot
