- **时长**: 约 40-50 秒

## 分镜脚本

**画面**: 赛博朋克风格，深色背景，中心大字
**内容**:
- 主标题: Maigret
- 副标题: OSINT 用户名搜索引擎
- 标签: 3000+网站 / 递归扩散 / 开源免费

**画面**: 一个人在网上有多个账号，分散在不同平台
**文案**: "想知道一个人在网上有哪些账号？"

### 场景2: 核心功能 (8-30秒)
**画面**: 工具界面展示
**文案** (按顺序):

3. "账号、ID、昵称全给你扒出来"
4. "发现新线索？自动继续搜"
5. "把数字足迹串成网"

### 场景3: 技术亮点 (30-38秒)
**画面**: 终端界面或代码

- "HTML、PDF、图表随便选"
- "还有 Web 可视化界面"

### 结尾 (38-45秒)
**画面**: 官网地址
**文案**:
- "github.com/soxoj/maigret"
- "开源免费，蓝红对抗必备"

## 视频文案 (配音脚本)

```
今天推荐一款 OSINT 神器：Maigret。

想查一个人在网上有哪些账号？Maigret 帮你搞定。

把用户名丢进去，3000多个网站同时开扫，账号、ID、昵称全给你扒出来。

它还会递归扩散——发现新线索就继续搜，把一个人的数字足迹直接串成网。

支持 Tor 和 I2P 网络，连暗网站点都能查。

输出也不含糊，HTML、PDF、图表随便选，还有 Web 可视化界面。

做溯源调查、蓝队防御、红队对抗、社媒分析，这个工具收藏好。

开源免费，访问 GitHub 看看。
```
