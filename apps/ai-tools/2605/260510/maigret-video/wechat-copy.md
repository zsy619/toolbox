# Maigret - 公众号文案

## 公众号标题
这个开源工具，输入用户名就能查遍全网

## 公众号正文

想查一个人在网上有哪些账号？

今天推荐一款 OSINT 神器：**Maigret**。

**它能做什么？**

1️⃣ **3000+网站同时扫描**
把用户名丢进去，Maigret 会在 3000 多个网站上同时搜索，账户、ID、昵称全给你扒出来。

2️⃣ **递归扩散**
发现新的用户名或线索？自动继续搜，把一个人的数字足迹串成网。

3️⃣ **Tor / I2P 支持**
支持暗网站点 (.onion)，可以查到更隐蔽的网络痕迹。

4️⃣ **多格式报告**
- HTML 报告 - 完整网页版
- PDF 报告 - 方便分享
- JSON / CSV - 机器可读
- XMind 脑图 - 可视化关联

**使用方式**

```bash
pip install maigret
maigret YOUR_USERNAME
```
