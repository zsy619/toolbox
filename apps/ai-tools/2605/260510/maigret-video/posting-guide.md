# Maigret - 发布指南

## 平台发布参数

### 微信视频号
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 时长 | 15-60 秒（建议 30-45 秒） |
| 文件大小 | ≤ 200MB |
| 格式 | MP4 (H.264) |
| 封面 | 1080×1920 (竖屏) |
| 标题 | 简洁有力，不超过 20 字 |
| 描述 | 包含核心亮点和关键词 |

**标题参考**:
- "输入用户名，全网账号都能查"
- "这个OSINT工具，红蓝对抗都在用"

**话题标签**:
\#OSINT \#开源情报 \#社媒分析 \#网络安全 \#红队 \#蓝队

### 小红书
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 或 1440×1920 |
| 封面 | 1440×2560 |
| 时长 | 15 秒 - 5 分钟 |
| 格式 | MP4 |

**标题** (8-20 字，带 emoji):
- "🔥 OSINT神器 | 输入名字查全网"
- "这个开源工具，查人效率提升100倍"

**正文** (100-500 字):
- 开头：痛点引入
- 中间：功能介绍
- 结尾：行动号召

**标签** (不少于 5 个):
\#OSINT \#开源情报 \#社媒分析 \#溯源 \#红队 \#蓝队 \#网络安全 \#工具推荐
