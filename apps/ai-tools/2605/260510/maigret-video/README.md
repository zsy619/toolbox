# Maigret Video Project

## 项目信息
- **项目名称**: maigret-video
- **来源**: GitHub soxoj/maigret
- **主题**: OSINT 用户名搜索工具
- **开始时间**: 2026-04-27

## 核心内容
Maigret - 一个用户名丢进去，3000+网站同时开扫，账号、ID、昵称全给你扒出来，还能递归扩散——发现新线索就继续搜，把一个人的数字足迹串成网。

**GitHub**: https://github.com/soxoj/maigret
**PyPI**: https://pypi.org/project/maigret/

## 核心亮点
- 🎯 **3000+网站扫描** - 支持3000多个网站的账户搜索
- 🔄 **递归扩散** - 自动发现新用户名继续搜索
- 🌐 **Tor/I2P支持** - 支持.onion暗网站点
- 📊 **多格式报告** - HTML、PDF、JSON、CSV、图表
- 🔍 **信息提取** - 从个人资料页提取所有可用信息
- 🤖 **Web可视化界面** - 交互式图形界面
- 🔓 **无需API密钥** - 直接使用，无需注册

## 技术栈
- Python 3.10+
- socid_extractor (信息提取)
- Tor / I2P 网络支持
- Flask / Web界面
- Docker 支持
