# NeuTTS Video Project

## 项目信息
- **项目名称**: neutts-video
- **来源**: GitHub neuphonic/neutts
- **主题**: 开源本地 TTS 语音克隆模型
- **开始时间**: 2026-04-27

## 核心内容
NeuTTS - 开源、本地运行、支持语音克隆的 TTS 模型。仅需 3 秒音频即可克隆声音，120M 参数，可在手机、笔记本、甚至树莓派上运行。

**GitHub**: https://github.com/neuphonic/neutts
**HuggingFace**: https://huggingface.co/neuphonic

## 核心亮点
- 🗣️ **即时语音克隆** - 仅需 3 秒音频即可创建自定义音色
- 📱 **本地运行** - GGUF 格式量化，笔记本、手机、树莓派都能跑
- ⚡ **实时生成** - 中端设备上实时合成
- 🌐 **多语言支持** - 英语、西班牙语、德语、法语
- 🔒 **内置水印** - 输出带感知水印，可追溯
- 🏗️ **LLM 架构** - 基于轻量级 LLM backbone

## 模型规格
| 模型 | 参数量 | 特点 |
|------|--------|------|
| NeuTTS-Air | ~360M | 最佳音质 |
| NeuTTS-Nano | ~120M | 最快速度 |
