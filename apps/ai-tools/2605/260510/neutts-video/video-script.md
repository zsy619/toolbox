## 视频文案 (配音脚本)

```
今天推荐一款开源本地 TTS 神器：NeuTTS。

做语音合成，你还在用云端 API？隐私泄露、延迟高、费用贵。

NeuTTS 帮你解决这些问题。这是一款开源、本地运行的 TTS 模型，基于 LLM backbone。

最厉害的是——仅需 3 秒音频，就能克隆任何声音。

120M 参数，体积小巧，手机、笔记本、甚至树莓派都能跑。

支持英语、西班牙语、德语、法语，多语言无缝切换。

 NeuCodec 神经编解码器，音质出色。

性能也很强——iMac M4 上达到 195 tokens 每秒，手机上也能实时运行。

内置感知水印，输出可追溯，安全合规。

开源免费，安装只需一行命令。访问 GitHub 看看。
```
