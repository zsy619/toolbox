# NeuTTS - 发布指南

## 平台发布参数

### 微信视频号
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 时长 | 15-60 秒（建议 30-40 秒） |
| 文件大小 | ≤ 200MB |
| 格式 | MP4 (H.264) |
| 封面 | 1080×1920 (竖屏) |
| 标题 | 简洁有力，不超过 20 字 |
| 描述 | 包含核心亮点和关键词 |

**标题参考**:
- "3秒克隆声音，这款开源 TTS 太猛了"
- "本地运行的语音克隆模型"

**话题标签**:
\#TTS \#语音合成 \#开源 \#语音克隆 \#本地运行 \#AI

### 小红书
| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920 或 1440×1920 |
| 封面 | 1440×2560 |
| 时长 | 15 秒 - 5 分钟 |
| 格式 | MP4 |

**标题** (8-20 字，带 emoji):
- "🔥 开源 TTS 神器 | 3秒克隆声音"
- "这款本地 TTS 模型，隐私安全！"

**正文** (100-500 字):
- 开头：痛点引入
- 中间：功能介绍
- 结尾：行动号召

**标签** (不少于 5 个):
\#TTS \#语音合成 \#开源 \#语音克隆 \#本地运行 \#AI \#隐私安全
