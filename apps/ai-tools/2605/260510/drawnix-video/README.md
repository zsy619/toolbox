# Drawnix 视频项目

## 项目信息

- **项目名称**: drawnix-video
- **来源**: https://github.com/plait-board/drawnix
- **主题**: 插件化架构的多模式绘图工具——思维导图、流程图、自由绘画一体化
- **官网**: 无需安装，打开演示站点即可上手
- **协议**: 开源

## 视频规格

- **分辨率**: 1080×1920 (9:16 竖屏)
- **帧率**: 60fps
- **时长**: 约50秒
- **风格**: 赛博朋克 (Cyberpunk)
- **主题色**: 深紫黑背景 + 霓虹青/品红发光

## 核心内容

1. **一句话介绍**: 基于插件化架构，把思维导图、流程图、自由绘画整合到一个画布里

2. **核心亮点**:
   - 多模式绘图：思维导图 / 流程图 / 自由绘画一体化
   - Markdown → 思维导图：文本一键结构化，立刻可视化
   - Mermaid → 流程图：语法直转图形
   - 无限画布：可缩放、可滚动
   - 自动保存：随时续画，移动端也能用
   - 导出分享：PNG 及专用格式

3. **适用场景**: 需要绘图的所有场景，一个工具搞定大多数

4. **安装方式**: 无需安装（在线演示），或自部署到服务器
