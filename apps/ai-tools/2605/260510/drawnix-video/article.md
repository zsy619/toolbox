# Drawnix - 原始内容分析

## 项目概述

**Drawnix** 是基于插件化架构打造的多模式绘图工具，把思维导图、流程图、自由绘画等常用能力整合到一个画布里。

## 核心问题

在日常工作中，我们经常需要：
- 画思维导图整理思路
- 画流程图说明过程
- 自由绘画表达想法

传统方案需要多个工具，切换麻烦，数据不互通。

Drawnix 用一个画布解决所有绘图需求。

## 核心功能

### 1. 多模式绘图一体化
- **思维导图**：快速整理思路
- **流程图**：清晰展示流程
- **自由绘画**：随意表达想法
- 三种模式无缝切换

### 2. Markdown → 思维导图
- 输入 Markdown 文本
- 一键生成结构化思维导图
- 立刻可视化

### 3. Mermaid → 流程图
- 输入 Mermaid 语法
- 直接转换为流程图
- 省去重复画图的麻烦

### 4. 无限画布
- 可无限缩放
- 可自由滚动
- 灵感不受限制

### 5. 自动保存
- 随时自动保存
- 可以随时续画
- 支持移动端

### 6. 导出分享
- 支持 PNG 导出
- 支持专用格式
- 方便传播与协作

## 使用方式

### 无需安装
- 直接打开演示站点
- 立即上手使用

### 自部署
- 可部署到自己的服务器
- 数据与使用方式更可控
