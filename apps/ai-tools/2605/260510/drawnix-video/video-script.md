# Drawnix 视频脚本

## 基本信息

- **项目**: Drawnix
- **来源**: GitHub plait-board/drawnix
- **风格**: 赛博朋克
- **总时长**: 约50秒
- **帧率**: 60fps

## 分镜脚本

### 场景1: 封面 (0-3秒)

**视觉**:
- 深紫黑背景 (#0D0221)
- 霓虹青色大标题 "Drawnix"
- 霓虹品红副标题 "一个画布搞定所有绘图"
- 底部: github.com/plait-board/drawnix

**动画**:
- 标题从中心放大出现 (spring动画)
- 文字带霓虹发光效果

**配音**: 无

---

### 场景2: 问题引入 (3-8秒)

**视觉**:
- 深紫黑背景
- 大字 "思维导图、流程图、自由绘画"
- 小字 "需要三个工具？"

**动画**:
- 文字依次出现
- 问号带闪烁效果

**配音**: 思维导图、流程图、自由绘画——你还在用三个工具吗？切换麻烦，数据不通！

---

### 场景3: 解决方案 (8-15秒)

**视觉**:
- 深紫黑背景
- 大字 "一个画布搞定所有"
- 三个模式图标依次出现

**模式**:
- 🎯 思维导图
- 📊 流程图
- 🎨 自由绘画

**动画**:
- 图标从底部滑入
- 带霓虹边框发光

**配音**: Drawnix 基于插件化架构，把三种模式整合到一个画布里！一个工具，覆盖大多数绘图场景！

---

### 场景4: 亮点功能 (15-30秒)

**视觉**:
- 深紫黑背景
- 六个功能卡片依次出现

**功能列表**:
1. Markdown → 思维导图：一键结构化，立刻可视化
2. Mermaid → 流程图：语法直转图形
3. 无限画布：可缩放、可滚动
4. 自动保存：随时续画
5. 移动端支持：手机也能用
6. PNG导出：方便传播协作

**动画**:
- 每个功能从侧边滑入
- 带霓虹边框发光

**配音**: Markdown 一键生成思维导图，立刻可视化！Mermaid 语法直接转流程图！无限画布，灵感不受限制！自动保存，随时续画，移动端也能用！支持 PNG 导出，方便传播与协作！

---

### 场景5: 使用方式 (30-38秒)

**视觉**:
- 深紫黑背景
- 两个选项

**选项**:
1. "无需安装" - 打开演示站点即可上手
2. "自部署" - 部署到自己的服务器，数据更可控

**动画**:
- 选项卡片依次出现

**配音**: 无需安装，打开演示站点就能用！也可以自部署到你的服务器，数据与使用方式更可控！

---

### 场景6: 结尾号召 (38-50秒)

**视觉**:
- 深紫黑背景
- 大字 "立即体验 Drawnix"
- 下方: github.com/plait-board/drawnix
- 底部: 霓虹光效渐变

**动画**:
- 链接从透明淡入
- 背景霓虹光效流动

**配音**: 一个画布搞定所有绘图，立即体验，把灵感变成生产力！

## 字幕设计

- **字体**: PingFang SC
- **大小**: 72px (竖屏必须≥72px)
- **颜色**: #00FFFF (霓虹青色)
- **对齐**: 底部居中 (Alignment 2 + \an2)
- **距底边**: 120px (MarginV)
- **描边**: 2px黑色

## 技术规格

| 参数 | 值 |
|------|-----|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 总帧数 | 3000帧 (50秒×60) |
| 字幕规格 | 72px, PingFang SC, 霓虹青色, 底部居中 |
