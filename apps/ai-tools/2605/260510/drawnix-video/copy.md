## 长文案 (公众号/博客)

**版本A**:
```
🔥 GitHub 新热榜！一个画布搞定所有绘图！

今天给大家介绍一个最近很火的开源项目——Drawnix。

## 它解决了什么问题？

思维导图、流程图、自由绘画——你还在用三个工具吗？切换麻烦，数据不通！

Drawnix 基于插件化架构，把三种模式整合到一个画布里，一个工具，覆盖大多数绘图场景！

## 核心亮点

1️⃣ **Markdown → 思维导图**
输入 Markdown 文本，一键生成结构化思维导图，立刻可视化！

2️⃣ **Mermaid → 流程图**
输入 Mermaid 语法，直接转换为流程图，省去重复画图的麻烦！

3️⃣ **无限画布**
可无限缩放、可自由滚动，灵感不受限制！

4️⃣ **自动保存**
随时自动保存，可以随时续画，支持移动端！

5️⃣ **PNG导出**
支持 PNG 及专用格式，方便传播与协作！

## 使用方式

- **无需安装**：直接打开演示站点，立即上手
- **自部署**：可部署到自己的服务器，数据更可控

一个画布搞定所有绘图，强烈推荐大家去试试！
```
