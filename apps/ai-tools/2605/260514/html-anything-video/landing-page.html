快速开始 

$ git clone https://github.com/nexu-io/html-anything
$ cd html-anything
$ pnpm install
$ pnpm dev
# → http://localhost:3000

打开浏览器，顶栏自动检测已登录的AI编程工具
右侧选择模板，左侧粘贴内容，⌘+Enter 即可生成
