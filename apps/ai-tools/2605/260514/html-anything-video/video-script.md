# 视频脚本 — HTML Anything

## 视频信息
- **项目**: HTML Anything
- **时长**: 52秒
- **帧率**: 60fps
- **尺寸**: 1080×1920 (9:16竖屏)

## 分镜设计

### 场景1 — 开场（0-8秒，120帧）
**画面**: 全屏深色背景，中央主标题渐入
**文字**:
- 主标题: HTML Anything（居中，白色大字）
- 副标题: Markdown是草稿，HTML是最终体验
**动画**: 背景色渐显，标题从下方滑入，粒子效果

### 场景2 — 核心价值（8-22秒，210帧）
**画面**: 三列卡片式布局展示核心特性
**内容**:
- 左: 零API密钥 — 复用本地AI编程工具，零额外成本
- 中: 75种模板 — 杂志文章、演示文稿、海报、小红书卡片、网页原型
- 右: 一键导出 — 微信、X、知乎，粘贴即发布
**动画**: 卡片依次从底部滑入，循环色带背景

### 场景3 — 技术架构（22-36秒，210帧）
**画面**: 架构图风格，展示4个开源项目支撑
**内容**:
- open-design — AI检测层和设计系统
- markdown-nice — CSS内联和微信适配
- markdown-to-image — 高清PNG导出
- huashu-md-html — 抗AI垃圾规范
**动画**: 四个模块从四个角向中心汇聚连接

### 场景4 — 使用流程（36-46秒，150帧）
**画面**: 步骤流程图，从左到右
**步骤**:
1. 克隆项目 → pnpm install → pnpm dev
2. 浏览器打开，AI工具自动检测
3. 选择模板，粘贴内容
4. ⌘+Enter 生成，导出发布
**动画**: 步骤依次高亮，箭头引导

### 场景5 — 结尾（46-52秒，90帧）
**画面**: 主标题+CTA
**文字**:
- 主标题: HTML Anything
- CTA: github.com/nexu-io/html-anything
**动画**: 最终帧淡入，背景粒子效果

## 音频
- **配音**: edge-tts zh-CN-YunjianNeural，1.2x语速
- **时长**: 约43秒（留9秒静音余量）

## 字幕
- **格式**: captions.json，startMs/endMs格式
- **字号**: 72px ASS（约40px视觉）
- **同步**: 按句子数等时分配
