# 公众号文案 — HTML Anything

## 标题
Markdown是草稿，HTML才是最终体验

## 摘要
无需API密钥，零成本生成专业HTML文档。75种模板，一键导出到微信/X/知乎。

## 正文

### 你还在为文档排版烦恼吗？

Markdown写完还要手动转HTML，微信/X/知乎格式各不相同，反复调整耗时间。

**HTML Anything** 来了。核心理念很简单：Markdown只是草稿，HTML才是读者真正阅读的形式。

### 零API成本

HTML Anything 自动检测你本地已有的 Claude Code、Cursor Agent、OpenAI Codex、Gemini CLI、GitHub Copilot CLI、OpenCode、Qwen Coder、Aider 等8款AI编程工具。

**无需任何API密钥**。它复用你已有的订阅，边际成本为零。

### 75种技能模板

覆盖9大输出场景：

| 场景 | 模板示例 |
|---|---|
| 杂志文章 | 印刷级排版质感 |
| 演示文稿 | Swiss International、Guizang Editorial等20款 |
| 海报 | 新闻纸风格大标题 |
| 小红书卡片 | 社交媒体竖屏适配 |
| 推文卡片 | X/推特分享图 |
| 网页原型 | SaaS落地页、仪表盘 |
| 数据报告 | 专业图表可视化 |
| 简历 | 专业排版模板 |
| Hyperframes视频 | Remotion兼容帧脚本 |

### 一键导出，粘贴发布

生成后支持一键导出：

- **微信** — juice内联CSS，粘贴即可，无需格式重调
- **X/微博/小红书** — modern-screenshot渲染高清2× PNG，剪贴板直传
- **知乎** — LaTeX公式自动转图片占位符
- **HTML/PNG下载** — 独立文件包

### 质量标准：生成即成品

HTML Anything 的质量标准是：**生成完成时，产出物就是受众最终看到的样子**。不需要"之后再调整"。

### 快速开始

```bash
git clone https://github.com/nexu-io/html-anything
cd html-anything
pnpm install
pnpm dev
# → http://localhost:3000
```

打开浏览器，顶栏自动检测已登录的AI编程工具，右侧选择模板，左侧粘贴内容，⌘+Enter 即可生成。
