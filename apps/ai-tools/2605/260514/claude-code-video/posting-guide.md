## 小红书
- **时长**: 30-60秒
- **比例**: 9:16 竖屏
- **封面**: 大字 + 副标题，吸睛
- **标题**: 8-20字，带emoji
- **正文**: 干货 + 情绪，100-500字
- **标签**: 不少于5个相关话题

- **比例**: 9:16 竖屏
