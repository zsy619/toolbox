# 微信视频号 多平台发布指南

## 平台配置

| 平台 | 封面尺寸 | 视频尺寸 | 建议时长 | 标签 |
|------|----------|----------|----------|------|
| 微信视频号 | 1080×1920 | 1080×1920 | 52秒 | AI工具、科技数码 |
| 抖音 | 1080×1920 | 1080×1920 | ≤60秒 | #科技 #工具 |
| 小红书 | 1440×2560 | 1080×1920 | 52秒 | AI工具、科技数码 |
| YouTube | 1280×720 | 1920×1080 | ≥60秒 | AI工具、科技数码 |

## 发布步骤

### 微信视频号
1. 打开微信视频号 App
2. 点击右上角「+」发布视频
3. 填写标题（30字以内）和描述
4. 添加话题标签：AI工具、科技数码
5. 选择「完整视频」发布

### 抖音
1. 打开抖音 App，点击「+」
2. 上传视频文件（不要直接拍摄）
3. 文案模板：「cyberpunk工具推荐｜第52秒有惊喜」
4. 添加话题：#科技 #工具推荐 #效率神器
5. @抖音小助手 获取流量扶持

### 小红书
1. 打开小红书 App
2. 点击「+」→「相册」选择视频
3. 封面选视频内帧（不要选白屏/黑帧）
4. 标题模板：「救命！这个cyberpunk工具也太好用了」
5. 正文：开头要有获得感，中段介绍功能，结尾引导互动
