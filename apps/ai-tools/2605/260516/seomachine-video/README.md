# SEOMachine - Claude Code SEO 内容创作工作流

> 📝 Claude Code 工作流 · SEO 优化长文内容生成

## 📌 项目简介

**SEOMachine** 是一个专门用于创建 SEO 优化长文内容的 Claude Code 工作流。它能够帮助用户自动化研究关键词、生成高质量文章、优化格式和结构，从而提升网站在搜索引擎中的排名。

| 特性 | 说明 |
|------|------|
| 🔍 关键词研究 | 自动化研究关键词和竞争对手分析 |
| ✍️ 高质量撰写 | 根据研究结果生成优质文章 |
| 📊 SEO 优化 | 自动化优化文章格式和结构 |
| 🤖 多代理协作 | 内容分析、SEO优化、元元素创建代理 |
| ⚡ 效率提升 | 批量生成文章，提升网站排名 |
