### 正文

**今天介绍一个非常实用的开源项目！**

SEOMachine，是一个专门用于创建 **SEO 优化长文内容**的 Claude Code 工作流。

**核心命令：**

🔍 **/research** - 关键词研究和竞争对手分析

✍️ **/write** - 根据研究结果撰写高质量文章

📊 **/optimize** - 对文章进行 SEO 优化

🎯 **/analyze-existing** - 分析现有文章并提出改进建议

📋 **/rewrite** - 重写不符合标准的文章

🔄 **/performance-review** - 效果评估

📤 **/publish-draft** - 发布草稿

🌐 **/priorities** - 确定内容优先级

🏠 **/landing-page** - 创建着陆页

**专业化代理：**

- 📝 内容分析代理
- 🎯 SEO 优化代理
- 🏷️ 元元素创建代理
- 📤 草稿发布代理

**技术特点：**

- 🐍 基于 Python 开发
- 🤖 专为 Claude Code 设计
- 📈 自动化整个 SEO 内容创作流程
