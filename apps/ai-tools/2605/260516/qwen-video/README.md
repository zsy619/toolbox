## 🚀 快速开始

### 视频文件位置
```
~/.openclaw/workspace/qwen-video/
├── qwen-video.mp4     # 主视频 (60秒, 4.8MB)
└── docs/assets/cover.png  # 封面图
```

### 本地预览
```bash
cd video-project
npx remotion serve src/index.tsx
```

### 重新渲染
```bash
cd video-project
npx remotion render src/index.tsx VerticalVideo --out out/video.mp4
```

### 修改内容
编辑 `video-project/src/index.tsx` 中的组件内容，然后重新渲染。
