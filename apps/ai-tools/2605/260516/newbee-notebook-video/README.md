# Newbee Notebook - 新蜂阅读器

> 🐝 对标 NotebookLM，更棒的阅读体验和 AI 交互

## 📌 项目简介

**Newbee Notebook**（新蜂阅读器）是一款 AI 驱动的自托管交互式文档阅读器，对标 Google NotebookLM，提供更棒的阅读体验和 AI 交互机制。

## 🎯 核心价值

| 特性 | 说明 |
|------|------|
| 📄 多格式支持 | PDF、Word、Excel、PPT、EPUB 等 |
| 🔒 隐私优先 | 数据完全不上云，本地运行 |
| 🎬 视频总结 | YouTube / B站视频内容分析 |
| 🧠 思维导图 | AI 自动绘制结构化图表 |
| 📝 Agent 笔记 | 边读边记，深度理解 |
| 🎯 高精度解析 | PDF 大文档精准提取 |

## 🎬 视频演示

本项目配套视频演示了 Newbee Notebook 的核心功能和用法：

- **平台**: 微信视频号 / 小红书 / 抖音 / YouTube
- **时长**: 48 秒
- **分辨率**: 1080×1920 (竖屏)
- **帧率**: 60fps
