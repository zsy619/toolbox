## 项目概述

本项目将头条文章内容转化为完整的视频、图文和结构化文档，包含：
- 📄 4个文档文件
- 🖼️ 2张AI生成图片
- 🎵 音频文件
- 🎬 126秒竖屏视频 (8个场景)

## Karpathy方法核心

### 三层架构
```
raw/     →  LLM编译  →  wiki/
(原始素材)    (编译器)    (结构化知识)
```

### 5步重建流程
1. 拆分旧库 → raw/ + inbox/
2. AI编译规则 → 定义处理文档的规则
3. 批量编译 → 先验证一份，再批量
4. 双链与索引 → 反向链接 + MOC入口
5. 闭环使用 → 丢素材→编译→提问→写回

### 必装插件
- **Jot** - 追加式速记
- **Dataview** - 动态目录
- **PDF Editor** - 批注论文
- **Graph Analysis** - 知识集群
