## 内容概要

### 是什么
Video Use 是 Browser Use 开源的 Claude Code Skill，让 Claude Code 直接变身专业视频编辑器。

### 四大功能
1. **说话输出** - 对着镜头说话，直接输出最终视频
2. **自动剪辑** - 自动剪掉填充词、调色、添加字幕
3. **动画效果** - 集成 Manim 和 Remotion 动画
4. **自我评估** - 渲染前进行质量评估

### 亮点
- 100% 开源免费
- 告别付费视频编辑软件
- 视频创作者和 Claude Code 用户可直接使用
