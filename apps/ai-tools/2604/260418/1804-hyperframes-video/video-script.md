# 视频脚本 - HeyGen HyperFrames

## 基本信息
- **时长**: 约 40-50 秒（1.2x 语速）
- **主题**: tech-modern
- **分辨率**: 1080×1920（竖屏）

## 配音文稿

太牛逼了！

HeyGen 发布了 HyperFrames，一个基于 HTML 自动做视频的工具。

有点类似 Remotion，但是感觉做的更加完善。

这个视频生成只用了一句指令：

npx skills add heygen-com/hyperframes

然后输入网站地址，HyperFrames 就能自动生成视频。

它是开源的、Agent 原生的框架，HTML 转 MP4。

现在可以用它来自动化你的视频制作流程了。
