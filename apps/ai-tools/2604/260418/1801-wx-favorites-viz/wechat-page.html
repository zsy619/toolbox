对 Claude Code 说一句，微信收藏自动变可视化报告

微信收藏了 1000+ 篇文章却从来不看？一个 Claude Code Skill 把它们全分析了一遍。

一句话搞定

在 Claude Code 里输入：微信收藏可视化

Claude 就会自动执行完整管线：密钥提取 → 数据库解密 → 数据解析 → 报告生成。全程不需要手动操作。

技术管线

第一步：frida 提取加密密钥

微信 Mac 4.x 版的收藏数据存在 favorite.db 里，是 SQLCipher 4 加密的。密钥通过 CCKeyDerivationPBKDF 函数在运行时派生。用 frida hook 捕获密钥派生调用。

第二步：AES-256-CBC 解密数据库

拿到密钥后，用 PyCryptodome 解密。AES-256-CBC、HMAC-SHA512、PBKDF2 256000 轮。

第三步：ECharts 生成交互报告

用 Python 解析数据库，生成单文件 HTML，内联 ECharts 5.x CDN。

报告功能

统计卡片、月度趋势图、内容类型甜甜圈图、来源 Top 15 排行榜、星期×小时活跃热力图、词云、标签云、可筛选可搜索可分页的收藏浏览区。

踩坑记录

实现过程踩了 8 个坑，迭代 6 轮。特别注意微信 4.x 表结构变化，收藏密钥只在打开收藏页面时才加载。
