## 正文

**【正文】**

🔥 GitHub 24k+ Star！AI克隆网站神器来了！

今天给大家介绍一个最近火出圈的开源项目——**Open Lovable**。

这是Firecrawl团队刚刚开源的工具，直接把网站克隆这事干成了黑科技！

把任意网站链接丢进去，几秒钟就能生成一个高度还原的React版本——布局、样式、交互都尽量贴近原站，复杂页面也稳。

**🚀 核心亮点**

• **一键克隆** - 任意网站输入，秒变React App
• **多模型支持** - OpenAI、Anthropic、Gemini、Grok随便选
• **高度还原** - 基于Firecrawl技术，还原度超高
• **实时预览** - 边生成边看，所见即所得
• **E2B沙盒** - 集成沙盒环境，测试更安全

**👥 适用人群**

前端开发者、独立开发者、产品设计师——想快速验证想法的人，这工具能省下无数时间！

**🔧 开源免费**

MIT协议，完全开源！

```bash
git clone https://github.com/firecrawl/open-lovable.git
cd open-lovable
pnpm install
pnpm dev
```

配好API Key就能跑！

把"抄作业"变成生产力，强烈推荐大家试试！
