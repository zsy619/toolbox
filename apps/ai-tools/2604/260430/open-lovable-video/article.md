# Open Lovable - 原始内容分析

## 项目概述

**Open Lovable** 是 Firecrawl 团队开源的 AI 网站克隆工具，通过对话方式几秒钟把任意网站转换为 React 应用。

## 核心功能

### 1. 一键克隆任意网站为React App
- 把任意网站链接丢进去
- 几秒钟生成高度还原的React版本
- 布局、样式、交互都尽量贴近原站
- 复杂页面也稳

### 2. 多模型支持
- **OpenAI** - GPT系列模型
- **Anthropic** - Claude系列模型
- **Gemini** - Google Gemini模型
- **Grok** - xAI的Grok模型
- **Groq** - 快速推理

### 3. Firecrawl技术底座
- 基于Firecrawl抓取结构化数据
- 还原度更高、更一致
- 比传统爬虫效果更好

### 4. 实时预览
- 边生成边预览
- 所见即所得
- 支持本地调试部署

### 5. E2B沙盒集成
- 集成E2B沙盒环境
- 运行测试更安全
- 隔离环境避免风险

## 技术特点

- **协议**: MIT，完全开源
- **技术栈**: Next.js + React
- **部署**: 支持Vercel或E2B沙盒
- **配置**: 只需配置API Key即可运行
