# Open Lovable 视频项目

## 项目信息

- **项目名称**: open-lovable-video
- **来源**: https://github.com/firecrawl/open-lovable
- **主题**: 用AI对话的方式，几秒钟把任意网站克隆成React应用
- **GitHub Stars**: 24k+
- **协议**: MIT

## 视频规格

- **分辨率**: 1080×1920 (9:16 竖屏)
- **帧率**: 60fps
- **时长**: 约50秒
- **风格**: 赛博朋克 (Cyberpunk)
- **主题色**: 深紫黑背景 + 霓虹青/品红发光

## 核心内容

1. **一行话介绍**: Firecrawl团队开源的Open Lovable，把任意网站链接丢进去，几秒钟生成一个高度还原的React版本

2. **核心亮点**:
   - 一键克隆任意网站为React App
   - 支持OpenAI、Anthropic、Gemini、Grok等多种模型
   - 基于Firecrawl抓取结构，还原度更高
   - 边生成边预览，所见即所得
   - 集成E2B沙盒，运行测试更安全

3. **适用人群**: 前端开发者、独立开发者、想快速验证想法的人
