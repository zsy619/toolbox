# Open Lovable 视频脚本

## 基本信息

- **项目**: Open Lovable
- **来源**: GitHub firecrawl/open-lovable
- **风格**: 赛博朋克
- **总时长**: 约50秒
- **帧率**: 60fps

## 分镜脚本

### 场景1: 封面 (0-3秒)

**视觉**:
- 深紫黑背景 (#0D0221)
- 霓虹青色大标题 "Open Lovable"
- 霓虹品红副标题 "AI网站克隆神器"
- 底部: github.com/firecrawl/open-lovable

**动画**:
- 标题从中心放大出现 (spring动画)
- 文字带霓虹发光效果

**配音**: 无

---

### 场景2: 震撼数据 (3-10秒)

**视觉**:
- 深紫黑背景
- 超大数字 "24k+" (霓虹青色，弹跳出现)
- 下方小字 "GitHub Stars"
- 快速闪过几个数字动画

**动画**:
- 数字弹跳放大出现
- 背景网格轻微浮动

**配音**: 24k+ Star！GitHub冲到24k+！这速度太疯狂了！

---

### 场景3: 核心功能介绍 (10-25秒)

**视觉**:
- 深紫黑背景
- 左侧: 功能图标 (霓虹发光)
- 右侧: 功能文字

**功能点**:
1. "一键克隆" - 把任意网站丢进去，几秒生成React App
2. "多模型支持" - OpenAI、Anthropic、Gemini、Grok随便选
3. "高度还原" - 基于Firecrawl抓取，布局样式交互都贴近原站
4. "实时预览" - 边生成边看，所见即所得
5. "E2B沙盒" - 集成沙盒环境，测试更安全

**动画**:
- 每个功能点逐个淡入
- 图标带脉冲发光效果

**配音**: 一键克隆任意网站！支持OpenAI、Anthropic、Gemini、Grok等多种模型！基于Firecrawl抓取技术，还原度更高更一致！边生成边预览，所见即所得！集成E2B沙盒，测试更安全！

---

**视觉**:

**人群**:

**配音**: 前端开发者、独立开发者、想快速验证想法的人，这工具能省下无数时间！

---

### 场景5: 开源免费 (35-45秒)

**视觉**:
- 深紫黑背景
- 大字 "MIT协议" "完全开源"
- 下方命令代码块 (霓虹绿)

**代码**:
```bash
git clone https://github.com/firecrawl/open-lovable.git
cd open-lovable
pnpm install
pnpm dev
```

**动画**:
- 代码块从左侧滑入
- 字符逐个出现 (打字机效果)

**配音**: MIT协议，完全开源！拉下来配好API Key就能跑！

## 字幕设计

- **字体**: PingFang SC
- **大小**: 72px (竖屏必须≥72px)
- **颜色**: #00FFFF (霓虹青色)
- **位置**: 底部居中
- **距底边**: 50px
- **描边**: 1px黑色

## 技术规格

| 参数 | 值 |
|------|-----|
| 分辨率 | 1080×1920 |
| 帧率 | 60fps |
| 总帧数 | 3000帧 (50秒×60) |
| 字幕规格 | 72px, PingFang SC, 霓虹青色 |
