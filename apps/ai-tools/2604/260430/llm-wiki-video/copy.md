# GitHub 2800+星！这个开源知识库，让LLM帮你增量构建Wiki

不想每次问AI都重新检索一遍？

这个GitHub上2800+星的开源项目，让LLM增量构建一个结构化的Wiki——知识编译一次，持续进化。

## 它解决什么问题？

传统RAG（检索增强生成）的痛点：
- 每次查询都从零检索，没有知识积累
- 无法形成结构化的知识网络
- 找不到你没意识到的知识盲区

LLM Wiki的思路完全不同：**知识编译一次，持续进化**。

## 核心功能

### 四信号知识图谱

不是乱连，是有算法的：
- 直接链接 ×3.0
- 来源重叠 ×4.0
- Adamic-Adar ×1.5
- 类型亲和 ×1.0

### Louvain 社区检测

自动发现知识簇，找到你没意识到的知识盲区。

### Chrome 网页剪藏

一键捕获网页内容，自动纳入知识库。

### Obsidian 兼容

三栏布局，[[wikilink]] 语法，颜值在线。

## 技术基础

基于 Andrej Karpathy 的 LLM Wiki 方法论：
- 三层架构：原始资料 → Wiki → Schema
- 三个核心操作：Ingest、Query、Lint
- 两步思维链摄入：先分析，再生成
