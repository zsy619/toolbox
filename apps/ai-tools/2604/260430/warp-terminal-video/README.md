# Warp Terminal - 项目概览

## 项目信息
- **项目名称**: warp-terminal-video
- **开始时间**: 2026-04-29 16:43 GMT+8
- **来源**: GitHub - warpdotdev/warp
- **链接**: https://github.com/warpdotdev/warp

## 核心内容
Warp is an agentic development environment, born out of the terminal. 用自然语言控制终端，AI Agent 原生集成。

## 功能亮点
- 🤖 **内置编码 Agent**：用自然语言控制终端
- 🔗 **多 Agent 支持**：Claude Code、Codex、Gemini CLI 等
- ⚡ **GPT 驱动**：Agentic 管理流程
- 🌐 **开源**：UI 框架 MIT 协议，后端 AGPL v3
- 💻 **跨平台**：macOS/Linux/Windows

## 技术规格
- **分辨率**: 1080×1920（竖屏 9:16）
- **帧率**: 60fps
- **时长**: 约45秒（1.2x语速）
- **主题**: 赛博朋克（Cyberpunk）
