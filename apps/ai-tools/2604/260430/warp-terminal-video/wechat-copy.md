# 这个终端有点酷！用自然语言控制命令行 💻

今天给大家介绍一个超酷的终端工具——**Warp**。

它是一个终端里的 AI 开发环境，用自然语言就能控制终端！

---

## 核心特性

| 特性 | 说明 |
|------|------|
| 🤖 内置编码 Agent | 用自然语言控制终端 |
| 🔗 多 Agent 支持 | Claude Code、Codex、Gemini CLI |
| 🌐 完全开源 | 客户端代码开源 |
| 📋 MIT 许可 | UI 框架采用 MIT 协议 |

---

## 多 Agent 集成

Warp 不仅有内置 Agent，还支持集成多种外部 Agent：

- **Claude Code** — Anthropic 的编码助手
- **Codex** — OpenAI 的编程模型
- **Gemini CLI** — Google 的命令行工具

---

## 开源透明

- **UI 框架**：MIT 许可
- **后端代码**：AGPL v3 协议
- **客户端代码**：完全开源
