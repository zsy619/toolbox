# Warp Terminal - 视频脚本

## 基本信息
- **平台**: 微信视频号 / 小红书 / 抖音
- **时长**: 约45秒（1.2x语速）
- **FPS**: 60fps
- **分辨率**: 1080×1920
- **主题**: 赛博朋克（Cyberpunk）

- **主标题**: Agentic Development Environment
- **副标题**: 终端里的 AI 开发环境

## 配音文稿（1.2x语速，约45秒）

Warp 是一个终端里的 AI 开发环境。

用自然语言就能控制终端，内置编码 Agent，支持 Claude Code、Codex、Gemini CLI 等多种 Agent。

Warp 客户端代码开源，UI 框架采用 MIT 许可，后端采用 AGPL v3 协议。

支持 macOS、Linux 和 Windows 系统。

快速开始：访问 warp.dev/download 下载安装。
