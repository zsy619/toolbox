# AI Cookbook 视频项目

## 项目信息

- **项目名称**: ai-cookbook-video
- **来源**: https://github.com/daveebbelaar/ai-cookbook
- **主题**: 面向实战的快速搭建 AI 系统手册
- **作者**: Dave（AI工程师，YouTube 25.5万+粉丝）
- **协议**: 开源

## 视频规格

- **分辨率**: 1080×1920 (9:16 竖屏)
- **帧率**: 60fps
- **时长**: 约50秒
- **风格**: 赛博朋克 (Cyberpunk)
- **主题色**: 深紫黑背景 + 霓虹青/品红发光

## 核心内容

1. **一句话介绍**: YouTube 25.5万+粉丝的AI工程师 Dave，整理了一本面向实战的「快速搭建 AI 系统手册」

2. **核心亮点**:
   - 真实项目级的 AI 代码示例
   - 经实战验证，可直接复制粘贴
   - 立刻用到你的项目里
   - 开源免费

3. **适用人群**: 开发者、数据专业人士、独立创业者
