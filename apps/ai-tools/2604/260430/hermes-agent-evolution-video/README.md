# Hermes Agent Self-Evolution 视频项目

## 项目概览

- **项目名称**: hermes-agent-evolution-video
- **来源**: https://github.com/NousResearch/hermes-agent-self-evolution
- **主题**: AI Agent 自我进化，GEPA + DSPy 优化技能和提示词
- **主题风格**: tech-modern（科技现代风）
- **平台**: 微信视频号 / 小红书 / 抖音

## 规格参数

| 参数 | 值 |
|------|------|
| 分辨率 | 1080×1920（9:16竖屏） |
| 帧率 | 60fps |
| 视频时长 | 约50秒 |
| 音频语速 | 1.2x |
| 字幕 | ASS格式，72px，黄色，底部居中 |
| 字体 | PingFang SC |

## 核心卖点

1. **无需GPU** — 纯API调用，$2-10/次优化
2. **GEPA引擎** — 读懂失败原因，不只是知道失败
3. **五阶段进化** — 技能→工具描述→系统提示→代码→持续循环
4. **Guardrails** — 测试通过+大小限制+语义保真+人工审核
5. **ICLR 2026 Oral** — 学术认可，MIT许可
