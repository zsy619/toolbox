## 内容摘要

**Y2A-Auto** 是一款将 YouTube 视频自动搬运到 AcFun / bilibili 的一体化工具，支持从下载、ASR、字幕翻译、字幕质检、内容审核到上传的全流程自动化。

### 核心亮点

1. **全流程自动化**：下载→ASR→字幕→翻译→审核→上传
2. **支持三大平台**：AcFun、bilibili、双平台同步
3. **AI 智能处理**：标题、简介、标签自动生成
4. **内容安全审核**：阿里云 Green 审核
5. **Web 管理后台**：可视化任务管理
6. **YouTube 监控**：频道/关键词定时抓取
7. **多编码器支持**：CPU/NVIDIA/Intel/AMD 硬件编码
