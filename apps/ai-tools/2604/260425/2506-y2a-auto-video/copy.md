### 核心功能

| 步骤 | 功能 |
|------|------|
| 1 | yt-dlp 下载视频与封面 |
| 2 | ASR 语音识别生成字幕 |
| 3 | 字幕翻译、质检、后处理 |
| 4 | AI 生成标题、简介、标签 |
| 5 | 内容安全审核 |
| 6 | 自动上传到 AcFun / bilibili |

### 支持平台

- AcFun
- bilibili
- 双平台同步

### 技术规格

- 语言：Python 3.11+
- 部署：Docker / 本地
- 硬件：NVIDIA / Intel / AMD / CPU
- 默认编码：HEVC / H.265
