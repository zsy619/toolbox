## 配音脚本

> 今天介绍 Y2A-Auto。
>
> 这是一款将 YouTube 视频自动搬运到 AcFun 和 bilibili 的一体化工具。
>
> 全流程自动化：下载、ASR 语音识别、字幕翻译、字幕质检、内容审核，最后自动上传。
>
> 支持三大平台：AcFun、bilibili，以及双平台同步上传。
>
> AI 智能处理：自动生成标题、简介、标签和分区推荐。
>
> 字幕支持 Whisper、Voxtral、FireRedASR2S，还能进行字幕质检确保准确。
>
> 内容安全审核：阿里云 Green 实时检测。
>
> Web 管理后台：可视化任务管理、人工审核、设置中心。
>
> YouTube 监控：支持频道监控和关键词搜索，定时抓取新视频。
>
> 部署方式灵活：Docker 一键部署、本地运行，或使用 Windows 便携包。
>
> 硬件编码支持：NVIDIA、Intel、AMD 或 CPU，默认使用 HEVC 编码。
>
> GitHub 搜索 Y2A-Auto，两百六十五 Stars！
