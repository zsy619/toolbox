## 配音脚本

> 今天介绍一个开源项目，火宝短剧。
>
> 这是一个基于 AI 的短剧自动化生产平台，一句话就能生成完整的短剧。
>
> 传统短剧制作，需要编剧、导演、演员，拍摄周期长，后期制作复杂，成本高昂。
>
> 而火宝短剧，只需输入剧本，AI 就会自动拆解分镜，生成角色和场景，一键合成视频。
>
> 核心功能包括：AI 角色生成、智能分镜拆解、多模型支持，以及 TTS 配音合成。
>
> 技术栈采用 TypeScript 全栈开发，使用 Nuxt 3、Vue 3、Hono 和 Mastra Agent 框架。
>
> 支持 Docker 一键部署，开箱即用。
>
> GitHub 搜索 huobao-drama，让 AI 帮我们做更有创造力的事。
