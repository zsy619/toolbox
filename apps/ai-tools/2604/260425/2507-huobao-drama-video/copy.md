## 长文案（150-300字）

### 版本1
**火宝短剧 - AI 短剧自动化生产平台**

你是否想过，只需一句话，AI 就能帮你生成完整的短剧？

火宝短剧是一个基于 AI 的开源短剧制作平台，实现从剧本到成片的全流程自动化。

**核心功能**：
- AI 角色生成与音色分配
- 智能分镜拆解
- 多模型图片/视频生成
- TTS 配音合成
- FFmpeg 视频合成

**技术栈**：
- TypeScript 全栈（Nuxt 3 + Vue 3 + Hono）
- Mastra AI Agent 框架
- Docker 一键部署

**支持厂商**：
- 图片：OpenAI、Gemini、MiniMax、火山引擎
- 视频：MiniMax、Vidu、阿里
- TTS：MiniMax

GitHub 搜索 huobao-drama，让 AI 帮我们做更有创造力的事。
