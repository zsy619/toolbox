# MiniCPM-o 端侧多模态大模型新标杆

> 「边看、边听、边说，全双工多模态实时交互」

## 核心摘要

MiniCPM-o 是从 MiniCPM-V 升级而来的最新一代端侧多模态大模型（MLLM）系列。

### MiniCPM-o 4.5：🔥🔥🔥 最新最强

| 参数 | 说明 |
|------|------|
| 9B | 总参数量 |
| Gemini 2.5 Flash 级 | 视觉、语音、全双工多模态 |
| 全双工实时流 | 边看、边听、边说 |
| 声音克隆 | 中英双语实时交互 |

### MiniCPM-V 4.0：⭐️⭐️⭐️ 高效

| 参数 | 说明 |
|------|------|
| 4B | 总参数量 |
| GPT-4.1-mini 级 | 图像理解超越 |
| 端侧部署 | 手机端侧理想选择 |

## 技术亮点

- **端到端 Omni-modal 架构**：SigLip2 + Whisper-medium + CosyVoice2 + Qwen3-8B
- **全双工实时流**：输入输出流互不阻塞
- **语音克隆**：支持声音克隆和角色扮演
- **OCR 能力**：状态-of-the-art 性能
- **多语言**：30+ 语言支持
