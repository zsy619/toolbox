Hermes WebUI - 在浏览器里用AI Agent

Lightweight dark-themed Web UI

今天给大家介绍一个超实用的开源项目——Hermes WebUI，它能让你在浏览器里使用 Hermes Agent。

核心特性

  • 三栏布局 - 会话列表、聊天窗口、文件浏览器
  • Token 用量环 - 实时显示上下文使用情况
  • Composer Footer - 模型/Profile/Workspace 控制始终可见
  • 完整 CLI 对等 - 无需构建步骤

技术亮点

  • 轻量暗色主题
  • 纯 Python + 原生 JavaScript
  • SSH 隧道安全访问
  • 单一命令启动
