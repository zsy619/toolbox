# Hermes WebUI 项目分析

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | Hermes WebUI |
| 定位 | 在浏览器中完整复刻 CLI 体验 |
| 核心功能 | 轻量暗色主题 Web UI |
| 技术栈 | Python + Vanilla JS |

## 核心内容（用户指定）

轻量暗色主题的 Web UI，在浏览器中完整复刻 CLI 体验，三栏界面集成会话列表、聊天窗口和文件浏览器，并可实时查看上下文 token 使用。

## 核心功能

### 1. 三栏布局
- **左侧边栏**：会话列表和导航
- **中间**：聊天窗口
- **右侧**：文件浏览器（支持内联预览）

### 2. Composer Footer
- 模型选择
- Profile 配置
- Workspace 控制
- 始终可见

### 3. Token 用量环
- 圆形上下文环
- 实时显示 token 使用情况

### 4. Hermes Control Center
- 所有设置
- 会话工具
- 启动器在侧边栏底部

## 技术特点

- **轻量级**：无需构建步骤
- **暗色主题**：深色设计
- **无框架**：纯 Python + 原生 JS
- **完整对等**：CLI 能做的，UI 都能做
- **SSH 隧道**：安全访问

## 与 CLI 的对等性

Hermes WebUI 提供了与 CLI 体验 1:1 的对等性：
- 终端能做的，UI 都能做
- 通过 SSH 隧道安全访问
- 单一命令启动
