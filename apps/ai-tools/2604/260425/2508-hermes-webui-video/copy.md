## 长文案（150-300字）

### 版本1
**Hermes WebUI - 浏览器里的AI Agent**

Hermes WebUI 是一款轻量级、暗色主题的 Web 应用，在浏览器中完整复刻 CLI 体验。三栏界面集成会话列表、聊天窗口和文件浏览器，并可实时查看上下文 Token 使用情况。

**核心特性**：
- 三栏布局：会话列表、聊天窗口、文件浏览器
- Composer Footer：模型/Profile/Workspace 控制始终可见
- Token 用量环：圆形上下文环，实时显示
- Hermes Control Center：所有设置和会话工具

**技术亮点**：
- 无需构建步骤
- 纯 Python + 原生 JavaScript
- SSH 隧道安全访问
- 单一命令启动

### 版本2
**AI Agent 的 Web 界面革命**

大多数 AI 工具每次会话都会重置。Hermes WebUI 打破了这个限制。

三栏布局：
- 左侧：会话列表和导航
- 中间：聊天窗口
- 右侧：文件浏览器（支持内联预览）

实时 Token 用量环让你随时掌握使用情况。
