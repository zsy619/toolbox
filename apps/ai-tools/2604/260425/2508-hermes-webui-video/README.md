# Hermes WebUI 视频项目

## 项目信息

| 参数 | 值 |
|------|------|
| 项目名称 | hermes-webui-video |
| 来源 | https://github.com/nesquena/hermes-webui |
| 主题 | tech-modern |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 时长 | ~45秒 |

## 核心内容（用户指定）

轻量暗色主题的 Web UI，在浏览器中完整复刻 CLI 体验，三栏界面集成会话列表、聊天窗口和文件浏览器，并可实时查看上下文 token 使用。

## 视频规格

- **分辨率**：1080×1920（竖屏）
- **帧率**：60fps
- **时长**：45秒
- **编码**：H.264 / AAC
