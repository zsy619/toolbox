## 配音脚本

> 今天介绍 Dory，AI 原生 SQL 工作站。
>
> 它把 SQL 编辑器、AI 助手和数据库运维整合到一个桌面应用里。
>
> 核心亮点：
>
> 第一，ClickHouse 深度集成。支持实时监控和权限管理。

> 第二，兼容主流数据库。PostgreSQL、MySQL、SQLite 都能用。

> 安装非常方便。macOS 用户用 Homebrew，其他用户可以直接 Docker 部署。
>
> GitHub 搜索 Dory，一百零二 Stars！
