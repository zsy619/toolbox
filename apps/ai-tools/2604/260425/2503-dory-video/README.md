## 内容摘要

**Dory** 把 SQL 编辑器、AI 助手和数据库运维整合到一个桌面应用里。

### 核心摘要（用户指定）

- **SQL 编辑器 + AI 助手 + 数据库运维**三合一
- **ClickHouse 深度集成**：监控 + 权限管理
- **兼容主流数据库**：PostgreSQL、MySQL 等
- **本地安装或 Docker 部署**
- **数据存在本地，只有 AI 请求走 Cloudflare**

### 核心功能

1. **SQL Copilot** - AI 辅助写 SQL，自然语言生成、修复、优化
2. **Schema-Aware 编辑器** - 基于真实数据库结构的智能补全
3. **Database Chatbot** - 对话式数据库探索
4. **ClickHouse 监控** - 实时指标监控
5. **ClickHouse 权限管理** - 用户和角色管理界面
