## 长文案版本

### 标题
Dory：AI 原生 SQL 工作站

### 正文
今天介绍 Dory，AI 原生 SQL 工作站。

### 核心功能

**1. SQL Copilot**
AI 助手 grounded in real database schema：
- 自然语言生成 SQL
- 修复或重写当前 SQL
- 解释查询逻辑和字段含义

**2. ClickHouse 深度集成**
- 实时监控：查询数、延迟、吞吐量
- 权限管理：用户、角色、授权

**3. 多数据库支持**
PostgreSQL、MySQL、SQLite 等。

### 安全特性

- 数据存在本地
- 只有 AI 请求走 Cloudflare

### 安装方式

| 平台 | 命令 |
|------|------|
| macOS | `brew install dorylab/dory/dory` |
| Docker | `docker run -d --name dory ...` |
