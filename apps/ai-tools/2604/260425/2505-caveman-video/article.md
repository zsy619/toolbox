# caveman - 节省75% tokens的AI代码助手

## 项目概述

**caveman** 是一个 Claude Code 技能，让 AI 用"穴居人说话方式"回复，大幅减少 token 消耗，同时保持 100% 技术准确性。

> **一句话理解**：用最少的话，说最准的事。

## 核心亮点

### 效果对比

| 指标 | 普通模式 | caveman 模式 |
|------|----------|--------------|
| Tokens | 69 | 19 |
| 技术准确性 | 100% | 100% |
| 速度 | 1x | ~3x |

### 强度级别

| 级别 | 风格 | 适用场景 |
|------|------|----------|
| 🪶 Lite | 轻度压缩 | 日常对话 |
| 🪨 Full | 完全穴居人 | 代码审查 |
| 🔥 Ultra | 极度精简 | 极简风格 |
| 📜 文言文 | 古文模式 | 特色需求 |

| Agent | 安装命令 |
