## 内容摘要

**caveman** 是一个 Claude Code 技能，通过"穴居人说话方式"大幅减少 token 消耗，同时保持技术准确性。

### 核心亮点

1. **节省 75% tokens**：输出 tokens 减少约 75%
2. **技术准确性不变**：所有技术信息保留，只删除冗词
3. **速度提升 3x**：更少的 token 生成 = 速度更快
4. **省钱**：减少输出 tokens = 降低成本
5. **有趣**：每个代码审查都变成喜剧
