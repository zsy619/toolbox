# InfiniteTalk 让任何人按你的台词说话

> 「上传一段视频和音频，AI 让任何人按你的台词说话」

## 核心功能

### 1. 稀疏帧视频配音

输入一段视频和一段音频，生成口型准确的新视频。

**与传统工具的区别**：

| 传统工具 | InfiniteTalk |
|----------|--------------|
| 仅同步口型 | 口型 + 头部摆动 + 身体姿势 + 面部表情 |

### 2. 无限时长生成

支持生成**超长时长**的视频，打破了许多同类 AI 工具只能生成几秒钟短片的限制。

### 3. 静态照片说话

只需一张人物照片和一段音频，即可生成该人物说话的动画视频。

### 4. 高稳定性

相比 MultiTalk：
- 更好地保持身份一致性
- 减少手部或身体的扭曲变形

## 技术亮点

- 基于 **Wan2.1** 基础模型开发
- 针对音频驱动任务专门优化
- 支持 **480P 和 720P** 分辨率
- 提供 **Gradio** 网页演示界面
- 提供 **ComfyUI** 工作流节点支持

## 适用场景

| 场景 | 说明 |
|------|------|
| 视频自媒体/搬运 | 外语视频翻译配音，同步口型，像母语播报 |
| 虚拟数字人 | AI 讲解员、虚拟主播，一张照片快速产出 |
| 影视后期 | 台词修改、口型订正 |
