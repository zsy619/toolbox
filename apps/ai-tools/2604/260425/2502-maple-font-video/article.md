# Maple Font - 圆角等宽字体的开源新选择

## 项目概述

**Maple Font**（Maple Mono）是一款开源等宽字体，具有圆角、连字和 Nerd-Font 图标支持。

> **一句话理解**：一款专为 IDE 和终端设计的圆角等宽字体，支持连字、小体积、高可读性。

## 核心特点

### 1. 全新造型
重新设计 `@ # $ % &` 等符号，以及斜体样式的新造型。

### 2. 更多连字
支持 `.., ..., /*, /**` 等连字组合，让代码更美观。

### 3. 小巧体积
仅包含拉丁字符、标准重音符号、表格控制字符和少量符号，体积小巧。

### 4. 优秀渲染效果
根据 Fira Code Retina 重新设计间距和字形，确保在不同字号下都能完美呈现。

### 5. 更高可读性
- 斜体风格
- 优化大写字母和数字高度
- 调整 `+ - * = ^ ~ < >` 等操作符的间距

### 6. 可自定义
可按需启用/禁用字体特性，打造专属字体。
