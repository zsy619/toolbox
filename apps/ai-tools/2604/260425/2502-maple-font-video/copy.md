## 长文案版本

### 标题
Maple Font：圆角等宽字体的开源新选择

### 正文
今天介绍 Maple Font，一款专为程序员设计的开源等宽字体。

### 核心特点

**1. 全新造型**
重新设计 @ # $ % & 等符号，以及斜体样式。

**2. 更多连字**
支持 `.., ..., /*, /**` 等连字组合。

**3. 小巧体积**
仅包含必要字符，字体文件精简。

**4. 优秀渲染**
根据 Fira Code Retina 重新设计。

**5. 高可读性**
斜体风格，降低大写字母高度。

**6. 可自定义**
按需启用/禁用字体特性。

### 安装方式

| 平台 | 命令 |
|------|------|
| macOS | `brew install --cask font-maple` |
| Arch Linux | `paru -S ttf-maple` |
| 其他 | releases 下载 |
