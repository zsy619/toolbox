# Maple Font 程序员的专属字体

> 「25390 Stars 的开源等宽字体」

## 为什么程序员都在用 Maple Font？

### 圆角设计
视觉更柔和，告别生硬棱角。

### 连字支持
`.., ..., /*, /**` 等连字组合，代码更美观。

### 小巧体积
仅包含必要字符，字体文件精简，加载快速。

### 优秀渲染
根据 Fira Code Retina 重新设计间距和字形。

### 可自定义
按需启用/禁用字体特性，打造专属字体。

## 核心特点

| 特点 | 说明 |
|------|------|
| 全新造型 | 重新设计符号外观 |
| 更多连字 | 多种连字组合 |
| 小巧体积 | 精简字体文件 |
| 优秀渲染 | Fira Code Retina 级 |
| 高可读性 | 斜体风格优化 |
| 可自定义 | 字体特性可调 |
