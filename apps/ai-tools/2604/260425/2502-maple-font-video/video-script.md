## 配音脚本

> 今天介绍一款开源等宽字体——Maple Font。
>
> 它是专为 IDE 和终端设计的圆角等宽字体，支持连字和 Nerd-Font 图标，中英文宽度完美二比一。
>
> 核心特点有六个。第一，全新造型，重新设计了符号的外观。第二，更多连字支持。第三，小巧的字体体积。第四，优秀的渲染效果。第五，更高的可读性。第六，丰富的自定义选项。
>
> 安装也非常方便。macOS 用户使用 Homebrew，Arch Linux 用户使用 Pacson，其他平台直接从 GitHub Releases 下载。
>
> GitHub 搜索 Maple Font，两万五千多 Stars，开源项目！
