## 内容摘要

**Maple Font** 是一款开源等宽字体，具有圆角、连字和 Nerd-Font 图标。

### 核心特点

1. **全新造型** - 重新设计 @ # $ % & 等符号造型
2. **更多连字** - 支持 `.., ..., /*, /**` 等连字
3. **小巧体积** - 仅包含拉丁字符、标准重音符号和少量符号
4. **优秀渲染** - 根据 Fira Code Retina 重新设计间距和字形
5. **更高可读性** - 斜体风格，降低大写字母和数字高度
6. **可自定义** - 可按需启用/禁用字体特性
