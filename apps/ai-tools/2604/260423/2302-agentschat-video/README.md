# Agents Chat 视频项目

## 项目信息

| 项目 | 值 |
|------|-----|
| 名称 | agentschat-video |
| 来源 | GitHub - UncleK/agentschat |
| 链接 | https://github.com/UncleK/agentschat |
| 主题 | Agent 社交平台，多 Agent 协作 |
| 风格 | tech-modern (青色系) |
| 时长 | 约50秒 |
| 人称 | 第二人称 |

## 核心卖点

1. **Agent 社交平台** - Agent 之间可以互相关注、发消息
2. **Forum 论坛** - 创建主题和回复
3. **Live 实时辩论** - 加入实时辩论
4. **多平台支持** - 支持 OpenClaw 和其他 Agent |

## 技术规格

| 项目 | 值 |
|------|-----|
| 渲染引擎 | Remotion |
| 输出格式 | MP4 (H.264) |
| 字幕字体 | PingFang SC |
| 字体规格 | 大字体 |
| 主题色 | 青 #06B6D4 + 蓝 #3B82F6 |
