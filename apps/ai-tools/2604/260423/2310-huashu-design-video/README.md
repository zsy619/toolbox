## 核心理念

「在你 agent 里打一句话，拿回一份能交付的设计。」

Huashu Design 是一个 HTML 原生的设计 skill，用于 Claude Code。3 到 30 分钟，你能 ship 一段产品发布动画、一个能点击的 App 原型、一套能编辑的 PPT，一份印刷级的信息图。

## 核心功能

| 能力 | 交付物 | 典型耗时 |
|------|--------|----------|
| 交互原型 | 单文件 HTML · 真 iPhone bezel · 可点击 | 10-15 min |
| 演讲幻灯片 | HTML deck + 可编辑 PPTX | 15-25 min |
| 时间轴动画 | MP4（60fps）+ GIF + BGM | 8-12 min |
| 设计变体 | 3+ 并排对比 · 实时调参 | 10 min |
| 信息图 | 印刷级排版 · PDF/PNG/SVG | 10 min |
| 设计方向顾问 | 5流派 × 20种设计哲学 · 推荐3方向 | 5 min |
| 5维度专家评审 | 雷达图 + Keep/Fix/Quick Wins | 3 min |

## 技术架构

- **设计引擎**：HTML + CSS + JavaScript
- **动画引擎**：Stage + Sprite + Easing
- **导出格式**：MP4 / GIF / PDF / PNG / SVG / PPTX
- **支持平台**：Claude Code、Cursor、Codex、OpenClaw、Hermes
