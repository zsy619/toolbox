Huashu Design

Huashu Design · 2026-04-21

在你 agent 里打一句话，拿回一份能交付的设计。

这个工具是什么

Huashu Design 是一个 HTML 原生的设计 skill，装进 Claude Code 等 AI 编码工具。

3 到 30 分钟，你能 ship 一段产品发布动画、一个能点击的 App 原型、一套能编辑的 PPT，一份印刷级的信息图。

能做什么

  • 交互原型：单文件 HTML，真 iPhone bezel，可点击
  • 演讲幻灯片：HTML deck + 可编辑 PPTX
  • 时间轴动画：MP4（60fps）+ GIF + BGM
  • 信息图：印刷级排版，可导 PDF/PNG/SVG
  • 5 维度专家评审：雷达图 + Keep/Fix/Quick Wins

安装使用

一行命令安装：

npx skills add alchaincyf/huashu-design

然后直接说话：

  • 「做个 iOS 原型，4 个核心屏幕要真能点击」
  • 「做一份演讲 PPT，推荐 3 个风格方向让我选」
  • 「把这个逻辑做成 60 秒动画，导出 MP4」

跨 Agent 通用

Claude Code、Cursor、Codex、OpenClaw、Hermes 都能装。
