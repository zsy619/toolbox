> ### Huashu Design
>
> 一个 HTML 原生的设计 skill，装进 Claude Code。
>
> **核心功能：**
>
> - **交互原型**：单文件 HTML，真 iPhone bezel，可点击
> - **演讲幻灯片**：HTML deck + 可编辑 PPTX
> - **时间轴动画**：MP4（60fps）+ GIF + BGM
> - **信息图**：印刷级排版，PDF/PNG/SVG 导出
> - **5 维度专家评审**：雷达图 + Keep/Fix/Quick Wins
>
> **安装方式：**
>
> ```bash
> npx skills add alchaincyf/huashu-design
> ```
>
> **使用示例：**
>
> ```
> 「做个 AI 番茄钟 iOS 原型，4 个核心屏幕要真能点击」
> 「做一份 AI 心理学演讲 PPT，推荐 3 个风格方向让我选」
> 「把这个逻辑做成 60 秒动画，导出 MP4 和 GIF」
> ```
>
> 跨 agent 通用——Claude Code、Cursor、Codex 都能装。
