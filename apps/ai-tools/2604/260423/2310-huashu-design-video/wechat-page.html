核心价值

Huashu Design 是一个 HTML 原生的设计 skill，装进 Claude Code 等 AI 编码工具。

不是「AI 做的还行」那种水平——是看起来像大厂设计团队做的！

功能矩阵

能力 交付物 典型耗时
交互原型 单文件 HTML · iPhone 真机可点击 10-15 min
演讲幻灯片 HTML deck + 可编辑 PPTX 15-25 min
时间轴动画 MP4（60fps）+ GIF + BGM 8-12 min
信息图 印刷级排版 · PDF/PNG/SVG 10 min
5维度评审 雷达图 + 可操作清单 3 min

安装使用

npx skills add alchaincyf/huashu-design

然后直接说话：

• 「做个 iOS 原型，4 个核心屏幕要真能点击」

• 「做一份演讲 PPT，推荐 3 个风格方向让我选」

• 「把这个逻辑做成 60 秒动画，导出 MP4」
