## 核心卖点

1. **跨平台 AI 客户端** - Web、iOS、Android、Mac、Linux、Windows 全平台
2. **数据隐私** - 目标直指数据隐私和模型自由
3. **灵活接入** - 支持云端 API 和本地 Ollama 模型
4. **自建后端** - 支持 Docker/Kubernetes 部署
5. **完全自控** - 数据存放在自己的服务器上
