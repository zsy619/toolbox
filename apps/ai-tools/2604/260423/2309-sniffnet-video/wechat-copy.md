# Rust写的网络流量监控器，实时看得见！6000+协议识别

> 「用 Rust 写的开源网络流量监控工具，实时查看流量、IP 位置、协议类型。」

## 核心功能

| 功能 | 说明 |
|------|------|
| 🌐 网络适配器 | 一键选择要监控的网卡 |
| 📊 实时统计 | 查看流量强度图表，带宽消耗一目了然 |
| 🌍 地理位置 | 显示每个连接 IP 所在的国家/城市 |
| 🔍 协议识别 | 识别 6000+ 种协议 |
| 💻 程序识别 | 查看哪些程序在产生网络流量 |
