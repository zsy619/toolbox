## 核心理念

Sniffnet 是一个用 Rust 编写的开源桌面应用，用来监控网络流量。它基于 iced 做 GUI、pcap 做底层抓包，支持 Windows、macOS 和 Linux。

## 核心功能

1. **网络适配器选择**：选择电脑的网络适配器开始抓包
2. **流量过滤规则**：设定过滤规则
3. **实时统计图表**：查看流量统计图表
4. **地理位置识别**：查看连接的地理位置
5. **域名/ASN信息**：识别域名和 ASN 信息
6. **协议识别**：识别 6000+ 种上层服务协议

## 技术架构

- **语言**：Rust（高性能）
- **GUI框架**：iced（跨平台 GUI 库）
- **抓包引擎**：pcap
- **IP数据**：MaxMind GeoIP
- **支持平台**：Windows、macOS、Linux

## 适用场景

- 网络故障诊断
- 流量异常检测
- 隐私安全监控
- 开发调试
