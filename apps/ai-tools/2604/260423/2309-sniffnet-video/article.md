# Sniffnet 内容分析

> 来源：https://github.com/GyulyVGC/sniffnet

## 项目概述

Sniffnet 是一个用 Rust 编写的开源桌面应用，专门用于监控网络流量。它基于 iced 做 GUI、pcap 做底层抓包，支持 Windows、macOS 和 Linux 三大平台。

## 为什么需要网络流量监控？

1. **隐私安全**：知道你的电脑在和谁通信
2. **故障诊断**：快速定位网络问题
3. **流量分析**：了解带宽消耗情况
4. **异常检测**：发现可疑的网络活动

## 核心功能

### 1. 网络适配器选择
- 选择电脑的网络适配器开始抓包
- 支持多种网络接口

### 2. 流量过滤规则
- 设定过滤规则
- 只看关心的流量

### 3. 实时统计图表
- 查看流量统计图表
- 实时了解流量强度

### 4. 地理位置识别
- 发现连接的远程主机地理位置
- 显示 IP 对应的国家/城市

### 5. 域名和 ASN 信息
- 查找正在通信的 hosts 的域名
- 获取 ASN（自治系统号）信息

### 6. 协议识别
- 识别 6000+ 种上层服务协议
- 包括 HTTP、HTTPS、DNS、SSH 等
- 还能识别木马和蠕虫

### 7. 程序识别
- 查看哪些程序在产生网络流量
- 识别流量来源

### 8. PCAP 文件
- 导入和导出 PCAP 抓包文件
- 方便分享和分析

### 9. 自定义通知
- 设置自定义通知
- 网络事件发生时提醒

### 10. IP 黑名单
- 导入自定义 IP 黑名单
- 高亮显示潜在危险连接

### 11. 主题支持
- 多种样式选择
- 支持自定义主题

## 技术架构

| 组件 | 技术 |
|------|------|
| 编程语言 | Rust |
| GUI 框架 | iced |
| 抓包引擎 | pcap |
| IP 地理 | MaxMind GeoIP |
| 支持平台 | Windows / macOS / Linux |
