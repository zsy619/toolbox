网络流量监控神器
用 Rust 写的 Sniffnet

Sniffnet · 2026-04-21

一款用 Rust 编写的开源网络流量监控工具，让你看清电脑在和谁通信。

为什么需要网络监控？

你的电脑每天都在和几十个服务器通信，包括后台服务、浏览器请求、各种 SDK 的心跳包……

你都知道这些连接是谁吗？有没有可疑的通信？

核心功能

  • 网络适配器选择：选择网卡，一键开始抓包
  • 实时流量统计：查看流量强度图表
  • 地理位置追踪：显示每个 IP 的国家/城市
  • 协议识别：识别 6000+ 种协议
  • 程序识别：查看哪些程序在产生流量

技术架构

  • Rust：性能出色，安全可靠
  • iced：简洁的跨平台 GUI
  • pcap：工业级抓包引擎
  • MaxMind：IP 地理位置数据

跨平台支持

完全跨平台，Windows、macOS、Linux 都能用。

适用场景

  • 🔍 网络故障诊断
  • 🔒 隐私安全监控
  • 📈 带宽分析
  • 🐛 开发调试
