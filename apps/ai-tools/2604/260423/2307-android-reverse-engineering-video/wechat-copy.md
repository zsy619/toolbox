# Android逆向技能！自动反编译，省时省力！

> 「只需把 APK 丢给它，就能自动完成反编译！」

## 问题痛点

手动反编译 + 从混淆代码里找 API 调用，费时费力！

## 解决方案

**android-reverse-engineering-skill** 专门用来反编译安卓应用并自动提取接口信息！

## 核心亮点

| 功能 | 说明 |
|------|------|
| 📦 多格式支持 | APK、XAPK、JAR、AAR |
| 🔍 接口提取 | 自动找出网络请求地址、认证方式 |
| 🛡️ 反混淆策略 | 面对代码混淆也有应对策略 |
| 🔗 调用链路追踪 | 追踪从页面到网络请求的完整调用链路 |

## 适用人群

- 需要进行安全研究的开发者
- 需要接口分析的开发者
- 大幅降低安卓逆向分析的门槛
