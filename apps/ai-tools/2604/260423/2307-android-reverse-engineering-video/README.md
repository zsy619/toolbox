## 核心卖点

1. **自动反编译** - 把 APK 丢给它就能自动完成反编译
2. **接口提取** - 自动找出所有网络请求地址、认证方式等关键信息
3. **多格式支持** - 支持 APK、XAPK、JAR、AAR 等格式
4. **反混淆** - 面对代码混淆也有应对策略
5. **调用链路追踪** - 追踪从页面到网络请求的完整调用链路
6. **降低门槛** - 大幅降低安卓逆向分析的门槛
