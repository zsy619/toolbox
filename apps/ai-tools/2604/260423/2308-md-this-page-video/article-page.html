网页转 Markdown 神器
给 AI 喂饭级工具

MD-This-Page · 2026-04-21

一个浏览器扩展，一键把任意网页转换成干净的 Markdown。

为什么需要这个工具？

每次给 AI 喂网页内容，你是否也在烦恼那些广告、导航栏、脚本噪音？

复制过来的内容，80% 是没用的 HTML 代码，真正有用的正文反而被埋在里面。

核心功能

  • 一键转换：Alt+M 或右键菜单，0.5 秒完成
  • 智能提取：基于 Mozilla Readability，只提取正文内容
  • 自定义选项：图片、链接、元数据，想留就留，想删就删
  • 多格式导出：复制、下载 md、直接复制成 Prompt 格式

为什么 LLM 需要 Markdown？

给 LLM 喂过网页都知道，HTML 的噪音（广告、导航、脚本）会占用大量的上下文窗口，却不提供任何意义。

  • 更少的噪音，更多的信号
  • 更好的结构理解
  • 更高的 Token 效率
  • 更准确的推理质量

适用场景

  • 🤖 AI 工作流内容准备
  • 📚 文章收藏与整理
  • 📖 技术文档提取
  • 🔬 研究资料收集

安装

Chrome 和 Firefox 用户都可以安装：

  • Chrome：Chrome Web Store 搜索 MD-This-Page
  • Firefox：Add-ons 商店搜索 MD-This-Page

用这个扩展，把"网页"变成"LLM-ready 文档"
