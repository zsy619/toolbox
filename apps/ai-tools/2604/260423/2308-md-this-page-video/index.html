核心功能

⚡

一键转换

Alt+M 或右键菜单，0.5 秒完成网页到 Markdown 的转换

🧠

智能提取

基于 Mozilla Readability，自动识别并提取网页正文内容

🤖

LLM 即食

输出的 Markdown 结构清晰，直接喂给 LLM 使用

使用方法

1

安装扩展

从 Chrome Web Store 或 Firefox Add-ons 安装 MD-This-Page

2

打开网页

浏览任意想要转换的网页

3

一键转换

按 Alt+M 或右键选择 ".MD this page"，获得干净的 Markdown

自定义选项

内容选项

  • ✓ 保留/移除图片
  • ✓ 保留/移除链接
  • ✓ 显示/隐藏元数据
  • ✓ 生成文档结构图

导出方式

  • 📋 复制到剪贴板
  • 💾 下载为 .md 文件
  • 🤖 复制为 Prompt 格式
