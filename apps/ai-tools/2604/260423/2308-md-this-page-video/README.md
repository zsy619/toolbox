## 核心理念

HTML 页面包含大量噪音（广告、导航栏、脚本），占用上下文窗口却不增加意义。MD-This-Page 将网页转换为简洁、结构化的 Markdown 格式，让 LLM 更容易处理和推理。

## 核心功能

1. **一键转换**：右键菜单或 Alt+M 快捷键
2. **智能提取**：基于 Mozilla Readability 分离主体内容
3. **自定义输出**：保留/移除图片、链接、元数据
4. **多模式导出**：复制、下载为 .md、作为 Prompt 导出

## 技术栈

- Plasmo (浏览器扩展框架)
- React + Tailwind CSS
- Mozilla Readability (内容提取)
- Turndown (HTML → Markdown)

## 适用场景

- AI 工作流内容准备
- 文章收藏与整理
- 技术文档提取
- 研究资料收集
