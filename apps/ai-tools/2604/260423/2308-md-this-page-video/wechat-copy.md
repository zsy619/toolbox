# 浏览器扩展 | 一键把网页转Markdown，给AI喂饭级工具！

> 「一个浏览器扩展，Alt+M 一键把网页转成干净 Markdown，去广告去导航，LLM 直接用。」

## 问题痛点

给 LLM 喂网页时，HTML 的噪音（广告、导航、脚本）占用大量上下文窗口，却不提供任何意义。

**复制过来的内容，80% 是没用的代码！**

## 解决方案

**MD-This-Page** 浏览器扩展，一键把任意网页转换成干净的 Markdown。

## 核心功能

| 功能 | 说明 |
|------|------|
| ⚡ 一键转换 | Alt+M 或右键菜单，0.5 秒完成 |
| 🧠 智能提取 | 基于 Mozilla Readability，只提取正文 |
| 🎛️ 自定义选项 | 图片、链接、元数据，想留就留 |
| 📋 多格式导出 | 复制、下载 md、直接复制成 Prompt |

## 转换效果

- **Before**：网页充满广告、导航栏、弹窗，73% 是噪音
- **After**：转换后只剩干净的 Markdown，100% 干货

## 适用场景

- 🤖 给 LLM 准备干净的输入
- 📚 文章收藏与整理
- 📄 技术文档提取
- 🔬 研究资料收集

## 安装方式

- Chrome：Chrome Web Store 搜索 MD-This-Page
- Firefox：Add-ons 商店搜索 MD-This-Page
