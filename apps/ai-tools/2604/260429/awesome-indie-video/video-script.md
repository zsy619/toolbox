# Awesome Indie 视频脚本

## 基本信息

| 参数 | 值 |
|------|-----|
| 平台 | 视频号/抖音/小红书 |
| 时长 | ~50秒 |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 风格 | 赛博朋克 |

## 场景时间轴

| 场景 | 帧数 | 时长 | 内容 |
|------|------|------|------|
| 封面 | 0-180 | 3秒 | 主标题 |
| 核心理念 | 180-540 | 6秒 | 代码赚钱越来越简单 |
| 关键洞察 | 540-900 | 6秒 | 项目小而美 |
| 社区资源 | 900-1440 | 9秒 | 核心社区 |
| 必读资源 | 1440-1980 | 9秒 | 书籍和演讲 |
| 成功案例 | 1980-2460 | 8秒 | 独立开发者案例 |
| CTA | 2460-2820 | 6秒 | 立即行动 |
| 延续 | 2820-3120 | 5秒 | 收尾 |

## 场景详情

### 场景1: 封面 (0-180帧)
- **主标题**: "Awesome Indie"
- **副标题**: "独立开发者资源大全"

### 场景2: 核心理念 (180-540帧)
- **文字**: "用你自己的代码赚钱从未如此简单"
- **音频**: 介绍主题

### 场景3: 关键洞察 (540-900帧)
- **文字**: "项目不需要大，只需要盈利"
- **音频**: 强调小而美的理念

### 场景4: 社区资源 (900-1440帧)
- IndieHackers、bootstrapped.fm、HackerNews、Makerlog

### 场景5: 必读资源 (1440-1980帧)
- Start Small Stay Small、Getting Real、MAKE、Rework

### 场景6: 成功案例 (1980-2460帧)
- NomadList、Basecamp、Bugmuncher、Carrd.co

### 场景7: CTA (2460-2820帧)
- **文字**: "MAKE and TRY stuff"

### 场景8: 延续 (2820-3120帧)
- **文字**: "开始你的独立开发之旅"

## 音频时长计算

目标时长: 52秒 → 3120帧 @ 60fps
语速: 1.2x
