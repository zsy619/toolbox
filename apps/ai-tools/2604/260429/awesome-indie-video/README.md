## 核心内容

- Awesome Indie：帮助独立开发者赚钱的资源列表
- 核心理念：项目不需要大，只需要盈利
- 核心行动：MAKE and TRY stuff
- 社区：IndieHackers、bootstrapped.fm、HackerNews、Makerlog
- 书籍：Start Small Stay Small、Getting Real、MAKE、Rework
- 案例：NomadList、Basecamp、Bugmuncher、Carrd.co
