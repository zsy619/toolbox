## 正文

### 一、用代码赚钱从未如此简单

Making money from your own code has never been easier, but it's still hard.

今天给大家推荐一个超全的独立开发者资源列表：**Awesome Indie**。

### 二、核心理念

**项目不需要大，其实越小越好，只需要盈利。**

- 项目可以产生被动收入
- 帮助达到财务自由
- 独立开发有很多生活方式上的好处

**最重要的是：MAKE and TRY stuff！**

### 三、核心社区推荐

| 社区 | 说明 |
|------|------|
| IndieHackers | 向成功开发者学习，盈利能力最强的独立项目集合 |
| bootstrapped.fm | 自举者论坛 |
| HackerNews | 黑客新闻，YC维护 |
| Makerlog | 免费的创作者社区 |

### 四、必读资源

| 书籍 | 作者 |
|------|------|
| Start Small, Stay Small | Rob Walling |
| Getting Real | 37signals |
| MAKE | Pieter Levels |
| Rework | 37signals |

### 五、成功案例

- **NomadList**：数字游民列表
- **Basecamp**：37signals
- **Bugmuncher**：透明财务报告
- **Carrd.co**：简单建站工具

### 六、关键行动

**MAKE and TRY stuff！**

立即开始你的独立开发之旅！
