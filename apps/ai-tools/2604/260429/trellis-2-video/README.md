- **开始时间**: 2026-04-27 07:22 GMT+8

## 规格
- **分辨率**: 1080×1920 (竖屏)

## 核心内容
TRELLIS.2 是微软开源的最新3D生成大模型（4B参数），通过O-Voxel稀疏体素结构实现高质量图像转3D生成：
- 512³分辨率仅需~3秒
- 支持任意拓扑（非流形几何、开放曲面）
- 完整PBR材质（颜色、粗糙度、金属度、透明度）
- 无需渲染优化，直接转换
