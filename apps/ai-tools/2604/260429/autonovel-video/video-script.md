# AutoNovel 视频脚本

## 基本信息

| 参数 | 值 |
|------|-----|
| 平台 | 视频号/抖音/小红书 |
| 时长 | ~45秒 |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 风格 | 赛博朋克 |

## 场景时间轴

| 场景 | 帧数 | 时长 | 内容 |
|------|------|------|------|
| 封面 | 0-180 | 3秒 | 主标题 + 副标题 |
| 痛点 | 180-540 | 6秒 | 百万字长篇小说的挑战 |
| 方案 | 540-900 | 6秒 | AutoNovel 登场 |
| 速度 | 900-1260 | 6秒 | 200+ tokens/s |
| 全流程 | 1260-1620 | 6秒 | 世界观→角色→大纲→正文 |
| 实测 | 1620-1980 | 6秒 | 几十分钟百万字 |
| CTA | 1980-2340 | 6秒 | 立即体验 |
| 延续 | 2340-2700 | 6秒 | 收尾信息 |

## 场景详情

### 场景1: 封面 (0-180帧)
- **画面**: 深色背景，霓虹发光大字
- **主标题**: "AutoNovel"
- **副标题**: "几十分钟，完成百万字长篇小说"
- **音频**: 开场白

### 场景2: 痛点 (180-540帧)
- **画面**: 左侧问题文字，右侧时钟图标
- **文字**: "还在为长篇小说熬夜码字？"
- **音频**: 描述长篇写作的痛点

### 场景3: 方案 (540-900帧)
- **画面**: Logo 出现，光效动画
- **文字**: "AutoNovel 长篇写作助手"
- **音频**: 介绍 AutoNovel

### 场景4: 速度 (900-1260帧)
- **画面**: 数据展示，200+ tokens/s
- **文字**: "200+ tokens/s"
- **音频**: 强调极速生成

### 场景5: 全流程 (1260-1620帧)
- **画面**: 流程图展示
- **文字**: 世界观设定 → 角色构建 → 大纲生成 → 正文创作
- **音频**: 介绍全流程覆盖

### 场景6: 实测 (1620-1980帧)
- **画面**: 数据对比
- **文字**: "几十分钟写完百万字"
- **音频**: 强调实测效果

### 场景7: CTA (1980-2340帧)
- **画面**: 渐变背景，主 CTA
- **文字**: "立即体验 AutoNovel"
- **音频**: 行动召唤

### 场景8: 延续 (2340-2700帧)
- **画面**: 底部链接
- **文字**: "开始你的长篇创作之旅"
- **音频**: 收尾
