# 精益副业 视频脚本

## 基本信息

| 参数 | 值 |
|------|------|
| **项目名称** | lean-side-bussiness-video |
| **视频规格** | 1080×1920 竖屏，60fps |
| **预估时长** | ~55 秒 |
| **语速** | 1.2x（edge-tts） |
| **主题风格** | 赛博朋克（Cyberpunk） |
