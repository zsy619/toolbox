# 发布指南 - Qwen3.6-Plus 视频发布指南

## 📱 多平台发布指南

### 微信视频号

| 属性 | 要求 |
|------|------|
| **分辨率** | 1080×1920 (9:16) |
| **时长** | 15-60秒（推荐30秒） |
| **文件大小** | < 100MB |
| **格式** | MP4 (H.264, AAC) |

**标题要求**：
- 简洁有力，不超过30字
- 包含关键词：Qwen、大模型、AI

**标题示例**：
```
Qwen3.6-Plus：产品级交付能力的突破
```

**描述要求**：
- 描述内容核心价值，50-150字
- 添加话题标签

**描述示例**：
```
国产大模型评判标准已从"博学"全面转向"稳定性"与"工程交付能力"。Qwen3.6-Plus像资深员工一样独立完成任务，每百万Tokens输入最低2元。#Qwen #大模型 #AI
```

---

### 小红书

| 属性 | 要求 |
|------|------|
| **分辨率** | 1080×1920 (9:16) |
| **时长** | 15秒-5分钟 |
| **文件大小** | < 300MB |
| **格式** | MP4 (H.264, AAC) |

**标题要求**：
- 吸引眼球，带emoji，不超过20字

**标题示例**：
```
Qwen3.6-Plus发布！AI进入产品级交付时代 🚀
```

**正文要求**：
- 100-500字
- 段落清晰
- 添加相关标签

**正文示例**：
```
国产大模型评判标准已从"博学"全面转向"稳定性"与"工程交付能力"。

Qwen3.6-Plus三大核心能力：
✅ 逻辑推理能力
✅ 工具使用能力
✅ 工程落地能力

像资深员工一样独立完成任务：任务自动拆解、规避业务禁区、输出系统性工程方案。

每百万Tokens输入最低2元，AI时代重新定义生产力！
```

**标签要求**：
- 不少于5个相关标签

**标签示例**：
```
#AI #Qwen #阿里云 #大模型 #产品级交付 #工程能力
```

---

- 添加热门话题

## 📋 发布前检查清单

### 内容检查
- [ ] 标题吸引眼球
- [ ] 内容完整准确
- [ ] 标签/话题相关且足够

### 视频检查
- [ ] 分辨率正确 (1080×1920)
- [ ] 帧率达标 (60fps)
- [ ] 时长合适
- [ ] 文件大小合规

### 平台检查
- [ ] 视频号：文件 < 100MB
- [ ] 小红书：文件 < 300MB
- [ ] 抖音/快手：文件 < 200MB
