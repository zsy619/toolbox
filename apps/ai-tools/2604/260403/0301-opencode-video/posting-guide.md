# 发布指南 - OpenCode 视频发布指南

## 📱 多平台发布指南

### 微信视频号

| 属性 | 要求 |
|------|------|
| **分辨率** | 1080×1920 (9:16) |
| **时长** | 15-60秒（推荐30秒） |
| **文件大小** | < 100MB |
| **格式** | MP4 (H.264, AAC) |

**标题要求**：
- 简洁有力，不超过30字
- 包含关键词：开源、AI、编程、终端

**标题示例**：
```
开源终端AI编程神器！5分钟搭建AI开发团队
```

**描述要求**：
- 描述内容核心价值，50-150字
- 添加话题标签

**描述示例**：
```
OpenCode + oh-my-opencode 一站式安装教程。终端原生、多模型随便切、多Agent协同、完全免费！#开源 #AI编程 #程序员
```

---

### 小红书

| 属性 | 要求 |
|------|------|
| **分辨率** | 1080×1920 (9:16) |
| **时长** | 15秒-5分钟 |
| **文件大小** | < 300MB |
| **格式** | MP4 (H.264, AAC) |

**标题要求**：
- 吸引眼球，带emoji，不超过20字

**标题示例**：
```
终端AI编程神器！开源免费，5分钟搭建你的AI开发团队 🚀
```

**正文要求**：
- 100-500字
- 段落清晰
- 添加相关标签

**正文示例**：
```
还在浏览器、IDE、AI工具之间反复横跳？这款开源终端AI组合让你在命令行里完成项目分析、代码生成、多智能体协作！

✅ OpenCode = 基础AI助手
✅ oh-my-opencode = 升级成AI开发团队

支持 Claude/GPT/Gemini/本地 Ollama 模型，不绑定平台、全免费！

安装只需3步：
1. curl -fsSL https://opencode.ai/install | bash
2. opencode auth login
3. bunx oh-my-opencode install

5分钟搭建好环境，直接开启AI辅助开发新模式！👇
```

**标签要求**：
- 不少于5个相关标签

**标签示例**：
```
#编程工具 #AI编程 #开源 #程序员 #终端 #效率工具 #OpenCode #Claude
```

## 📋 发布前检查清单

### 内容检查
- [ ] 标题吸引眼球
- [ ] 内容完整准确
- [ ] 标签/话题相关且足够

### 视频检查
- [ ] 分辨率正确 (1080×1920)
- [ ] 帧率达标 (60fps)
- [ ] 时长合适
- [ ] 文件大小合规

### 平台检查
- [ ] 视频号：文件 < 100MB
- [ ] 小红书：文件 < 300MB
- [ ] 抖音/快手：文件 < 200MB

## 📊 数据追踪

发布后建议追踪以下数据：

| 指标 | 说明 |
|------|------|
| 曝光量 | 视频被展示的次数 |
| 播放量 | 视频被播放的次数 |
| 完播率 | 用户看完整视频的比例 |
| 点赞数 | 用户点赞数量 |
| 评论数 | 用户评论数量 |
| 转发数 | 用户分享次数 |
| 关注转化 | 观看后关注账号的数量 |
