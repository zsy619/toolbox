神秘漂流瓶1 2026-03-31

还在切换浏览器、IDE、AI工具写代码？

这款开源免费的终端AI组合，能让你在命令行里完成项目分析、代码生成、多智能体协作，媲美Claude Code，还支持本地模型！

一、它们是什么？

OpenCode

开源终端AI编程助手，CLI+TUI双模式，支持 Claude / GPT / Gemini / 本地 Ollama 模型，不绑定平台、全免费。

oh-my-opencode

OpenCode的增强插件包，类似Oh My Zsh，一键开启多Agent协作，任务自动拆解、规划、分派，复杂项目不跑偏。

OpenCode = 基础AI助手
oh-my-opencode = 升级成AI开发团队

二、一键安装（复制即跑，零门槛）

1）安装 OpenCode（核心程序）

curl -fsSL https://opencode.ai/install | bash

或 npm 安装：npm install -g opencode-ai

2）绑定 AI 模型（API Key 配置）

opencode auth login

按提示选择厂商，输入 Key 即可。

3）安装 oh-my-opencode（增强必装）

# 先装 Bun 环境 curl -fsSL https://bun.sh/install | bash # 再装插件 bunx oh-my-opencode install

按提示回答是否有 Claude/Gemini 订阅，自动优化配置。

三、安装完怎么用？

进入项目目录，直接启动：

opencode

核心功能（新手必看）

  • 主控 Orchestrator 智能体：自动拆解复杂任务
  • Tab 切换模式：plan（规划）/ build（编码）
  • /init：生成 AGENTS.md，定义项目规范
  • /add 文件名：把文件加入AI上下文
  • 多Agent协同：规划、编码、调试分工完成

四、关键配置文件

  • AGENTS.md：项目架构、规范、技术栈（AI 理解项目的核心）
  • opencode.json：全局配置，存放模型与插件设置
  • 启动后自动加载，无需手动干预

五、适合谁用？

喜欢终端高效开发的程序员 不想被付费AI绑定的开发者 做复杂项目重构/新功能开发 想本地部署、隐私优先的用户

OpenCode + oh-my-opencode 是目前开源AI编程里最稳的组合之一：

终端原生、多模型随便切、多Agent协同、完全免费。
