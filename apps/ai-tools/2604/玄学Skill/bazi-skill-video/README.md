## 核心内容

赛博算命 Skill — 基于 Claude Code 的八字排盘与命理分析工具。

通过交互式对话收集出生信息，排出四柱八字，参照九本经典命理典籍进行专业分析。

功能：信息收集 → 排盘计算 → 综合分析
