Claude Code 八字排盘与命理分析

基于 Claude Code 的八字排盘与命理分析工具，通过交互式对话收集出生信息，排出四柱八字，参照九本经典命理典籍进行专业分析。

三大功能

  • 🔢 信息收集 — 逐步收集姓名、阳历/农历生日、出生时辰、性别、出生地
  • 📊 排盘计算 — 自动排出年柱、月柱、日柱、时柱，计算大运与流年
  • 📝 综合分析 — 日主强弱、十神关系、五行平衡、格局判定

九本经典参考典籍

《穷通宝典》《三命通会》《滴天髓》《渊海子平》《千里命稿》《协纪辨方书》《果老星宗》《子平真诠》《神峰通考》

使用方法和安装

在 Claude Code 中输入关键词：算八字、看八字、批八字、排八字等即可触发。
