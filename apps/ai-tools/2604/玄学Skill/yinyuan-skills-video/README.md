## 核心内容

月老 · 姻缘测算 Skills — 赛博月老，用中华传统术数帮你算姻缘。

六大测算模式，覆盖各种感情需求：
1. 八字合婚
2. 生肖配对
3. 紫微夫妻宫
4. 求签问姻缘
5. 桃花运势
6. 红线测算

## 设计理念

不再依赖 AI 玄学幻觉，通过严格的 Prompt 约束 + 结构化知识库的架构方式，让姻缘测算透明可控。
