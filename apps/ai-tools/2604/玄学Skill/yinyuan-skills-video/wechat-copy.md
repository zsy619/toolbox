# 用 Claude Code 算姻缘？这个赛博月老太神了

## 想算姻缘，但：

- 😵 传统测算太复杂？
- 🤷 不知道从哪开始？
- 🤔 AI 测算不靠谱？

## 赛博月老帮你搞定！

基于 **Claude Code** 的姻缘测算技能，用中华传统术数帮你算姻缘。

## 六大测算模式

| 模式 | 说明 | 需要的信息 |
|------|------|-----------|
| 🔮 八字合婚 | 看两个人的八字配不配 | 双方出生日期+时间+性别 |
| 🐉 生肖配对 | 用生肖看合不合 | 双方生肖或出生年份 |
| ⭐ 紫微夫妻宫 | 看命盘里的婚姻格局 | 出生日期+时间+性别 |
| 🎋 求签问姻缘 | 抽一支姻缘签 | 想问的问题 |
| 🌸 桃花运势 | 看近期的感情运势 | 生肖+当前感情状态 |
| 🔴 红线测算 | 综合分析正缘特征和时间 | 出生日期+时间+你的期待 |

## 设计理念

**不再依赖 AI 玄学幻觉**，通过严格的 Prompt 约束 + 结构化知识库的架构方式，让姻缘测算透明可控。

核心原则：
- 娱乐为主，理性参考
- 不说宿命，不制造焦虑
- 先问清需求再测算
- 有据可依的传统文化知识

## 使用方式

在 Claude Code 中直接说：
- "帮我测姻缘"
- "我和XX配不配"
- "什么时候能遇到对的人"
- "求一支姻缘签"
- "看看我最近的桃花"

或者直接 `/yinyuan` 进入选择界面。
