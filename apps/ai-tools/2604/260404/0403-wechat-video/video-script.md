# Mole 视频脚本

## 基础信息

| 属性 | 值 |
|------|-----|
| **视频ID** | mole-video |
| **主题** | 一行命令，干掉 Mac 上那些付费清理软件 |
| **时长** | 45秒 |
| **分辨率** | 1080×1920 (9:16) |
| **帧率** | 60fps |
| **平台** | 微信视频号 / 小红书 / 抖音 |
| **风格** | 科技简约风 / 深色系 |
