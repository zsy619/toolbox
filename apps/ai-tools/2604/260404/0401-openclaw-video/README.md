# OpenClaw 4.2 文档说明

本文档目录包含 OpenClaw 4.2 视频项目的所有相关文档。

| 文件 | 说明 |

## 快速开始

1. **查看视频**：打开 `openclaw-video.mp4` 即可观看45秒视频
2. **修改文案**：编辑 `copy.md` 获取不同平台的文案
3. **发布视频**：参考 `posting-guide.md` 在各平台发布

## 技术信息

- **分辨率**：1080×1920 (9:16竖屏)
- **帧率**：60fps
- **时长**：45秒
- **编码**：H.264 + AAC
