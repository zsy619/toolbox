# Trello 技能视频脚本

## 基本信息
- **平台**: 微信视频号 / 小红书 / YouTube Shorts
- **时长**: 48.8 秒
- **帧率**: 60fps
- **分辨率**: 1080×1920 (9:16 竖屏)
- **主题**: 科技现代风 (Tech Vision)

## 配色方案
- **主色**: `#2563EB` (科技蓝)
- **辅色**: `#7C3AED` (电紫色)
- **强调色**: `#10B981` (活力绿)
- **背景色**: `#0F172A` (深空黑)

## 场景结构

### 场景 1: 封面 (0-5.5s)
- **画面**: Trello 大字标题、技能徽章、四大功能标签
- **文字**: "Trello" + "看板 · 列表 · 卡片管理"
- **视觉**: 科技蓝主色调，大字体居中

### 场景 2: REST API (5.5-11.5s)
- **画面**: REST API 概念展示
- **文字**: HTTP 方法 GET / POST / PUT / DELETE
- **动画**: 弹入效果

### 场景 3: 看板管理 (11.5-18.5s)
- **画面**: Board API 端点展示
- **文字**: 获取、创建、更新、删除看板

### 场景 4: 列表操作 (18.5-24.5s)
- **画面**: 列表管理功能
- **文字**: 创建列表、重命名、移动排序、删除列表

### 场景 5: 卡片管理 (24.5-31.5s)
- **画面**: Card API 端点展示
- **文字**: 创建卡片、移动卡片、归档完成任务

### 场景 6: 标签与成员 (31.5-36.5s)
- **画面**: 精细化权限管理
- **文字**: 颜色标签、成员指派、到期日、附件

### 场景 7: Webhook (36.5-42.5s)
- **画面**: 实时事件订阅
- **文字**: cardCreated → 触发自动化等事件流

### 场景 8: 适用场景 (42.5-47s)
- **画面**: 四大场景展示
- **文字**: 个人任务追踪、多人协作、自动化工作流、数据报表

### 场景 9: CTA (47-53s)
- **画面**: 安装命令
- **文字**: `npx clawhub install steipete/trello`
