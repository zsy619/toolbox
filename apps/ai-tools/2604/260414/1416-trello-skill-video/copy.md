### 正文
**前言**

Trello 是很多人都在用的项目管理工具。但你有没有想过——用 AI 来自动管理 Trello？

**这个技能能做什么？**

1. **看板管理**：获取、创建、更新、删除看板
2. **列表操作**：在任意看板上增删改查列表
3. **卡片管理**：创建、移动、归档卡片
4. **标签与成员**：精细化权限控制
5. **Webhook**：实时订阅事件，触发自动化流程

**安装命令**

```bash
npx clawhub install steipete/trello
```

**适用场景**

- 个人任务追踪
- 多人协作项目
- 自动化工作流
- 数据报表生成

用 AI 做项目管理，就从 OpenClaw 开始。
