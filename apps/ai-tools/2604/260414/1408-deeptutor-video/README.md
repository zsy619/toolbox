# DeepTutor - Agent-Native 个性化学习助手

> 🎓 HKUDS 研究团队出品 · Agent-Native 个性化学习助手

## 📌 项目简介

**DeepTutor** 是由 HKUDS 研究团队打造的 Agent-Native 个性化学习助手。它不仅仅给答案，而是提供带有视觉解释的引导式学习之旅。通过持久记忆系统、五大工作区模式和 TutorBots，让 AI 成为具有记忆和个性的专属学习导师。

## 🎯 核心价值

| 特性 | 说明 |
|------|------|
| 🧠 持久记忆 | 构建持续更新的学习档案，记录学了什么、怎么学的 |
| 💬 五大模式 | Chat / Deep Solve / Quiz / Research / Math 五大统一工作区 |
| 🎓 TutorBots | 具有记忆和个性的自主 AI 导师 |
| 📚 知识图谱 | LightRAG 驱动，建立语义连接 |
| 📄 多模态 | PDF、LaTeX、图片、代码执行 |
| 🔍 深度研究 | Deep Research 主题探索和引导式学习 |
