# claudian - Obsidian AI 协作者

> 🧠 Obsidian AI 协作者 · 把 Claude Code 嵌入知识库

## 📌 项目简介

**claudian** 是一个 Obsidian 插件，将 Claude Code 嵌入到你的知识库中，作为 AI 协作者。它可以在笔记中直接与 AI 对话、生成内容、整理思路，适用于知识管理和个人研究。

## 🎯 核心价值

| 特性 | 说明 |
|------|------|
| 💬 直接对话 | 在笔记中直接与 AI 对话，无需切换工具 |
| ✍️ 生成内容 | 让 AI 帮你生成文章、草稿、摘要 |
| 🧠 整理思路 | AI 辅助知识梳理和思维整理 |
| 📚 知识管理 | 将知识库变成智能 AI 协作文档平台 |
