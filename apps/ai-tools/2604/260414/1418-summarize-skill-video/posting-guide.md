## 视频文件生成命令

```bash
# 微信视频号版本（30秒循环）
ffmpeg -y -stream_loop 1 -i out/final_video.mp4 -t 30 \
  -c:v libx264 -preset fast -b:v 10M \
  -c:a aac -b:a 128k \
  out/video-wx.mp4

# 小红书版本（直接使用原版）
cp out/final_video.mp4 out/video-xhs.mp4

# YouTube 版本
ffmpeg -y -i out/final_video.mp4 \
  -c:v libx264 -preset fast -b:v 10M \
  -c:a aac -b:a 192k \
  out/video-yt.mp4
```
