# OpenDataLoader PDF - AI-Ready 数据提取

> 📄 PDF 解析神器 · Benchmark 第一名 · AI 数据准备

## 📌 项目简介

**OpenDataLoader PDF** 是目前唯一一个开源的 PDF 解析器，专为 AI 数据准备而生的 PDF 解析工具。它自动化提取 PDF 文档中的文字、表格和结构信息，生成 AI 训练可用的结构化数据。

## 🎯 核心价值

| 特性 | 说明 |
|------|------|
| 🏆 Benchmark 第一 | 总体准确率 0.90，表格准确率 0.93 |
| 📝 自动化提取 | 文字、表格、结构信息一键提取 |
| 📦 结构化输出 | Markdown、JSON、HTML 三种格式 |
| 🔲 边界框定位 | 每个元素都有精确边界框 |
| ⚡ 极速处理 | 0.05 秒/页，无需 GPU |
| 🛡️ AI 安全过滤 | 内置 AI 安全过滤器 |

## 🔧 技术特点

1. **基于规则确定性提取** - 无需 GPU，CPU 即可高效运行
2. **边界框定位** - 每个元素都有精确的边界框坐标
3. **XY-Cut++ 阅读顺序** - 保证内容阅读顺序正确
4. **内置 AI 安全过滤器** - 自动过滤敏感信息
5. **原生 Tagged PDF 支持** - 完整保留文档结构
6. **混合 AI 模式** - 处理复杂文档时调用 AI 增强
