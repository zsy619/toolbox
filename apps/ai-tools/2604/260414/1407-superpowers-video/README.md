# Superpowers - Codex 代理开发工作流

> ⚡ 代理技能框架 · 多代理协作 · Shell 脚本驱动

## 📌 项目简介

**Superpowers**（超能力）是一套完整的代理技能框架和软件开发方法论，专为 AI 编程代理设计。通过 Hooks 系统自定义 Codex 行为，支持多代理团队协作完成复杂任务，实时显示任务进度和状态。

## 🎯 核心价值

| 特性 | 说明 |

| 🪝 Hooks 系统 | 自定义 Codex 行为，让代理更懂你的需求 |
| 🤖 多代理协作 | 一个发起任务，多个并行处理，效率翻倍 |
| 📊 实时进度 | 任务状态一目了然，进度全程可控 |
| 🔌 插件系统 | 热插拔架构，灵活扩展 |

| 💻 Shell 驱动 | 基于 Shell 脚本，轻量高效 |

## 🔧 工作原理

Superpowers 基于一套可组合的"技能"（Skills）和初始指令，让代理能够正确使用这些技能：

1. **Hooks 系统** - 在关键节点插入自定义行为
2. **多代理分发** - 主代理发起任务，子代理并行处理
3. **事件驱动** - 基于事件的响应式架构
4. **插件扩展** - 通过插件系统热插拔新功能

## 💡 核心优势

- **从单打独斗到团队协作** - AI 编程不再是单一代理的工作
- **效率翻倍** - 多代理并行处理复杂任务
- **可控可追踪** - 实时进度显示，状态一目了然
- **灵活扩展** - 插件系统支持自定义功能
