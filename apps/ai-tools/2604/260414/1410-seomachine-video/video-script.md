## 配音文案（用于TTS生成）

今天介绍一个非常实用的开源项目！SEOMachine，是一个专门用于创建 SEO 优化长文内容的 Claude Code 工作流。它能够帮助用户自动化研究关键词、生成高质量文章、优化格式和结构，从而提升网站在搜索引擎中的排名。这个系统的核心是一系列专业化命令：首先是斜杠Research，用于关键词研究和竞争对手分析。然后是斜杠Write，根据研究结果撰写高质量文章。还有斜杠Optimize，对文章进行 SEO 优化。斜杠Analyze-Existing 用于分析现有文章并提出改进建议。斜杠Rewrite 可以重写不符合标准的文章。斜杠Performance-Review 进行效果评估。斜杠Publish-Draft 发布草稿。还有斜杠Priorities 帮助确定内容优先级。最后还有斜杠LandingPage，用于创建着陆页。除了这些命令，系统还包含多个专业化代理：内容分析代理、SEO 优化代理、元元素创建代理，以及草稿发布代理。技术特点方面，SEOMachine 基于 Python 开发，专为 Claude Code 设计，能够自动化整个 SEO 内容创作流程。适用人群包括内容营销团队、SEO 专业人士，以及需要批量生成文章的网站运营者。GitHub 上已经达到了 5,171 颗星，昨天还增长了 725 颗。赶紧去 GitHub 搜索 TheCraigHewitt slash SEOMachine，Star 一下，让你的内容创作效率直接起飞！
