# Archon - 开源 AI 编程 Harness

> ⚡ 首个开源 AI 编程 Harness Builder，让 AI coding 变得确定可重复

## 📌 项目简介

**Archon** 是 GitHub 上首个开源的 AI 编程 Harness Builder。它将 AI 编程代理包装在 YAML 定义的工作流中，让 AI 编程变得**确定**、**可重复**、**可控制**。

## 🎯 核心价值

| 特性 | 说明 |
|------|------|
| 🔄 确定性工作流 | 同样的流程，每次都一样 |
| 🌳 Git Worktree 隔离 | 5个任务并行跑不冲突 |
| ⏱️ Fire and Forget | 丢给它任务，回来就是 PR |
| 🔧 17 个预置工作流 | 开箱即用 |
| 📦 多平台适配 | Web UI / CLI / Slack / Telegram |
