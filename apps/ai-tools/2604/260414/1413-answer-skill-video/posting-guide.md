5. 添加话题标签

## YouTube

### 发布步骤
1. 登录 YouTube Studio
2. 上传 `output/youtube_video.mp4`
3. 上传缩略图（建议另行制作英文版缩略图）
4. 填写英文标题和描述（见下方）
5. 添加标签
6. 设置为 Shorts（竖屏自动识别）

## 发布检查清单

## 注意事项

1. **微信视频号**：视频大小需 < 100MB（当前 3.7MB，远低于限制）
2. **小红书**：视频大小需 < 300MB，时长 15秒-5分钟
3. **YouTube Shorts**：竖屏视频 < 60秒会自动识别为 Shorts
4. 三个平台的文案需要略作调整，微信视频号语气偏正式，小红书更口语化
