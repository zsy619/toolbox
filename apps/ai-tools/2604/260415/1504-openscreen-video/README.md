> 免费创建精美演示视频。开源、无订阅、无水印，支持商业使用。

## 核心特性

- **4K 60fps 录制** — 超高清流畅录制
- **完全免费** — 无任何隐藏费用
- **无水印** — 导出视频干净整洁
- **支持商用** — 商业使用无限制
- **丰富视觉效果** — 多种视觉增强选项
- **内置视频编辑器** — 录制后可即时编辑

## 适用场景

- 内容创作者
- 在线教育
- 产品演示
- 教程制作

## 行业影响

为内容创作者提供了 Screen Studio 的免费替代方案，降低了高质量演示视频的制作门槛。

## 快速开始

```bash
# Clone 项目
git clone https://github.com/siddharthvaddem/openscreen.git
cd openscreen

# 安装依赖
npm install

# 启动开发
npm run dev
```
