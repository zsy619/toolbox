今天给大家介绍一个微软开源的 AI Agent 编排框架：agent-flow。

**它能做什么？**

简单来说，它能帮你可视化的设计 AI 工作流。拖拖拽拽，就能完成复杂的 AI 任务编排。

**核心功能：**

1. 可视化编排
   拖拽式设计，零代码基础也能快速上手

2. 多模型支持
   OpenAI、Anthropic、Azure、本地模型，无缝切换

3. 技术栈现代化
   Python + React 前端，Docke 容器化部署，开箱即用
