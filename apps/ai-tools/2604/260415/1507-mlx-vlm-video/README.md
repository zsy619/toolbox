# MLX-VLM 视频项目

> 为 Mac 而生的视觉语言模型

## 项目信息

- **项目名**: MLX-VLM
- **类型**: Python / MLX 框架
- **GitHub Stars**: 3,394 ⭐
- **项目地址**: https://github.com/Blaizzy/mlx-vlm

## 主题色

- **主色**: `#0891B2` (青色)
- **强调色**: `#4F46E5` (靛蓝) / `#06B6D4` (亮青)
- **背景色**: `#030712` (深海黑)

## 核心特性

| 特性 | 说明 |
|------|------|
| Apple Silicon 原生 | 充分利用 M 系列芯片的 GPU/NPU |
| 本地运行 | 无需云端，保护隐私 |
| 多种 VLM 支持 | Llava, Bakllava, Qwen-VL 等 |
| 易于微调 | 简单 API，快速上手 |
| 内存优化 | 支持大模型在 Mac 上运行 |

## 适用场景

- Mac 用户本地运行视觉语言模型
- 图像理解与问答
- 模型微调实验
- 边缘 AI 开发

## 视频规格

- **分辨率**: 1080 × 1920 (竖屏)
- **帧率**: 60fps
- **时长**: 40-50 秒
- **配音**: 微软神经网络 (zh-CN-YunjianNeural)
- **字幕**: SRT 格式，黄色 10px
