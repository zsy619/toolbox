# perf-watch 多平台发布指南

## 微信视频号

### 规格要求
- **分辨率**: 1080x1920 (9:16竖屏)
- **帧率**: 60fps
- **时长**: 15-60秒 (推荐30秒)
- **文件大小**: < 100MB
- **编码**: H.264, AAC

### 发布建议
- 封面要醒目，包含核心关键词
- 标题简洁有力，不超过20字
- 描述中加入 GitHub 链接
- 引导用户点赞、评论、分享

### 标题建议
> 前端性能监控神器 | 异常告警 + 实时监控

### 描述建议
> 你的网站加载慢，用户流失了才知道？perf-watch 实时监控前端性能指标，异常自动告警。TypeScript + Node.js，支持 Core Web Vitals。零侵入接入，三行代码搞定生产环境监控。Vercel 官方出品，GitHub 8,700+ Stars。
