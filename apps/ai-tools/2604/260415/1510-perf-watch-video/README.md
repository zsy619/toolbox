# perf-watch 视频项目

## 项目信息

- **主题**: perf-watch - 前端性能监控工具
- **Stars**: +1,800 (总计 8,700)
- **核心功能**: 实时性能指标采集 | 异常自动告警
- **技术特点**: TypeScript + Node.js | 支持 Core Web Vitals
- **适用人群**: 前端团队需要监控生产环境
- **项目地址**: https://github.com/vercel/perf-watch

## 目录结构

```
perf-watch-video/
├── docs/                          # 文档目录
│   ├── assets/                    # 视觉素材
│   │   └── cover.png              # 封面图
│   ├── README.md                  # 项目文档
│   ├── video-script.md            # 视频脚本
│   ├── copy.md                    # 营销文案集
│   └── posting-guide.md           # 发布指南
├── video-project/                # 视频项目
│   ├── src/                       # Remotion 源码
│   ├── out/                       # 渲染输出
│   └── assets/                    # 视频素材
└── audio/                         # 音频文件
    ├── full_narration.txt         # 配音文案
    ├── neural_full.mp3            # 原始配音
    └── neural_processed.m4a       # 处理后配音
```

## 视频规格

- **分辨率**: 1080x1920 (9:16竖屏)
- **帧率**: 60fps
- **时长**: 45-60秒
- **主题**: 科技现代风
- **配音**: edge-tts zh-CN-YunjianNeural

## 字幕规格

- **字体**: 10px 宋体 (SimSun)
- **颜色**: 黄色 &H0000FFFF
- **粗体**: 是
- **描边**: 黑色 1px
- **位置**: 底部居中 (Alignment=2)
- **距底边**: 30px (MarginV=30)

## 工作流程

1. 内容研究 → 2. 文档生成 → 3. 封面图生成 → 4. 配音合成 → 5. 字幕生成 → 6. 视频渲染
