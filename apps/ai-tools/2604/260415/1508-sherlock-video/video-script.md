# Sherlock 视频脚本

---

## 版本一：小红书/抖音版本（40秒）

### 开场 (0-3秒)
**画面**: 黑色背景，霓虹紫色渐变，SHERLOCK 标题从中心放大出现
**配音**: "你知道自己在网上有多少个账户吗？"

### 痛点引入 (3-8秒)
**画面**: 多个社交平台图标快速闪过
**配音**: "微博、微信、知乎、B站...随手一注册，账户就散落全网。"

### 解决方案 (8-15秒)
**画面**: Sherlock Logo 出现，光束扫描效果
**配音**: "现在，一个工具帮你搞定。Sherlock，通过用户名，跨平台搜索 300 多个社交网络账户。"

### 核心特性 (15-30秒)
**画面**: 分屏展示四个特性
**配音**:
- "第一，300+平台全覆盖，从国内到海外，一个不落"
- "第二，并行查询，秒级返回，不用漫长等待"
- "第三，多格式报告，JSON、文本，想怎么用就怎么用"
- "第四，智能识别高准确率，自动过滤无效结果"

### 适用场景 (30-38秒)
**画面**: 四个场景图标依次出现
**配音**: "网络安全从业者、数字身份管理者、社交媒体监控、渗透测试——都是它的用武之地。"

### 结尾 (38-40秒)
**画面**: 项目地址和 Star 数
**配音**: "想保护自己的数字身份？赶紧去 GitHub 搜 Sherlock Project。"

## 版本二：视频号版本（45秒）

### 开场 (0-4秒)
**画面**: 赛博朋克风标题动画
**配音**: "全网账户一键搜索，来了！"

### 问题陈述 (4-10秒)
**画面**: 网络安全警示风格
**配音**: "你在全网注册了多少个账户？还能记得清吗？"

### 工具介绍 (10-18秒)
**画面**: Sherlock 工具界面展示
**配音**: "今天介绍一款开源神器——Sherlock，跨平台社交账户搜索工具。"

### 功能详解 (18-35秒)
**画面**: 逐个展示功能点
**配音**: 
- "支持超过 300 个社交网络平台"
- "并行查询技术，搜索速度极快"
- "支持 JSON、文本等多种输出格式"
- "智能识别系统，高准确率，过滤无效结果"

### 价值强调 (35-42秒)
**画面**: 适用人群展示
**配音**: "无论是网络安全从业者、数字身份管理者，还是普通用户，Sherlock 都能帮你了解和管理自己的网络足迹。"

### 行动号召 (42-45秒)
**画面**: GitHub 地址 + Star 数
**配音**: "GitHub 搜 Sherlock Project，78,961 颗星，值得一试！"
