# Sherlock - 社交媒体账户搜索

> 通过用户名，一键跨平台搜索 300+ 社交网络账户

## 项目概览

**Sherlock** 是一款强大的开源工具，能够通过用户名在 300+ 个社交网络平台上快速查找对应的账户。无论你是网络安全从业者、数字身份管理者，还是普通用户想了解自己的网络足迹，Sherlock 都是你的得力助手。

## 核心特性

| 特性 | 说明 |
|------|------|
| 🔍 **跨平台搜索** | 支持 300+ 社交网络平台 |
| ⚡ **并行查询** | 秒级返回结果 |
| 📊 **多格式报告** | 支持 JSON、文本等多种输出格式 |
| 🎯 **高准确率** | 智能识别误报和无效结果 |
| 🌍 **全球平台** | 覆盖全球主流社交网络 |

## 适用场景

- **网络安全从业者** - 渗透测试、账户安全审计
- **数字身份管理** - 了解和管理个人网络足迹
- **社交媒体监控** - 品牌保护、舆情监控
- **合规调查** - 调查人员身份核实

## 技术栈

- Python 3.x
- 支持 Linux、macOS、Windows
- MIT 开源许可证

## 快速开始

```bash
# 安装
pip install sherlock-project

# 搜索用户名
sherlock username
```
