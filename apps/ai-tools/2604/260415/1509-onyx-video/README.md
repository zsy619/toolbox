# Onyx - 开源 AI 平台

> 兼容所有主流大语言模型的企业级 AI 平台

## 项目信息

| 项目 | 信息 |
|------|------|
| **项目名** | Onyx |
| **类型** | Python |
| **Stars** | 23,768 (+1,212) |
| **官网** | https://github.com/onyx-dot-app/onyx |

## 核心特性

- 🤖 **兼容所有主流 LLM** - 支持 GPT、Claude、Gemini、国产大模型等
- 🏢 **企业级功能** - 团队协作、权限管理、审计日志
- 🔒 **数据隐私保护** - 私有化部署，数据不上云
- 🎨 **现代化界面** - 支持自定义主题

## 适用场景

- 企业 AI 部署
- 多模型管理
- 私有化 AI 服务
- 团队协作

## 行业影响

Onyx 为企业提供了灵活可控的 AI 平台解决方案，降低了大模型应用门槛，让更多企业能够快速拥抱 AI 技术。

## 快速开始

```bash
# 安装
pip install onyx

# 启动
onyx start
```
