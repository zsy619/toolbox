# goose - AI 编程代理

## 项目信息

- **项目名称**: goose

- **GitHub**: https://github.com/block/goose

- **语言**: Rust
- **许可**: 开源

## 核心定位

goose 是一个 AI 编程代理，能够**自主执行完整的开发任务**，开发者只需描述需求，goose 即可完成代码编写、调试、优化全流程。

## 核心功能

1. **自主执行完整开发任务** - 从需求到交付，无需人工干预
2. **支持连接任何 LLM** - 兼容 OpenAI、Anthropic、本地模型等
3. **基于工具调用架构** - 安全的任务执行能力
4. **Rust 语言开发** - 高性能、高可靠性

## 技术特点

- **Rust**: 内存安全、高性能
- **工具调用 (Tool Calling)**: 架构化任务执行
- **多模型支持**: 灵活对接各类 LLM API
- **可扩展**: 易于集成和二次开发

## 适用人群

- 需要 AI 辅助编程的开发者
- 希望自动化重复开发任务的团队
- 研究 AI 编程代理技术的研究者

## 快速开始

```bash
# 安装 goose
npm install -g @block/goose

# 启动交互式会话
goose

# 连接特定 LLM
goose --provider openai --model gpt-4
```
