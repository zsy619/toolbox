# goose 视频脚本

## 视频信息

- **平台**: 微信视频号 / 小红书 / 抖音
- **时长**: 约 50 秒
- **主题**: 科技现代风
- **帧率**: 60fps
- **分辨率**: 1080×1920

## 场景设计

### 场景 1: 封面 (0-5秒)
**视觉**: 深色背景，品牌名 "goose" 大字居中
**文字**: goose - AI 编程代理
**动画**: 淡入 + 轻微放大

### 场景 2: 核心定位 (5-15秒)
**视觉**: 关键词依次出现
**文字**: 自主执行完整开发任务
**动画**: 逐字出现

### 场景 3: 技术特点 (15-25秒)
**视觉**: 技术标签展示
**文字**: Rust 语言 · 工具调用架构 · 高性能
**动画**: 标签网格入场

### 场景 4: 模型支持 (25-35秒)
**视觉**: LLM 图标展示
**文字**: 支持连接任何 LLM
**动画**: 图标依次排列

### 场景 5: 数据展示 (35-45秒)
**视觉**: Stars 数据突出显示
**文字**: 18,900 Stars · GitHub 开源
**动画**: 数字增长动画

### 场景 6: 结尾 (45-50秒)
**视觉**: GitHub 地址
**文字**: github.com/block/goose
**动画**: 淡入
