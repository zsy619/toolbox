# WeRSS：AI Powered 微信公众号热度分析系统

> 「定时采集 + 关键词提取 + 主题聚类 + 多平台推送」

## 核心功能

### 定时采集
定时采集订阅公众号文章，自动转 MarkDown 和 PDF 导出。

### AI 关键词提取
智能分析文章内容，提取关键词，快速把握核心信息。

### 主题聚类分析
将相关文章聚类，发现主题趋势和热点话题。

### 热度可视化
直观展示文章热度，帮你快速筛选重要内容。

## 多平台推送

|------|------|
| 飞书 | ✅ |
| 钉钉 | ✅ |
| 微信群 | ✅ |

- **MCP 协议支持**：AI Agent 接入无忧
