# WeRSS 项目分析

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | WeRSS |
| 类型 | 微信公众号助手 / RSS 订阅工具 |
| 来源 | Gitee |
| 语言 | 中文 |

## 核心内容（用户指定）

WeRSS : AI Powered 微信公众号热度分析系统。

支持微信公众号定时采集、文章导出、关键词提取、主题聚类分析、可视化、文章导出、飞书/钉钉/微信消息支持，附带外部可访问API/MCP及AI支持。

## 核心功能

### 1. 定时采集
- 微信公众号定时更新订阅文章
- 自动抓取最新发布内容

### 2. 格式转换
- 微信公众号转 MarkDown
- 微信公众号转 PDF
- 导出微信公众号订阅源

### 3. AI 分析（AI Powered）
- 关键词提取
- 主题聚类分析
- 热度分析

### 4. 可视化
- 数据可视化展示
- 文章热度图表

### 5. 消息推送
- 飞书消息支持
- 钉钉消息支持
- 微信消息支持

### 6. 外部扩展
- RESTful API
- MCP 协议支持
- AI Agent 接入

## 技术特点

- 符合阅读习惯的微信公众号助手
- 生成 RSS 订阅源
- 支持 Webhook
- AI Agent 接入支持
