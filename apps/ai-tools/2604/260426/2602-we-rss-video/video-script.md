### 场景 1：开场（0-5秒）
- **视觉**：深色背景 + Logo 居中
- **标题**：WeRSS
- **副标题**：AI Powered 微信公众号热度分析

### 场景 2：核心功能（5-18秒）
- **视觉**：功能卡片网格
- **标题**：核心功能
- **内容**：
  - 定时采集订阅
  - 格式转换（MarkDown/PDF）
  - 关键词提取 + 主题聚类

### 场景 3：AI 分析（18-28秒）
- **视觉**：分析流程图
- **标题**：AI Powered 分析
- **内容**：
  - 热度分析
  - 可视化图表
  - 主题聚类

### 场景 4：消息推送（28-38秒）
- **视觉**：推送平台展示
- **标题**：多平台消息推送
- **内容**：
  - 飞书消息
  - 钉钉消息
  - 微信消息

### 场景 5：API 扩展（38-45秒）
- **视觉**：接口列表
- **标题**：外部扩展
- **内容**：
  - RESTful API
  - MCP 协议
  - AI Agent 接入

### 场景 6：结尾（45-50秒）
- **视觉**：深色背景 + CTA
- **标题**：开始使用 WeRSS
- **副标题**：gitee.com/rachel_os/we-mp-rss

> 今天介绍 WeRSS，AI 加持的微信公众号热度分析系统。
