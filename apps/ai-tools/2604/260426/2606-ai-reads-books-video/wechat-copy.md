### 让 AI 逐页分析你的 PDF

**AI Reads Books** 是一个开源的 PDF 知识提取工具。

它的工作方式很简单：

1. **放入你的 PDF 文件**
2. **AI 逐页分析内容**
3. **自动提取关键知识点**
4. **生成 Markdown 摘要**

---

### 核心特性

**📚 自动化 PDF 分析**
智能逐页处理，深入理解每一页内容。

**🤖 AI 驱动知识提取**
使用 OpenAI API 进行智能分析，准确提取关键信息。

**💾 持久化知识库**
提取的知识点存储为 JSON 文件，支持断点续传。

**📝 Markdown 摘要**
生成格式化的摘要，支持间隔摘要和最终摘要。

**🚫 智能内容过滤**
自动跳过目录页、索引页等无关内容。

---

### 三步开始

```bash
# 1. 安装
pip install -r requirements.txt

# 2. 放入 PDF
# 将你的 PDF 文件放入项目目录

# 3. 运行
python read_books.py
```
