让 AI 逐页分析你的 PDF

AI Reads Books 是一个开源的 PDF 知识提取工具。它的工作方式很简单：放入你的 PDF 文件，AI 逐页分析内容，自动提取关键知识点，生成 Markdown 摘要。

核心特性

  • 📚 自动化 PDF 分析：智能逐页处理，深入理解每一页内容
  • 🤖 AI 驱动知识提取：使用 OpenAI API 进行智能分析
  • 💾 持久化知识库：JSON 格式存储，支持断点续传
  • 📝 Markdown 摘要：生成格式化的摘要
  • 🚫 智能内容过滤：自动跳过目录页、索引页等无关内容

三步开始

# 1. 安装

pip install -r requirements.txt

# 2. 放入 PDF

# 3. 运行

python read_books.py

适用场景

  • 📖 学术研究者：快速把握书籍核心要点
  • 🎓 学习者：制作结构化学习笔记
  • ✍️ 内容创作者：提取书籍精华用于创作
  • 🏢 企业培训：整理培训资料的关键信息
