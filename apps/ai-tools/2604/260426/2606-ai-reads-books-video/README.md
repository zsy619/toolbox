# AI-reads-books-video 项目

## 项目概览

- **项目名称**: AI-reads-books-video
- **源链接**: https://github.com/echohive42/AI-reads-books-page-by-page
- **主题**: AI 逐页分析 PDF 书籍，提取知识点并生成渐进式摘要
- **创建时间**: 2026-04-24

- **分辨率**: 1080×1920 (9:16 竖屏)
- **帧率**: 60fps
- **时长**: 约 45-60 秒
- **语速**: 1.2x
- **主题风格**: tech-modern (蓝紫科技风)
