# 视频脚本 - AI Reads Books

## 基本信息

- **视频时长**: 约 50 秒
- **帧率**: 60fps
- **分辨率**: 1080×1920
- **语速**: 1.2x
- **主题**: tech-modern (蓝紫科技风)

## 场景列表

### 场景 1: 封面 (0-3秒)

- **视觉**: 深色科技背景 + 项目名称
- **文字**: "AI Reads Books" 主标题 + "逐页分析PDF，提取知识精华" 副标题
- **动画**: 渐入效果
- **配音**: 无

### 场景 2: 痛点引入 (3-8秒)

- **视觉**: 书本堆叠的抽象图
- **文字**: "读完就忘？知识散落各处？"
- **动画**: 打字机效果
- **配音**: 你是否曾为阅读大量书籍却难以消化而苦恼？知识散落在书页间，难以系统整理。

### 场景 3: 解决方案 (8-14秒)

- **视觉**: AI 分析页面的抽象图
- **文字**: "AI 逐页分析 PDF"
- **动画**: 渐入效果
- **配音**: 这个脚本让你告别手动整理。AI 逐页分析你的 PDF 书籍，自动提取关键知识点。

### 场景 4: 核心特性 1 (14-20秒)

- **视觉**: 知识库示意图
- **文字**: "💾 持久化知识库"
- **动画**: 缩放效果
- **配音**: 它会把你提取的知识点持久化存储成 JSON，随时可以查阅和更新。

### 场景 5: 核心特性 2 (20-26秒)

- **视觉**: 摘要生成图
- **文字**: "📝 Markdown 摘要"
- **动画**: 滑入效果
- **配音**: 自动生成间隔摘要和最终摘要，输出为 Markdown 格式，方便阅读和分享。

### 场景 6: 核心特性 3 (26-32秒)

- **视觉**: 过滤示意图
- **文字**: "🚫 智能内容过滤"
- **动画**: 渐入效果
- **配音**: 还能智能过滤目录页、索引页等无关内容，只保留真正有价值的信息。

### 场景 7: 使用方法 (32-40秒)

- **视觉**: 代码/命令图
- **文字**: "三步开始：pip install → 放PDF → python read_books.py"
- **动画**: 打字机效果
- **配音**: 使用起来也非常简单：安装依赖、放入 PDF、运行脚本，三步即可开始分析。

### 场景 8: 结尾 (40-47秒)

- **视觉**: GitHub 页面抽象图
- **文字**: "GitHub: echohive42/AI-reads-books-page-by-page"
- **动画**: 渐入效果
- **配音**: 这个项目是 400 多个 AI 项目集合的一部分。快去 GitHub 看看，告别无效阅读吧。

### 场景 9: 结束 (47-50秒)

- **视觉**: 纯色背景 + 关注提示
- **文字**: "点赞 & 关注，获取更多 AI 工具"
- **动画**: 渐入效果
- **配音**: 如果你觉得这个工具有用，点赞关注，我会持续分享更多实用的 AI 工具。
