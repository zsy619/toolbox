## 核心功能

1. 多平台支持：YouTube、TikTok、Bilibili等30+平台
2. 字幕优先架构：原生字幕直接提取，速度极快
3. Whisper智能转录：无字幕时使用Faster-Whisper
4. AI文本优化：自动纠错、补全句子
5. 多语言摘要：支持多种语言生成摘要
6. 自定义API端点：支持OpenAI、OpenRouter等
