# DenchClaw 项目分析

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | DenchClaw |
| 公司 | DenchHQ |
| 类型 | OpenClaw WebUI / CRM 框架 |
| 协议 | MIT |

## 核心定位

Fully Managed OpenClaw Framework for all knowledge work ever. CRM Automation and Outreach agents. The only local productivity tool you need.

## 核心内容（用户指定）

openclaw WebUI——DenchClaw 生成的表格、邮件草稿、文档、图片，全部直接呈现在聊天窗口旁边。最方便：不需要跳去 Notion 看文档，不需要切到邮箱确认，不需要开第二个窗口。所有指令、所有产出，都在同一个界面完成。Agent 做的每一步都透明可见。

## 核心特性

### 统一工作区
- 聊天窗口旁边直接展示所有产出
- 表格、邮件草稿、文档、图片
- 不需要切换应用

### CRM 自动化
- Outreach agents
- 本地托管
- 数据隐私

### Agent 透明度
- 每一步操作都透明可见
- 实时查看 Agent 工作状态

### 技术栈
- 基于 OpenClaw 框架
- Web UI 界面
- npx denchclaw@latest 安装
- 默认端口 3100
