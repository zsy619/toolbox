# DenchClaw 视频脚本

## 视频信息

| 参数 | 值 |
|------|------|
| 时长 | 45-50秒 |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 主题 | tech-modern |
| 语速 | 1.2x |

## 场景列表

### 场景 1：开场（0-5秒）
- **视觉**：深色背景 + Logo 居中
- **标题**：DenchClaw
- **副标题**：OpenClaw WebUI

### 场景 2：痛点（5-15秒）
- **视觉**：切换应用示意
- **标题**：痛点
- **内容**：
  - 跳去 Notion 看文档
  - 切到邮箱确认
  - 开第二个窗口

### 场景 3：解决方案（15-25秒）
- **视觉**：统一界面展示
- **标题**：统一工作区
- **内容**：
  - 表格直接呈现
  - 邮件草稿展示
  - 文档图片预览

### 场景 4：透明可见（25-35秒）
- **视觉**：Agent 步骤展示
- **标题**：每一步都透明可见
- **内容**：
  - Agent 操作实时可见
  - 不再黑盒
  - 工作状态清晰

### 场景 5：结尾（35-45秒）
- **视觉**：深色背景 + CTA
- **标题**：一个界面完成所有
- **副标题**：npx denchclaw

## 配音脚本

> 今天介绍 DenchClaw，OpenClaw WebUI。
>
> 传统 Agent 工作流中，表格要跳去 Notion 看，邮件要切到邮箱确认，文档要开第二个窗口。
>
> DenchClaw 把所有产出直接呈现在聊天窗口旁边。表格、邮件草稿、文档、图片，全部同一个界面完成。
>
> 最方便的是，不需要跳来跳去。所有指令、所有产出，都在同一个界面。
>
> 而且，Agent 做的每一步都透明可见，不再是黑盒操作。
>
> 基于 OpenClaw 框架，本地托管，隐私安全。
>
> 一键安装，npx denchclaw at latest，打开浏览器 localhost 3100 开始使用。
