## 配音脚本

> 今天介绍 OpenGame，一句话 prompt 直接生成完整可玩网页游戏的开源框架。
>
> 游戏开发需要协调游戏引擎、实时循环、跨文件状态管理，传统 AI 代码助手只能生成零散片段，无法构建完整项目。
>
> OpenGame 解决了这个问题。核心是 GameCoder-27B 模型，通过三阶段训练，专攻游戏引擎代码生成。配合 Game Skill 技能系统，Template Skill 构建项目骨架模板，Debug Skill 系统性修复集成错误，而不是逐个修补语法问题。
>
> 基于 Phaser 游戏引擎，支持从一句话 prompt 生成完整游戏工程。
>
> 在 150 个多样化游戏 prompt 上测试，包括超级英雄闯关、魔法卡牌对战、塔防射击等，全部可玩。
>
> 开源生态，基于 Qwen-Code 驱动，GitHub 搜索 leigest519 斜杠 OpenGame。
>
> 一句话 prompt，生成完整游戏工程。开启你的游戏开发之旅。
