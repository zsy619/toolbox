# OpenGame：一句话生成完整可玩网页游戏

> 「一句话 prompt，直接生成完整可玩网页游戏」

## 游戏开发的难点

游戏开发需要协调游戏引擎、实时循环、跨文件状态管理。传统 AI 代码助手只能生成零散片段，无法构建完整项目。

## OpenGame 解决方案

核心是 **GameCoder-27B** 模型，通过三阶段训练专攻游戏引擎代码。配合 Game Skill 技能系统：

| 技能 | 说明 |
|------|------|
| Template Skill | 构建项目骨架 |
| Debug Skill | 系统性修复集成错误 |

## 实测效果

在 150 个多样化游戏 prompt 上测试，包括：
- 超级英雄闯关
- 魔法卡牌对战
- 塔防射击

**全部可玩！**
