## 四大核心功能

### 1. 智能任务

用自然语言描述需求，AI 自动完成开发、设计或代码审查。支持从 Git 仓库导入代码，可自由选择 AI 模型。

### 2. 在线开发环境

提供完整的在线 IDE、Web 终端、文件管理和在线预览功能。无需本地配置，随时随地开发。

### 3. 代码审查

配置 Git 机器人，自动审查 GitHub、GitLab 和 Gitee 的 PR 和 MR，提供智能代码改进建议。

### 4. 团队协作

团队管理员可统一管理成员、分配资源，实现权限控制和资源统一管理。
