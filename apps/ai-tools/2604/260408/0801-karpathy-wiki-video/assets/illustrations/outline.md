# Karpathy Wiki 视频内容插图大纲

## 插图清单

1. **cover** - 封面图：数字大脑 + Markdown 文档，象征 LLM 作为知识工程师
2. **problem** - 问题场景：传统 RAG 方案的痛点示意图
3. **idea** - 核心理念：散乱信息 → 结构化知识网络
4. **layers** - 三层架构图：Raw Sources / Wiki / Schema
5. **ops-ingest** - Ingest 操作示意：来源 → 多页面更新
6. **ops-query** - Query 操作示意：提问 → 综合回答 → 回存 Wiki
7. **ops-lint** - Lint 操作示意：体检 → 修复问题
8. **compound** - 知识复利：增长曲线
