三层架构

📋

The Schema

规则文件层

告诉 LLM 这个 Wiki 怎么组织、用什么约定。对 Claude Code 来说就是 CLAUDE.md，对 Codex 来说就是 AGENTS.md。

📚

The Wiki

知识库层

LLM 生成的 Markdown 文件目录，包括摘要、实体页面、概念页面、对比分析、综述等等。这层完全由 LLM 拥有和维护。

📁

Raw Sources

原始资料层

你收集的论文、文章、图片、数据文件。这层是不可变的，LLM 只读不写，这是你的原始数据来源。

三个核心操作

📥

Ingest

增量录入

一个来源可能牵动 10-15 个 Wiki 页面的更新

❓

Query

智能提问

好的回答可以回存到 Wiki 里，变成新的页面

🔍

Lint

定期体检

保持 Wiki 在增长过程中健康
