# Skill 制作过程工作流视频

本视频展示使用 skill-creator 创建「周公解梦」skill 的完整过程。

## 视频内容结构

### 场景1: 开场 (0-5秒)
- 标题：「如何用 AI 制作一个 Skill」
- 副标题：「从需求到上线完整演示」

### 场景2: 需求分析 (5-15秒)
- 展示用户需求：「帮我造一个周公解梦的skill」
- 分析触发词：「解梦」、「做梦」、「梦见」
- 确定skill定位：古风古韵、传统梦境解析

### 场景3: 读取技能模板 (15-25秒)
- 读取 skill-creator/SKILL.md
- 了解创建流程：捕获意图 → 访谈研究 → 编写SKILL.md → 测试

### 场景4: 创建Skill文件 (25-40秒)
- 创建目录：~/.agents/skills/zhougong-dream/
- 编写 SKILL.md 内容：
  - 名称与描述
  - 解梦原则与框架
  - 意象体系表格
  - 解梦格式模板
  - 示例输出

### 场景5: 测试Skill (40-50秒)
- 使用 subagent 调用新创建的 skill
- 输入测试梦境：「梦见自己飞起来了」
- 展示古风解读输出

### 场景6: 制作配套视频 (50-70秒)
- 创建视频项目目录
- 编写视频脚本
- 生成封面图与插图
- 创建 Remotion 视频代码
- 渲染输出 MP4

### 场景7: 添加配音 (70-85秒)
- 编写配音文稿
- 使用 edge-tts 生成神经网络配音
- 音频处理（去静音、调速）
- 合并音视频

### 场景8: 结尾 (85-95秒)
- 展示成品文件路径
- 总结关键步骤
- 引导语：「收藏备用」

## 技术规格

- 分辨率: 1080x1920 (9:16)
- 时长: 约95秒
- 帧率: 60fps
- 主题: 暗夜极简风 (Dark Minimal)
