# ArcReel - AI 短剧自动化制作工具

## 项目简介

ArcReel 把从小说到成片的整个流程串成一条自动化流水线，上传小说内容，AI 自动完成剧本生成、角色设计、分镜绘制、视频片段生成。支持 Gemini、Grok、OpenAI 等主流模型，一键导出剪映草稿。

## 功能特性

- 🎬 自动化流水线 - 上传小说自动生成短剧
- 🎭 角色一致性 - 同一角色不同镜头保持一致
- 🔄 多模型支持 - Gemini / Grok / OpenAI 随时切换
- ✂️ 剪映导出 - 一键导出剪映草稿

## 适用场景

- AI 短剧创作
- 小说视频化
- 短视频制作
- 内容创作

## 快速开始

```bash
# Docker 部署
docker run -p 8000:8000 acreel/acreel

# 访问
open http://localhost:8000
```
