用 AI 自动生成代码架构图！Claude Code 一键配置

GitHub Daily · 开发工具 · 2024

痛点问题

用 AI 开发项目越来越大，想回头看自己的代码库，架构是什么样的、数据怎么流转的，反而越来越模糊。

手动画架构图费时费力，而且代码更新后图表就过时了。

解决方案：Oh-my-Mermaid

它能让 AI 自动扫描代码库，生成可视化的架构文档。

在 AI 编程工具里输入一条指令，就能自动分析项目结构，生成带有 Mermaid 图表的多维度架构文档，还能在浏览器里交互查看。

核心能力

  • 🤖 AI 自动扫描 — 输入指令，自动分析项目结构
  • 📊 Mermaid 图表 — 生成专业可视化图表
  • 🔄 递归分析 — 复杂逻辑节点自动递归拆解
  • 📁 目录树生成 — 本地生成清晰目录结构
  • 🌐 交互查看 — 支持浏览器交互浏览

已适配主流工具

目前已适配 Claude Code、Codex 等主流 AI 编程工具，一条命令自动配置，还能把文档同步到云端分享给团队。

GitHub 开源免费

对冲基金花几百万做专属模型，彭博终端一年要 2.4 万美元，但 Oh-my-Mermaid 在笔记本上就能跑，几行代码就能调用。

快速开始

# Claude Code 中使用
/claude install oh-my-mermaid
/mermaid generate

如果你的项目已经大到自己都记不清架构了，用它扫一遍，比手动画图省事 100 倍。
