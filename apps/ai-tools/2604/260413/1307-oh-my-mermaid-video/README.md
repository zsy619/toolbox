# Oh-my-Mermaid - AI 代码架构图生成器

## 项目简介

Oh-my-Mermaid 是一款能让 AI 自动扫描代码库，生成可视化架构文档的工具。支持 Mermaid 图表、递归分析复杂逻辑、Claude Code 适配。

## 功能特性

- 🤖 AI 自动扫描代码库
- 📊 生成 Mermaid 可视化图表
- 🔄 递归分析复杂逻辑节点
- 📁 本地生成清晰目录树
- 🌐 浏览器交互式查看
- ☁️ 云端同步分享

## 适用场景

- 项目架构不清晰时
- 需要向团队展示代码结构时
- 接手遗留项目需要快速了解时
- 代码审查和文档编写时

## 快速开始

```bash
# Claude Code 中使用
/claude install oh-my-mermaid
/mermaid generate

# 或者直接命令行
npx oh-my-mermaid scan ./your-project
```
