# PhoneClaw - iPhone 本地运行 Gemma 4

## 项目简介

PhoneClaw 让 Google Gemma 4 在 iPhone 上完全本地运行，实现离线推理，速度最高 20 tokens/s。支持 E4B 和 E2B 量化版，真正具备 Agent 能力。

## 核心功能

- ⚡ **20 tokens/s** - 本地推理速度
- 🔒 **零联网** - 完全离线运行
- 🤖 **Agent 能力** - 飞行模式也能用
- 🔐 **隐私优先** - 数据不离开设备

## 技术实现

- Gemma 4 (E4B & E2B 量化版)
- iPhone 本地推理
- Skills 支持（设备信息、剪贴板、文本工具）
