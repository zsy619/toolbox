# ViMax - 香港大学 AI 视频生成框架

## 项目简介

ViMax 是香港大学数据科学实验室（HKUDS）推出的多智能体视频生成框架，整合导演、编剧、制片人功能，通过多智能体协作实现"自编自导自演"。

## 核心功能

- 🎬 多智能体协作：导演、编剧、制片人、视频生成器
- 📊 解决三大痛点：片段短、一致性差、缺叙事
- 🎥 分钟级长视频生成
- 🎭 角色和场景一致性保持

## 四大模式

| 模式 | 说明 |
|------|------|
| Idea2Video | 一句话生成视频 |
| Novel2Video | 小说转视频 |
| Script2Video | 剧本转视频 |
| AutoCameo | 智能分镜生成 |

## 支持模型

整合 Google Veo、豆包 Seedance 等主流视频生成模型
