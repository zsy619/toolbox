# Medvi - AI 一人独角兽神话

## 项目简介

2万美元启动，1年干出4亿美元营收、6500万美元净利润的真实创业故事。

41岁的Matthew Gallagher在2024年9月，靠着ChatGPT、Claude、Midjourney等AI工具快速上线项目，主打GLP-1减肥药复合调配。2025年拿下4.01亿美元营收，服务25万客户，净利润率16.2%。
