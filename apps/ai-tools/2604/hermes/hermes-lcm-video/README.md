## 核心概念

Hermite-LCM 是一个损失极低的上下文管理插件，将对话保存为层次化 DAG，可通过 lcm_grep、lcm_expand 等工具检索和展开被压缩的历史。

## 视频规格

- **分辨率**：1080×1920（竖屏）
- **帧率**：60fps
- **时长**：50秒
- **编码**：H.264 / AAC
