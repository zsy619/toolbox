# Hermes-LCM - 项目分析文档

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | Hermes-LCM |
| 定位 | 损失极低的上下文管理插件 |
| 核心功能 | 将对话保存为层次化 DAG |
| 工具 | lcm_grep、lcm_expand 等 |

## 核心定位

**一句话**：让 AI 记住对话历史，损失极低的上下文管理方案。

## 核心技术

### 1. 层次化 DAG 结构
- 有向无环图存储对话历史
- 保留对话之间的层次关系
- 高效检索和压缩

### 2. 损失极低压缩
- 最小化信息丢失
- 保持关键上下文
- 可逆的压缩操作

### 3. 检索工具
- **lcm_grep**：检索被压缩的历史
- **lcm_expand**：展开被压缩的历史
- 快速定位和恢复

## 技术特点

| 特点 | 说明 |
|------|------|
| DAG 存储 | 层次化有向无环图 |
| 低损失压缩 | 最小化信息丢失 |
| 工具检索 | lcm_grep、lcm_expand |
| 快速展开 | 恢复被压缩的历史 |

## 应用场景

- 长期对话记忆
- 上下文恢复
- 对话历史检索
- 多轮对话管理
