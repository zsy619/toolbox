## 长文案（150-300字）

### 版本1
**Hermes Web Search Plus - 智能多搜索引擎插件**

Hermes Web Search Plus 是一款智能多搜索引擎插件，能根据查询自动路由到最佳搜索服务。

**核心特性**：
- 7大搜索服务商：Serper、Tavily、Exa、Querit、Perplexity、You.com、SearXNG
- 智能自动路由：根据查询意图选择最佳提供商
- 深度研究模式：多源综合和跨文档分析
- 路由透明：每次响应都包含路由解释
- 自适应故障转移：自动跳过故障提供商

### 版本2
**搜索的智能革命**

传统搜索需要手动选择搜索引擎。Hermes Web Search Plus 打破了这一限制。

智能路由自动分析查询意图，选择最合适的搜索服务。7大搜索服务商任你调用，深度研究模式让信息获取更全面。
