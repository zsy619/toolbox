Hermes Web Search Plus - 智能多搜索引擎插件

Multi-provider web search with intelligent auto-routing

今天给大家介绍一个超实用的 Hermes Agent 插件——Hermes Web Search Plus，它能让你的搜索效率翻倍。

核心特性

  • 7大搜索服务商 - Serper、Tavily、Exa、Querit、Perplexity、You.com、SearXNG
  • 智能自动路由 - 根据查询意图选择最佳提供商
  • 深度研究模式 - 多源综合和跨文档分析
  • 路由透明 - 每次响应都包含路由解释
  • 自适应故障转移 - 自动跳过故障提供商

支持的搜索服务

  • Serper - Google搜索API
  • Tavily - AI搜索
  • Exa - 深度搜索
  • Querit - 开源搜索
  • Perplexity - AI搜索
  • You.com - 搜索平台
  • SearXNG - 自托管搜索
