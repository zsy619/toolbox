# Hermes Web Search Plus 项目分析

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | Hermes Web Search Plus |
| 定位 | Hermes Agent 智能多搜索引擎插件 |
| 核心功能 | 自动路由到最佳搜索引擎 |
| 提供商数 | 7个 |

## 核心内容（用户指定）

智能多搜索引擎插件，能根据查询自动路由到 Serper、Tavily、Exa 等七大服务，支持深度研究、时间和域名过滤，并提供查询路由解释。

## 核心功能

### 1. 智能自动路由
- 根据查询意图选择最佳提供商
- 每次响应都包含 routing 对象解释提供商选择

### 2. 7大搜索服务商
- **Serper** - Google搜索API
- **Tavily** - AI搜索
- **Exa** - 深度搜索
- **Querit** - 开源搜索
- **Perplexity** - AI搜索
- **You.com** - 搜索平台
- **SearXNG** - 自托管搜索

### 3. Exa 深度研究
- `depth=deep` - 多源综合
- `depth=deep-reasoning` - 跨文档分析

### 4. 自适应故障转移
- 提供商故障后自动跳过
- 1小时冷却期后重试

### 5. 路由透明
- 每个响应包含 routing 对象
- 解释提供商选择原因

## 技术特点

- **智能路由**：自动选择最佳搜索服务
- **多提供商**：支持7种搜索服务
- **深度研究**：支持深度搜索和分析
- **透明解释**：提供路由决策说明
