# Hermes Web Search Plus 视频项目

## 项目信息

| 参数 | 值 |
|------|------|
| 项目名称 | hermes-web-search-plus-video |
| 来源 | https://github.com/robbyczgw-cla/hermes-web-search-plus |
| 主题 | tech-modern |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 时长 | ~45秒 |

## 核心内容（用户指定）

智能多搜索引擎插件，能根据查询自动路由到 Serper、Tavily、Exa 等七大服务，支持深度研究、时间和域名过滤，并提供查询路由解释。

## 视频规格

- **分辨率**：1080×1920（竖屏）
- **帧率**：60fps
- **时长**：45秒
- **编码**：H.264 / AAC
