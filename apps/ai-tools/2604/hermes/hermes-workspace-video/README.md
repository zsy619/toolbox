## 核心功能（视频重点）

1. **WeChat 桥接** — 在微信中直接与 Hermes Agent 交互
2. **聊天控制** — 通过微信聊天控制 Agent、接收结果
3. **日常自动化** — 适合消息场景的自动化
4. **SSE 实时流** — 实时 Agent 输出，工具调用渲染
5. **多端支持** — PWA 安装，手机电脑同步
