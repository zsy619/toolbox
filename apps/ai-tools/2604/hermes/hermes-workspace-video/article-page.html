Hermes Workspace

WeChat 桥接工具 · 在微信中与 Hermes Agent 直接交互

在微信中直接与 Hermes Agent 交互，通过聊天控制 Agent、接收结果，适合日常自动化和消息场景

🤖 WeChat 桥接

Hermes Workspace 支持通过 WeChat 与 Hermes Agent 直接交互：

  • 微信聊天发送指令给 Agent
  • Agent 自动执行任务
  • 结果实时推送回微信

⚡ 实时 SSE 流

Agent 输出实时推送，零延迟响应，支持工具调用渲染。

📱 移动端优先

PWA 安装，手机电脑同步体验，通过 Tailscale 在任何设备上获得完整功能。

🔒 安全认证

所有 API 路由认证中间件、CSP headers、数据安全有保障。

🐳 Docker 一键部署

一条命令启动，配置简单：

docker compose up
