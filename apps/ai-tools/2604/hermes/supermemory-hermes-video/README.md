# SuperMemory Hermes 视频项目

## 项目信息

| 参数 | 值 |
|------|------|
| 项目名称 | supermemory-hermes-video |
| 来源 | https://supermemory.ai/docs/integrations/hermes |
| 主题 | tech-modern |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 时长 | ~50秒 |

## 核心概念

SuperMemory 是一个基于知识图谱的原生记忆提供者，集成到 Hermes 生命周期钩子中，自动捕捉对话，维护用户画像并支持多容器路由。

## 视频规格

- **分辨率**：1080×1920（竖屏）
- **帧率**：60fps
- **时长**：50秒
- **编码**：H.264 / AAC
