## 核心概念

Hermes Neurovision 是一个 Terminal 神经可视化器，用于 Hermes Agent。85个动画主题，实时可视化AI活动，纯Python标准库零依赖。

## 视频规格

- **分辨率**：1080×1920（竖屏）
- **帧率**：60fps
- **时长**：45秒
- **编码**：H.264 / AAC
