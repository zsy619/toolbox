# Hermes Neurovision 项目分析

## 项目基本信息

| 参数 | 值 |
|------|------|
| 项目名称 | Hermes Neurovision |
| 定位 | Terminal neurovisualizer for Hermes Agent |
| 核心功能 | AI活动可视化终端 |
| 主题数 | 85个动画主题 |

## 一句话介绍

Terminal neurovisualizer for Hermes Agent - 观看AI思考的终端神经可视化器。

## 核心功能

### 1. 85个动画主题
- 全屏生成场域
- 奇怪吸引子
- 混合节点/场域屏幕
- 经典节点图

### 2. 实时事件可视化
- Agent活动直接驱动视觉强度
- 数据包传输
- 脉冲扩散
- 粒子爆发

### 3. 7个数据源
- Sessions（会话）
- Tool Calls（工具调用）
- Memory Writes（内存写入）
- Cron Jobs（定时任务）
- Trajectories（轨迹）
- Security Events（安全事件）

### 4. 叠加层功能
- **Log Overlay** - 彩色实时事件流
- **Tuner Overlay** - 实时元素控制
- **Debug Panel** - 诊断叠加层

### 5. 运行模式
- **Live Mode** - 默认模式，响应agent事件
- **Quiet Mode** - 仅agent事件驱动，无环境动画
- **Gallery Mode** - 浏览所有主题
- **Daemon Mode** - 空闲时画廊，活跃时直播

### 6. 纯标准库
- Zero external dependencies（零外部依赖）

## 技术特点

| 特点 | 说明 |
|------|------|

- 观看AI思考过程
- 调试Agent行为
