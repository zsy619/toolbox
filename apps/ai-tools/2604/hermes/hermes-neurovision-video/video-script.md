# Hermes Neurovision 视频脚本

| 参数 | 值 |
|------|------|
| 时长 | 40-50秒 |
| 帧率 | 60fps |
| 分辨率 | 1080×1920 |
| 主题 | tech-modern（科技现代风） |

## 场景列表

### 场景 1：开场（0-5秒）

- **视觉**：深色背景 + Logo 居中
- **标题**：Hermes Neurovision
- **副标题**：观看 AI 思考的过程
- **动画**：渐入

### 场景 2：核心定位（5-12秒）

- **视觉**：终端界面效果
- **标题**：Terminal neurovisualizer
- **内容**：
  - 实时可视化AI活动
  - 驱动视觉：亮度、密度、数据包

### 场景 3：85个动画主题（12-22秒）

- **视觉**：主题展示网格
- **标题**：85 Animated Themes
- **内容**：
  - 全屏生成场域
  - 奇怪吸引子
  - 混合节点/场域屏幕

### 场景 4：7个数据源（22-30秒）

- **视觉**：数据源图标
- **标题**：7 Data Sources
- **内容**：
  - Sessions 会话
  - Tool Calls 工具调用
  - Memory Writes 内存写入

### 场景 5：交互功能（30-38秒）

- **视觉**：功能列表
- **标题**：Interactive Controls
- **内容**：
  - Log Overlay 日志叠加
  - Tuner Overlay 调谐器叠加
  - Debug Panel 调试面板

### 场景 6：结尾（38-45秒）

- **视觉**：深色背景 + CTA
- **标题**：Watch Your AI Think
- **副标题**：GitHub搜索 hermes-neurovision
- **动画**：渐入

## 配音脚本

> 今天介绍 Hermes Neurovision。
>
> 这是一个 Terminal 神经可视化器，用于 Hermes Agent。
>
> 让你在终端中观看 AI 思考的过程。
>
> 核心特点：85个动画主题，实时可视化 AI 活动。
>
> 支持7种数据源：会话、工具调用、内存写入、定时任务、轨迹、安全事件等。
>
> 交互功能包括：日志叠加层、调谐器叠加层、调试面板。
>
> 支持多种模式：实时模式、安静模式、画廊模式、守护进程模式。
>
> 纯标准库实现，零外部依赖。
>
> GitHub 搜索 hermes-neurovision，观看你的 AI 思考。
