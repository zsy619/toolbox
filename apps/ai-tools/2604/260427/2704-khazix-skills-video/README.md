## 核心功能（视频重点）

1. **Prompts** — 轻量级，复制粘贴到任何 AI 对话或 Deep Research 里就能用
2. **Skills** — 重量级，遵循 Agent Skills 开放标准，安装后 Agent 自动加载
3. **hv-analysis** — 横纵分析法深度研究 Skill，自动联网收集信息，输出 PDF 研究报告
4. **khazix-writer** — 公众号长文写作 Skill，包含写作风格规则、四层自检体系
