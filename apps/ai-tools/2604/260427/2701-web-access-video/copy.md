# 营销文案集 - Web Access

## 小红书版本

### 标题
给 AI Agent 装上完整联网能力！这个 Skill 太强了 ⚡

### 正文
AI Agent 原本的联网能力（WebSearch、WebFetch）缺少调度策略和浏览器自动化。

Web Access Skill 补上的是：
✅ 联网策略 + CDP 浏览器操作 + 站点经验积累

核心能力：
🔹 联网工具自动选择（WebSearch / WebFetch / curl / Jina / CDP）
🔹 CDP Proxy 浏览器操作（直连 Chrome，携带登录态）
🔹 三种点击方式（JS click / 真实鼠标事件 / 文件上传）
🔹 并行分治（多目标分发子 Agent 并行执行）
🔹 站点经验积累（跨 session 复用）

安装超简单：
npx skills add eze-is/web-access

兼容 Claude Code、Cursor、Gemini CLI 等所有主流 Agent。
