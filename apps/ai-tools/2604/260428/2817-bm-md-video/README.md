# bm.md 排版神器视频创作项目

## 项目信息
- **项目名称**: bm-md-video
- **开始时间**: 2026-04-25 22:01 GMT+8
- **状态**: 进行中
- **来源**: https://github.com/miantiao-me/bm.md

## 核心内容
它不是新的 Markdown 编辑器，而是专门处理写完之后最烦的排版问题。

**核心功能**：
- 实时预览
- 14 种样式
- 14 种代码主题
- 一键适配

**核心卖点**：
- 标题、代码块、间距不用来回手调，写完直接看效果
- 发发文前那种差一点就不舒服的细节，它能省掉很多
- 注意力终于可以留给内容，而不是留给格式

## 视频规格
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **预估时长**: 约40-50秒
- **主题**: cyberpunk（赛博朋克风）
- **大字体**: 主标题120-180px，副标题48-72px，正文40-56px
