## 正文

### 版本A（功能导向）

**SOTA 文档 OCR！这款开源工具将 PDF 转文本太准了！**

PDF 和图片转文本还在手动录入？

今天给大家介绍一个开源项目——**Chandra OCR 2**。

这是 Datalab 推出的 SOTA 文档智能识别模型。

**核心亮点：**

🏆 **SOTA 性能**
在外部 olmocr benchmark 中排名第一，多语言性能显著提升。

🌐 **90+ 语言支持**
强大的多语言 OCR 能力，覆盖全球主要语言。

✍️ **手写识别**
优秀的手写内容识别能力，精准还原手写文档。

📊 **复杂文档处理**
- 表格识别准确
- 数学公式提取
- 复杂布局解析
- 表单重建（含复选框）

📄 **多格式输出**
支持 Markdown、HTML 或 JSON，结构化输出，完整保留布局信息。

🔧 **双推理模式**
- 本地 HuggingFace
- 远程 vLLM 服务器（推荐）

**快速开始：**

```bash
pip install chandra-ocr

# 使用 vLLM（推荐）
chandra input.pdf ./output

# 使用 HuggingFace
chandra input.pdf ./output --method hf
```

完全开源免费，Apache 2.0 许可证！

链接：https://github.com/datalab-to/chandra
