这个开源工具，把电子书变成了随身听

2026-04-25 · 3分钟阅读

你是否有这样的烦恼：书架上堆满了想读的书，却总是找不到时间坐下来看？今天给大家介绍一个开源项目——Audiblez。

它能把你书架上的 epub 电子书，一键变成可以随时听的有声书。使用 Kokoro-82M 语音合成模型，82M 参数，却能产生极其自然的语音。

🎯 Kokoro-82M 语音模型

Kokoro-82M 是 recently published 的 TTS 模型，仅 82M 参数就能产生非常自然的语音输出。训练数据少于 100 小时，Apache 许可证开源。

🌍 9种语言支持

支持的语言

🇺🇸🇬🇧 英语 · 🇪🇸 西班牙语 · 🇫🇷 法语 · 🇮🇳 印地语 · 🇮🇹 意大利语 · 🇯🇵 日语 · 🇧🇷 葡萄牙语 · 🇨🇳 中文

⚡ GPU 加速

使用 CUDA 加速，5分钟就能完成《动物农场》这样的长篇著作（约160,000字符），速率约 600 字符/秒。

🎨 v4 新功能

v4 版本亮点

• 图形界面，拖拽即用
• 更多音色选择
• 交互式章节选择

💻 如何使用

# 安装
pip install audiblez
# 运行
audiblez book.epub -v af_sky
