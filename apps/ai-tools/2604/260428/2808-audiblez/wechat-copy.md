## 正文

### 版本A（功能导向）

**这个开源工具，把电子书变成了随身听**

你是否有这样的烦恼：书架上堆满了想读的书，却总是找不到时间坐下来看？

今天给大家介绍一个开源项目——**Audiblez**。

它能把你书架上的 epub 电子书，一键变成可以随时听的有声书。

**核心亮点：**

🎯 **Kokoro-82M 语音模型**
82M 参数，却能产生极其自然的语音。效果远超传统 TTS。

🌍 **9种语言支持**
英语、中文、日语、西班牙语、法语、意大利语、印地语、葡萄牙语全覆盖。

⚡ **GPU 加速**
使用 CUDA 加速，5分钟就能完成《动物农场》这样的长篇著作（约16万字符）。

🎨 **v4 新功能**
- 图形界面，拖拽即用
- 更多音色选择
- 交互式章节选择

**如何使用？**

```bash
pip install audiblez
audiblez yourbook.epub -v af_sky
```

然后等待转换完成，你就能得到一个 m4b 格式的有声书了。用 VLC 或者任意音频播放器都能听。

**适用场景：**

- 📚 通勤路上听书
- 👀 解放双眼，耳朵享受
- 🌍 学习外语听力
- ♿ 辅助视力障碍人士

**免费、开源、MIT 许可证。**

链接：https://github.com/santinic/audiblez

### 版本B（情怀导向）

**程序员的情怀：给自己写的有声书工具**

作为程序员，我经常有这样的需求：想把手头的技术书籍变成可以听的格式，利用通勤时间学习。

于是我找到了 Audiblez。

这是一个开源的电子书转有声书工具。使用 Kokoro-82M 语音合成模型，82M 参数，却能产生非常自然的语音输出。

**实测效果：**

在 M2 MacBook Pro 上，使用 CPU 转换《动物农场》需要约1小时。
在 Google Colab T4 GPU 上，使用 CUDA 加速只需5分钟，速率约600字符/秒。

**9种语言支持：**

中文音色包括 zm_yunjian、zm_yunxi、zm_yunxia、zm_yunyang 等多个选择。

**命令行和 GUI 两种使用方式：**

命令行适合自动化和批量处理，GUI 适合日常使用。

**MIT 开源，完全免费。**

链接：https://github.com/santinic/audiblez

如果你也想把书架上的书变成随身听，不妨试试。
