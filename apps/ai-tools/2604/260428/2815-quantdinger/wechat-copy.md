## 正文

### 版本A（功能导向）

**这个开源项目，让每个人都能拥有自己的量化交易系统**

量化交易，听起来很专业、很遥远？

今天给大家介绍一个开源项目——**QuantDinger**，让你可以搭建自己的 AI 量化交易系统。

**核心亮点：**

🎯 **AI 市场分析**
支持 OpenRouter、OpenAI、Gemini、DeepSeek 等多种 AI 模型，一键进行跨市场研究。

💻 **Python 策略开发**
直接用 Python 写策略，或者让 AI 帮你生成代码。Indicator IDE 支持可视化图表。

📊 **完整回测**
回测记录完整保存，支持复现和回放，让策略验证有据可依。

🚀 **实盘交易**
对接多家加密交易所，支持自动和半自动交易模式。

🌍 **多市场覆盖**
- 🪙 加密货币（现货+合约）
- 📈 美股（IBKR）
- 💱 外汇（MT5）
- 🔮 预测市场（Polymarket）

**技术架构：**

- Docker Compose 一键部署
- PostgreSQL 生产级数据库
- Redis 高性能缓存
- Python 3.10+

不是玩具级别的产品，是真正可以用于生产的系统。

**快速开始：**

```bash
git clone https://github.com/brokermr810/QuantDinger.git
cd QuantDinger
docker-compose up -d --build
```

访问 http://localhost:8888

**开源免费，Apache 2.0 许可证。**

链接：https://github.com/brokermr810/QuantDinger
