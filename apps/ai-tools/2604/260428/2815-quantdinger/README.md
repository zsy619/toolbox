# QuantDinger 视频项目

## 项目概述

- **项目名称**: QuantDinger - AI 量化交易平台
- **来源**: https://github.com/brokermr810/QuantDinger
- **主题**: 开源 AI 量化交易系统，自部署、本地优先
- **标签**: AI, Quant, Trading, Crypto, Python, Docker

## 核心亮点

1. **AI 分析**: OpenRouter/OpenAI/Gemini/DeepSeek 一键跨市场研究
2. **Python 策略**: 直接用 Python 写策略，AI 帮你生成代码
3. **完整回测**: 回测记录完整保存，可复现、可回放
4. **实盘对接**: 多家加密交易所，自动/半自动交易
5. **多市场覆盖**: IBKR 美股、MT5 外汇、Polymarket 预测市场

## 规格

- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约50-60秒
- **语速**: 1.2x
- **主题风格**: cyberpunk（赛博朋克）
- **字体**: 大字体（主标题120px+）
- **帧数**: ≥10帧

## 技术栈

- Docker + PostgreSQL + Redis
- 生产级部署标准
- Python 3.10+
- 支持多交易所 API
