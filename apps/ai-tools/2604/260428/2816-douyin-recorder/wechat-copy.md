## 正文

### 版本A（功能导向）

**这款开源工具，帮你自动录制 40+ 平台直播**

喜欢看直播，但总错过精彩内容？

今天给大家介绍一个开源项目——**DouyinLiveRecorder**。

它是一款简易的可循环值守的直播录制工具，基于 FFmpeg 实现多平台直播源录制。

**核心亮点：**

🎯 **40+ 平台支持**
抖音、TikTok、B站、快手、斗鱼、虎牙、YouTube……基本上主流直播平台都支持。

🛠️ **FFmpeg 驱动**
基于 FFmpeg 实现，稳定性高，输出格式多样。

⚡ **自动监测**
自动监测直播状态，开播即录制，无需人工干预。

🔄 **循环值守**
支持循环值守模式，七乘二十四小时运行，不错过任何一场直播。

📦 **批量录制**
支持同时录制多个主播，一键管理所有任务。

🐳 **Docker 部署**
一行命令即可部署，兼容 Windows、Linux 和 Mac。

**适用场景：**

- 📺 长期追直播的主播粉丝
- 🎬 视频创作者采集素材
- 📚 研究直播内容的学者
- 🏢 MCN 机构批量管理

**快速开始：**

```bash
docker run -d \
  --name douyin-recorder \
  -v /path/to/config:/app/config \
  ihmily/douyin-live-recorder
```

完全开源免费，链接：https://github.com/ihmily/DouyinLiveRecorder
