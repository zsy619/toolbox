# gnhf 视频脚本

## 视频信息

- **项目**: gnhf - AI 代码迭代循环工具
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约55秒
- **语速**: 1.2x
- **主题**: cyberpunk（赛博朋克）
- **字体**: 大字体（主标题100px+）
- **帧数**: 11帧

---

## 分镜脚本（11帧）

### 帧 1: 开场 Hook（0-4秒）

**画面**: 赛博朋克背景，霓虹粒子，月亮/夜晚图标
**文字**:
```
gnhf
Good Night, Have Fun
```

**配音**: 想让 AI 替你值夜班、榨干 AI 生产力吗？

---

### 帧 2: 痛点（4-8秒）

**画面**: 赛博朋克背景，问题闪烁
**文字**:
```
代码优化太费时？
需要 AI 持续迭代？
不想一直盯着屏幕？
```

**配音**: 代码优化太费时？需要 AI 持续迭代？不想一直盯着屏幕？

---

### 帧 3: 解决方案（8-12秒）

**画面**: Logo + 主题
**文字**:
```
gnhf
一句话启动 AI 代码迭代
```

**配音**: 今天给大家介绍 gnhf，一款让 AI 替你值夜班的代码自动迭代工具。

---

### 帧 4: 一句话启动（12-17秒）

**画面**: 命令行图标
**文字**:
```
输入一句指令
唤起 Claude Code 或 Codex
全自动代码迭代
```

**配音**: 只需输入一句指令，就能唤起 Claude Code 或 Codex，进入全自动代码迭代循环。

---

### 帧 5: 自动 Git 提交（17-22秒）

**画面**: Git 图标
**文字**:
```
每次成功修改
自动生成独立 Git 提交
保留清晰工作轨迹
```

**配音**: 每次成功修改都会自动生成独立的 Git 提交记录，保留清晰的工作轨迹。

---

### 帧 6: 自动回滚重试（22-27秒）

**画面**: 回滚图标
**文字**:
```
运行报错？
自动回滚代码
并执行重试
```

**配音**: 遇到运行报错会自动回滚代码并执行重试，完全不需要人工干预。

---

### 帧 7: 迭代记忆机制（27-32秒）

**画面**: 记忆图标
**文字**:
```
迭代记忆机制
每轮结果写入笔记
供下一轮读取
```

**配音**: 内置迭代记忆机制，每轮结果会写入笔记文件供下一轮读取，让智能体知道之前做了什么。

---

### 帧 8: 智能退避策略（32-37秒）

**画面**: 策略图标
**文字**:
```
成功单独提交
失败自动回滚
连续失败指数退避
```

**配音**: 成功的改动单独提交，失败的自动回滚。连续失败会指数退避，不会一直烧钱。

---

### 帧 9: Worktree 多智能体（37-43秒）

**画面**: 多窗口图标
**文字**:
```
Worktree 模式
同时运行多个智能体
各自独立互不干扰
```

**配音**: 还能用 worktree 模式同时跑多个智能体，各自独立互不干扰。

---

### 帧 10: 支持多种智能体（43-48秒）

**画面**: 智能体图标
**文字**:
```
Claude Code · Codex
Rovo Dev · OpenCode
开箱即用
```

**配音**: 支持 Claude Code、Codex、Rovo Dev 和 OpenCode，开箱即用。

---

### 帧 11: 结尾 CTA（48-55秒）

**画面**: 赛博朋克背景
**文字**:
```
gnhf
让 AI 替你值夜班
github.com/kunchenguid/gnhf
```

**配音**: 让 AI 替你值夜班，榨干 AI 生产力！链接在描述栏，快去试试吧！
