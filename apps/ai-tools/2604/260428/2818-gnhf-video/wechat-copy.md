## 正文

### 版本A（功能导向）

**让 AI 替你值夜班，这款开源工具太强了！**

想持续优化代码，却不想一直盯着屏幕？

今天给大家介绍一个开源项目——**gnhf**（Good Night, Have Fun）。

这是一款 ralph/autoresearch 风格的 AI 编排器，让你的智能体在你睡觉时持续运行。

**核心亮点：**

🎯 **一句话启动**
只需输入一句指令，就能唤起 Claude Code 或 Codex，进入全自动代码迭代循环。

📝 **自动 Git 提交**
每次成功修改都会自动生成独立的 Git 提交记录，保留清晰的工作轨迹。

🔄 **自动回滚重试**
遇到运行报错会自动回滚代码并执行重试，完全不需要人工干预。

🧠 **迭代记忆机制**
每轮结果会写入笔记文件供下一轮读取，让智能体知道之前做了什么。

⏱️ **智能退避策略**
连续失败会指数退避，不会一直烧钱。

🌳 **Worktree 多智能体**
同时运行多个智能体，各自独立互不干扰。

**支持多种智能体：**
- Claude Code
- Codex
- Rovo Dev
- OpenCode

**快速开始：**

```bash
# 安装
npm install -g gnhf

# 一句话启动
gnhf "reduce complexity of the codebase"

# Worktree 多智能体模式
gnhf --worktree "implement feature X" &
gnhf --worktree "add tests for module Y" &
```

完全开源免费，让 AI 替你值夜班！

链接：https://github.com/kunchenguid/gnhf
