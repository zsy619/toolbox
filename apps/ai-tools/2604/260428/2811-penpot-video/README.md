# PenPot - 开源设计平台 for 设计协同

## 项目概览

| 项目 | 内容 |
|------|------|
| **名称** | PenPot Video |
| **来源** | https://github.com/penpot/penpot |
| **主题** | 开源设计工具 × 设计代码协同 × AI工作流 |
| **风格** | Cyberpunk 赛博朋克 |
| **场景数** | 8帧（封面+7功能场景）|
| **帧率** | 60fps |
| **分辨率** | 1080×1920 |
| **预估时长** | 70-90秒 |

## 核心功能点（7个场景）

1. **开源设计平台** - 团队级开源设计基础设施，完全自主可控
2. **自托管部署** - 浏览器或自有服务器，支持 Docker/K8s
3. **实时协作** - 团队实时协同，缩短设计和产品的距离
4. **设计令牌** - Design Tokens 统一设计开发语言
5. **MCP服务器** - AI工作流集成，多方向设计代码协同
6. **代码检查模式** - Inspect 一键查看 SVG/CSS/HTML 代码
7. **插件系统** - 可扩展编程工作区，自动化 AI 工作流
8. **设计系统** - Components + Variants 构建可扩展设计系统
