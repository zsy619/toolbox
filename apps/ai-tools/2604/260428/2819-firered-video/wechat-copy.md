## 正文

### 版本A（功能导向）

**输入一句话 = 输出成片，这款开源工具太强了！**

视频制作太复杂、剪辑软件难学、批量制作太费时间？

今天给大家介绍一个核弹级开源项目——**FireRed-OpenStoryline**。

这是一款基于 LLM/VLM 构建的自动化视频创作智能体。

**核心亮点：**

🎯 **自然语言驱动**
只需用自然语言描述创作意图，系统自动完成素材收集、剪辑、故事线构建、配音和配乐。

💬 **对话式精修**
支持对话式精修，通过自然语言删减、重组、修改字幕，全程自然语言操作，即时生效。

📦 **剪辑技能包**
一键保存完整编辑工作流为自定义技能，换个素材应用技能即可快速复刻同风格视频。

🎵 **智能音乐推荐**
根据内容和情绪自动推荐 BGM，智能节拍同步，简单描述想要的风格即可匹配。

🎬 **多风格支持**
中草风格、幽默风格、产品种草、艺术风格、开箱、talking Pet、旅行 Vlog、年终回顾等。

🛠️ **ASR 粗剪**
内置 ASR 语音识别粗剪技能，自动删除填充词、重复句，精准时间戳分段。

**适用场景：**

- 🎬 视频创作者快速制作
- 📱 社交媒体内容批量生产
- 🎨 风格化视频模板制作
- 🏢 企业宣传视频制作

**快速开始：**

```bash
# HuggingFace 直接体验
# https://fireredteam-firered-openstoryline.hf.space/

# 或克隆本地运行
git clone https://github.com/FireRedTeam/FireRed-OpenStoryline.git
cd FireRed-OpenStoryline
bash run.sh
```

完全开源免费，Apache 2.0 许可证！

链接：https://github.com/FireRedTeam/FireRed-OpenStoryline
