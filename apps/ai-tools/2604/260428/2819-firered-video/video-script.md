# FireRed-OpenStoryline 视频脚本

## 视频信息

- **项目**: FireRed-OpenStoryline - AI 视频创作智能体
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约55秒
- **语速**: 1.2x
- **主题**: cyberpunk（赛博朋克）
- **字体**: 大字体（主标题100px+）
- **帧数**: 11帧

**文字**:

```

### 帧 4: 核心能力 - 自然语言（12-17秒）

**画面**: 语音/文字图标
**文字**:
```

```

**配音**: 只需用自然语言描述你的创作意图，系统会自动完成素材收集、剪辑、故事线构建、配音和配乐。

### 帧 6: 剪辑技能包（22-27秒）

```

**配音**: 可一键保存为剪辑技能包，方便快速复刻同风格视频，实现高效批量创作。

### 帧 8: 智能推荐（33-38秒）
