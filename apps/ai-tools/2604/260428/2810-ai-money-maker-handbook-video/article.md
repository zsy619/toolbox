# AI 副业赚钱手册

## 项目概览

- **项目名称**: AI 副业赚钱手册 (AI Money Maker Handbook)
- **GitHub**: https://github.com/XiaomingX/ai-money-maker-handbook
- **主题**: AI 副业实操手册，总结目前主流的变现路径

## 核心内容

AI 副业变现拆解为四个部分：

### 1. 认知逻辑
- **核心理念**: "做资产"而非"卖时间"
- **关键策略**: 卖铲子而非挖金子，关注出海市场，利用付费习惯差异和信息差

### 2. 技术变现
面向具备开发能力的用户：
- 代客部署 OpenClaw 或 Claude Code 赚取服务费
- 通过 Agent 接入海外广告 API 赚取佣金
- 开发垂类插件、SaaS 工具和 API 聚合站

### 3. 内容生产
涵盖自动化流程：

**视频方面**：
- 虚拟人口播
- 小说推文
- 无人直播

**图文方面**：
- AI 绘本
- 模特换装
- LOGO 制作

### 4. 创业实务
初创公司指南：
- PMF 概念
- 单位经济模型（LTV/CAC）
- 出海合规（GDPR）
- 融资基础
