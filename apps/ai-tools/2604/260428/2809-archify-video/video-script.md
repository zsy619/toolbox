## 配音命令（edge-tts）

```bash
edge-tts --voice zh-CN-YunjianNeural \
  --text "$(cat << 'EOF'
Archify — 聊两句就画出专业架构图

画一张专业的系统架构图，需要花几个小时？选工具、拖组件、调样式、对齐像素……改一行需求，整张图重来。

Archify 是一个 Claude Skill。你用大白话描述系统，它直接生成一张技术图。深色浅色，一键切换。PNG、JPEG、WebP、SVG，四种格式下载。或者直接复制到剪贴板，粘贴到任何地方。

Archify 支持五种图表类型：Architecture，架构图，系统组件一目了然；Workflow，流程图，请求生命周期轻松表达；Sequence，时序图，API调用链清晰展示；Data Flow，数据流图，数据管线一览无余；Lifecycle，生命周期图，状态机跃然眼前。

深色浅色主题，一键切换，浏览器自动记住。导出图片全部是4倍源分辨率原生光栅化，不是位图放大，没有一丝模糊。单文件HTML，零依赖，发一个文件就能分享。继续聊天迭代，加组件、改颜色、换布局。

React加Node.js加Postgres加Redis，描述一句，出来一张。AWS微服务架构，Kafka事件流，DeepSeek模型调用链，Agent Run生命周期状态机，全都能画。

使用超简单。下载archify.zip，Claude Settings开启Skill，上传zip文件，然后直接跟Claude说：用archify画一张架构图，粘贴你的系统描述，完事。

描述你的系统，获得一张publication-ready的专业架构图。立刻体验：unzip archify.zip。
EOF
)" \
  --output audio/tts_script.txt \
  --write-media audio/neural_1_2x.m4a \
  --rate +12% \
  --volume +0%
```
