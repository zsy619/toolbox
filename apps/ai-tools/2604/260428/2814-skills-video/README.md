## 核心内容
Gumroad 创始人给出了另一条路：先找社区，再看需求，最后写代码。
他把《极简创业》的精髓，开源成了 9 个可交互的 AI Agent Skills。
这是一套「一人公司」赚钱必备的生存指南。

## 9个Skills概览

| # | Skill | 核心观点 |
|---|-------|---------|
| 1 | 找社区 /find-community | 找赛道❌ 找社区✅ 在真实抱怨里找机会 |
| 2 | 验证需求 /validate-idea | 只看交易信号，不看口头夸奖 |
| 3 | 最小可行性产品 /mvp | 先手工交付 → 梳理流程 → 最后产品化 |
| 4 | 搞定首批客户 /first-customers | 前100个客户都是挨个聊出来的 |
| 5 | 定价 /pricing | 尽早收费，定价是商业闭环的探针 |
| 6 | 营销计划 /marketing-plan | 把营销看作规模化的销售 |
| 7 | 可持续增长 /grow-sustainably | 活下去是底线，护好现金流 |
| 8 | 公司价值观 /company-values | 一人公司也要有红线 |
| 9 | 核心复盘 /minimalist-review | 防上头开关，用底层原则重新审视 |
