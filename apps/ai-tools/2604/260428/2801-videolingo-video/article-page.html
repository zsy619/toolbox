Netflix级视频字幕翻译与配音

元曜科技 · 2026-04-25 · GitHub 8700+ Stars

你刷到的那些翻译搬运视频，背后可能就靠这一个工具。

VideoLingo 是一款一站式视频翻译、配音工具，能做出媲美 Netflix 级别的字幕效果。

🎬 核心功能

Netflix级字幕 单行不拆行 三步翻译 多TTS配音 多语言支持 一键全自动

用 WhisperX 做词级识别，NLP 加持智能断句，只出单行字幕告别拆行混乱，然后通过多 TTS 接口配上自然配音。

变现思路

把 YouTube 上的前沿播客、冷门教程无损翻译成中文，发到 B 站/小红书；或者把国内的爆款解说翻译成英文发 TikTok。纯靠打破语言壁垒来赚流量分成。

使用方法

git clone https://github.com/Huanshere/VideoLingo.git cd VideoLingo python setup_env.py streamlit run st.py

适用场景

🎥 YouTube搬运翻译（英→中）
🌐 TikTok内容本地化（中→英）
📚 知识付费冷门教程翻译
🎙️ 播客翻译二次创作
