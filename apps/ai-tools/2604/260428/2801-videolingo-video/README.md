# VideoLingo 视频翻译配音神器

## 项目信息
- **项目名**: videolingo-video
- **开始时间**: 2026-04-25 09:27 GMT+8
- **状态**: 进行中
- **来源**: https://github.com/Huanshere/VideoLingo

## 核心内容
VideoLingo 是一款一站式视频翻译、配音工具，能做出媲美 Netflix 级别的字幕效果。

## 变现思路
利用信息差——把 YouTube 上的前沿播客、冷门教程无损翻译成中文发 B 站/小红书；或者把国内的爆款解说翻译成英文发 TikTok。纯靠打破语言壁垒来赚流量分成。

## 视频规格
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约45-50秒
- **主题**: tech-modern（科技现代风）
- **大字体**: 主标题120-180px，副标题48-72px，正文40-56px
