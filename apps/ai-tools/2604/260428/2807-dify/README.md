# Dify 视频项目

## 项目概述

- **项目名称**: Dify - AI 智能体开发平台
- **来源**: https://github.com/langgenius/dify
- **主题**: 不用写代码就能搭 AI 助手
- **标签**: AI, LLM, Agent, No-Code, 开发平台

## 核心亮点

1. **开源**: Linux Foundation 旗下项目
2. **不用写代码**: 可视化界面，拖拽即用
3. **支持多种模型**: GPT、Llama3、Mistral 等
4. **RAG 管道**: 文档处理、检索增强
5. **Agent 能力**: 50+ 内置工具

## 规格

- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约35-45秒
- **语速**: 1.2x
- **主题风格**: tech-modern（蓝紫系）
- **字体**: 大字体（主标题120px+）

## 变现思路

提供技术服务，给传统电商和线下门店搭建 AI 客服机器人。
