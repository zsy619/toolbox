## 核心内容

### 是什么
Fooocus 是一款图像生成软件，基于 Stable Diffusion XL 架构，重新定义了图像生成器的设计。

### 核心特点

1. **Midjourney级别的效果**
   - 无需提示词工程
   - 无需参数调优
   - 内置 GPT-2 提示词处理引擎

2. **极简安装**
   - 下载到出图，鼠标点击不超过3次
   - 最低4GB显存（Nvidia）
   - 自动下载模型

3. **专业功能**
   - 图生图（Image Prompt）
   - 局部重绘（Inpaint）
   - 放大/变换（Upscale/Vary）
   - 人脸交换（FaceSwap）
   - 多种风格预设（Fooocus V2、电影感、摄影等）

4. **支持模型**
   - SDXL 基础模型
   - Civitai 上的所有 SDXL 模型
   - anime / realistic 多种预设

### 变现思路

**视觉素材服务**：

1. **电商卖家单**
   - 把商品 P 到各种高端背景里
   - 制作产品场景图
   - 批量生成模特图

2. **网文作者插画**
   - 定制小说推文插画
   - 角色设定图
   - 封面图

3. **效率赚钱**
   - 熟练后出图极快（3060显卡约1.35秒/张）
   - 赚的是工具效率差
   - 批量接单模式

### 使用方法

```bash
# Windows
下载 → 解压 → 运行 run.bat

# 或 Colab（免费云端）
# GitHub页面有在线运行链接

# Anaconda
git clone https://github.com/lllyasviel/Fooocus.git
cd Fooocus
conda env create -f environment.yaml
conda activate fooocus
python entry_with_update.py
```
