## 核心内容
Fooocus 是一款专注提示词和图像生成的开源工具，界面像 Midjourney，但完全免费离线可用。

## 变现思路
视觉素材服务。比如去接电商卖家的单，帮他们把商品 P 到各种高端背景里；或者帮网文作者生成定制的小说推文插画。熟练之后出图极快，赚的是工具效率差。

## 视频规格
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约45-50秒
- **主题**: tech-modern（科技现代风）
- **大字体**: 主标题120-180px，副标题48-72px，正文40-56px
