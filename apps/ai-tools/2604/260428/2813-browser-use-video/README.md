## 核心内容
Browser Use 是一个让 AI Agent 能够自动化操作浏览器的开源项目。你只要给它一句话，它就能像真人一样自动操作浏览器。

## 变现思路
自动化获客。比如接了留学的单子，可以让它"去小红书/推特搜索'想去英国留学'的帖子，把博主 ID 提取到表格里"。拿到这些精准客户名单，无论是自己做业务还是提供给中介，都是实打实的需求。

## 视频规格
- **分辨率**: 1080×1920（竖屏）
- **帧率**: 60fps
- **时长**: 约45-50秒
- **主题**: cyberpunk（赛博朋克风）
- **大字体**: 主标题120-180px，副标题48-72px，正文40-56px
