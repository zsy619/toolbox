## 正文

最近爆火的一个项目，你只要给它一句话，它就能像真人一样自动操作浏览器。

**Browser Use** 是一个让网站对 AI Agent 可访问的开源项目，GitHub 已斩获五万多星。

### 核心功能

**🌐 自然语言驱动**
- 给一句话，AI 自动执行浏览器任务
- 支持 ChatGPT、Claude、Gemini 等主流 LLM
- 自定义工具扩展

**🔒 云端隐身浏览器**
- 反指纹检测
- 代理轮换
- 解决 CAPTCHAs
- 1000+ 集成（Gmail、Slack、Notion 等）

**⚡ 快速迭代**
- CLI 命令行快速测试
- 维持浏览器状态和认证会话

### 变现思路

**自动化获客**：

接了留学的单子，让它去小红书搜索"想去英国留学"的帖子，把博主 ID 提取到表格里。拿到这些精准客户名单，卖给中介或者自己做业务，都是实打实的需求。

**适用行业**：
- 留学/移民
- 金融/保险
- 招聘
- 任何需要精准客户数据的行业

### 如何使用

```bash
# 安装
uv init && uv add browser-use && uv sync
uvx browser-use install

# CLI 快速开始
browser-use open https://example.com
browser-use click 5
browser-use type "Hello"
```
