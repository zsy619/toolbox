Browser Use

元曜科技 · 2026-04-25 · GitHub 50K+ Stars

最近爆火的一个项目，你只要给它一句话，它就能像真人一样自动操作浏览器。

Browser Use 是一个让网站对 AI Agent 可访问的开源项目，GitHub 已斩获五万多星。

🌐 核心功能

自然语言驱动 自动点击输入 云端隐身浏览器 解决验证码 1000+集成

支持 ChatGPT、Claude、Gemini 等主流 LLM，自定义工具扩展。云端隐身浏览器反指纹检测，代理轮换，解决 CAPTCHAs。

变现思路

接了留学的单子，让它去小红书搜索"想去英国留学"的帖子，把博主 ID 提取到表格里。拿到这些精准客户名单，卖给中介或者自己做业务，都是实打实的需求。

使用方法

uv init && uv add browser-use && uv sync uvx browser-use install browser-use open https://example.com browser-use click 5 browser-use type "Hello"
