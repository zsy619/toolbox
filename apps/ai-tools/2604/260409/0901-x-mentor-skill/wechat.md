## 为什么你需要X导师

六位年收入百万美元级X创作者的方法论，加上X开源算法精确权重数据，帮你从0到1掌握X运营的核心能力。

### 6个核心心智模型

| 模型 | 一句话 |
|------|--------|
| 精益验证飞轮 | 先发tweet验证，数据好再扩展 |
| 注意力工程 | 前2行决定生死，hook可以被工程化 |
| 品类创造 | 不找赛道挤进去，创造只有你的品类 |
| 价值前置 | 把秘密免费给出去，卖执行 |
| 公开建造 | 把过程变成内容，观众变成利益相关者 |
| 系统化复利 | 用模板替代灵感，让产出可预测 |

### X算法权重揭秘

你知道吗？在X平台上：

- **对话回复（被作者回复）= 150倍权重**
- **普通回复 = 27倍**
- **停留2分钟 = 20倍**
- **转发 = 2倍**
- **点赞 = 1倍基准**

这意味着：与其追求点赞，不如花时间写一条能引发深度对话的回复。

## 10条决策启发式

1. **先发推文再写长文** — tweet是想法炼油厂
2. **Hook占50%创作时间** — 写10-15个版本选最好的
3. **对话碾压一切** — 对话回复=150个点赞
4. **1/3/1节奏** — 一句hook+三句展开+一句过渡
5. **超级碗响应** — 新模型发布=AI赛道的超级碗
6. **拥有你的受众** — 算法会变，newsletter不会
7. **4A选题矩阵** — 一个话题×4角度=无限选题
8. **给出秘密卖执行** — 99%的人不会自己做
9. **模板大于灵感** — Cole用7种模板写了200+条Thread
10. **评论区是金矿** — 一条回复获得6700次曝光
