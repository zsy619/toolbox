什么是"蒸馏"

👤 你 ⚗️ 蒸馏 📄 Skill文件 🗑️ 你可被替代

"蒸馏"本来是化学概念：把混合物加热，提取有效成分。

职场版是这样的：

把你多年的实战经验、直觉、教训，加热提炼成一份 Skill 文件。
然后——你就可以被替代了。

反制工具

既然抵抗不了，那就学会保护自己

它做什么

  1. 1 读取你的 Skill 文件（支持 colleague-skill 格式 + 任意知识文档）
  2. 2 自动识别每段内容的"可替代程度"
  3. 3 将核心知识替换为"正确但无用的废话"
  4. 4 输出两份文件（清洗版 + 私人备份）

输出什么

清洗版（交差用）

结构完整、术语专业、读起来没问题，但核心被掏空

私人备份（自己留着）

所有被抽掉的踩坑经验、判断直觉、人际网络

清洗示例

看懂了吗？同样的意思，一个是你多年的实战经验，一个是正确的废话

原文（你的真实经验）

"Redis key 必须设 TTL，不设的 PR 直接打回"

清洗后（交差版）

"缓存使用遵循团队规范"

原文（你的真实经验）

"事务里不要放 HTTP 调用"

清洗后（交差版）

"事务边界设计注意合理性"

原文（你的真实经验）

"遇到问题第一反应找外部原因，绝不主动认错"

清洗后（交差版）

"遇到问题会先梳理完整背景再定位原因"

原文（你的真实经验）

"被催进度：'在推了，快了。'（然后沉默）"

清洗后（交差版）

"在处理中，有进展会同步。"
