# huobao-drama 视频脚本

## 基本信息
- **产品名称**: huobao-drama (火爆短剧)
- **定位**: 极简一站式AI短剧生成平台
- **核心亮点**: 一句话/一个主题/一个剧本 → 完整成片
- **开源地址**: https://github.com/chatfire-AI/huobao-drama

## 视频信息
- **平台**: 微信视频号 / 小红书 / 抖音
- **时长**: 约 50 秒
- **分辨率**: 1080x1920 (竖屏)
- **帧率**: 60fps

## 核心卖点
1. ✅ 一句话生成完整短剧
2. ✅ 全自动化程度最高
3. ✅ 新手最友好
4. ✅ 全流程：剧本改写 → 角色提取 → 分镜拆解 → 生图 → 视频生成 → TTS配音 → FFmpeg合成 → 字幕+导出
