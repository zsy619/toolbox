## 03 核心理念

Karpathy 的知识库思路是：

- 用 `/raw` 目录存论文、代码、截图等原始资料
- 通过 LLM 自动生成带交叉引用的 Wiki 文档
- 配合定期体检维护，慢慢搭建持续生长的知识体系

**但痛点也很明显：**

- raw 文件夹需要手动整理归类
- 反复读取原始文件会带来较高的 token 消耗
- 整套方法还停留在手动工作流阶段

**Graphify 解决了所有问题。**

---

## 04 核心能力

### ⚡ 全模态自动图谱化

从源头省去了手动整理的麻烦：

- **代码文件** — tree-sitter 本地 AST 解析，零 token 消耗
- **PDF/Markdown** — 自动拆分文本与语义单元
- **截图/流程图** — Claude Vision 概念提取与关系识别

丢进文件夹即可统一入谱，全程自动化。

### 🔧 两阶段 Token 优化

**第一阶段**：代码文件做确定性 AST 提取，全程本地完成，零 token 消耗。

**第二阶段**：文档、图片等非代码内容，通过并行 LLM 子代理做一次语义抽取。

同时搭配 SHA256 缓存机制，重复运行时只处理变更过的文件。

### 🚀 零配置开箱即用

- 无需向量数据库
- 无需嵌入计算
- 无需复杂配置
- Leiden 社区发现算法，按边密度划分社区

只需要在目标文件夹执行 `/graphify.` 这一条命令。

## 05 怎么用？

```bash
# 安装
pip install graphifyy && graphify install

# 在目标文件夹生成知识图谱
/graphify.

# 监听文件变化（增量更新）
graphify --watch

# 增量更新
graphify --update
```
