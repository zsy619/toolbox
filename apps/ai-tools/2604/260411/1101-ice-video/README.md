# Ice - macOS 菜单栏管理神器

## 项目概述

**Ice** 是一款强大的 macOS 菜单栏管理工具，主要功能是隐藏和显示菜单栏图标，同时支持丰富的自定义功能，让你的菜单栏更加整洁和个性化。

- **官网**: https://icemenubar.app
- **GitHub**: https://github.com/jordanbaird/Ice
- **版本**: 0.11.12
- **下载量**: 131,000+
- **开源协议**: GPL-3.0
- **平台**: macOS 14+
- **价格**: 完全免费

## 核心功能

### 菜单栏项目隐藏
- 隐藏任意菜单栏图标
- "始终隐藏"专用区域
- 悬停显示隐藏项目
- 点击空白区域显示
- 滚动/滑动显示
- 自动重新隐藏

### Ice Bar（独立菜单栏）
- 为 MacBook Notch 设计
- 在菜单栏下方显示隐藏项目
- 独立的显示区域

### 拖拽排序
- 直观的拖拽界面
- 自由排列菜单栏图标
- 所见即所得

### 菜单栏外观自定义
- 菜单栏着色（纯色/渐变）
- 菜单栏阴影
- 菜单栏边框
- 自定义形状（圆角/分割）

### 快捷键支持
- 切换各菜单栏区域
- 快捷键呼出搜索面板
- 启用/禁用 Ice Bar
- 显示/隐藏分隔符图标
- 切换应用菜单

### 其他功能
- 开机自启动
- 自动更新检查
- 菜单栏项目搜索

## 安装方式

### Homebrew（推荐）
```bash
brew install --cask jordanbaird-ice
```

### 手动安装
1. 从 [GitHub Releases](https://github.com/jordanbaird/Ice/releases/latest) 下载 `Ice.zip`
2. 解压并移动到应用程序文件夹
