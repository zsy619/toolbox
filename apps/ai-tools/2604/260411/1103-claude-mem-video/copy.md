## 小红书正文

用 Claude Code 编程，每次新建会话都要重新解释项目背景？

Claude-Mem 来了！

它可以自动记录你之前的操作、决策和发现，下次会话直接继承上下文。

支持自然语言搜索：
"上次我们是怎么实现这个功能的？"
"之前修复过这个 bug 吗？"

而且完全免费开源！

安装只需两行命令：
```
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```

## 视频号描述

Claude-Mem 是一个持久化内存系统，自动记录 AI 编程过程中的决策和发现，让下一个会话直接继承上下文。支持自然语言搜索，无需手动整理。

## 核心卖点

1. **持久化记忆** - 跨会话保留上下文
2. **自然语言搜索** - 问"上次怎么做的"直接回答
3. **自动操作** - 无需手动整理
4. **隐私控制** - `<private>` 标签保护敏感内容
5. **免费开源** - AGPL-3.0 协议
