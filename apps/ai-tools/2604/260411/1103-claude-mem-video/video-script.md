## 小红书版本

### 标题
Claude Code 会"记忆"了！这个插件让 AI 编程效率翻倍 🧠

### 正文
用 Claude Code 编程，每次新建会话都要重新解释项目背景？

Claude-Mem 来了！

它可以自动记录你之前的操作、决策和发现，下次会话直接继承上下文。

支持自然语言搜索：
"上次我们是怎么实现这个功能的？"
"之前修复过这个 bug 吗？"

而且完全免费开源！

安装只需两行命令：
```
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```

## 视频脚本

### 场景 1: 封面 (0-3秒)
- **视觉**: 深色背景，中央显示 App 图标和标题
- **文字**:
  - 主标题: "Claude-Mem"
  - 副标题: "让 AI 记住一切"
- **动画**: 图标从远处飞入，标题淡入

### 场景 2: 痛点引入 (3-8秒)
- **视觉**: 模拟会话切换界面
- **文字**: "每次新建会话，AI 什么都不记得"
- **动画**: 对比：新会话 vs 有记忆的会话

### 场景 3: 解决方案 (8-13秒)
- **视觉**: Claude-Mem 工作流程图
- **文字**:
  - "自动记录"
  - "语义摘要"
  - "跨会话继承"
- **动画**: 流程逐条展示

### 场景 4: 搜索功能 (13-18秒)
- **视觉**: 搜索界面
- **文字**: "自然语言查询：上次我们怎么做的？"
- **动画**: 搜索结果快速展示

### 场景 5: 快速开始 (18-22秒)
- **视觉**: 终端命令
- **文字**: 两行安装命令
- **动画**: 命令行打字机效果

### 场景 6: 结束 (22-25秒)
- **视觉**: GitHub 图标 + 项目名
- **文字**: "搜索 thedotmack/claude-mem"
- **动画**: 淡出
