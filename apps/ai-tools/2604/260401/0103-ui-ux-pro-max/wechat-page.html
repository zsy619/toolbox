⚡ 实际效果示例

"帮我做一个美容SPA的落地页"

它不会直接开始写代码，而是先跑5路并行搜索，输出的设计系统方案包含：

  • 页面模式：Hero-Centric + Social Proof（情感驱动+信任元素）
  • UI风格：Soft UI Evolution（柔和阴影、有机形状、高级感）
  • 配色：柔粉 #E8B4B8 + 鼠尾草绿 #A8D5BA + 金色CTA #D4AF37
  • 字体：Cormorant Garamond（标题）+ Montserrat（正文）

🛡️ 智能反模式检查

每个行业的推理规则里都有"Anti-Patterns"，专门列了该行业不该做什么：

  • 🏦 银行类产品 → 不该用"AI紫粉渐变"
  • 👶 儿童教育类 → 不该用深色模式
  • 🏢 企业级SaaS → 不该用夸张动画
  • 🎮 游戏类 → 不该用过于正式的字体
