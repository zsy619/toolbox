什么是 Claude Code？

Anthropic 官方推出的命令行工具，为 Claude AI 模型提供强大的编程能力

命令行工具

通过终端直接与 Claude 交互，执行复杂的编程任务，支持管道和脚本集成

智能代理

理解复杂需求，自动规划并执行多步骤编程任务，具备自我纠错能力

工具生态

内置文件操作、Git 命令、网络搜索等丰富工具，支持 MCP 扩展协议

安全可控

多层安全机制，操作确认系统，危险命令拦截，完整的操作审计日志

Security & Safety

安全机制

Claude Code 如何在执行操作的同时保障系统安全

操作确认

敏感操作需要用户授权

对于敏感操作（如删除文件、执行破坏性命令），Claude Code 会请求用户确认。

// 敏感操作需要确认 Action: Bash Confirm: 即将执行 rm -rf node_modules 等待用户输入 y/n

危险命令拦截

自动识别并阻止危险操作

自动识别并阻止潜在的危险操作，如格式化磁盘、删除系统文件等。

// 自动拦截危险命令 BlockedCommandError: "rm -rf /" 被安全系统拦截

操作审计

完整的操作记录和追踪

记录所有执行的操作，便于事后审查和问题排查。

// 操作日志 [2024-01-15 10:23:45] Read("./src/index.ts") [2024-01-15 10:23:47] Edit("line 15-20")

权限控制

细粒度的操作权限管理

支持配置允许和禁止的命令列表，细粒度控制 AI 的操作范围。

// .claude/settings.json { "allowedCommands": ["git", "npm"], "deniedCommands": ["rm -rf"] }
