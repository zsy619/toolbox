# 多平台发布指南

## 视频号

### 基础参数
- 分辨率：1080×1920（竖屏）
- 帧率：60fps
- 时长：50秒（建议30-60秒）
- 文件大小：≤50MB
- 编码：H.264

### 标题规范
- 字数：8-20字
- 风格：吸引眼球、有悬念
- 示例：让AI帮你做PPT！24套主题随便换，再也不返工

### 描述规范
- 前50字要抓人
- 添加2-3个相关话题
- 示例话题：#AI工具 #PPT制作 #效率神器

### 发布时间
- 最佳时段：12:00-13:00、20:00-22:00
- 周末效果通常优于工作日

## 小红书

### 基础参数
- 分辨率：1080×1920（竖屏）
- 帧率：60fps
- 时长：50秒内
- 文件格式：MP4

### 标题规范
- 字数：8-20字
- 必须带emoji
- 风格：年轻化、有冲击力
- 示例：让AI帮你做PPT！24套主题随便换，再也不返工 🙌

### 正文规范
- 字数：100-500字
- 干货+情绪结合
- 标签：不少于5个相关话题

### 标签推荐
`#AI工具 #PPT制作 #效率神器 #AI效率工具 #办公自动化 #程序员兼职 #副业`

### 发布时间
- 最佳时段：18:00-21:00
- 周末全天皆可

## 抖音/快手

### 基础参数
- 分辨率：1080×1920（竖屏）
- 帧率：60fps
- 时长：15秒-3分钟
- 文件格式：MP4

### 标题规范
- 字数：8-30字
- 前3秒必须抓人
- 风格：快节奏、有冲击

### 描述规范
- 添加相关话题
- 引导互动（评论、点赞）

### 发布时间
- 最佳时段：12:00-14:00、18:00-20:00

## 发布前检查清单

### 内容检查
- [ ] 视频画质清晰，无抖动

- [ ] 封面图吸引眼球
- [ ] 标题符合平台规范

### 技术检查
- [ ] 分辨率正确（1080×1920）
- [ ] 帧率为60fps
- [ ] 文件格式为MP4
- [ ] 文件大小在限制内

### 平台检查
- [ ] 标题字数符合要求
- [ ] 添加了相关话题
- [ ] 描述引导互动
