# html-ppt-skill：让AI自己设计PPT的智能技能

# 开头（Hook）

PPT这件事，大多数人还在用错误的方式做。

用PowerPoint、Keynote点来点去，改一个主题全部返工，换个字体整个样式崩掉——做完还长得像2010年企业汇报。

有人做了一个AI Agent技能，直接解决这个问题。

# 引出问题

为什么我们做PPT总是这么痛苦？

根本原因在于：**传统PPT工具是为设计师设计的，不是为内容创作者设计的。**

当我们需要专注内容本身时，却要把大量精力花在：
- 调整字体和配色
- 统一页面风格
- 逐页添加动画
- 处理格式兼容

这些机械重复的工作，AI其实可以做得更好。

# 解决方案

html-ppt-skill是一套专门给AI Agent调用的HTML幻灯片生成系统。

它的核心思路很简单：**把PPT制作变成网页开发，让AI来写代码。**

你只需要描述需求，AI自动完成主题选择、布局设计、内容填充、动画添加，最终输出一个完整的HTML幻灯片文件。

# 功能介绍

**24套精美主题**
覆盖商务、科技、创意、学术等多种风格，一键切换无需返工。

**31种布局选择**
从封面、目录、内容到结尾，每种场景都有专业布局支撑。

**20+动画效果**
打字机、渐入、滑动、缩放……声明式配置，无需逐页设置。

**纯HTML实现**
浏览器直接打开，跨平台零障碍，分享和嵌入都极其方便。

**AI原生集成**
专为AI Agent设计，支持Claude Code、OpenClaw等主流AI助手。
