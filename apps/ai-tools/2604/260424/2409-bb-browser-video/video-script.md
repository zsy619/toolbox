## 配音脚本

> 今天介绍一个超强的工具：bb-browser。
>
> 你的浏览器就是 API。不需要 key，不需要爬虫，AI 直接用你的登录状态访问任何网站。
>
> 传统方式有问题：Playwright 是 Headless 浏览器，没有登录状态；爬虫容易被检测；99% 的网站根本没有 API。
>
> bb-browser 的创新是：让机器直接使用人类的界面。Adapter 在你的浏览器标签页内运行，使用你的 cookies。网站以为是你在操作，因为确实是你。
>
> 103 个命令，覆盖 36 个平台。Twitter、Reddit、GitHub、YouTube、知乎、雪球，全部支持！
>
> 还支持 MCP，Claude Code 和 Cursor 直接调用。
>
> 一行命令安装：npm install -g bb-browser
>
> GitHub 搜索 bb-browser，4740 Stars，MIT 开源！
