## 内容摘要

**bb-browser** 是 BadBoy Browser，用你的浏览器作为 API。

### 核心卖点

- **你的浏览器就是 API** - 不需要 key，不需要爬虫
- **103 个命令，36 个平台** - Twitter、Reddit、YouTube、知乎、GitHub 等
- **MCP 支持** - Claude Code / Cursor 直接调用
- **OpenClaw 集成** - 无需扩展

### 支持的平台

| 类别 | 平台 |
|------|------|
| 搜索 | Google, Baidu, Bing, DuckDuckGo |
| 社交 | Twitter/X, Reddit, Weibo, 小红书, 微博 |
| 开发者 | GitHub, StackOverflow, HackerNews |
| 视频 | YouTube, Bilibili |
| 金融 | 雪球、东方财富、Yahoo Finance |
| 知识 | Wikipedia, 知乎, Open Library |
