# M-Flow 中国团队开发的 AI 认知记忆引擎

> 「真正的 Agent 记忆，不是搜索引擎，而是要像人一样从联想中获得启发」

## 为什么火

M-Flow 最近在海外开发者社区讨论度飙升，GitHub Stars 瞬间破千。

它解决了一个所有人都在做、但所有人都做得不够好的问题：**Agent Memory**。

## 锥形图谱结构

| 层级 | 说明 |
|------|------|
| **Episode** | 完整的语义焦点——情景 |
| **Facet** | 把事件拆成若干截面——切面 |
| **FacetPoint** | 最小颗粒的原子事实 |
| **Entity** | 实体锚线，串起所有层级 |

## Benchmark 成绩

| 榜单 | 成绩 |
|------|------|
| LoCoMo | 第一 |
| LongMemEval | 第一 |
| EvolvingEvents | 第一 |
| 竞品对比 | 超越 Mem0、Zep、Graphiti |

## 核心理念：搜索 ≠ 联想

| | 搜索 | 联想 |
|---|---|---|
| 问题 | 哪段最像？ | 该想起什么？ |
| 结果 | 最相似的片段 | 最该想起来的情景 |
| 本质 | 从库里捞 | 顺着关系走 |

**M-Flow 赌的不是"搜得更准"，是"想得更对"。**
