## 内容摘要

**M-Flow** 是中国19岁团队开发的认知记忆引擎，被称为 Graph RAG 新范式。

### 核心创新

**Cone Graph（锥形图谱）分层结构**：
- Episode（情景）—— 完整的语义焦点
- Facet（切面）—— 把事件拆成若干截面
- FacetPoint（切面点）—— 最小颗粒的原子事实
- Entity（实体）—— 人、项目、地点，一条锚线串起所有层级

### Benchmark 成绩

四个主流榜单全部第一：
- LoCoMo
- LongMemEval
- EvolvingEvents
- 超越 Mem0、Zep、Graphiti、Cognee、Supermemory

### 核心理念

**搜索 ≠ 联想**
- 搜索给你最相似的片段
- 联想给你最该被想起来的情景

**M-Flow 实现的是全新的记忆维度**：不把记忆看成一堆平铺的文本，而是看成一个有结构的关联空间。
