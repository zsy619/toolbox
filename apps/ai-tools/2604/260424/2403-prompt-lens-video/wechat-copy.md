# 做AI视频的必备利器，反向解析提示词！

> 「做 AI 视频还在为写提示词发愁吗？」

## 你是否也有这样的困扰？

- 🤔 不知道如何描述视频画面
- 😓 视频台词要手动听写
- 💭 提示词写不准，效果差
- 📉 模仿优秀作品却不知道该怎么入手

## 解决方案：PromptLens

**PromptLens** 只需要丢进去一段视频：

1. 📹 **AI 自动抽关键帧**
2. 🖼️ **分析画面内容**
3. ✍️ **生成完整提示词**
4. 📝 **台词旁白提取成文本**

## 核心功能

| 功能 | 说明 |
|------|------|
| 📹 视频分析 | 上传视频，AI 自动提取关键帧并分析 |
| 🖼️ 图片分析 | 支持单图或多图批量分析 |
| 📝 台词提取 | 视频里的台词、旁白直接提取成文本 |
| 🤖 多 API | 智谱AI、Gemini、OpenRouter |

## 技术栈

| 分类 | 技术 |
|------|------|
| 前端 | Next.js 15, React 19 |
| UI | Tailwind CSS, shadcn/ui |
| 视频处理 | FFmpeg |
| AI | 智谱AI / Gemini / OpenRouter |

## 一行命令安装

```bash
git clone https://github.com/raojiacui/prompt-lens.git
cd prompt-lens
pnpm install
pnpm dev
```
