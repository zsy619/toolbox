## 长文案（落地页）

### 标题

做 AI 视频的必备利器，反向解析提示词

### 副标题

PromptLens - 丢视频，得提示词

### 核心亮点

- **反向解析** - 丢进去一段视频，AI 自动生成完整提示词
- **关键帧提取** - AI 自动抽关键帧，分析画面内容
- **台词提取** - 视频里的台词、旁白直接提取成文本
- **多 API 支持** - 智谱AI、Gemini、OpenRouter
- **MIT 开源** - 完全免费，社区活跃

### 功能介绍

**📹 视频分析**
上传视频，AI 自动提取关键帧并分析，生成完整提示词

**🖼️ 图片分析**
支持单图或多图批量分析

**📝 台词提取**
视频里的台词、旁白都能直接提取成文本

**🤖 多 API 支持**
智谱AI、Google Gemini、OpenRouter

### 技术栈

- Next.js 15 + React 19
- Tailwind CSS + shadcn/ui
- FFmpeg 视频处理
- Supabase PostgreSQL
