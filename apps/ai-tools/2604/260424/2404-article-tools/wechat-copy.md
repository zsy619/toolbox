# 写作5分钟，排版1秒搞定！这套浏览器端排版神器太香了

> 「做内容创作，最费时间的不是写文章，而是排版。」

## 问题痛点

很多内容创作者每天都在重复一个痛苦循环：

| 步骤 | 耗时 |
|------|------|
| 写文章 | 5-10 分钟 |
| 排版调整 | 30-60 分钟 |
| 复制到各平台 | 10-20 分钟 |

## 四个工具，覆盖内容发布全部场景

| 工具 | 功能 |
|------|------|
| 🎨 封面生成器 | 多种配色、装饰风格、字体，支持导出 PNG |
| 📱 二维码生成器 | 带 Logo 二维码，自定义颜色尺寸 |
| 📝 Markdown → 公众号 | 左边粘贴 MD，右边实时预览，一键复制 |
| 🐦 Markdown → X | 自动处理换行、emoji、话题标签 |

## 零安装、零门槛

- ✅ 零安装：直接用浏览器打开 HTML 文件即可
- ✅ 不联网：文件在本地浏览器执行，不上传数据
- ✅ 不注册：不用登录
- ✅ 完全免费：开源项目，MIT 协议

## 完整工作流

**Step 1：用 Markdown 写文章**

**Step 2：一键排版**
- 用封面生成器做封面图
- 用 Markdown 转公众号排版工具生成富文本
- 用 Markdown 转 X 排版工具生成推文

**Step 3：发布**

三个步骤，写作 5 分钟，排版 1 秒搞定！
