这个工具是什么

Browser Harness 是最简单的、最薄的、self-healing 的 harness，让 LLM 能够完全自由地完成任何浏览器任务。

直接建立在 CDP (Chrome DevTools Protocol) 上。Agent 在任务中途发现缺什么函数，直接自己写进去。

Self-healing 原理

  ● agent: wants to upload a file
  │
  ● helpers.py → upload_file() missing
  │
  ● agent edits the harness and writes it
  │   helpers.py   192 → 199 lines
  │                   + upload_file()
  ✓ file uploaded

Agent 在任务中途发现缺少某个函数，它会直接动手写进去，然后继续执行。这就是真正的 self-healing。

极简架构

整个项目只有 592 行 Python 代码：

  • run.py (~36 lines) — 运行预加载 helper 的 Python
  • helpers.py (~195 lines) — 起始工具调用，agent 会编辑这些
  • admin.py + daemon.py (~361 lines) — CDP websocket 和 socket bridge

CDP 直连

直接建立在 Chrome DevTools Protocol 上，一个 WebSocket 连 Chrome，中间什么都不夹。

无框架、无配方、无护栏。
