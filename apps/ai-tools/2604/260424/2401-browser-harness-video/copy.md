### 公众号版本
> 你以后再也不用自己操作浏览器了。
>
> **今天推荐的这款工具，重新定义了 AI 浏览器交互。**
>
> ### Browser Harness
>
> 最简单的、最薄的、self-healing 的 harness，让 LLM 能够完全自由地完成任何浏览器任务。直接建立在 CDP (Chrome DevTools Protocol) 上。

> **核心特性：**
>
> - **Self-healing**：Agent mid-task 发现缺什么函数，直接自己写进去
> - **极简架构**：只有 592 行 Python 代码
> - **CDP 直连**：一个 WebSocket 连 Chrome，中间什么都不夹
> - **Domain Skills**：可扩展的领域技能系统
>
> **免费远程浏览器：**
>
> - 3 个并发浏览器
> - 代理支持
> - Captcha 解决
> - 完全免费
>
> **安装方式：**
>
> GitHub 搜索 browser-use/browser-harness
> 或复制 setup prompt 到 Claude Code
