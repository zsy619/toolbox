传统 AI 浏览器工具，框架臃肿，动不动就失败。Browser Harness 不一样。

核心亮点

Browser Harness 是最简单的、self-healing 的 harness，让 LLM 能够完全自由地完成任何浏览器任务。

Self-healing 原理

Agent 说要上传文件
→ helpers.py 缺 upload_file 函数
→ Agent 直接动手写进去
→ 继续执行
→ ✓ 文件上传成功
