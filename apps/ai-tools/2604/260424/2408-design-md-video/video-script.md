## 场景列表

### 场景 1：开场（0-5秒）

- **视觉**：深色背景 + 粒子动画 + 主标题居中
- **标题**：design.md
- **副标题**：Design Tokens 的双层结构革命
- **动画**：渐入 + 发光效果

### 场景 2：问题引出（5-12秒）

- **视觉**：深色背景 + 问题列表
- **标题**：传统 Design Token 的问题
- **内容**：
  - 只有数值，没有上下文
  - AI 容易"猜错"品牌色
  - 设计意图无法传递
- **动画**：逐条滑入

### 场景 3：解决方案 - 双层结构（12-22秒）

- **视觉**：两栏对比布局
- **标题**：design.md 的双层结构
- **内容**：
  - 左：YAML Front Matter（机器可读）
  - 右：Markdown Body（人类可读）
- **动画**：左右对比展开

### 场景 4：YAML Front Matter（22-30秒）

- **视觉**：代码块展示
- **标题**：YAML Front Matter
- **内容**：
  - colors：语义化命名
  - typography：字体、字号、字重
  - rounded / spacing：圆角与间距
  - components：组件级 token

### 场景 5：Markdown 8章节（30-38秒）

- **视觉**：章节列表
- **标题**：Markdown Body 8章节
- **内容**：
  - Overview / Colors / Typography
  - Layout / Elevation & Depth
  - Shapes / Components
  - Do's and Don'ts

### 场景 6：CLI 工具链（38-45秒）

- **视觉**：工具列表
- **标题**：CLI 工具链
- **内容**：
  - lint：结构校验 + WCAG 检测
  - diff：版本对比
  - export：Tailwind / W3C 导出
  - spec：规范原文输出

### 场景 7：结尾（45-50秒）

- **视觉**：深色背景 + 最终标题
- **标题**：让 AI 真正理解设计意图
- **副标题**：github.com/google-labs-co/design.md
- **动画**：渐入 + 发光

## 配音脚本

> 设计系统中的 Design Token，你真的用对了吗？
>
> 传统格式只有冷冰冰的数值，AI 容易猜错品牌色，设计意图无法传递。
>
> Google Labs 推出了 design.md，用双层结构解决这个问题。
>
> 第一层：YAML Front Matter，定义精确的 token。颜色、字体、圆角、间距，全部精确数值。
>
> 第二层：Markdown Body，用自然语言解释为什么这样设计。
>
> 正文分为 8 个章节：Overview、Colors、Typography、Layout、Elevation、Shapes、Components、Do's and Don'ts。
>
> 还有强大的 CLI 工具链。lint 校验结构，diff 对比版本，export 导出 Tailwind 或 W3C 格式。
>
> token 是规范数值，prose 解释为什么和如何应用。两者结合，让 AI 既能获取精确值，又能理解设计意图。
>
> GitHub 搜索 design.md，让 AI 真正理解你的设计！
