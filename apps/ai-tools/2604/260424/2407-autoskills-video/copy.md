## 长文案版本

### 标题
autoskills：一个命令配齐整个 AI Skill 栈的神器

### 正文
在 AI 开发时代，我们经常需要为项目安装各种 AI Skills。但手动安装费时费力，还容易踩坑。

**autoskills** 完美解决了这个问题。

### 核心功能

**自动检测技术栈**
autoskills 会扫描你的项目，自动识别使用的技术栈：React、Next.js、Vue、Tailwind、Prisma、tRPC 等等。

**自动安装 Skills**
根据检测结果，autoskills 会推荐并安装匹配的 AI Skills。无需手动搜索，一键搞定。

**人工精选，安全可靠**
所有 Skill 都经过人工审核，没有安全隐患。可以放心使用。

**支持 Monorepo**
完美支持 monorepo 项目结构，自动定位每个包。

### 支持的技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React, Next.js, Vue, Nuxt, Svelte |
| CSS框架 | Tailwind, CSS Modules |
| 数据库 | Prisma, Drizzle |
| 认证 | Auth.js, Clerk |
| API | tRPC, GraphQL |

### 使用方式

一行命令：

```bash
npx autoskills
```
