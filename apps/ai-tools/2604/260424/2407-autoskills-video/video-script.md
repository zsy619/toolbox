## 场景列表

### 场景 1：开场（0-5秒）

- **视觉**：深色背景 + 粒子动画 + 主标题居中
- **标题**：autoskills
- **副标题**：一键配齐 AI Skill 栈
- **动画**：渐入 + 发光效果

### 场景 2：痛点引出（5-10秒）

- **视觉**：深色背景 + 问题列表
- **标题**：手动安装 Skill 的烦恼
- **内容**：
  - 不知道需要哪些 Skills
  - 一个个搜索太麻烦
  - 担心来源不安全
- **动画**：逐条滑入

### 场景 3：解决方案（10-20秒）

- **视觉**：命令行界面演示
- **标题**：autoskills 一键搞定
- **内容**：
  - 自动扫描技术栈
  - 自动安装匹配 Skills
  - 人工精选，安全可靠

### 场景 4：功能展示（20-30秒）

- **视觉**：技术栈图标 + Skill 列表
- **标题**：支持的主流技术栈
- **内容**：
  - React / Next.js / Vue
  - Tailwind / Prisma
  - tRPC / Auth.js

### 场景 5：monorepo 支持（30-35秒）

- **视觉**：monorepo 目录结构
- **标题**：完美支持 Monorepo
- **内容**：
  - Nx / Turborepo / Rush
  - 精准定位每个包

### 场景 6：结尾（35-45秒）

- **视觉**：深色背景 + 最终标题
- **标题**：一个命令，配齐整个 AI Skill 栈
- **副标题**：npx autoskills
- **动画**：渐入 + 发光
