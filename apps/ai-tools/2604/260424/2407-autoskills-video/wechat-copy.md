# 一个命令配齐AI Skill栈！autoskills太神了

> 「还在手动一个个安装 AI Skills？」

## 问题痛点

手动安装 Skill 的烦恼：

| 问题 | 影响 |
|------|------|
| 不知道需要哪些 Skills | 无从下手 |
| 一个个搜索太麻烦 | 浪费时间 |
| 担心来源不安全 | 安全风险 |

## 解决方案：autoskills

**一个命令，自动搞定！**

```bash
npx autoskills
```

## 核心功能

### 🔍 自动扫描技术栈
- 扫描 package.json 和配置文件
- 识别 React、Next.js、Tailwind、Prisma 等
- 覆盖主流技术栈

### ⚡ 自动安装 Skills
- 根据检测结果推荐 Skills
- 一键安装，无需手动搜索
- 版本兼容，自动处理

### 🛡️ 人工精选
- 所有 Skill 经过人工审核
- 无安全隐患
- 安全可靠

### 📦 支持 Monorepo
- 支持 Nx、Turborepo、Rush
- 精准定位每个包

## 支持的技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React, Next.js, Vue, Nuxt, Svelte |
| CSS框架 | Tailwind, CSS Modules, Styled Components |
| 数据库 | Prisma, Drizzle, MongoDB |
| 认证 | Auth.js, NextAuth, Clerk |
| 部署 | Vercel, Netlify, Cloudflare |
| API | tRPC, GraphQL, REST |

## 使用方式

```bash
# 一键安装
npx autoskills

# monorepo 项目
cd packages/my-app
npx autoskills
```
