## 内容摘要

**autoskills** 是一个命令行工具，一键扫描项目技术栈，自动安装匹配的 AI Skills。

### 核心卖点

1. **一键扫描**：自动检测项目使用的技术栈
2. **自动安装**：根据检测结果自动安装匹配的 Skills
3. **人工精选**：所有 Skill 都经过人工审核，安全可靠
4. **支持 monorepo**：完美支持 monorepo 项目结构

### 使用示例

```
npx autoskills
```

检测到 React、Next.js、Tailwind、Prisma？自动安装对应 Skill。
