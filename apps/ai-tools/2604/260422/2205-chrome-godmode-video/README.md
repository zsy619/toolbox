## 核心内容

### 什么是 Chrome 上帝模式

Chrome解锁隐藏功能，原生集成Gemini+垂直标签+技能商店，直接降维打击！

### 四大隐藏功能

1. **垂直标签** - Arc同款侧边栏，效率翻倍
2. **技能商店** - 官方内置AI技能库
3. **Gemini侧边栏** - 实时读取页面，跨标签对比
4. **深度整合** - 免费的AI员工

### 开启步骤

1. `chrome://flags`
2. 搜索 "vertical" → Enabled
3. 搜索 "skills" → Enabled
4. `chrome://skills/browse`
5. 点击 "Ask Gemini"
