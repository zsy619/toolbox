## 视频内容

### rsync 核心参数

1. **rsync -avz source dest** - 基本用法
2. **a** - 保留所有权限和时间
3. **v** - 显示详细信息
4. **z** - 压缩传输

### 隐藏技巧

- **--delete** - 目标端多余文件会被删除
- **--exclude** - 排除特定文件
- **-P** - 显示进度
