## 长文案

### rsync - 让备份速度快10倍

**一句话介绍**

rsync 是一个快速且通用的文件同步工具，可以让备份速度提升10倍。

**核心参数**

1. **-a** 保留所有权限和时间
2. **-v** 显示详细信息
3. **-z** 压缩传输

**高级参数**

- **--delete** 目标端多余文件会被删除
- **--exclude** 排除特定文件
- **-P** 显示进度

**常用命令**

```bash
# 基本同步
rsync -avz source/ dest/

# 带删除同步
rsync -avz --delete source/ dest/

# 排除特定文件
rsync -avz --exclude='*.log' source/ dest/

# 显示进度
rsync -avzP source/ dest/
```
