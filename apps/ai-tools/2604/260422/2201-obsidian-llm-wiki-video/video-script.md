| 属性 | 值 |
|------|-----|

| 时长 | 55秒 |

## 分镜脚本

### 场景 1：开场 Hook (0-5秒)

**视觉**：深色背景，Karpathy 风格图示 + Obsidian 图标

**文字**：
- 主标题：「让你的 AI 成为知识管家」
- 副标题：「Obsidian LLM Wiki」

**配音**：你知道吗？LLM 每次回答问题都在重复同样的工作。

### 场景 2：RAG 问题揭示 (5-10秒)

**视觉**：显示 RAG 检索流程图

**文字**：「传统 RAG：每次查询，重新检索，重新推导」

**配音**：传统 RAG 方式，每次查询都要从零开始检索，没有知识积累。

### 场景 3：LLM Wiki 解决方案 (10-18秒)

**视觉**：三层架构图

**文字**：
- 「raw 层：原始资料，只读」
- 「wiki 层：LLM 生成，持久化」
- 「schema 层：配置层，CLAUDE.md」

**配音**：LLM Wiki 的做法不同，LLM 持续构建和维护一个持久化的 wiki，知识编译一次，然后保持最新。

### 场景 4：Obsidian 集成 (18-25秒)

**视觉**：Obsidian 界面截图风格

**文字**：「Obsidian 是 IDE，LLM 是程序员，wiki 是代码库」

**配音**：Obsidian 是这个方案的理想前端，LLM 写 wiki，你在 Obsidian 里实时浏览。

### 场景 5：核心命令 (25-35秒)

**视觉**：命令列表展示

**文字**：
- 「ingest：新资料集成」
- 「query：知识问答」
- 「lint：健康检查」
- 「migrate：迁移笔记」

**配音**：`/obsidian-llm-wiki ingest` 处理新资料，`query` 回答问题，`lint` 检查健康，`migrate` 迁移旧笔记。

### 场景 6：限制与守则 (35-42秒)

**视觉**：规则列表

**文字**：
- 「raw 层只读不变」
- 「覆盖前确认」
- 「日志 append-only」

**配音**：规则很简单，raw 层只读，覆盖前确认，日志只追加不删除。

### 场景 7：安装使用 (42-48秒)

**视觉**：终端命令

**文字**：`/obsidian-llm-wiki` 启动

**配音**：在 Claude Code 里输入斜杠命令，一键启动初始化向导。

### 场景 8：结尾 CTA (48-55秒)

**视觉**：渐变背景，GitHub 链接

**文字**：
- 主标题：「Obsidian LLM Wiki」
- 副标题：「github.com/Lesterffx/obsidian-llm-wiki」

**配音**：去 GitHub 搜索 Lesterffx/obsidian-llm-wiki，一键安装，我是你的 AI 工具猎手，下期见。
