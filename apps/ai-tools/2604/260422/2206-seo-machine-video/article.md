## 推文内容

SEO Machine 这个项目有点牛逼啊，吊打市面上一堆 AI 写文工具，感觉 Semrush 的钱也可以省了！

它不是单模型调用，而是整个 workspace + 多 agents + 真实数据接入（GA4 + Search Console）。

我最喜欢的是它强制你喂上下文（brand voice、写作示例），不然效果就一般——这反而是优点，逼你把品牌调性固化下来。

当然，没有 Claude Code + API key 等于白搭，配置初期要花点时间。

## 核心卖点

1. **吊打市面AI写文工具** - 可以替代 Semrush
2. **Workspace + 多 Agents** - 不是单模型调用
3. **真实数据接入** - GA4 + Search Console
4. **强制喂上下文** - brand voice + 写作示例
5. **品牌调性固化** - 逼你把品牌固化下来

## 技术要求

- 需要 Claude Code + API key
- 配置初期要花点时间
