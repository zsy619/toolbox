| 项目 | 值 |
|------|-----|
| 名称 | ghostty-config-video |
| 来源 | GitHub - zerebos/ghostty-config |
| 链接 | https://github.com/zerebos/ghostty-config |

| 风格 | tech-modern (青色系) |
| 时长 | 约45秒 |

## 核心卖点

1. **可视化配置编辑** - 字体、颜色、光标、透明度实时调整
2. **实时预览** - 所见即所得的配置预览
3. **一键导出** - 生成可用的 Ghostty 配置文件
