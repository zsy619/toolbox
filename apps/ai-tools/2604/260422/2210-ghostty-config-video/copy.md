## 长文案（落地页）

### Ghostty Config - 漂亮的终端配置生成器

**痛点**

手动编辑文本文件，担心格式和语法错误？

配置 Ghostty 终端太麻烦了？

**解决方案**

Ghostty Config 是一个漂亮的基于 Web 的配置生成器，
让自定义 Ghostty 终端变得轻松简单。

**核心功能：**

1. **交互式设置编辑器** - 轻松调整字体、颜色、光标样式、透明度、模糊等
2. **字体游乐场** - 实验 JetBrains Mono、Nerd Fonts 或任何自定义字体
3. **实时预览** - 即时查看光标、选择、应用图标和调色板的演示
4. **一键导出** - 生成干净的 Ghostty 配置文件

**技术栈：**
Bun + Svelte + TypeScript + Vite + GitHub Actions
