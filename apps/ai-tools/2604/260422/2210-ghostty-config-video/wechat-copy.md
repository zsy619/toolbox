# Ghostty Config：让终端配置变得轻松简单！

> 「还在为手动编辑 Ghostty 配置文件烦恼吗？」

## 解决方案

**Ghostty Config** 一个漂亮的 Web 配置生成器，让自定义 Ghostty 终端变得轻松简单！

## 核心功能

| 功能 | 说明 |
|------|------|
| 🎨 可视化配置编辑器 | 轻松调整字体、颜色、光标样式、透明度、模糊等 |
| 👀 实时预览 | 所见即所得，即时查看效果 |
| 🔤 字体游乐场 | 实验 JetBrains Mono、Nerd Fonts 或自定义字体 |
| 📤 一键导出 | 生成干净的 Ghostty 配置文件 |

## 技术栈

| 分类 | 技术 |
|------|------|
| 运行时 | Bun |
| 前端框架 | Svelte |
| 语言 | TypeScript |
| 构建工具 | Vite |
| 部署 | GitHub Actions |
