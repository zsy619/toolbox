# dot-skill 视频项目

## 原始内容

**来源**: GitHubDaily (@GitHub_Daily)
**链接**: https://x.com/GitHub_Daily/status/2045857489745551732

## 推文内容

在 GitHub 上发现一个能把任何人蒸馏成 Skill 的开源项目：dot-skill，狂拦了 15000+ Star。

只要提供目标人物的聊天记录、文档或公开资料，就能提取出一个拥有对方思考方式的 AI 技能。

不仅限于表面模仿语气，更是深度复刻对方的思维框架、决策习惯甚至情绪反应。

针对工作同事、亲密关系和公众人物，分别内置了三套完全不同的提取逻辑。

能帮我们轻松打造一个懂业务的赛博同事，或者一个能提供情绪价值的赛博老友。

支持接入各种主流 Agent 环境，直接输入一条指令就能自动完成安装。

能对接飞书、钉钉自动拉取工作文档，也支持导入本地微信聊天记录，数据都在自己手里。

支持在 Claude Code、Hermes Agent、OpenClaw 等平台使用。

## 核心卖点

1. **15000+ GitHub Stars** - 热门开源项目
2. **蒸馏任何人** - 聊天记录、文档、公开资料
3. **深度复刻** - 思维框架、决策习惯、情绪反应
4. **三类场景** - 工作同事、亲密关系、公众人物
5. **多平台支持** - Claude Code、Hermes Agent、OpenClaw
6. **数据安全** - 本地处理，数据在自己手里

## 技术特点

- 支持飞书、钉钉、微信数据导入
- 一句话安装
- 多 Agent 环境兼容
