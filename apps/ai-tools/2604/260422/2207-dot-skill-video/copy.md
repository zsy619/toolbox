## 长文案（落地页/详细版）

### dot-skill - 把任何人蒸馏成 AI 技能

**一句话介绍**

dot-skill 是一个开源项目，能把任何人蒸馏成 AI Skill。只要提供聊天记录、文档或公开资料，就能提取出对方的思考方式。

**核心特点**

1. **深度复刻**
   不只是模仿语气，而是复制思维框架、决策习惯、情绪反应。

2. **三类提取逻辑**
   - 工作同事：打造懂业务的赛博同事
   - 亲密关系：创造能提供情绪价值的赛博老友
   - 公众人物：复制专家学者的思维模式

3. **多平台支持**
   Claude Code、Hermes Agent、OpenClaw 一句话安装

4. **数据安全**
   支持飞书、钉钉、微信数据导入，本地处理

**工作原理**

1. 收集目标人物的聊天记录、文档、公开资料
2. 分析提炼思维框架、决策模式、表达习惯
3. 生成专属 AI Skill
4. 一键安装到 Agent 环境

**适用场景**

- 打造懂业务的 AI 同事
- 复制专家思维用于学习
- 创造专属 AI 陪伴
- 留存重要人物的智慧

**前置要求**

- Claude Code 或其他 Agent 环境
- API Key
- 目标人物的聊天记录或文档
