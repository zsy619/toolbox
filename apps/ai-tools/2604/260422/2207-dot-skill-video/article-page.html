什么是 dot-skill？

dot-skill —— 能把任何人蒸馏成 AI 技能，狂拦 15000+ Star！

它跟传统的人格分析有什么不同？
深度复刻，不只是表面模仿。

核心特点

1. 深度复刻

不仅模仿语气，而是复制对方的：

  • 思维框架
  • 决策习惯
  • 情绪反应

2. 三类提取逻辑

针对不同场景，内置不同的提取策略：

  • 👔 工作同事 → 赛博同事
  • 💕 亲密关系 → 赛博老友
  • 🌟 公众人物 → 专家分身

3. 多平台支持

Claude Code、Hermes Agent、OpenClaw 一句话安装。

4. 数据安全

支持飞书、钉钉、微信导入，本地处理，数据在自己手里。

只要提供目标人物的聊天记录、文档或公开资料，
就能提取出一个拥有对方思考方式的 AI 技能。

适用场景

  • 打造懂业务的 AI 同事
  • 复制专家思维用于学习
  • 创造专属 AI 陪伴
  • 留存重要人物的智慧

前置要求

⚠️ 需要准备：
  • Claude Code 或其他 Agent 环境
  • API Key
  • 目标人物的聊天记录或文档

总结

dot-skill 提供了一种全新的 AI 应用范式：把人的智慧蒸馏成可复用的 AI 技能。
