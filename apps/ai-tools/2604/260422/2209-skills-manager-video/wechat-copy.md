# 志辉开源了一个Skills管理工具，打磨了两周！

> 「解决了我自己平时的痛点，现在基本自己一边用一边开发」

## 六大核心功能

| 功能 | 说明 |
|------|------|
| 🌍 全局管理 | ~/.agents/skills 全局管理 |
| ⚡ 一键安装 | 安装 GitHub 上的 skills 仓库 |
| 💻 项目级管理 | 电脑全局项目 skills 管理 |
| 🏪 Skills 市场 | 官方和最佳推荐 |
| 🔌 多平台支持 | 各 大 Coding Agent、OpenClaw、Hermes |
| 🤖 AI 解释 | 支持 AI 解释 skills |
