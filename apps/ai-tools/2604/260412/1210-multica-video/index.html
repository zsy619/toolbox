下一个招聘的 10 个人可能不是人类。

Multica：开源 Agent 管理平台，把编码 Agent 变成真正的同事。

像分配任务给同事一样分配工作给 Agent，他们会自动捡起任务、写代码、报告阻塞、更新状态。

不再需要复制粘贴提示词，不再需要盯着运行。

你的 Agent 会出现在看板、参与讨论、随着时间推移复合可复用的技能。

把它想象成开源的基础设施，用于管理 Agent——供应商中立、自托管、为人机团队设计。

支持 Claude Code、Codex、OpenClaw 和 OpenCode。

开源免费。

目标受众

适合使用 Multica 的人群和使用场景

开发者

希望将 AI Agent 集成到开发流程中，提高编码效率

技术团队

需要管理多个 AI Agent，实现团队协作和人机协作

AI 爱好者

对 AI Agent 技术感兴趣，希望探索人机协作的未来

快速开始

# 克隆仓库

git clone https://github.com/multica-ai/multica

# 安装和运行

npm install && npm run dev
