配音文案

VoxCPM2 开源了！

国产TTS太牛了！2B参数，支持30语言，48kHz studio音质。

三大核心能力：

Voice Design — 文字描述直接生成声音，不需要参考音频。

Controllable Cloning — 克隆任何声音，同时用文字控制风格、语速、情绪。

Ultimate Cloning — 完美复刻每个声音细节，音色、节奏、情感全部保留。

RTF低至0.3，支持实时流式输出。

基于MiniCPM-4语言模型基座，完全开源可商用。

完全开源可商用！

目标受众

适合使用 VoxCPM2 的人群和使用场景

内容创作者

短视频、有声书、播客配音，无需专业录音设备

企业应用

智能客服、语音助手、导航系统，降低配音成本

开发者

集成到应用中，快速实现多语言语音合成功能

快速开始

# 克隆仓库

git clone https://github.com/OpenBMB/VoxCPM

# 安装和运行

pip install voxcpm && voxcpm generate
