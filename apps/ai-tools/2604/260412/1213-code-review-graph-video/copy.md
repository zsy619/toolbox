# code-review-graph 多平台营销文案

## 小红书版本

### 标题
Claude Code 每次都重读整个代码库？这个开源工具让AI只读需要的内容 🚀

### 正文
AI 编程工具每次任务都重读整个代码库？太浪费了！

code-review-graph 用知识图谱解决这个痛点：

✅ Tree-sitter 解析代码结构，构建持久化地图
✅ MCP 协议让 AI 只读相关代码
✅ 8.2× token 节省，代码审查最高 49×

支持 Codex、Claude Code、Cursor，Windsurf 等主流工具。

19 种语言 + Jupyter notebook 支持。

完全本地存储，开源免费！
