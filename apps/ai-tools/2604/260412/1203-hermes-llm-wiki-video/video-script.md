## 配音文案 (full_narration.txt)

Karpathy 提出了一种革命性的知识管理新范式——LLM Wiki。

传统 RAG 的核心问题是"即查即忘"：每次查询都是独立的，系统不会记住之前的处理结果，无法形成真正意义上的知识积累。

而 LLM Wiki 的核心理念是：让大模型担任"知识库管理员"，主动编译、检查和维护知识库。

这个系统采用三层架构设计：

第一层是原始资料层，存储所有不可变的原始数据——论文、文档、代码、会议记录。一旦摄入，原文永久保存，确保可追溯性。

第二层是维基层，这是整个系统的核心产出。LLM 将原始资料转化为结构化的 Markdown 文档，每个文件代表一个知识单元，文件之间通过链接形成知识网络。

第三层是模式层，定义了 LLM 如何理解和处理知识。通过 CLAUDE.md 和 AGENTS.md 等配置文件，指导 LLM 的工作流程和行为规范。

LLM Wiki 定义了三大核心操作：灌入、提问和巡检。

灌入是知识的入口，将原始资料转化为结构化知识单元。

提问是知识的使用方式，基于语义理解返回精准答案。

巡检是 LLM Wiki 的独特创新，定期检查知识库的完整性和一致性。

当 Hermes Agent 与 LLM Wiki 结合时，产生了一种强大的协同效应。

Hermes 是 Nous Research 开发的自我进化 AI 代理框架，其核心创新是技能系统——从执行任务的经验中提取可复用的能力，封装为 Markdown 格式的技能文件。

llm-wiki 就是 Hermes 的一项核心技能，实现了 LLM Wiki 的完整工作流。

这种组合实现的不只是知识的自动化管理，更重要的是知识管理能力本身的持续进化。

如果你也在思考如何更好地管理个人或团队的知识资产，LLM Wiki + Hermes 的组合值得关注。
