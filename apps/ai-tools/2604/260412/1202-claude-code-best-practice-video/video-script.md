## 配音文案 (full_narration.txt)

GitHub 上有个仓库一路飙到 3.2 万 Star，叫 claude-code-best-practice。

专门整理 Claude Code 的各种使用技巧和工作流，从入门到进阶全覆盖。还拿过 GitHub Trending 日榜第一，连 Claude Code 的创造者 Boris Cherny 都在 X 上多次引用这个项目。

这个仓库最顶的地方有三个：

第一，紧跟最新 Beta 功能。收录了 Ultraplan、Claude Code Web、Auto Mode、Computer Use 等最新功能动态，还有一个无闪烁模式，能实现点击输入框定位光标位置。

第二，10+ 套开发工作流横向对比。追求质量选 Superpowers，追求效率选 Get Shit Done，想要全家桶选 Everything Claude Code，流程驱动选 Spec Kit。

第三，精选小技巧。收录了 86 条实战技巧，还有 Boris 分享的 15 条官方使用贴士。

这个仓库本身就是一个完整的 Claude Code 项目结构，.claude 目录下有现成的 agents、commands、skills 配置文件，可以直接 Clone 下来用。

核心思路就是：不用全盘接收，按需取用。

如果你正在用 Claude Code，或者准备开始用，这个仓库值得收藏。

觉得 Claude Code 用起来没啥感觉的同学，可能不是工具不行，是打开方式不对。
