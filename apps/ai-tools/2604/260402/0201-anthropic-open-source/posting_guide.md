# 多平台发布指南

## 平台规格

### 微信视频号
- **分辨率**: 1080x1920 (9:16)
- **时长**: 45秒
- **文件大小**: < 100MB
- **格式**: MP4 (H.264, AAC)

### 小红书
- **分辨率**: 1080x1920 (9:16) 或 1440x1920 (3:4)
- **时长**: 15秒-5分钟
- **文件大小**: < 300MB

### 抖音/快手
- **分辨率**: 1080x1920 (9:16)
- **时长**: 15秒-3分钟
- **文件大小**: < 200MB
