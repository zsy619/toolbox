事件回顾

Anthropic 因一次发布失误，把 Claude Code 的大部分核心源码直接暴露在了网上。

关键发现

  • 用户文件会被保存上传 - Every file viewed is saved & uploaded
  • 远程管理设置 - Settings can be modified remotely
  • 防蒸馏机制形同虚设 - Can be easily circumvented
  • 每天浪费25万次API调用 - 250K Wasted API Calls/Day

写在最后

Claude Code 代码实际上已经在网上公开 13 个月了。过去 13 个月里，这套代码被反复扒出、镜像、逆向、整理，直到这一次才真正引爆舆论。

Once code is out, it's hard to take it back.
