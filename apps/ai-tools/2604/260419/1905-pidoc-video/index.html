快速开始

1

克隆仓库

将树莓派中文文档仓库克隆到本地

2

安装依赖

运行 npm install 安装项目依赖

3

本地开发

4

构建部署

运行 npm run build 生成静态文件，npm run deploy 部署到 GitHub Pages
