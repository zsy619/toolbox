• 适合中文读者参考
• 基于Docusaurus构建
• 需要Node.js 18+环境

📦 常用脚本：
• `npm install` 安装依赖
• `npm run dev` 本地开发服务器
• `npm run build` 生成静态站点
• `npm run deploy` 部署到GitHub Pages

📁 文件结构：
• config：配置文件
• sidebars：侧边栏路由
• docs：文档内容
• static：静态资源

🤝 贡献方式：
