### 项目介绍
Raspberry Pi 官方文档的中文翻译与本地化版本，内容基于官方英文文档并做适当本地化处理，目标是为中文读者提供便捷的参考资料与示例。

### 技术特点

基于 **Docusaurus** 构建，需要 **Node.js 18** 以上环境。

安装依赖只需一行命令，然后本地开发、生成生产构建、本地预览构建，都非常简单。

### 文件结构

项目文件结构清晰：

- 配置在 docusaurus config 文件
- 侧边栏路由在 sidebars 文件
- 文档内容在 docs 目录
- 静态资源在 static 目录
