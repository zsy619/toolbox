# pidoc

树莓派中文文档，来了！

Raspberry Pi 官方文档的中文翻译与本地化版本，内容基于官方英文文档并做适当本地化处理，目标是为中文读者提供便捷的参考资料与示例。

这个项目基于 Docusaurus 构建，需要 Node.js 18 以上环境。

安装依赖只需一行命令，然后本地开发、生成生产构建、本地预览构建，都非常简单。

常用脚本包括：本地开发服务器、生成静态站点、本地预览、部署到 GitHub Pages。

项目文件结构清晰：配置在 docusaurus config 文件，侧边栏路由在 sidebars 文件，文档内容在 docs 目录，静态资源在 static 目录。

如果你要编辑或新增文档，只需修改 docs 目录下的文件，并确保格式正确。

翻译与生成器部分需要注意，program 目录下以横杠开头的页面是生成产物，修改前请查阅生成脚本。

贡献也很简单：Fork 仓库、新建分支、编辑文档、提交 PR。

如果遇到问题，可以加入项目交流群，或者在 GitHub Issues 中讨论。
