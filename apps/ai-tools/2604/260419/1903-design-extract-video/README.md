# design-extract-video - designlang 介绍视频

## 项目信息
- **源内容**: GitHub Manavarya09/design-extract
- **主题**: tech-modern (靛蓝系)
- **平台**: 视频号 / 小红书 / 抖音

## 视频规格
- 分辨率: 1080×1920（竖屏）
- 帧率: 60fps
- 时长: 41.6 秒
- 大小: 2.55MB

## 核心卖点
1. 一行命令逆向设计系统
2. 生成8个输出文件
3. 支持 Claude Code、Cursor、Codex 等40+智能体
4. 布局系统、响应式、交互状态等独特功能
