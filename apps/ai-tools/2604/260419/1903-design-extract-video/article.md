# design extract

designlang，一行命令逆向任何网站的设计系统。

它用无头浏览器爬取任何网站，从实时 DOM 提取所有计算样式，生成8个输出文件。

包括：AI 优化的降价文件、视觉 HTML 预览、Tailwind 配置、React 主题、shadcn/ui 主题、Figma 变量、W3C 设计标识符，还有 CSS 自定义属性。

但和其他工具不同的是，它还提取布局模式，捕捉4个断点的响应行为，记录交互状态，评分 WCAG 可访问性，让你比较多个品牌，或同步实时站点到本地标识符。

使用很简单，直接用 npx 运行，或者安装为 AI 编程助手的技能，支持 Claude Code、Cursor、Codex 等40多个智能体。

一行命令，生成完整设计系统。
