# multiagent ppt

GitHub 上一款多智能体协作的 PPT 生成器：MultiAgentPPT。

从选题调研到排版成稿，全流程自动化。

你只要输入一个主题，就能快速生成结构完整、内容扎实的高质量 PPT，并支持在线编辑，随改随用。

主要特性：

多智能体分工协作。大纲构建、任务拆分、资料调研、内容汇总各就各位。

流式输出。生成过程实时可见，边生成边查看结果。

外部检索加智能体协同。信息更全、内容更准、质量更稳。

在线编辑。生成即成稿，细节随时调整。

A2A 加 MCP 加 ADK 架构。工程化落地，稳定可靠。

前后端完整开源，支持 Docker 加数据库一键部署。
