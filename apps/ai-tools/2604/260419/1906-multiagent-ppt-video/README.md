## 内容概要

### 是什么
MultiAgentPPT 是一款多智能体协作的 PPT 生成器，从选题调研到排版成稿，全流程自动化。输入一个主题，就能快速生成结构完整、内容扎实的高质量 PPT。

### 核心特性
1. **多智能体分工协作** - 大纲构建、任务拆分、资料调研、内容汇总各就各位
2. **流式输出** - 生成过程实时可见，边生成边查看结果
3. **外部检索加智能体协同** - 信息更全、内容更准、质量更稳
4. **在线编辑** - 生成即成稿，细节随时调整
5. **A2A + MCP + ADK 架构** - 工程化落地，稳定可靠
6. **完整开源** - 支持 Docker + 数据库一键部署
