## 分镜脚本

### 场景 1｜开场引入（3秒）

**视觉**: 粉色渐变背景，大字「hue」出现，品牌色彩从中心扩散。

**配音文字**: hue，一个开源技能，从网址、名称或截图学习任何品牌，并将其转换为完整的设计系统。

**字幕**: 「hue」大白字居中

---

### 场景 2｜核心概念（4秒）

**视觉**: 三种输入方式图标：网址 / 名称 / 截图 → 输出设计系统。

**配音文字**: 支持Claude Code和Codex。安装一次后，你的AI助手构建的每个界面都会匹配你的品牌风格。

**字幕**: 支持：Claude Code / Codex · 一次安装 · 永久匹配

---

### 场景 3｜AI设计语言（5秒）

**视觉**: 完整设计系统图示：色彩标识 + 字体排版 + 间距 + 组件库 + 明暗模式 + 图标选择。

**配音文字**: 你获得的是完整的AI设计语言，包括：色彩标识、字体排版、间距、组件库、明暗模式、图标选择等。足够有主见，不同会话使用生成的设计技能都能产生视觉一致的输出。

**字幕**: 色彩 | 字体 | 间距 | 组件库 | 明暗模式 | 图标

---

### 场景 4｜使用方法（4秒）

**视觉**: 两步流程：克隆到本地 → 对话中描述风格。

**配音文字**: 安装方法很简单，克隆到本地，然后在对话中描述你想要的风格即可。比如，说"基于某个网站创建设计技能"，AI助手会引导你完成分析。

**字幕**: git clone · 描述风格 · AI自动分析

---

### 场景 5｜品牌案例（5秒）

**视觉**: 17个品牌案例缩略图网格展示。

**配音文字**: 项目中包含了十七个品牌案例，展示hue的输出范围。

**字幕**: 17个品牌案例

---

### 场景 6｜视觉预览（4秒）

**视觉**: 设计模型文件 + 落地页HTML浏览器预览。

**配音文字**: 每个案例都有设计模型文件和落地页_html，打开浏览器就能看到系统渲染的效果。

**字幕**: 设计模型文件 + 落地页HTML · 浏览器预览

---

### 场景 7｜收尾（4秒）

**视觉**: 全屏粉色渐变，大字「AI辅助设计领域的一个有趣突破」。

**配音文字**: 这是AI辅助设计领域的一个有趣突破。

**字幕**: 「AI辅助设计的有趣突破」大白字居中
