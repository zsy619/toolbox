Chapter 01

JVM 容器感知原理

💡 概念: JDK 11+ 自动读取 cgroup limits;MaxRAMPercentage 设置堆占比。
🎯 使用场景: 所有 Java 应用容器化。
💻 代码示例: bash
docker run -d --memory=512m myapp-java
CMD java -XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0 -jar app.jar
⚠️ 注意事项: 不设 MaxRAMPercentage = JVM 默认 25% 堆。

💡 概念: Eclipse Temurin/Amazon Corretto/BellSoft Liberica/Alibaba Dragonwell。
🎯 使用场景: Java 应用基础镜像选型。
💻 代码示例: bash
docker pull eclipse-temurin:21-jre-alpine
docker pull amazoncorretto:21-alpine
docker pull dragonwell8:21-alpine
⚠️ 注意事项: Corretto 含 AWS 优化;Dragonwell 适合国产化。
Chapter 03

多阶段构建 Maven + JRE

💡 概念: builder maven,runner temurin:21-jre-alpine。
🎯 使用场景: Spring Boot 项目。
💻 代码示例: dockerfile
FROM maven:3.9-eclipse-temurin-21 AS builder
RUN mvn package -DskipTests
FROM eclipse-temurin:21-jre-alpine
COPY --from=builder /app/target/*.jar app.jar
⚠️ 注意事项: alpine JRE 镜像比 Debian 小 50%+。
Chapter 04

Layered JAR 加速启动

💡 概念: Spring Boot 2.4+ 支持分层 JAR。
🎯 使用场景: 提升 CI 构建速度。
💻 代码示例: dockerfile
RUN java -Djarmode=layertools -jar app.jar extract
COPY --from=builder /app/dependencies/ ./
COPY --from=builder /app/application/ ./
⚠️ 注意事项: Layered JAR 减少 CI 缓存失效。
Chapter 05

JVM 启动优化 6 配置

💡 概念: UseContainerSupport/MaxRAMPercentage/UseG1GC 等。
🎯 使用场景: Java 启动速度。
💻 代码示例: bash
java -XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0 \
-XX:+UseG1GC -Djava.security.egd=file:/dev/./urandom \
-jar app.jar
⚠️ 注意事项: SecureRandom 默认阻塞;用 urandom 避免延迟。
Chapter 06

Native Image GraalVM

💡 概念: GraalVM AOT 编译生成原生二进制,启动 50ms。
🎯 使用场景: Serverless Java。
💻 代码示例: dockerfile
FROM ghcr.io/graalvm/graalvm-ce:java17-22 AS builder
RUN ./mvnw -Pnative native:compile
FROM gcr.io/distroless/base-debian12
COPY --from=builder /app/target/myapp /myapp
⚠️ 注意事项: Native Image 限制:反射/动态代理需提前配置。
Chapter 07

容器与镜像核心概念

💡 概念: 镜像(Image)是静态只读模板,容器(Container)是运行实例,Docker 基于 Linux Namespace(隔离)+Cgroups(资源限制)+UnionFS(分层)三大内核特性。
🎯 使用场景: 理解 Docker 工作原理;区分 Image/Container/Volume/Network 概念。
💻 代码示例: bash
docker images
docker ps -a
docker history nginx:alpine
docker inspect nginx | jq '.[0].GraphDriver.Data'
⚠️ 注意事项: 镜像层(ReadOnly)+容器层(ReadWrite)=完整文件系统;层数过多拖慢拉取。
Chapter 08

Docker 安装与配置

💡 概念: Docker 支持 Linux/macOS/Windows;Linux 推荐 docker-ce+buildx+compose;macOS/Windows 用 Docker Desktop。
🎯 使用场景: 首次安装;配置镜像加速器;权限管理。
💻 代码示例: bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# /etc/docker/daemon.json
{
"registry-mirrors": ["https://docker.m.daocloud.io"],
"experimental": true
}
sudo systemctl restart docker
docker run hello-world
⚠️ 注意事项: macOS/Windows 用 Docker Desktop;Linux 服务器用 docker-ce;中国网络需镜像加速器。

Chapter 10

Dockerfile 编写规范

💡 概念: Dockerfile 是镜像构建脚本;FROM/RUN/COPY/ENV/EXPOSE/CMD/ENTRYPOINT;最佳实践:小基础镜像、合并 RUN、非 root。
🎯 使用场景: 应用容器化;CI/CD 流水线构建。
💻 代码示例: dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build

FROM node:20-alpine
USER node
COPY --from=builder --chown=node:node /app/dist ./dist
HEALTHCHECK --interval=30s CMD curl -f http://localhost:3000/ || exit 1
CMD ["node", "dist/main.js"]
⚠️ 注意事项: USER 非 root;HEALTHCHECK 必加;CMD exec 形式。
Chapter 11

多阶段构建高级用法

💡 概念: 多阶段用 AS 命名,--from= 跨阶段 COPY;BuildKit --mount/--secret/--ssh 高级特性。
🎯 使用场景: 需编译应用(Java/Go/Node);CI/CD 加速;体积优化。
💻 代码示例: dockerfile
#syntax=docker/dockerfile:1.7
FROM golang:1.22 AS builder
WORKDIR /app
COPY go.mod ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o /bin/app

FROM gcr.io/distroless/base-debian12
COPY --from=builder /bin/app /app
USER 1000
ENTRYPOINT ["/app"]
⚠️ 注意事项: BuildKit 替代 DOCKER_BUILDKIT;--mount type=cache 持久化缓存。
Chapter 12

Docker Compose 编排

💡 概念: docker compose 用 YAML 定义多服务;version 已弃用(v2);profiles/depends_on/healthcheck 高级特性。
🎯 使用场景: 本地多服务开发(API+DB+Cache);中小团队生产部署;CI 集成测试。
💻 代码示例: yaml
services:
api:
build: .
ports: ["3000:3000"]
depends_on:
db: { condition: service_healthy }
develop:
watch:
- action: sync
path: ./src
target: /app/src

db:
image: postgres:16-alpine
volumes: ["db-data:/var/lib/postgresql/data"]
healthcheck: { test: ["CMD-SHELL", "pg_isready"] }

volumes: { db-data: }
⚠️ 注意事项: Compose Watch 2025 GA 替代 nodemon;depends_on+healthcheck。
Chapter 13

Docker Swarm 集群编排

💡 概念: Docker Swarm 是内置容器编排工具;manager/worker 节点、service/stack/replicas、overlay 网络、滚动更新。
🎯 使用场景: 中等规模集群( < 200 节点);不想引入 K8s;学习编排入门。
💻 代码示例: bash
docker swarm init --advertise-addr 
docker swarm join --token  :2377

docker service create --name web \
--replicas 3 --publish 80:80 \
--network my-overlay nginx:alpine

docker service update --image nginx:1.25 web
⚠️ 注意事项: Swarm 比 K8s 简单但生态较弱;新项目建议 K8s。
Chapter 14

Kubernetes 入门对接

💡 概念: K8s 是容器编排事实标准;Pod/Deployment/Service/Ingress/ConfigMap/Secret/PV 等核心概念。
🎯 使用场景: 生产环境大规模部署;多云/混合云;微服务架构。
💻 代码示例: yaml
apiVersion: apps/v1
kind: Deployment
metadata: { name: myapp }
spec:
replicas: 3
selector: { matchLabels: { app: myapp } }
template:
spec:
containers:
- name: myapp
image: myapp:v1
resources:
limits: { memory: 512Mi, cpu: 500m }
readinessProbe:
httpGet: { path: /health, port: 8080 }
⚠️ 注意事项: K8s 是大势所趋;Swarm 是过渡;学习曲线陡但生态强大。
