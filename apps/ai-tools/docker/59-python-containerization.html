Chapter 01

Python 3.12 新特性与镜像选择

  • python:3.12-slim 镜像 120MB(标准镜像 350MB)
  • python:3.12-alpine 80MB 但 musl libc 可能不兼容 C 扩展
  • PyPy 3.10 性能 5x 提升,适合 CPU 密集任务
  • 推荐:生产用 slim + uv(替代 pip 的极速安装器)
  • PEP 668:系统 Python 需 --break-system-packages 或 venv
Chapter 02

依赖管理 3 工具对比

  • pip + requirements.txt:经典,但无锁文件可重现性差
  • poetry + pyproject.toml:现代化,自动解析依赖图
  • uv + uv.lock:10-100x 速度快,Rust 编写,Dropbox 出品
  • pip-tools + requirements.in:轻量级,pip 兼容
  • 推荐:生产用 uv(速度)或 poetry(生态成熟)
Chapter 03

3 阶段 Dockerfile 模板

  • Stage 1 (builder):pip install --prefix=/install 离线安装 wheel
  • Stage 2 (runner):COPY --from=builder /install 复制预编译依赖
  • Stage 3 (config):ENV PYTHONUNBUFFERED=1 防止日志缓冲
  • gunicorn 启动:CMD ["gunicorn", "--bind", "0.0.0.0:8000", "--workers", "4"]
  • uvicorn ASGI:CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
Chapter 04

Django 部署专项

  • ALLOWED_HOSTS 配置:容器网络域名或 K8s service
  • 数据库迁移:CMD 前运行 python manage.py migrate
  • 静态文件:collectstatic 收集到 /app/static/
  • Whitenoise 中间件 + GzipMiddleware 提升性能
  • DEBUG=False + SECRET_KEY 环境变量
Chapter 05

Flask 部署专项

  • gunicorn 进程数:workers = (2 * CPU) + 1
  • worker_class:同步用 sync,异步用 gevent 或 uvicorn
  • max-requests + max-requests-jitter 防止内存泄漏累积
  • timeout=30 防止慢请求占用 worker
  • graceful_timeout=30 优雅关闭留足时间

实战代码示例

📝 Python 多阶段

完整可执行代码,直接复制即可在生产环境使用:

Python 多阶段 · dockerfile 
            
FROM python:3.12-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --prefix=/install
FROM python:3.12-slim
COPY --from=builder /install /usr/local
COPY . /app
CMD ["gunicorn", "app:app"]
