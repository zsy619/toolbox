Spring Cloud 微服务架构容器化实战

Eureka + Gateway + Config + Sleuth 全套容器化

详解 Spring Cloud 微服务体系的容器化部署:服务发现 Eureka、API 网关 Gateway、配置中心 Config、链路追踪 Sleuth、熔断 Hystrix、K8s 集成。

Chapter 01

Spring Cloud 核心组件

  • Eureka/Nacos:服务注册与发现(健康检查)
  • Gateway/Zuul:API 网关(路由/限流/鉴权)
  • Config/Nacos:分布式配置中心
  • Sleuth/Zipkin:分布式链路追踪
  • Hystrix/Sentinel:熔断限流降级
Chapter 02

服务发现容器化

  • Eureka Server 单节点开发,生产至少双节点互备
  • Docker Compose 部署 Eureka + 3 服务,验证服务注册
  • healthcheck 端点:GET /actuator/health 返回 UP
  • 环境变量:eureka.client.service-url.defaultZone 配置集群
  • K8s 部署:用 Service + headless + StatefulSet 保证稳定
Chapter 03

API 网关容器化

  • Spring Cloud Gateway 基于 WebFlux 响应式,性能 10x Zuul
  • 路由配置:routes: - id: user-service uri: lb://user-service
  • 过滤器:限流、鉴权、跨域、限流(RequestRateLimiter)
  • CORS 配置:allowedOrigins 动态从配置中心读取
  • Kubernetes 集成:K8s Service 自动发现 + Ribbon 负载均衡
Chapter 04

配置中心容器化

  • Spring Cloud Config Server:Git/SVN/JDBC 后端
  • Nacos:配置 + 注册二合一,阿里出品,推荐
  • Apollo:携程出品,企业级特性完善
  • 动态刷新:@RefreshScope + Spring Cloud Bus MQ 广播
  • 敏感配置加密:jasypt-spring-boot-starter + ENC() 包裹
Chapter 05

可观测性三件套

  • Prometheus + Grafana 监控:JVM / HTTP / DB 连接池指标
  • Jaeger/Zipkin 链路追踪:traceId 串联微服务调用链
  • ELK/Loki 日志聚合:logback-spring.xml 输出 JSON
  • Sentry 错误追踪:异常自动上报 + 告警
  • 告警:Alertmanager + PagerDuty / 企业微信 / 钉钉
💡 Spring Cloud 替代

Spring Cloud Netflix 进入维护,推荐 Spring Cloud Alibaba(Nacos/Sentinel/Seata)

🎯 部署模式

Compose 适合中小项目,生产用 Helm + K8s Service Mesh

操作流程

可视化操作流程

🔄 5 步标准操作流程

  1. 引入 actuator → 启动容器或检查环境
  2. 配置端点 → 拉取依赖或配置
  3. 集成 Prometheus → 启动核心服务
  4. 配 K8s 健康检查 → 验证运行状态
  5. 结构化日志 → 部署上线
