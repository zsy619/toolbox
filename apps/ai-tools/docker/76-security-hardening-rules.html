Chapter 02

容器运行时 5 规则

01

USER:非 root 用户(node / appuser)

02

--read-only:只读根 + tmpfs(/tmp /run)

03

--cap-drop ALL:移除所有 capability + --cap-add 必要项

04

--security-opt no-new-privileges:禁止提权

05

--security-opt seccomp=custom.json:自定义 seccomp 规则

操作流程

可视化操作流程

🔄 5 步标准操作流程

  1. 集成到 CI → 启动容器或检查环境
  2. 设 CRITICAL 阈值 → 拉取依赖或配置
  3. 定期全量扫描 → 启动核心服务
  4. 修复漏洞 → 验证运行状态
  5. 报告审计 → 部署上线
