Chapter 01

5 种 Docker 日志驱动

  • json-file:默认,每容器 1 个 JSON 文件,需 logrotate
  • journald:systemd 集成,query-by-attribute
  • syslog:写入远端 syslog 服务
  • fluentd/gelf:直推日志聚合系统,无本地存储
  • awslogs/azurelogs:云厂商日志服务集成
Chapter 02

Fluentd + Elasticsearch 完整链路

  • fluent/fluent-bit:Sidecar 模式收集容器 stdout
  • DaemonSet 部署:每节点 1 个 fluent-bit
  • input:docker.sock 监听所有容器日志
  • filter:解析 JSON / 附加 Kubernetes labels
  • output:elasticsearch 索引按日期 daily
Chapter 03

Loki + Promtail 轻量级方案

  • Grafana Loki:类似 Prometheus 但针对日志
  • Promtail:DaemonSet 部署,采集 + 标签 + push
  • LogQL:类 PromQL 的日志查询语言
  • Grafana 一体化:同一面板看 Metrics + Logs + Traces
  • 存储成本低:不建索引,只压缩原始日志
Chapter 04

JSON 结构化日志

  • Java:logback-spring.xml + logstash-logback-encoder
  • Python:python-json-logger 输出 JSON
  • Node.js:winston + format: winston.format.json()
  • Go:log/slog 内置 JSON formatter(Go 1.21+)
  • 字段标准化:timestamp / level / message / traceId / spanId
Chapter 05

日志轮转与保留

  • json-file:max-size=10m + max-file=3(单文件 10MB × 3 轮转)
  • ES ILM:热(SSD)→ 温(HDD)→ 冷(对象存储)→ 删除
  • Loki retention 7d 数据 + 30d 压缩存储
  • Fluentd buffer:file buffer 防进程崩溃数据丢失
  • 生产建议:默认 7 天 + 1 年归档 OSS/S3
