为什么需要私有镜像中心

Docker Hub 和阿里云都是公网镜像中心,用户可以将镜像 push 到镜像中心的镜像仓库里,也可以将仓库设为私有库,保证镜像安全。但 实际工作中,一般在公司内部搭建一个私有镜像中心 。

私有镜像中心的核心价值

1) 安全性 :镜像不出内网,杜绝敏感信息(密钥、内部代码)泄露;

2) 传输效率 :内网带宽充足,大镜像(几 GB)推送速度快;

3) 权限管控 :可对接 LDAP/AD,按角色分配 pull/push 权限;

4) 合规审计 :满足金融、医疗等行业的合规要求,操作可追溯。

Chapter 01

发布镜像到阿里云

阿里云提供"容器镜像服务"(个人版免费),作为国内最常用的公网镜像中心。发布流程分为 4 步:注册 → 创建实例 → 创建命名空间 → 推送镜像。

1.1 准备工作

  1. 注册阿里云账号,完成实名认证
  2. 搜索并进入 容器镜像服务 ,创建个人实例
  3. 设置 Registry 登录密码
  4. 创建 命名空间 (用于分类管理仓库)
  5. 在命名空间下创建 本地仓库

1.2 推送镜像四步曲

bash 
                
                  
# 1. 登录阿里云镜像中心
                  
                  
docker login
                  
                  
--username
                  
=dt_5224810793 \
  crpi-8nnmc9aojy1lrfpp.cn-chengdu.personal.cr.aliyuncs.com
                  
# 2. 复制并重命名镜像(添加仓库地址前缀)
                  
                  
docker tag
                  
 hello-my-world \
  crpi-8nnmc9aojy1lrfpp.cn-chengdu.personal.cr.aliyuncs.com/ali_1/ali_1_ck:1.0
                  
# 3. 推送镜像
                  
                  
docker push
                  
 \
  crpi-8nnmc9aojy1lrfpp.cn-chengdu.personal.cr.aliyuncs.com/ali_1/ali_1_ck:1.0
                  
# 4. 登出
                  
                  
docker logout
                  
 \
  crpi-8nnmc9aojy1lrfpp.cn-chengdu.personal.cr.aliyuncs.com
💡

阿里云命名空间相当于"分组",同一个命名空间内的仓库名不能重复。不同环境(测试/生产)建议创建不同命名空间,便于管理。

Chapter 03

容器退出状态码

退出状态码用于向用户反馈 容器中应用 的退出方式,范围是 [0, 255] 的整数,分为三类:

状态码范围 类别 含义
0 正常退出 容器中应用正常退出
[1, 128] 应用错误 容器内部运行错误或应用出错
[129, 255] 信号终止 容器接收到操作系统/Docker 信号而退出

3.1 常见状态码详解

状态码 含义 触发原因
1 程序内部错误 分母为 0、内存溢出、 Dockerfile 中无效引用
125 command 未运行成功 引用了未定义变量、执行了无权限目录
126 command 未运行成功 缺少依赖
127 command 未运行成功 引用了不存在的文件或目录
128 退出码越界 自定义代码不在 0-255 范围时,被强制设为 128
130 SIGINT(信号 2) 应用接收到操作系统的终止信号
137 SIGKILL(信号 9) Docker 强制终止(OOM、 docker kill )
143 SIGTERM(信号 15) 优雅终止(无访问时立即,否则 10s 后强杀)

状态码可通过 docker ps -a 查看 STATUS 列,或通过 docker inspect 查看详细字段。

Chapter 04

容器重启策略

生产环境下,容器退出后手动重启不现实,可在容器创建时指定 --restart 选项,自动应用重启策略。

策略 行为 适用场景
no 默认,退出时不重启 一次性任务、批处理
on-failure[:n] 非正常退出(状态码非 0)才重启,可选最大次数 n 数据库、缓存等有状态服务
always 任何退出都无限重启 API、Web 等无状态服务
unless-stopped 任何退出都重启,除非 docker stop 开发环境、本地服务
bash 
                
                  
docker run
                  
                  
-d
                  
                  
--restart
                  
=on-failure:5 nginx:alpine
                  
docker run
                  
                  
-d
                  
                  
--restart
                  
=always redis:7
                  
docker run
                  
                  
-d
                  
                  
--restart
                  
=unless-stopped mysql:8
Chapter 05

Harbor 私有镜像中心 (HTTP)

Harbor 是 Go 语言 开发的开源 Registry server 项目,在 Docker Registry 基础上进行二次封装。作为 企业级私有 Registry 服务器 ,Harbor 提供更好的性能与安全,也提供方便的 Web 管理界面。

5.1 角色划分

  • Harbor 服务器 :专用于 Registry 服务,不运行普通业务容器
  • Docker 客户端 :其他需要 push/pull 镜像的 Docker 主机

5.2 Harbor vs Docker Registry

特性 Docker Registry Harbor
Web UI ❌ ✅
用户认证 需 htpasswd 手动配置 ✅ 内置(LDAP/AD/OIDC)
角色权限(RBAC) ❌ ✅
镜像复制 ❌ ✅ 多 Harbor 同步
漏洞扫描 ❌ ✅ Trivy 集成
镜像签名 ❌ ✅ Cosign 集成
审计日志 ❌ ✅
部署复杂度 极简 中等(10 个容器)

Harbor 启停管理

Harbor 由 10 个容器 协同运行,通过 docker-compose 完成容器编排。安装后会在解压目录生成 docker-compose.yml 文件,所有启停命令都在 Harbor 解压目录 中执行。

bash 
                
                  
# 停止 Harbor
                  
                  
docker compose stop
                  
                  
# 启动 Harbor
                  
                  
docker compose up
                  
                  
-d
💡

新版 Docker 已内置 docker compose (无连字符);若使用旧版,需要 docker-compose (有连字符)。

FAQ

常见问题

什么是 Docker 私有镜像中心?为什么需要它?

Docker 私有镜像中心是企业内部搭建的 Registry 服务器,用于存储、管理、分发 Docker 镜像。相比 Docker Hub、阿里云等公网镜像中心,私有镜像中心具有:1) 镜像安全可控,不对外公开;2) 内网传输速度快;3) 可定制化权限管理;4) 满足合规审计要求。Harbor 是目前最主流的企业级开源 Registry,提供 Web UI、用户认证、镜像复制、漏洞扫描、镜像签名等高级功能。

Harbor 与 Docker Registry 有什么区别?

Docker Registry 是 Docker 官方的开源镜像存储项目,功能单一(仅 push/pull);Harbor 是基于 Docker Registry 二次封装的企业级项目,提供更丰富的功能:Web 管理界面、基于角色的访问控制(RBAC)、镜像复制策略、漏洞扫描(Trivy)、镜像签名(Cosign)、审计日志等。生产环境推荐 Harbor,学习测试可使用 Docker Registry。

容器退出状态码 137 是什么意思?

状态码 137 表示容器被强制终止(SIGKILL,信号 9)。常见原因:1) Docker 守护进程主动 kill 容器(资源超限、节点 OOM);2) 手动执行 docker kill ;3) 宿主机内存不足触发 OOM Killer。137 = 128 + 9(信号 9),所以看到 137 说明是收到 SIGKILL 信号而非正常退出。

容器重启策略 on-failure 和 always 怎么选?

on-failure 仅在容器非正常退出(状态码非 0)时重启,适合有状态服务(数据库、缓存),避免无意义重启;always 任何退出都重启,适合无状态服务(API、Web),最大化可用性;unless-stopped 总是重启但 docker stop 不会触发重启,适合开发环境。一般推荐:生产用 on-failure[:n] (n 为最大重试次数),开发用 unless-stopped 。

如何修改阿里云镜像仓库的登录密码?

登录阿里云控制台 → 搜索"容器镜像服务" → 进入个人版 → 左侧菜单"访问凭证" → 设置 Registry 登录密码。修改后需要重新执行 docker login 登录才能推送镜像。

Harbor 的默认管理员账号密码是什么?

Harbor 安装时通过 harbor.yml 配置 admin 用户的初始密码(默认 admin/Harbor12345 )。首次登录后应立即修改默认密码。生产环境建议同时修改 admin 密码、删除默认库 library、配置 OIDC/LDAP 集成。

htpasswd 的 -B、-b、-c 三个选项分别什么作用?

-B 使用 bcrypt 加密(最安全,推荐); -b 表示从命令行直接输入密码(非交互,适合脚本); -c 表示创建新文件(已存在则覆盖,首次创建用,后续创建用户不要再加 -c )。
