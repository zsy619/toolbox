Chapter 01

Java 实战(JDK 17)

  • eclipse-temurin:17-jdk-alpine builder 阶段
  • JLink 定制 JRE:jlink --strip-debug --no-man-pages
  • distroless 基础镜像:含 CA 证书 + 时区数据
  • EXPOSE 8080 + HEALTHCHECK 配合 Spring Boot Actuator
Chapter 02

Node.js 实战

  • node:20-alpine builder + node:20-alpine runner
  • npm ci --omit=dev 生产环境排除 dev 依赖
  • Next.js Standalone 输出:output: 'standalone'
  • Vite 静态资源:nginx-alpine + 多阶段 COPY
Chapter 03

Go 实战(scratch 极简)

  • golang:1.22-alpine builder + scratch 运行时
  • CGO_ENABLED=0 静态编译,无 libc 依赖
  • GOMAXPROCS=0 自动检测容器 CPU(Go 1.25+)
  • ca-certificates 仅 100KB,scratch 也支持 HTTPS
Chapter 04

Python 实战

  • python:3.12-slim builder + python:3.12-slim runner
  • uv 极速安装:10-100x 比 pip 快
  • 多阶段分离 wheel 编译与运行时
  • gunicorn:4 workers + 异步 gevent worker
Chapter 05

Rust 实战

  • rust:1.75 builder + debian:bookworm-slim runner
  • cargo build --release 编译优化
  • strip 减小二进制 30-40%
  • musl 静态链接完全无 libc 依赖
💡 镜像大小

scratch 15MB / distroless 20MB / alpine 30MB / debian-slim 80MB

🎯 缓存技巧

--mount=type=cache,target=/root/.cache 复用下载/编译缓存
