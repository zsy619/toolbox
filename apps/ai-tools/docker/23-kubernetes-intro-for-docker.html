Kubernetes 入门与 Docker 协同演进

kubectl + Pod + Deployment + Service

Chapter 01

K8s 8 大核心资源

  • Pod:K8s 最小调度单元(可含多容器)
  • Deployment:无状态应用控制器(滚动升级/回滚)
  • StatefulSet:有状态应用(DB/消息队列)
  • DaemonSet:每节点一个 Pod(日志/监控)
  • Service:服务抽象 + ClusterIP + 负载均衡
  • Ingress:HTTP 路由入口(nginx/traefik)
  • ConfigMap / Secret:配置 / 密钥管理
  • Job / CronJob:一次性任务 / 定时任务
Chapter 02

Pod 深入 4 概念

  • Pod 是 K8s 调度的最小单元,可含 1+ 容器
  • Pod 内容器共享网络/存储(localhost 互通)
  • Init Container:Pod 启动前运行的初始化容器
  • Sidecar:日志/代理等横切关注点容器
Chapter 03

kubectl 5 大命令

  • kubectl get pods 列出 Pod
  • kubectl describe pod 看详情
  • kubectl logs 看日志(-f 实时)
  • kubectl exec -it /bin/sh 进容器
  • kubectl apply -f deployment.yaml 部署
Chapter 04

Compose 迁移 K8s 4 步

  • Kompose 一键转换:kompose convert -f docker-compose.yml
  • 手动转换:每个 service → Deployment + Service
  • 数据卷:Compose volume → K8s PVC + PV
  • 环境变量:Compose env → ConfigMap / Secret
Chapter 05

Ingress 路由实战

  • Ingress:HTTP/HTTPS 路由(nginx ingress controller)
  • TLS:cert-manager + Let's Encrypt 自动证书
  • 路由规则:host / path / header 维度
  • 示例:foo.example.com → service-a,bar.example.com → service-b
  • Annotation:rewrite-target / rate-limit / cors
