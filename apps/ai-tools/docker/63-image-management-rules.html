01

1) 登录:docker login registry.cn-hangzhou.aliyuncs.com

02

2) 打标签:docker tag myapp:v1.0 registry.../mycorp/myapp:v1.0

03

3) 推送:docker push registry.../mycorp/myapp:v1.0

04

4) 验证:docker pull registry.../mycorp/myapp:v1.0

05

5) 漏洞扫描:trivy image registry.../mycorp/myapp:v1.0

6) 台账登记:地址+版本+漏洞等级到镜像仓库台账

Chapter 03

清理策略 5 规则

01

定期清理悬虚镜像:每周 docker image prune -f

02

保留最近 3 个版本:便于回滚

03

删除前确认:无容器依赖再删

04

强制删除依赖:docker rmi -f 镜像ID

05

大文件清理:docker system prune -a --volumes(高危需备份)

💡 digest vs tag

digest 是 sha256 哈希(不可变,精确拉取);tag 是标签(可变,可能被覆盖)

⚠️ latest 陷阱

tag latest 可能被重新推送,生产部署必须用 digest 或固定版本号

操作流程

可视化操作流程

🔄 5 步标准操作流程

  1. 拉取镜像 → 启动容器或检查环境
  2. 验证 SHA256 → 拉取依赖或配置
  3. 扫描漏洞 → 启动核心服务
  4. 推 Registry → 验证运行状态
  5. 清理旧 tag → 部署上线
