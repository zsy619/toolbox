Chapter 01

ClickHouse 3 大优势

  • 列式存储:分析查询比 MySQL 快 100-1000x
  • 压缩比高:列存 ZSTD/LZ4 压缩比 10-20x
  • 向量引擎:ClickHouse 23.x 内置 SIMD 加速
  • 实时插入:批量 + 异步 + 强一致 3 种模式
  • 生态完善:Kafka/MySQL/PostgreSQL JDBC 桥接
Chapter 02

单节点快速启动

  • docker run -d -p 8123:8123 -p 9000:9000 clickhouse/clickhouse-server:23.8
  • clickhouse-client 连接 9000 端口执行 SQL
  • 默认数据库 default,用户 default 无密码
  • 数据持久化:/var/lib/clickhouse 目录
  • 8123 端口 HTTP 接口,9000 端口 native 接口
Chapter 03

Zookeeper + 集群模式

  • ReplicatedMergeTree 表引擎需 Zookeeper 协调
  • docker run 启动 zookeeper 3.7 单节点(开发)或 3 节点(生产)
  • 配置 节点指定 zk 集群地址
  • ReplicatedMergeTree('zoo_path', 'replica_name')
  • Distributed('cluster', 'db', 'table') 分布式表代理
Chapter 04

亿级数据查询优化

  • 分区 PARTITION BY toYYYYMM(event_date) 按月分区
  • 排序键 ORDER BY (user_id, event_time) 优化过滤
  • 主键 PRIMARY KEY 与排序键分离(避免数据膨胀)
  • 索引:bloom_filter + minmax + set 跳数索引
  • SAMPLE 抽样查询,大幅减少扫描量
Chapter 05

生态集成与监控

  • Kafka 引擎:CREATE TABLE ... Engine = Kafka() 实时消费
  • MaterializedView 自动物化查询结果
  • clickhouse-exporter:暴露 /metrics 给 Prometheus
  • Tabix / DBeaver:Web SQL 客户端
  • 备份:clickhouse-backup 工具支持 S3/MinIO 增量备份

clickhouse/clickhouse-server:23.8 官方 / Altinity 提供企业增强版
