Docker 多平台安装与配置实战

Linux/macOS/Windows 全平台安装 + 升级

详解 CentOS 7/8、Ubuntu 20/22、Debian、macOS、WSL2、Windows 全平台 Docker 安装;docker-ce-cli-containerd.io 三件套;镜像加速器配置;离线安装;版本升级;完全卸载。

Chapter 01

Linux 4 大发行版安装

  • CentOS 7/8:yum-utils + yum config-manager + 阿里云源
  • Ubuntu 20/22:apt + apt-transport-https + ca-certificates
  • Debian 10/11:curl -fsSL get.docker.com | bash 一键脚本
  • openEuler 20/22:dnf + 华为云镜像源(国产化首选)
Chapter 02

macOS 与 Windows

  • macOS:Docker Desktop for Mac(Intel/Apple Silicon 双架构)
  • Windows:WSL 2 后端(推荐)+ Hyper-V 备选
  • Docker Desktop 含 docker engine + Compose + GUI
  • WSL 2:Ubuntu 发行版 + Systemd 集成
Chapter 03

镜像加速器配置

  • 阿里云:registry.cn-hangzhou.aliyuncs.com
  • 腾讯云:mirror.ccs.tencentyun.com
  • DaoCloud:docker.m.daocloud.io
  • 网易:hub-mirror.c.163.com
  • daemon.json /etc/docker/daemon.json 配置后 systemctl restart docker
Chapter 04

离线安装方案

  • 内网/专网环境无外网:下载 rpm/deb 包本地安装
  • docker save 镜像到 tar.gz + docker load 导入
  • kind(K8s in Docker)本地快速测试集群
  • vagrant 完整开发环境:一台 VM = 完整 k8s 集群
Chapter 05

升级与卸载

  • yum update docker-ce -y 升级到最新稳定版
  • apt upgrade docker-ce -y Debian/Ubuntu 升级
  • 完全卸载:yum remove + rm -rf /var/lib/docker
  • 数据卷:卸载前 docker volume ls 备份所有卷
💡 升级策略

生产环境先 staging 验证 → 灰度 → 全量,避免大版本升级不兼容

⚠️ 数据保留

升级和卸载都默认保留数据卷,显式 --volumes 才删除
