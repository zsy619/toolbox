Chapter 01

前端构建工具 3 选

  • Webpack 5:成熟稳定,生态丰富,构建慢(分钟级)
  • Vite 5:esbuild + Rollup,启动 < 1s,生产 10x 更快
  • Turbopack:Vite 替代,Rust 实现,Beta 中
  • 推荐:新项目用 Vite 5,老项目保留 Webpack
  • SSR 用 Nuxt 3 / Next.js 14(支持 SSG/ISR/SSR)
Chapter 02

3 阶段 Dockerfile 模板

  • Stage 1 (deps):npm ci 精确安装,lock 文件锁定版本
  • Stage 2 (build):npm run build 输出 dist/ (Vue) 或 build/ (React)
  • Stage 3 (runtime):nginx:1.25-alpine + 静态文件 + 配置
  • COPY --from=build /app/dist /usr/share/nginx/html
  • nginx 配置:history 路由 fallback、gzip、长缓存
Chapter 03

Nginx 关键配置 5 选

  • 1) history 路由:try_files $uri $uri/ /index.html (Vue Router/React Router)
  • 2) gzip on + gzip_types text/css application/javascript
  • 3) brotli on (brotli 模块需 --with-compat 编译)
  • 4) 静态资源长缓存:location ~* \.(js|css|png)$ expires 1y
  • 5) HTML 不缓存:location / expires -1 add_header Cache-Control no-cache
Chapter 04

CDN 缓存策略

  • index.html:no-cache(确保更新即时生效)
  • main.js + main.css:immutable + 1y(文件名带 hash,内容不变)
  • 图片/字体:1y + immutable(CDN 自动优化)
  • API 响应:no-store(永缓存)
  • 用文件名 hash 而非 query:foo.abc123.js 优于 foo.js?v=abc123
Chapter 05

性能优化 4 指标

  • FCP (First Contentful Paint) < 1.8s
  • LCP (Largest Contentful Paint) < 2.5s
  • CLS (Cumulative Layout Shift) < 0.1
  • TTI (Time to Interactive) < 3.8s
  • Lighthouse 评分 > 90
💡 镜像大小

Vue/React + Nginx 整体 < 30MB(含 dist)

🎯 缓存陷阱

文件名带 hash 才可设 immutable,否则用 max-age=3600

实战代码示例

📝 Vue Vite 多阶段

完整可执行代码,直接复制即可在生产环境使用:

Vue Vite 多阶段 · dockerfile 
            
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
FROM nginx:1.25-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
