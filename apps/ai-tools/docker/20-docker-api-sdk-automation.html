Docker API 与 SDK 自动化

REST API + Go SDK + Python SDK

Chapter 01

Docker Engine REST API 4 选

  • GET /containers/json 列出所有容器
  • POST /containers/create 创建容器(等同 docker run)
  • POST /containers/{id}/start 启动容器
  • GET /containers/{id}/logs?stdout=true&stderr=true 获取日志
Chapter 02

API 认证与 HTTPS

  • 本地:无认证,默认 socket /var/run/docker.sock
  • 远程:2375 端口(HTTP,明文,开发用)
  • 生产:2376 + TLS 证书(HTTPS 加密)
  • dockerd -H tcp://0.0.0.0:2376 --tlsverify 启用
Chapter 03

Go SDK (moby/moby)

  • import github.com/docker/docker/client
  • client.NewClientWithOpts(client.FromEnv) 创建客户端
  • client.ContainerList(ctx, types.ContainerListOptions{All: true})
  • client.ContainerCreate(ctx, &container.Config{}, &container.HostConfig{}, nil, name)
  • 应用:容器编排平台、CI/CD 触发器、监控 Agent
Chapter 04

Python SDK (docker-py)

  • pip install docker 安装 SDK
  • import docker; client = docker.from_env() 加载环境变量
  • client.containers.run('nginx', detach=True, ports={'80/tcp': 8080})
  • client.containers.list() 列出 + filter 过滤
  • client.images.build(path='./app', tag='myapp:v1')
Chapter 05

自动化场景 4 选

  • 1) 动态扩缩容:基于 CPU 利用率自动创建容器
  • 2) 批量部署:一次启动 10 个 worker 节点
  • 3) 镜像同步:跨 registry 自动复制镜像
  • 4) 健康巡检:定时检查容器健康 + 自动重启
💡 安全建议

生产启用 TLS + 防火墙限制 + API 限流

🎯 选型建议

Python 适合快速脚本,Go 适合性能要求高的工具
