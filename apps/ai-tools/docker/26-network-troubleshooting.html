Chapter 01

Docker 网络架构基础

💡 概念: Docker 网络基于 namespace(隔离)+bridge/veth+iptables;5 种驱动。
🎯 使用场景: 理解网络问题根因;性能调优。
💻 代码示例: bash
docker network ls
docker network inspect bridge | jq '.[0].Containers'
ip link show | grep veth
⚠️ 注意事项: 容器 eth0 是 veth pair 一端。
Chapter 02

5 种网络驱动对比

💡 概念: bridge/host/none/overlay/macvlan 性能与场景对比。
🎯 使用场景: 新项目选型;性能瓶颈排查。
💻 代码示例: bash
docker network create -d bridge mynet
docker network create -d overlay swarm-net
docker network create -d macvlan -o parent=eth0 phys-net
docker run -d --network host nginx
⚠️ 注意事项: bridge 开发默认;host 性能首选。
Chapter 03

DNS 服务发现机制

💡 概念: 自定义网络内置 DNS,容器名即主机名。
🎯 使用场景: 微服务调用;避免硬编码 IP。
💻 代码示例: bash
docker network create mynet
docker run -d --network mynet --name api myapi
docker run -d --network mynet --name web alpine ping api
⚠️ 注意事项: 容器重建 IP 变;服务名是稳定标识。
Chapter 04

nftables 后端切换

💡 概念: Docker 25+ 默认 nftables 替代 iptables。
🎯 使用场景: 大规模网络策略;iptables 性能瓶颈。
💻 代码示例: bash
nft list ruleset | grep docker
⚠️ 注意事项: nftables 工具链较新。
Chapter 05

Cilium eBPF 网络

💡 概念: Cilium 基于 eBPF 替代 iptables,性能高 30%+。
🎯 使用场景: K8s 生产部署;网络策略复杂。
💻 代码示例: bash
helm install cilium cilium/cilium --version 1.15 \
--set kubeProxyReplacement=true
⚠️ 注意事项: eBPF 内核要求 4.19+。
Chapter 06

容器与镜像核心概念

💡 概念: 镜像(Image)是静态只读模板,容器(Container)是运行实例,Docker 基于 Linux Namespace(隔离)+Cgroups(资源限制)+UnionFS(分层)三大内核特性。
🎯 使用场景: 理解 Docker 工作原理;区分 Image/Container/Volume/Network 概念。
💻 代码示例: bash
docker images
docker ps -a
docker history nginx:alpine
docker inspect nginx | jq '.[0].GraphDriver.Data'
⚠️ 注意事项: 镜像层(ReadOnly)+容器层(ReadWrite)=完整文件系统;层数过多拖慢拉取。
Chapter 07

Docker 安装与配置

💡 概念: Docker 支持 Linux/macOS/Windows;Linux 推荐 docker-ce+buildx+compose;macOS/Windows 用 Docker Desktop。
🎯 使用场景: 首次安装;配置镜像加速器;权限管理。
💻 代码示例: bash
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# /etc/docker/daemon.json
{
"registry-mirrors": ["https://docker.m.daocloud.io"],
"experimental": true
}
sudo systemctl restart docker
docker run hello-world
⚠️ 注意事项: macOS/Windows 用 Docker Desktop;Linux 服务器用 docker-ce;中国网络需镜像加速器。
Chapter 08

基本命令速查

💡 概念: Docker CLI 涵盖 image/container/network/volume/system 子命令。
🎯 使用场景: 日常运维;脚本自动化;面试准备。
💻 代码示例: bash
# 镜像: pull/push/tag/rmi/images/inspect
# 容器: run/exec/start/stop/logs/stats/cp
# 网络: network create/connect
# 卷:   volume create/prune
# 系统: system df/prune/info
# Compose: docker compose up/down
⚠️ 注意事项: 2024+ 新增:scout/debug/init/buildx/sbom/model-runner;高频命令熟记。
Chapter 09

Dockerfile 编写规范

💡 概念: Dockerfile 是镜像构建脚本;FROM/RUN/COPY/ENV/EXPOSE/CMD/ENTRYPOINT;最佳实践:小基础镜像、合并 RUN、非 root。
🎯 使用场景: 应用容器化;CI/CD 流水线构建。
💻 代码示例: dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build

FROM node:20-alpine
USER node
COPY --from=builder --chown=node:node /app/dist ./dist
HEALTHCHECK --interval=30s CMD curl -f http://localhost:3000/ || exit 1
CMD ["node", "dist/main.js"]
⚠️ 注意事项: USER 非 root;HEALTHCHECK 必加;CMD exec 形式。
Chapter 10

多阶段构建高级用法

💡 概念: 多阶段用 AS 命名,--from= 跨阶段 COPY;BuildKit --mount/--secret/--ssh 高级特性。
🎯 使用场景: 需编译应用(Java/Go/Node);CI/CD 加速;体积优化。
💻 代码示例: dockerfile
#syntax=docker/dockerfile:1.7
FROM golang:1.22 AS builder
WORKDIR /app
COPY go.mod ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -o /bin/app

FROM gcr.io/distroless/base-debian12
COPY --from=builder /bin/app /app
USER 1000
ENTRYPOINT ["/app"]
⚠️ 注意事项: BuildKit 替代 DOCKER_BUILDKIT;--mount type=cache 持久化缓存。
Chapter 11

Docker Compose 编排

💡 概念: docker compose 用 YAML 定义多服务;version 已弃用(v2);profiles/depends_on/healthcheck 高级特性。
🎯 使用场景: 本地多服务开发(API+DB+Cache);中小团队生产部署;CI 集成测试。
💻 代码示例: yaml
services:
api:
build: .
ports: ["3000:3000"]
depends_on:
db: { condition: service_healthy }
develop:
watch:
- action: sync
path: ./src
target: /app/src

db:
image: postgres:16-alpine
volumes: ["db-data:/var/lib/postgresql/data"]
healthcheck: { test: ["CMD-SHELL", "pg_isready"] }

volumes: { db-data: }
⚠️ 注意事项: Compose Watch 2025 GA 替代 nodemon;depends_on+healthcheck。
Chapter 12

Docker Swarm 集群编排

💡 概念: Docker Swarm 是内置容器编排工具;manager/worker 节点、service/stack/replicas、overlay 网络、滚动更新。
🎯 使用场景: 中等规模集群( < 200 节点);不想引入 K8s;学习编排入门。
💻 代码示例: bash
docker swarm init --advertise-addr 
docker swarm join --token  :2377

docker service create --name web \
--replicas 3 --publish 80:80 \
--network my-overlay nginx:alpine

docker service update --image nginx:1.25 web
⚠️ 注意事项: Swarm 比 K8s 简单但生态较弱;新项目建议 K8s。
Chapter 13

Kubernetes 入门对接

💡 概念: K8s 是容器编排事实标准;Pod/Deployment/Service/Ingress/ConfigMap/Secret/PV 等核心概念。
🎯 使用场景: 生产环境大规模部署;多云/混合云;微服务架构。
💻 代码示例: yaml
apiVersion: apps/v1
kind: Deployment
metadata: { name: myapp }
spec:
replicas: 3
selector: { matchLabels: { app: myapp } }
template:
spec:
containers:
- name: myapp
image: myapp:v1
resources:
limits: { memory: 512Mi, cpu: 500m }
readinessProbe:
httpGet: { path: /health, port: 8080 }
⚠️ 注意事项: K8s 是大势所趋;Swarm 是过渡;学习曲线陡但生态强大。
Chapter 14

容器安全加固 6 步

💡 概念: 非 root/最小 capabilities/只读根 FS/资源限制/网络隔离/漏洞扫描;CIS Benchmark 完整列表。
🎯 使用场景: 生产安全合规;金融/医疗/政府行业。
💻 代码示例: bash
docker run -d \
--user 1000 \
--cap-drop ALL --cap-add CHOWN \
--read-only \
--tmpfs /tmp:size=100m \
--security-opt no-new-privileges \
--memory 512m --cpus 1.0 --pids-limit 100 \
myapp:v1

docker scout cves myapp:v1
trivy image myapp:v1
⚠️ 注意事项: 非 root+cap-drop+read-only 是三件套;DHI 镜像 CVE 数 < 5。
