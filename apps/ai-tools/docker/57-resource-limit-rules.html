Chapter 01

CPU 资源 3 限制

01

--cpus=1.5:最多使用 1.5 个 CPU 核心(最直观)

02

--cpu-shares=512:相对权重(默认 1024,512=其他容器一半)

03

--cpuset-cpus=0,1:绑定到特定 CPU 核心(避免跨核开销)

Chapter 02

内存 3 限制

01

--memory=512m:硬上限,超过 OOM Killer

02

--memory-reservation=256m:软保证,系统压力时优先回收

03

--memory-swap=1g:总内存+swap(默认等于 memory,0 禁用)

Chapter 03

磁盘 IO 2 限制

01

--device-read-bps / --device-write-bps /dev/sda:1mb:读写速度

02

--blkio-weight=500:块 IO 权重(默认 500)

Chapter 04

Compose 资源 3 配置

01

deploy.resources.limits.cpus: '1.5'

02

deploy.resources.limits.memory: 512M

03

deploy.resources.reservations.cpus: '0.5'(K8s/Swarm 模式)

💡 OOM 排查

docker inspect | grep OOMKilled,若为 true 则内存超限

实战代码示例

📝 K8s 资源限制

完整可执行代码,直接复制即可在生产环境使用:

K8s 资源限制 · yaml 
            
resources:
  requests:
    memory: "256Mi"
    cpu: "250m"
  limits:
    memory: "512Mi"
    cpu: "500m"
