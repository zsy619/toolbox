Chapter 01

Nginx 镜像 3 选择

  • nginx:1.25-alpine:精简 8MB,推荐生产
  • nginx:mainline:最新主分支,新特性
  • nginxinc/nginx-unprivileged:非 root 镜像,安全性高
  • 自定义镜像:Dockerfile 基于 alpine 编译 + 自带配置
  • 推荐:nginx:1.25-alpine + 自定义 nginx.conf
Chapter 02

多域名虚拟主机

  • server { listen 443 ssl; server_name a.example.com; ... }
  • SSL 证书:/etc/nginx/ssl/a.example.com.crt + .key
  • HTTP 重定向:server { listen 80; return 301 https://$host$request_uri; }
  • 日志:access_log /var/log/nginx/a.example.com.access.log
  • 缓存:proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=cache:10m
Chapter 03

Let's Encrypt 自动证书

  • certbot certonly --webroot -w /var/www/certbot -d a.example.com
  • 自动续期:certbot renew --deploy-hook 'nginx -s reload'
  • DNS 验证:Cloudflare API + certbot-dns-cloudflare 插件
  • 镜像:jrcs/letsencrypt-nginx-proxy-companion 自动申请与续期
  • 续期 crontab:0 0,12 * * * certbot renew
Chapter 04

upstream 负载均衡 4 算法

  • round-robin(默认):轮询,适合均匀后端
  • least_conn:最少连接,适合长连接
  • ip_hash:按 IP 哈希,黏性会话(适合 WebSocket)
  • random:随机(配合 consistent_hash 减少重建)
  • 健康检查:health_check interval=5000 fails=3 passes=2
Chapter 05

HTTP/2 与性能优化

  • http2 on 启用 HTTP/2(需 SSL)
  • gzip on + gzip_comp_level 6 + gzip_types 文本类型
  • gzip_static on 预压缩文件
  • sendfile on + tcp_nopush on 零拷贝
  • open_file_cache max=1000 inactive=20s 缓存元数据

📝 Nginx 反向代理

以下是该主题的完整可执行代码,直接复制即可在生产环境使用:

Nginx 反向代理 · yaml 
            
upstream backend {
  server app1:8080;
  server app2:8080;
}
server {
  listen 80;
  location / {
    proxy_pass http://backend;
    proxy_set_header Host $host;
  }
}
操作流程

可视化操作流程

🔄 5 步标准操作流程

  1. 1. 配置 upstream 负载均衡 → 启动容器或检查环境
  2. 2. 配置 server 块 → 拉取依赖或配置
  3. 3. 设置 proxy_set_header → 启动核心服务
  4. 4. 添加 SSL 证书 → 验证运行状态
  5. 5. nginx -s reload 热加载 → 部署上线或回归测试
