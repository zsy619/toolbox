Chapter 01

4 大应用场景

  • 微服务架构:每个服务独立容器化,便于管理和扩展
  • CI/CD 流水线:与 Jenkins/GitLab CI/GitHub Actions 集成,自动化构建和测试
  • 开发环境标准化:新成员一键启动全套依赖服务(数据库/缓存/消息队列)
  • 云原生基础:K8s 等编排工具基于 Docker 管理容器集群
Chapter 02

4 大核心优势

  • 跨平台一致性:解决「在我机器上能跑」的经典痛点
  • 资源高效:容器共享主机内核,无需虚拟化整个 OS,节省内存和 CPU
  • 快速部署:秒级启动容器,支持自动化扩缩容
  • 隔离性:每个容器独立的文件系统/网络/进程空间
Chapter 03

4 大核心概念

  • 镜像(Image):只读模板,定义容器运行环境,通过分层存储优化空间
  • 容器(Container):镜像的运行实例,轻量化、隔离、共享主机内核
  • Dockerfile:文本文件,描述如何自动构建镜像(声明式语法)
  • 仓库(Registry):存储和分发镜像的平台(Docker Hub/ Harbor/ ECR/ GCR)
Chapter 04

基本命令速查

  • docker pull nginx # 拉取镜像
  • docker run -d -p 80:80 nginx # 后台运行并映射端口
  • docker ps / docker ps -a # 查看运行/全部容器
  • docker build -t myapp . # 基于 Dockerfile 构建镜像
  • docker exec -it id /bin/bash # 进入容器内部
  • docker logs -f id # 实时查看日志
Chapter 05

5 大发行版

  • Docker CE(社区版):免费,中小项目首选(本教程用 CE)
  • Docker EE(企业版):商业,企业级支持(已更名为 Mirantis)
  • Docker Desktop:macOS/Windows 桌面端(含 GUI + K8s)
  • Moby:开源上游项目,二次开发基础
  • Mirantis:2019 年 Docker 拆分,EE 由其维护

Docker 命令速查

常用命令可直接复制到终端执行:

bash · 9 大常用命令 
              
# 拉取镜像
docker pull nginx

# 后台运行容器 + 端口映射
docker run -d -p 80:80 --name myweb nginx

# 查看运行中的容器
docker ps
docker ps -a  # 含已停止

# 启动/停止/重启
docker start myweb
docker stop myweb
docker restart myweb

# 进入容器执行命令
docker exec -it myweb /bin/bash

# 查看容器日志
docker logs -f --tail 100 myweb

# 构建自定义镜像
docker build -t myapp:v1 .

# 推送镜像到仓库
docker push myorg/myapp:v1

# 清理
docker system df
docker image prune -a -f  # 清理悬虚+未用镜像
