Chapter 01

Linux 网络栈基础

  • veth pair:成对虚拟网卡,容器与宿主机互通的网线
  • Linux bridge:软件交换机,相当于 vSwitch
  • iptables:L4 防火墙,NAT + filter 规则
  • 路由表:ip route 决定包转发路径
Chapter 02

bridge 模式实现原理

  • docker0:宿主机虚拟网桥(172.17.0.0/16)
  • vethXXX:容器端网卡(eth0@ifN) ↔ 宿主机端(XXXXXXXX@ifM)
  • 容器 IP:网桥 DHCP 自动分配
  • DNS:容器内 /etc/resolv.conf 指向 dockerd
  • iptables DNAT:宿主机端口 → 容器 IP:端口
Chapter 03

iptables 5 链 4 表

  • PREROUTING / INPUT / FORWARD / OUTPUT / POSTROUTING
  • filter:包过滤(ACCEPT/DROP/REJECT)
  • nat:地址转换(SNAT/DNAT/MASQUERADE)
  • mangle:包修改(TOS/TTL/MARK)
  • raw:连接跟踪豁免(NOTRACK)
Chapter 04

overlay 模式实现

  • VXLAN 隧道:UDP 4789 端口,跨主机封装 L2 帧
  • Swarm 内置 K/V 存储:etcd 同步集群状态
  • vxlan-id 24 位,理论 1600 万虚拟网络
  • 性能损失 10-15%(封装开销) vs macvlan 0 损失
Chapter 05

5 种模式性能对比

  • bridge:性能中等,网络隔离,适合开发
  • host:性能最高,网络零开销,端口冲突风险
  • none:无网络,适合计算任务
  • overlay:跨主机,适合 K8s/Swarm
  • macvlan:物理网络层接入,适合需要外部 L2 访问
💡 性能调优

桥接模式 MTU 1450(VXLAN 头部占 50 字节),避免分片
