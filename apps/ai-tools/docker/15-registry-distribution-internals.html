Chapter 01

Registry v2 协议 5 大概念

  • Manifest:列出镜像所有层与配置,JSON 格式
  • Blob:实际数据层,按 digest 寻址(sha256)
  • Tag:可变标签,docker push 写入
  • Digest:不可变内容寻址,sha256:abc123
  • Repository:相同名称的 tag 集合
Chapter 02

OCI Distribution Spec

  • specs.opencontainers.org/distribution-spec/
  • Pull/Push API 标准化,镜像格式不再依赖 Docker 私有协议
  • 镜像由 manifest + config + layers 组成
  • Helm chart 也基于相同 spec 实现 OCI artifact
Chapter 03

镜像层与 Tag 关系

  • tag → digest → manifest → layers
  • 同一 digest 可对应多个 tag(共享层)
  • 层按 digest 去重,digest 即 sha256 不可变
  • 多架构镜像:1 个 tag → 多个 manifest → 不同架构 layers
Chapter 04

主流仓库对比

  • Docker Hub:官方,免费私有仓库限制 1 个
  • Harbor:开源企业级,RBAC + 漏洞扫描 + 镜像复制
  • Quay:Red Hat 出品,Build trigger + Clair 扫描
  • AWS ECR / GCP GCR / Azure ACR:云厂商托管,深度集成
  • registry:2.8+ 官方轻量级,适合自建小型仓库
Chapter 05

镜像同步与复制

  • Harbor 跨实例同步:push-based/pull-based 双向
  • Skopeo 工具:不下载镜像直接复制(skopeo copy)
  • CRIU 实时迁移:几乎零停机跨主机迁移
  • 镜像签名:cosign 签名 → OCI 验证 cosign verify
💡 选择建议

🎯 签名验证

cosign + Notary v2 是 OCI 官方签名方案,防中间人攻击
