Chapter 01

PostgreSQL 容器化 4 优势

  • ACID 强一致 + MVCC 并发控制
  • 丰富扩展:PostGIS(GIS) / TimescaleDB(时序) / pgvector(AI 向量)
  • WAL 预写日志:PITR 任意时间点恢复
  • 逻辑复制:CDC + 跨版本订阅 + 选择性同步
  • 流复制:异步/同步两种模式,平衡性能与一致性
Chapter 02

Dockerfile 与初始化

  • postgres:15-alpine 基础镜像,100MB
  • /docker-entrypoint-initdb.d/ 目录挂载 init.sql 自动执行
  • POSTGRES_USER / POSTGRES_PASSWORD / POSTGRES_DB 环境变量自动建库
  • initdb -D /var/lib/postgresql/data 初始化
  • pg_hba.conf 配置客户端认证方式
Chapter 03

主从流复制部署

  • pg_basebackup -D /backup -Ft -Xs -P 创建基础备份
  • master 配 postgresql.conf:wal_level=replica + max_wal_senders=3
  • slave 恢复后建 recovery.conf:standby_mode = on + primary_conninfo
  • pg_is_in_recovery() 验证 slave 角色
  • pg_last_wal_replay_lsn() 检查复制延迟
Chapter 04

PITR 时间点恢复

  • archive_mode = on + archive_command 归档 WAL 到 OSS/S3
  • restore_command 从归档恢复 WAL
  • recovery_target_time = '2026-01-01 10:00:00' 指定恢复时间
  • recovery.conf 配 pause_at_recovery_target = true 验证后再 promote
  • PITR 可恢复任意误操作,误删数据找回归档 + binlog
Chapter 05

AI 时代新特性:pgvector

  • pgvector 扩展:存储高维向量,实现语义搜索
  • CREATE EXTENSION vector 启用
  • ivfflat 索引:基于向量近邻搜索,O(log n)
  • hnsw 索引:基于图算法,更快但内存占用高
  • 应用:ChatGPT 知识库 RAG 检索,Embedding + 向量搜索

🔄 5 步标准操作流程

  1. 主库开 WAL 复制 → 启动容器或检查环境
