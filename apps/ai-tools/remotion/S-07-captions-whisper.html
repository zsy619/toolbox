Chapter 01

三个相关包

Chapter 02

导入已有 SRT 字幕

bash
npx remotion add @remotion/captions

解析标准 .srt 文件:

tsx
import { useState, useEffect, useCallback } from 'react';
import { staticFile, useDelayRender } from 'remotion';
import { parseSrt, type Caption } from '@remotion/captions';

const { delayRender, continueRender, cancelRender } = useDelayRender();
const [captions, setCaptions] = useState<Caption[] | null>(null);
const [handle] = useState(() => delayRender());

const fetchCaptions = useCallback(async () => {
  try {
    const r = await fetch(staticFile('subtitles.srt'));
    const text = await r.text();
    setCaptions(parseSrt({ input: text }).captions);
    continueRender(handle);
  } catch (e) { cancelRender(e); }
}, [handle]);

useEffect(() => { fetchCaptions(); }, [fetchCaptions]);
if (!captions) return null;
Chapter 03

OpenAI Whisper API 转录

bash
npm i @remotion/openai-whisper @remotion/captions
ts
import { generateTranscript } from '@remotion/openai-whisper';
import { openAiWhisperApiToCaptions } from '@remotion/openai-whisper';

const transcript = await generateTranscript({
  apiKey: process.env.OPENAI_API_KEY!,
  audioUrl: 'https://example.com/speech.mp3',
  language: 'en',
  timestampGranularities: ['word'],  // 单词级时间戳
});

const { captions } = openAiWhisperApiToCaptions({ transcription: transcript });
Chapter 04

浏览器内 Whisper(零 API 成本)

bash
npx remotion add @remotion/whisper-web

适合隐私敏感场景(用户语音不外传)与开发调试:

tsx
import { transcribe } from '@remotion/whisper-web';

const result = await transcribe({
  model: 'tiny.en',  // tiny/base/small/medium
  audioBuffer,        // 来自 AudioContext.decodeAudioData
  language: 'en',
});
⚠️

首次加载需下载约 75MB(tiny)~ 1.5GB(medium)WASM 模型,适合开发或一次性任务,生产建议用云端 API。

Chapter 05

TikTok 风格高亮字幕

使用 createTikTokStyleCaptions 把 caption 切分为短页:

tsx
import { createTikTokStyleCaptions, type TikTokPage } from '@remotion/captions';

const { pages } = useMemo(() => createTikTokStyleCaptions({
  captions,
  combineTokensWithinMilliseconds: 1200,  // 每 1.2 秒换页
}), [captions]);

渲染并高亮当前单词:

tsx
const frame = useCurrentFrame();
const { fps } = useVideoConfig();
const t = page.startMs + (frame / fps) * 1000;

return (
  <div style={{ fontSize: 80, whiteSpace: 'pre' }}>
    {page.tokens.map(token => (
      <span style={{ color: token.fromMs <= t && t < token.toMs ? '#39E508' : 'white' }}>
        {token.text}
      </span>
    ))}
  </div>
);
