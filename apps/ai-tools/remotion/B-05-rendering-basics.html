Chapter 01

四大核心命令

命令作用典型场景
npx remotion studio启动交互预览开发调试、热更新
npx remotion render导出 MP4 视频生成最终视频文件

npx remotion compositions列出已注册的视频检查 Composition 状态
Chapter 02

render 命令详解

最常用的命令,完整签名:

npx remotion render <composition-id> <output-file> [options]

常用 options:

# 并发数(默认 CPU 核心数的一半)
npx remotion render HelloWorld out/hello.mp4 --concurrency=4

# 输出质量(0-100,默认 80)
npx remotion render HelloWorld out/hello.mp4 --quality=90

# 指定编码格式(支持 mp4 / webm / mov)
npx remotion render HelloWorld out/hello.webm

# 自定义 bundle 路径(适合 CI)
npx remotion render HelloWorld out/hello.mp4 --bundle=build

# 限制帧率(快速预览)
npx remotion render HelloWorld out/preview.mp4 --fps=15
Chapter 03

still 命令:截取单帧

导出特定帧的 PNG/JPG,常用于封面图:

# 截取第 75 帧
npx remotion still HelloWorld out/cover.png --frame=75

# 输出 JPG
npx remotion still HelloWorld out/thumb.jpg --frame=0
Chapter 04

渲染流程:Bundle + 帧渲染 + 合流

render 内部执行 3 个阶段:

  1. Bundle:Webpack 打包你的 React 代码到 build/ 目录
  2. 帧渲染:Puppeteer 打开每个帧对应的 HTML 截图
  3. 合流:FFmpeg 把所有帧合并为 MP4
⚡

--concurrency 增大可以并行渲染多帧,但每个 Puppeteer 实例约耗 300MB 内存,需根据机器配置调整。

Chapter 05

remotion.config.ts 常用配置

在项目根目录的 remotion.config.ts 中持久化配置:

import { Config } from '@remotion/cli/config';

Config.setVideoImageFormat('jpeg');         // 帧截图用 jpeg(更快)
Config.setConcurrency(4);                   // 默认并发
Config.setEntryPoint('src/index.ts');      // 入口文件
Config.setCachingEnabled(true);             // 启用 bundle 缓存
Chapter 06

常见问题

⚠️

Q: 渲染卡在 bundle 阶段?
A: 检查 Node.js 版本是否 >= 18,或删除 build/ 目录后重试。

⚠️

Q: 内存不足崩溃?
A: 降低 --concurrency;大视频可拆为多个 Composition 单独渲染再拼接。

Chapter 07

frameRange:精确帧范围渲染

Remotion 4.0 起,渲染指定帧范围替代了已废弃的 <Clipper> 组件:

bash
# CLI:只渲染第 100-199 帧
npx remotion render Video out.mp4 --frame-range=100-199

# 从指定帧到结尾
npx remotion render Video out.mp4 --frame-range=100-
ts
import { renderMedia } from '@remotion/renderer';

await renderMedia({
  composition, serveUrl, outputLocation: 'out.mp4',
  frameRange: [100, 199],  // [start, end] 或 [start, null]
});
⚠️

<Clipper> 组件已在 v4.0.228 删除,因性能反而比完整渲染慢。务必迁移到 frameRange。

SSR API 全集

Node.js 端 API 完整列表:

API作用

Chapter 09

@remotion/player 嵌入到 React App

Player 让你把 Remotion 视频嵌入到任何 React 应用(Next.js/Vite/CRA/Remix),无需重新渲染即可自定义 props 实时预览:

tsx
import { Player } from '@remotion/player';
import { MyVideo } from './remotion/MyVideo';

<Player
  component={MyVideo}
  durationInFrames={120}
  compositionWidth={1920}
  compositionHeight={1080}
  fps={30}
  controls  // 显示原生控件
  loop      // 循环播放
  autoPlay  // 自动播放
  inputProps={{ name: 'World' }}  // 注入 props
/>

常用回调:

tsx
import { useRef } from 'react';
import { Player, PlayerRef } from '@remotion/player';

const ref = useRef<PlayerRef>(null);
ref.current?.seekTo(60);  // 跳到第 60 帧
ref.current?.play();
ref.current?.pause();
ref.current?.addEventListener('pause', () => console.log('paused'));

自定义控件用 renderPlayPauseButton / renderFullscreenButton / renderSeekBar 等,完全替换默认 UI。CSS 变量可定制全部样式:--remotion-seek-bar-progress-color、--remotion-button-hover-color 等。

Chapter 10

<Thumbnail> 静态图组件

为 Composition 生成可拖拽的缩略图,常用于时间轴预览:

tsx
import { Thumbnail } from '@remotion/player';

<Thumbnail
  component={MyVideo}
  frameToDisplay={30}        // 显示第 30 帧
  durationInFrames={120}
  compositionWidth={1920}
  compositionHeight={1080}
  fps={30}
/>
