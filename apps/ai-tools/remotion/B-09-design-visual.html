Chapter 01

@remotion/paths SVG 路径工具

10+ 函数操作 SVG 路径:

函数作用
getLength(path)路径总长度
getPointOnPath(progress, path)沿路径某点 (x,y)
getSubpaths(path)拆分多段路径
getBoundingBox(path)包围盒
evolvePath(progress, path)笔画动画
interpolatePath(progress, a, b)形态插值(Morph)
translatePath(path, x, y)平移
scalePath(path, factor)缩放
reversePath(path)反向
resetPath(path)重置 M 命令

Chapter 03

@remotion/layout-utils 排版工具

函数作用
fitText({...})字体大小自适应容器宽度
measureText({...})测量文字尺寸
fillTextBox({...})多行自动排版
fitTextOnNLines({...})N 行内自适应字号
tsx
import { fitText, measureText } from '@remotion/layout-utils';

const { fontSize } = fitText({
  text: 'Long Headline',
  withinWidth: 800,
  fontFamily: 'Inter',
  fontWeight: 'bold',
  textTransform: 'uppercase',
});

const { width, height } = measureText({ text, fontSize: 40 });

const { fontFamily, waitUntilDone } = loadFont();

Chapter 06

@remotion/three 3D 集成

tsx
import { ThreeCanvas, useVideoTexture } from '@remotion/three';
import { useRef } from 'react';
import { useCurrentFrame, useVideoConfig, staticFile } from 'remotion';

const Cube: React.FC = () => {
  const ref = useRef<THREE.Mesh>(null);
  const frame = useCurrentFrame();
  const texture = useVideoTexture(staticFile('clip.mp4'));

  useEffect(() => { if (ref.current) ref.current.rotation.y = frame / 30; }, [frame]);
  return <mesh ref={ref}><boxGeometry /><meshBasicMaterial map={texture} /></mesh>;
};

<ThreeCanvas width={1920} height={1080}>
  <ambientLight />
  <Cube />
</ThreeCanvas>
