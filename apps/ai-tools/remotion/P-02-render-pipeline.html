Chapter 01

管线总览

Remotion 渲染的 6 步管线:

  1. Bundle:Webpack 打包用户代码
  2. Plan:计算元数据 (calculateMetadata)
  3. Chunk:将 N 帧切分为 M 个任务
  4. Render:每个任务启动 Puppeteer 渲染一组帧
  5. Stitch:FFmpeg 合并所有帧 + 音频
  6. Cleanup:清理临时文件
Chapter 02

任务切片策略

默认每任务渲染 1 帧。Lambda 模式可一次渲染多帧:

# 本地:每任务 1 帧
npx remotion render Video out.mp4 --concurrency=4
# 300 帧 = 300 个任务 → 4 并发 → 75 批次

# Lambda:每任务 60 帧
npx remotion lambda render Video out.mp4 --frames-per-lambda=60
# 300 帧 = 5 个任务 → 5 Lambda 并行

Lambda 模式显著减少冷启动开销。

Chapter 03

单帧渲染时序

每个帧的渲染需要 5 步:

1. await page.goto(bundleUrl)            // 加载 HTML
2. await page.waitForFunction()          // 等待 delayRender 就绪
3. await page.evaluate(setFrame, n)     // 注入当前帧号
4. await page.screenshot({clip, type})  // 截该帧
5. await fs.writeFile('frame-NNN.jpeg') // 写盘

典型一帧 50-200ms,瓶颈在 screenshot 阶段。

Chapter 04

错误重试与降级

Remotion 自动处理两类错误:

  • delayRender 超时:该帧渲染失败,标记为 retry
  • Chrome 崩溃:重启 Puppeteer,重新加载 bundle

可配置:

Config.setMaxRetries(3);                       // 最大重试次数
Config.setDelayRenderTimeoutInMilliseconds(60000);  // 60 秒
Chapter 05

状态机

init → bundle → plan → chunking →
  rendering[concurrency] → stitching → cleanup → done
       ↓
     failed (retry / abort)

Lambda 模式:每帧有独立状态,失败帧可单独重试。

Chapter 07

HTML-in-canvas(v4.0.455+)

Remotion 4.0.455 起支持 HTML-in-canvas 浏览器新 API,可将实时 DOM 节点绘制到 canvas,再用 Canvas 2D/WebGL/WebGPU 后处理:

tsx
import { HtmlInCanvas, type HtmlInCanvasOnPaint } from 'remotion';

const onPaint: HtmlInCanvasOnPaint = ({ canvas, elementImage }) => {
  const ctx = canvas.getContext('2d');
  ctx.filter = 'blur(8px)';
  ctx.drawElementImage(elementImage, 0, 0);
};

<HtmlInCanvas width={1920} height={1080} onPaint={onPaint}>
  <div style={{ fontSize: 80 }}>Remotion</div>
</HtmlInCanvas>

渲染时无需特殊配置,Remotion 已编译专用 Chrome 并默认开启该 flag(chrome://flags/#canvas-draw-element)。WebGL 着色器需加 --gl=angle。

💡

HTML-in-canvas 把视频编辑器的 canvas 效果(模糊、色彩调整、混合模式)带入 Remotion,极大拓展视觉效果。

Chapter 08

WebGL 着色器渲染

Remotion 通过 HTML5 Canvas 渲染 WebGL。关键:所有动画必须基于 useCurrentFrame() 才能保证帧精确。

tsx
const frame = useCurrentFrame();
const { fps, width, height } = useVideoConfig();
const time = frame / fps;  // 标准化为秒

useEffect(() => {
  const gl = canvasRef.current!.getContext('webgl')!;
  const program = createProgram(gl, VS, FS);
  // 每帧更新 uniform
  gl.uniform1f(timeLoc, time);
  gl.uniform2f(resLoc, width, height);
  gl.drawArrays(gl.TRIANGLE_STRIP, 0, 4);
}, [time]);

渲染时 必须加 --gl=angle:

bash
npx remotion render ShaderVideo out.mp4 --gl=angle

否则无头浏览器可能没有 WebGL context。
