B-03 Remotion 第一个视频 B 基础

从零开始构建你的第一个程序化视频:Hello World 完整流程。

阅读 ~ 12 分钟

Chapter 01

目标:5 秒淡入淡出标题

我们要做一个 5 秒的视频,中央显示 "Hello Remotion" 文字,带淡入淡出效果。涉及 4 个步骤:

  1. 编写视频组件 MyVideo.tsx
  2. 在 Root.tsx 中注册 Composition
  3. 启动 Studio 调试
  4. 渲染输出 MP4
Chapter 02

编写视频组件

创建 src/MyVideo.tsx:

import { AbsoluteFill, useCurrentFrame, useVideoConfig, interpolate } from 'remotion';

export const MyVideo: React.FC = () => {
  const frame = useCurrentFrame();
  const { durationInFrames } = useVideoConfig();

  // 淡入 0-30 帧,保持 30-120 帧,淡出 120-150 帧
  const opacity = interpolate(
    frame,
    [0, 30, 120, 150],
    [0, 1, 1, 0],
    { extrapolateRight: 'clamp' }
  );

  // 标题从下方滑入
  const translateY = interpolate(frame, [0, 30], [40, 0], {
    extrapolateRight: 'clamp',
  });

  return (
    <AbsoluteFill style={{ backgroundColor: '#0a1a2a' }}>
      <h1 style={{
        position: 'absolute',
        top: '50%', left: '50%',
        transform: `translate(-50%, calc(-50% + ${translateY}px))`,
        opacity,
        color: '#2496ED',
        fontSize: 120,
        fontWeight: 800,
      }}>
        Hello Remotion
      </h1>
    </AbsoluteFill>
  );
};
Chapter 03

注册 Composition

在 src/Root.tsx 中挂载组件:

import { Composition } from 'remotion';
import { MyVideo } from './MyVideo';

export const RemotionRoot: React.FC = () => {
  return (
    <>
      <Composition
        id="HelloWorld"
        component={MyVideo}
        durationInFrames={150}    // 5 秒 × 30 fps
        fps={30}
        width={1920}
        height={1080}
      />
    </>
  );
};
Chapter 04

Studio 实时调试

运行 npm start 打开 http://localhost:3000,你会看到:

  • 左侧 Composition 列表(目前只有 HelloWorld)
  • 中间视频预览,时间轴可拖动
  • 右侧属性面板,可临时改 width/fps

改代码会秒级热更新。每次保存 React 组件,Studio 自动重新渲染当前帧。

🎬

Studio 是 Remotion 杀手锏:在浏览器中精确渲染每一帧,所见即所得,远比 After Effects 的预览器直观。

Chapter 05

渲染输出 MP4

Studio 调试满意后,导出正式视频:

npx remotion render HelloWorld out/hello.mp4

过程会显示进度条,大约 10-30 秒完成。视频保存在 out/hello.mp4。

其他常用选项:

npx remotion render HelloWorld out/hello.mp4 --concurrency=4
npx remotion render HelloWorld out/hello.mp4 --quality=80
npx remotion still HelloWorld out/cover.png --frame=75    # 单帧截图
Chapter 06

Composition 生命周期

理解 Composition 渲染时,React 树是这样构建的:

RemotionRoot (静态,只渲染一次)
  └─ Composition 元数据(width, fps 等)
       └─ MyVideo() (为每一帧重新调用)
            ├─ useCurrentFrame()  // 当前帧
            ├─ useVideoConfig()   // 视频元数据
            └─ return JSX

每渲染一帧,Remotion 调用一次你的组件函数。这就是为什么 useCurrentFrame 能拿到当前帧号——它是 React Hook 调用的上下文。

Remotion 官方文档(2025)、Remotion Studio 指南、interpolate API 参考
Chapter 07

视频参数与编解码器

Composition 核心参数决定最终视频规格:

参数说明常见值
width × height分辨率1920×1080 / 1080×1920 / 1080×1080
fps帧率30 / 60 / 24
durationInFrames总帧数fps × 秒数
outputFormat封装格式mp4 / webm / gif / mov
codec编码器h264 / h265 / vp8 / vp9 / prores
💡

社交平台兼容性最佳组合:mp4 + h264 + AAC 音频 + 30fps。Apple 设备可选 prores 422 HQ 保留更多色彩细节。
