Chapter 01

Three.js 3D 集成

完整 3D 地球旋转动画:

import { useEffect, useRef } from 'react';
import { useCurrentFrame, AbsoluteFill } from 'remotion';
import * as THREE from 'three';

const Earth: React.FC = () => {
  const ref = useRef<HTMLDivElement>(null);
  const engine = useRef<{ scene: any; camera: any; renderer: any; earth: any }>({} as any);
  const frame = useCurrentFrame();

  useEffect(() => {
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(60, 16 / 9, 0.1, 1000);
    camera.position.z = 3;
    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(1920, 1080);
    ref.current!.appendChild(renderer.domElement);
    const earth = new THREE.Mesh(
      new THREE.SphereGeometry(1, 64, 64),
      new THREE.MeshPhongMaterial({ color: 0x2496ed })
    );
    scene.add(earth);
    engine.current = { scene, camera, renderer, earth };
    return () => renderer.dispose();
  }, []);

  useEffect(() => {
    const { earth, scene, camera, renderer } = engine.current;
    earth.rotation.y = frame * 0.02;
    renderer.render(scene, camera);
  }, [frame]);

  return <AbsoluteFill ref={ref} />;
};
Chapter 02

Lottie 动画渲染

设计师在 After Effects 用 Bodymovin 导出 JSON,在 Remotion 中用 lottie-web 渲染:

import { useEffect, useRef } from 'react';
import { useCurrentFrame, staticFile } from 'remotion';
import lottie from 'lottie-web';

const LottieBox: React.FC = () => {
  const ref = useRef<HTMLDivElement>(null);
  const anim = useRef<any>();
  const frame = useCurrentFrame();

  useEffect(() => {
    anim.current = lottie.loadAnimation({
      container: ref.current!,
      renderer: 'svg',
      loop: false,
      autoplay: false,
      path: staticFile('logo.json'),
    });
    return () => anim.current?.destroy();
  }, []);

  useEffect(() => {
    anim.current?.goToAndStop(frame, true);
  }, [frame]);

  return <div ref={ref} style={{ width: 400, height: 400 }} />;
};
Chapter 03

Whisper 字幕生成

OpenAI Whisper 离线 ASR 引擎,支持 99 种语言:

pip install openai-whisper
whisper voiceover.mp3 --language Chinese --output_format srt

输出 SRT 字幕文件,在 Studio 中用 getStaticFiles() 读取:

import { staticFile } from 'remotion';
import { useEffect, useState } from 'react';

const SrtParser = require('srt-parser-2');
const [subs, setSubs] = useState([]);

useEffect(() => {
  fetch(staticFile('subs.srt')).then(r => r.text()).then(srt => {
    setSubs(new SrtParser().fromSrt(srt));
  });
}, []);
Chapter 04

ffmpeg-wasm:浏览器内剪辑

用 wasm 版的 ffmpeg 在浏览器中处理视频,适合需要用户上传后立即预览:

import { FFmpeg } from '@ffmpeg/ffmpeg';
import { useEffect, useRef } from 'react';

const ffmpeg = useRef(new FFmpeg());

useEffect(() => {
  ffmpeg.current.load();
}, []);

const trim = async (file: File, start: number, end: number) => {
  await ffmpeg.current.writeFile('in.mp4', await file.arrayBuffer());
  await ffmpeg.current.exec(['-ss', String(start), '-to', String(end), '-i', 'in.mp4', 'out.mp4']);
  const data = await ffmpeg.current.readFile('out.mp4');
  return new Blob([data], { type: 'video/mp4' });
};

Chapter 06

@remotion/transitions 场景转场

v4.0.53+ 引入 <TransitionSeries>,在两个场景间添加转场效果:

bash
npx remotion add @remotion/transitions
tsx
import { TransitionSeries, linearTiming } from '@remotion/transitions';
import { fade } from '@remotion/transitions/fade';
import { slide } from '@remotion/transitions/slide';

<TransitionSeries>
  <TransitionSeries.Sequence durationInFrames={60}>
    <SceneA />
  </TransitionSeries.Sequence>
  <TransitionSeries.Transition
    timing={linearTiming({ durationInFrames: 30 })}
    presentation={fade()}
  />
  <TransitionSeries.Sequence durationInFrames={60}>
    <SceneB />
  </TransitionSeries.Sequence>
</TransitionSeries>

内置 7 种转场:fade / slide / wipe / flip / clockWipe / iris / zoomBlur。

import { TransitionSeries, linearTiming, springTiming } from '@remotion/transitions';

import { wipe } from '@remotion/transitions/wipe';
import { flip } from '@remotion/transitions/flip';
import { clockWipe } from '@remotion/transitions/clock-wipe';
import { iris } from '@remotion/transitions/iris';
import { zoomBlur } from '@remotion/transitions/zoom-blur';

  <TransitionSeries.Sequence durationInFrames={60}>
    <SceneA />
  </TransitionSeries.Sequence>
  <TransitionSeries.Transition
    presentation={fade()} timing={linearTiming({ durationInFrames: 15 })} />

Chapter 09

@remotion/light-leaks 光漏效果

v4.0.415+ 官方光漏叠加包,基于 WebGL,8 种预设:

tsx
import { LightLeak } from '@remotion/light-leaks';

<AbsoluteFill>
  <YourContent />
  <LightLeak
    seed={42}                   // 随机种子
    durationInFrames={60}       // 持续帧
    hueShift={0}                // 色相偏移 (-180~180)
    intensity={0.5}             // 强度 0~1
  />
</AbsoluteFill>

前 1/2 帧渐入,后 1/2 帧渐出,适合场景切换的瞬间渲染。
