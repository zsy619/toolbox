Chapter 01

Remotion 桥接模式

第三方库大多有命令式 API(new Renderer, 然后调用方法),Remotion 是声明式 React。桥接的关键模式:

  1. useEffect 初始化:首次渲染时创建对象
  2. useRef 保存实例:跨帧保持同一对象
  3. useCurrentFrame 驱动:每帧更新对象状态
  4. useEffect 清理:组件卸载时释放资源
Chapter 02

Three.js:3D 场景

完整 Three.js 组件模式:

import { useRef, useEffect } from 'react';
import { useCurrentFrame, AbsoluteFill } from 'remotion';
import * as THREE from 'three';

const Scene3D: React.FC = () => {
  const mountRef = useRef<HTMLDivElement>(null);
  const stateRef = useRef<{ scene?: any; camera?: any; renderer?: any }>({});
  const frame = useCurrentFrame();

  useEffect(() => {
    const w = 1920, h = 1080;
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(75, w / h, 0.1, 1000);
    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(w, h);
    mountRef.current!.appendChild(renderer.domElement);
    stateRef.current = { scene, camera, renderer };
    return () => renderer.dispose();
  }, []);

  useEffect(() => {
    const { scene, camera, renderer } = stateRef.current;
    if (!scene) return;
    scene.rotation.y = frame * 0.01;
    renderer.render(scene, camera);
  }, [frame]);

  return <AbsoluteFill ref={mountRef} />;
};
⚠️

Three.js 渲染需要 Puppeteer 启用 WebGL,Remotion 默认配置已包含。需 --gl=angle-egl(Linux) 或 macOS/Windows 原生 WebGL。

Chapter 03

Lottie:Bodymovin 动画

用 lottie-web 渲染 After Effects 导出的 JSON 动画:

import { useEffect, useRef } from 'react';
import lottie from 'lottie-web';
import { useCurrentFrame, staticFile } from 'remotion';

const LottieAnim: React.FC = () => {
  const ref = useRef<HTMLDivElement>(null);
  const animRef = useRef<any>();
  const frame = useCurrentFrame();

  useEffect(() => {
    animRef.current = lottie.loadAnimation({
      container: ref.current!,
      renderer: 'svg',
      loop: false,
      autoplay: false,
      path: staticFile('anim.json'),
    });
    return () => animRef.current?.destroy();
  }, []);

  useEffect(() => {
    if (animRef.current) animRef.current.goToAndStop(frame, true);
  }, [frame]);

  return <div ref={ref} style={{ width: '100%', height: '100%' }} />;
};
Chapter 04

SVG 动态生成

用 React JSX 直接写 SVG,Remotion 会自动序列化:

const ProgressRing: React.FC<{ progress: number }> = ({ progress }) => {
  const r = 80;
  const c = 2 * Math.PI * r;
  return (
    <svg width="200" height="200">
      <circle cx="100" cy="100" r={r} stroke="#eef3f9" strokeWidth="10" fill="none" />
      <circle cx="100" cy="100" r={r}
        stroke="#2496ED" strokeWidth="10" fill="none"
        strokeDasharray={c} strokeDashoffset={c * (1 - progress)}
        transform="rotate(-90 100 100)" />
    </svg>
  );
};
Chapter 05

Canvas 2D 离屏绘制

用 canvas + useEffect 逐帧绘制:

const CanvasAnim: React.FC = () => {
  const ref = useRef<HTMLCanvasElement>(null);
  const frame = useCurrentFrame();

  useEffect(() => {
    const ctx = ref.current!.getContext('2d')!;
    ctx.fillStyle = 'white';
    ctx.fillRect(0, 0, 1920, 1080);
    ctx.fillStyle = '#2496ED';
    ctx.beginPath();
    ctx.arc(960, 540, 100 + frame * 5, 0, Math.PI * 2);
    ctx.fill();
  }, [frame]);

  return <canvas ref={ref} width={1920} height={1080} />;
};

Chapter 08

@remotion/skia + @remotion/shapes

Skia 是 Google 2D 矢量图形库,@remotion/skia 把它集成到 React:

tsx
import { Canvas, Rect, Path, Skia } from '@remotion/skia';
import { Circle, Triangle, Rect as R } from '@remotion/shapes';

<Canvas width={1920} height={1080}>
  <R width={200} height={200} fill="cyan" />
  <Circle radius={100} fill="red" />
</Canvas>

vs SVG:Skia 性能更好(GPU 加速),SVG 兼容性更广;vs Canvas 2D:Skia 提供声明式 API,Canvas 2D 命令式。

Chapter 09

@remotion/rive + zod-types + layout-utils

三个高阶包:

bash
npx remotion add @remotion/rive @remotion/zod-types @remotion/layout-utils

// Rive 矢量动画(state machine 状态机)
import { Rive } from '@remotion/rive';
<Rive src={riveFile} stateMachine="default" input={true} />

<Composition schema={Schema} calculateMetadata={...} />

// 布局工具:fitText / measureText / 9-slice

Chapter 10

@remotion/paths SVG 路径工具

函数作用
getPointOnPath(progress, path)沿路径上某点坐标
getLength(path)路径总长度
evolvePath(progress, path)SVG 路径动画展开
interpolatePath(progress, a, b)两条路径插值(Morph)
translatePath(path, x, y)平移
reversePath(path)反向
tsx
// 让小球沿贝塞尔曲线动
const p = getPointOnPath(progress, 'M 0 0 C 100 200 300 200 400 0');
<Circle cx={p.x} cy={p.y} r={20} fill="red" />

// 笔画绘制动画
const { strokeDasharray, strokeDashoffset } = evolvePath(progress, path);
<path d={path} strokeDasharray={strokeDasharray} strokeDashoffset={strokeDashoffset} />

Chapter 12

@remotion/layout-utils 排版工具

tsx
import { fitText, measureText, fillTextBox, fitTextOnNLines } from '@remotion/layout-utils';

// 字体大小自适应宽度
const { fontSize } = fitText({
  text, withinWidth: 600, fontFamily: 'Inter', fontWeight: 'bold',
});

// 测量文字
const { width, height } = measureText({ text, fontSize: 40, fontFamily: 'Inter' });

// 多行排版
const lines = fillTextBox({ text, maxLines: 3, fontSize, withinWidth });

配合 useMeasureText(必须用 @remotion/google-fonts 的 loadFont().waitUntilDone())。
