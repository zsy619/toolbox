Chapter 02

FAQ 20+ 常见问题

Q:Remotion 能用 Tailwind v4 吗?

可以,装 @remotion/tailwind-v4(v4+ 推荐)。旧版用 @remotion/tailwind(v3 PostCSS)。

Q:为什么 Lambda 渲染比本地慢?

Lambda 用临时无头实例,冷启动约 5-15s。bundle 复用 + 多 Lambda 并行可显著加速。

Q:Bundle 太大怎么办?

1) tree-shake;2) webpackIgnore 标记 Node-only 包;3) 大依赖动态 import;4) 字体子集化;5) 大图不放源码。

Q:为什么 Player 控件没显示?

默认 controls={false},手动设 controls 或 showPlaybackRateControl。

Q:声音出不来?

1) <Html5Audio muted /> 默认静音;2) 视频含多音轨用 soundtrackAudio;3) 用 getAudioData 调试。

Q:How to support iOS Safari?

1) 用 OffthreadVideo 替代 Html5Video;2) 视频用 h264 + AAC;3) Player 关闭 autoplay。

Q:Remotion 是开源的吗?

remotion 主包 MIT 许可,@remotion/lambda 等少数商业包需付费订阅(详见 license.md)。

Q:How to 加速打包?

用 Rspack 替代 Webpack:--experimental-rspack 或在 config 中设置,加速 3-5x。

Q:AWS Lambda 限制?

最大 10GB 内存、15min 超时、6TB 临时磁盘。Remotion 默认开 --memory=2048。

Q:Chinese text 乱码?

装 fonts-noto-color-emoji + 中文字体(如 Source Han Sans),Docker 镜像中包含 apt-get install fonts-noto-cjk。

Q:Studio 中断网怎么办?

Studio 客户端是纯静态 + Webpack HMR,断网会失去 HMR;重启后 --webpack-poll=2000 适配远程磁盘。

Q:How to 防字体闪屏?

loadFont().waitUntilDone() 阻塞渲染;或 document.fonts.ready。

Q:如何用 Remotion 做字幕?

v4.0.327+ 用 @remotion/captions 的 createTikTokStyleCaptions;旧方案用 parseSrt() + 自渲染。

Q:Linux 单进程慢?

v4.0.137+ 默认 enableMultiProcessOnLinux: true;旧版需手动开启。

Q:How to 上千条视频批渲染?

Lambda 批处理:先用 renderMediaOnLambda 渲染一条,后续用 framesPerLambda=200 拆任务并行。

Q:HLS 流支持?

<Video> (@remotion/media) 完整支持;.m3u8 直接放 src;Chrome 142+ 可 SSR 部分 HLS。

Q:How to 优化 bundle?

用 webpack-bundle-analyzer 找出大模块,通常 Three.js/Lottie 体积最大。

Q:Studio 不能打开?

1) 关代理;2) 关防火墙;3) --no-open + 手动打开 http://localhost:3000。

Q:Remotion 跑在 Edge?

Player 可在 Edge 运行;SSR/Studio 不行(需要 Puppeteer + 大量 Node API)。

Q:How to 用 GPU?

需要手动配置 Chrome 启动参数 --use-gl=egl;Lambda/GCP Cloud Run 不直接支持。

Chapter 05

性能关键:enableMultiProcessOnLinux

v4.0.137+ 默认开启 Linux 多进程 Chrome,旧版需手动:

ts
await renderMedia({
  composition, serveUrl, outputLocation,
  chromiumOptions: { enableMultiProcessOnLinux: true },
  concurrency: '100%',  // 用满所有核
});

提速效果:同机器从 4 分钟降到 1 分钟(30s 视频 1080p)。
