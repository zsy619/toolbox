B-02 Remotion 核心概念 B 基础

Composition / Sequence / Series / Frame / FPS —— 视频数据结构化的四大基石。

阅读 ~ 10 分钟
前置 B-01 安装
类型 入门
Chapter 01

Composition:视频的元数据

<Composition> 是 Remotion 的根节点,描述一个"视频是什么":

  • id:Composition 唯一标识,渲染时通过此名选择
  • component:要渲染的 React 组件
  • durationInFrames:总帧数(必填)
  • fps:帧率,默认 30
  • width/height:分辨率,默认 1920×1080
<Composition
  id="MyVideo"
  component={MyVideo}
  durationInFrames={300}  // 10 秒,30 fps
  fps={30}
  width={1920}
  height={1080}
/>
Chapter 02

Sequence:时间轴切片

<Sequence> 控制子组件在视频中出现的时间段:

<Sequence from={30} durationInFrames={60}>
  <Title />
</Sequence>

该片段从第 30 帧开始,持续 60 帧(2 秒)。Sequence 内的 useCurrentFrame() 从 0 重新计数,便于嵌套时间轴。

💡

Sequence 嵌套 Sequence 可以构建层级时间轴,内层时间从外层的"经过帧数"开始重新计算,极大简化复杂动画。

Chapter 03

Series:顺序拼接场景

<Series> 是顺序播放多个 Sequence 的语法糖:

<Series>
  <Series.Sequence durationInFrames={90}>
    <Intro />
  </Series.Sequence>
  <Series.Sequence durationInFrames={120}>
    <Main />
  </Series.Sequence>
  <Series.Sequence durationInFrames={60}>
    <Outro />
  </Series.Sequence>
</Series>

自动累加 from,无需手动计算时间偏移。

Chapter 04

Frame 与 FPS 时间模型

Remotion 采用离散帧时间而非真实时间:

  • 时间单位是帧号(整数),不是毫秒
  • FPS(帧率)= 一秒播放多少帧
  • 30 fps 视频第 90 帧 = 第 3 秒

读取当前帧的方式:

import { useCurrentFrame, useVideoConfig } from 'remotion';

const frame = useCurrentFrame();         // 当前帧号(从 0 开始)
const { fps, width, height, durationInFrames } = useVideoConfig();
const timeInSeconds = frame / fps;       // 转秒
Chapter 05

布局:AbsoluteFill

视频的根元素默认是 1920×1080 的画布。子组件需要用 AbsoluteFill 绝对定位才能覆盖:

import { AbsoluteFill } from 'remotion';

<AbsoluteFill style={{ background: 'black' }}>
  <h1 style={{ position: 'absolute', top: 100, left: 100 }}>
    Hello Remotion
  </h1>
</AbsoluteFill>

组件顺序即 Z-Index 渲染顺序,后写的覆盖先写的。

Chapter 07

其它核心组件

除 Composition/Sequence/Series 外,Remotion 还提供 4 个常用容器组件:

01

<Still>:静态图,代替 Composition 表达单帧海报/封面,无 durationInFrames

02

<Folder>:在 Studio 侧边栏分组管理多个 Composition

03

<Freeze>:冻结某一帧的子组件,常用于长视频中插入定格画面

04

<Loop>:循环播放子组件 N 帧,适合 GIF 风格重复动画

tsx
<Still id="Cover" component={Cover} width={1920} height={1080} />
<Folder title="营销素材">
  <Composition id="ad-15s" ... />
  <Composition id="ad-30s" ... />
</Folder>
Chapter 08

registerRoot() 入口

项目入口文件 src/index.ts 调用 registerRoot() 注册根组件,告诉引擎从何处开始渲染:

ts
import { registerRoot } from 'remotion';
import { RemotionRoot } from './Root';
registerRoot(RemotionRoot);
💡

registerRoot() 必须在独立文件(如 index.ts)中,不要和 Root.tsx 混在一起。原因是 React Fast Refresh 会重新执行被修改的文件,而 registerRoot 应只调用一次。

Chapter 09

Easing 与数学函数

Remotion 提供 4 类数学函数驱动动画:

函数作用
interpolate(input, range, output, options?)线性插值,核心动画原语
interpolateColors(input, range, colors, options?)颜色插值,支持多种色彩空间
spring({ frame, fps, config? })弹簧物理动画
Easing.bezier(x1, y1, x2, y2)自定义贝塞尔曲线
random(name)种子化随机数(关键帧之间保持一致)
measureSpring({ ... })预计算弹簧总时长(用于序列同步)
watchStaticFile(file)监听静态文件变化,自动重渲染
prefetch(url)主动预加载资源(headers/视频/图片)
getStaticFiles()列出所有静态文件(SSR 用)

典型使用:

tsx
// 种子随机 - 不同帧/不同实例保持一致
const v = random('particle-0');  // 0~1

// 弹簧 - 物理自然动画
const t = spring({ frame, fps, config: { damping: 12, mass: 0.5 } });

// 贝塞尔 - 自定义缓动
const ease = Easing.bezier(0.25, 0.1, 0.25, 1);  // ease-out 风格
