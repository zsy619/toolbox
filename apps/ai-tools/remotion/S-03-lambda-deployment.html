S-03 Lambda 云端渲染 S 场景

AWS Lambda + S3 + CloudFront 完整部署,分钟级渲染长视频。

阅读 ~ 15 分钟
前置 A-05 性能优化
类型 场景实战
Chapter 01

Lambda 模式优势

对比本地渲染:

维度本地Lambda

Chapter 02

前置准备

在 AWS 控制台准备:

  1. IAM 角色:RemotionLambdaRole,含 S3 + Lambda + CloudWatch 权限
  2. S3 桶:remotion-bucket-xxx 存视频和 bundle
  3. AWS CLI 配置:aws configure
Chapter 03

部署函数

安装 CLI 并部署:

npm i @remotion/lambda
npx remotion lambda deploy \
  --memory=2048 \
  --disk=5120 \
  --timeout=900 \
  --region=us-east-1

返回的 functionName 后续调用要用:

# 保存函数名供后续命令使用
export REMOTION_FUNCTION_NAME=remotion-render-3y8x
export REMOTION_BUCKET=remotion-bucket-xxx
Chapter 04

部署 Bundle

把代码和静态资源上传到 S3:

npx remotion lambda sites create \
  --site-name=my-video-site \
  --bucket=$REMOTION_BUCKET

返回 siteId,后续渲染任务会引用它:

export REMOTION_SITE_ID=abc123def
Chapter 05

提交渲染任务

npx remotion lambda render \
  MyVideo \
  out/video-v1.mp4 \
  --function-name=$REMOTION_FUNCTION_NAME \
  --site-name=my-video-site \
  --frames-per-lambda=60 \
  --concurrency=10

Lambda 自动调度 10 个并发函数渲染 60 帧/任务,完成后输出到 S3 桶。

☁️

10 分钟视频每 Lambda 60 帧 = 约 10 个任务 × 60 秒 = 10 分钟,因并行实际 1-2 分钟完成。

Chapter 06

CloudFront CDN 分发

把 S3 桶接入 CloudFront,公开访问:

# 创建 CloudFront distribution,源为 S3 桶
aws cloudfront create-distribution \
  --origin-domain-name=$REMOTION_BUCKET.s3.amazonaws.com \
  --default-root-object=index.html

# 获得 CDN 域名,如 d1234.cloudfront.net
# 公开 URL:https://d1234.cloudfront.net/videos/video-v1.mp4

用户从 CDN 拉取视频,首字节延迟 < 100ms。

Chapter 07

批量与 CI/CD

生产中通常用 GitHub Actions 自动部署:

# .github/workflows/render.yml
- name: Deploy to Lambda
  run: npx remotion lambda deploy --memory=2048
- name: Render all videos
  run: |
    npx remotion lambda render VideoA out/a.mp4 --function-name=$FN
    npx remotion lambda render VideoB out/b.mp4 --function-name=$FN
AWS Lambda 文档、@remotion/lambda 官方指南、AWS CloudFront 配置

// 渲染输出到 R2(S3 兼容 API)
await renderMediaOnLambda({
