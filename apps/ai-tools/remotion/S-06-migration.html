Chapter 02

Zod schema 迁移

从无校验升级到 Zod:

// v3
type Props = { title: string };
<Composition component={MyComp} defaultProps={{ title: 'Hi' }} />

// v4
import { z } from 'zod';
const schema = z.object({ title: z.string().min(1).max(50) });
<Composition
  component={MyComp}
  schema={schema}
  defaultProps={{ title: 'Hi' }}   // 类型自动从 zod 推导
/>
💡

Zod 校验失败时 render 会拒绝执行,避免拼写错误导致线上视频失败。

Chapter 03

calculateMetadata 替换 getVideoMetadata

// v3
useEffect(() => {
  getVideoMetadata(staticFile('bg.mp4')).then(meta => {
    setDuration(meta.durationInSeconds * 30);
  });
}, []);

// v4 (Composition 级别,提前 bundle 期计算)
const calculate: CalculateMetadataFunction = async () => {
  const meta = await getVideoMetadata(staticFile('bg.mp4'));
  return { durationInFrames: Math.ceil(meta.durationInSeconds * 30), fps: 30 };
};
<Composition calculateMetadata={calculate} ... />
Chapter 04

ffmpeg 自带

v4 起 ffmpeg 二进制打包到 @remotion/renderer,无需全局安装:

// v3 需要 brew/apt 安装
// v4 自动下载
Config.setFfmpegOverrideFunction(({ args }) => args);  // 默认即可
⚠️

升级到 v4 后可移除 Dockerfile 中的 ffmpeg 安装,镜像体积减小 100MB+。

Chapter 05

Codemod 工具

Remotion 提供 codemod 自动重写部分代码:

npx remotion migrate v4 src/  # 自动转换 v3 语法到 v4

覆盖的转换:

  • getVideoMetadata → calculateMetadata
  • React.FC<Props> → Zod schema 推断
  • delayRender 用法更新
