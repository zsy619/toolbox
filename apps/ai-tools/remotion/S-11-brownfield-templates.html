Chapter 01

Brownfield 集成:加进现有项目

Remotion 4.x 可装入 Next.js / React Router 7 / Vite / CRA 等任意 React 项目:

bash
npm i --save-exact remotion@4.0.468 @remotion/cli@4.0.468
# 装在已有 Next.js 项目里
cd my-next-app
mkdir -p src/remotion

三件套文件结构:

text
src/
├── remotion/
│   ├── index.ts          # registerRoot(MyVideo)
│   ├── Root.tsx          # 列出所有 Composition
│   └── MyComp.tsx        # 单个视频组件
├── app/
└── App.tsx
Chapter 02

代码共享(Studio ↔ Player ↔ SSR)

写一次组件,3 个地方复用:Studio 预览 / Player 嵌入 / Lambda 渲染。

tsx
// remotion/MyComp.tsx
export const MyComp: React.FC<{ text: string }> = ({ text }) => (
  <AbsoluteFill>Hello {text}!</AbsoluteFill>
);

// app/page.tsx(Next.js 页面) - 嵌入 Player
import { Player } from '@remotion/player';
import { MyComp } from '@/remotion/MyComp';

<Player
  component={MyComp}
  inputProps={{ text: 'World' }}
  durationInFrames={120}
  compositionWidth={1920}
  compositionHeight={1080}
  fps={30}
  style={{ width: 1280, height: 720 }}
  controls
/>

// server.ts - SSR 渲染
import { bundle } from '@remotion/bundler';
import { renderMedia, selectComposition } from '@remotion/renderer';
const bundled = await bundle(path.join(cwd, 'src/remotion/index.ts'));
const comp = await selectComposition({ serveUrl: bundled, id: 'MyComp', inputProps: {} });
await renderMedia({ composition: comp, serveUrl: bundled, outputLocation: 'out.mp4', codec: 'h264' });

注意:Remotion 和宿主项目用不同 Webpack 配置,自定义配置时两边都要覆盖。

Chapter 05

Recorder:浏览器内视频录制

用 MediaRecorder + Remotion 实时录制:

tsx
// 1. MediaRecorder 录制 canvas 流
const stream = canvas.captureStream(30);  // 30fps
const chunks: Blob[] = [];
const recorder = new MediaRecorder(stream, { mimeType: 'video/webm' });
recorder.ondataavailable = e => chunks.push(e.data);
recorder.start();

// 2. 渲染时每帧推进
useEffect(() => {
  return () => {
    recorder.stop();
    const blob = new Blob(chunks, { type: 'video/webm' });
    saveAs(blob, 'output.webm');
  };
}, []);

官方 recorder 模板是端到端完整实现,推荐直接基于它定制。

Chapter 06

View Transitions 浏览器 API

v4.0+ 实验性支持 Chrome 浏览器原生 View Transitions API:

tsx
// Player 内启用
<Player component={MyComp} enableExperimentalViewTransitions />

// 组件内触发
if (document.startViewTransition) {
  document.startViewTransition(() => {
    setView('next');
  });
}

Studio 中开启:--enable-experimental-client-side-rendering + --allow-html-in-canvas。
