Chapter 01

Chrome DevTools 远程调试

Remotion 在 Puppeteer 启动的 Chrome 中渲染,可通过 CDP 远程调试:

# 1. 启动 Studio 时开启调试端口
remotion_config_set_browser_executable /usr/bin/google-chrome

# 2. 在 chrome 启动参数加 --remote-debugging-port=9222
# 3. 浏览器打开 chrome://inspect,连接 target

# 或更简单:Studio 中按 F12 自动弹 DevTools
Chapter 02

React Profiler 火焰图

定位组件渲染瓶颈:

import { Profiler } from 'react';

const onRender = (id, phase, actualDuration) => {
  if (actualDuration > 16) {  // 超过 1 帧
    console.warn('Slow:', id, actualDuration);
  }
};

<Profiler id="MyVideo" onRender={onRender}>
  <MyVideo />
</Profiler>

在 DevTools 的 React 面板录制一段,即可看到组件树渲染时间分布。

Chapter 03

Chrome Tracing 帧时间

更底层的 Performance 录制:

# 1. DevTools → Performance 面板 → 点录制
# 2. Studio 中播放视频 5-10 秒
# 3. 停止录制,查看 Main 线程火焰图
# 4. 关注长任务(>50ms 的黄色/红色块)

导出 .json trace 文件可在 ui.perfetto.dev 在线分析。

Chapter 05

Bundle 体积分析

用 webpack-bundle-analyzer 可视化:

npm i -D webpack-bundle-analyzer

# remotion.config.ts
Config.setWebpackOverride((config) => {
  if (process.env.ANALYZE) {
    const { BundleAnalyzerPlugin } = require('webpack-bundle-analyzer');
    config.plugins.push(new BundleAnalyzerPlugin());
  }
  return config;
});

ANALYZE=1 npx remotion render Video out.mp4
Chapter 06

Cold Start 调优

Lambda 模式首次启动 5-10 秒,需:

  1. 预热并发:在流量低峰保持 1-2 个 Lambda 活跃
  2. 减少 bundle 体积:tree-shaking + 删除未用 npm 包
  3. 静态资源外置:字体/图片放 S3,bundle 仅含 JS
  4. Lambda SnapStart(2026 GA):快照加速,启动 < 1s
Chrome DevTools 文档、React Profiler API、Perfetto Trace Viewer
Chapter 07

性能测量 API

用浏览器原生 performance.mark / measure 在重计算点埋点:

tsx
performance.mark('render-start');
// 复杂动画计算
performance.mark('render-end');
performance.measure('render', 'render-start', 'render-end');
console.table(performance.getEntriesByType('measure'));

Studio 自带 Chrome DevTools Profiler:按 F12 → Performance 面板录制,定位卡顿帧。
