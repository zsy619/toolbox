Chapter 01

三大安全威胁

Remotion 服务端渲染时面临的安全风险:

  1. 用户输入 XSS:Props 来自数据库/API,含恶意脚本
  2. Bundle 代码注入:Webpack 加载恶意 npm 包
  3. Chrome 逃逸:渲染时浏览器被攻破
Chapter 02

Zod Schema 校验

Props 接收外部数据时,首道防线是 schema 校验:

import { z } from 'zod';

const userSchema = z.object({
  username: z.string().min(1).max(30)
    .regex(/^[a-zA-Z0-9_]+$/),  // 仅允许字母数字下划线
  email: z.string().email().max(100),
  age: z.number().int().min(0).max(150),
  bio: z.string().max(500).optional(),
});

<Composition
  id="UserCard"
  component={UserCard}
  schema={userSchema}
  defaultProps={{ username: 'guest', email: 'guest@example.com', age: 18 }}
/>
Chapter 03

避免 dangerouslySetInnerHTML

展示用户内容时禁止直接 HTML 注入,改用 React 文本节点(自动转义):

// ❌ 危险:XSS
<div dangerouslySetInnerHTML={{ __html: userInput }} />

// ✅ 安全:React 自动转义
<div>{userInput}</div>

// ✅ 允许受信任富文本:DOMPurify
import DOMPurify from 'dompurify';
<div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(userInput) }} />
Chapter 04

Chrome 沙箱配置

Puppeteer 渲染时的安全选项:

Config.setPuppeteerConfig({
  args: [
    '--no-sandbox',                     // ⚠️ 仅在容器中需要
    '--disable-setuid-sandbox',
    '--disable-dev-shm-usage',
    '--disable-gpu',
  ],
  executablePath: '/usr/bin/google-chrome',
  headless: true,                        // 必须 true
});
⚠️

--no-sandbox 会让 Chrome 失去沙箱保护,只有 Docker 容器(Linux namespace 已隔离)才用。本地开发不要开。

Chapter 05

Lambda 内存隔离

AWS Lambda 默认每个函数 512MB 内存、3GB 临时磁盘。即使一个渲染任务出问题,不会影响其他任务:

npx remotion lambda functions deploy \
  --memory=2048        # 提升到 2GB 适合复杂场景
  --disk=5120          # 5GB 临时磁盘
  --timeout=900        # 15 分钟最长

结合 CloudWatch + DLQ 死信队列,异常任务可自动告警与重试。

Chapter 07

Webhook 回调

Lambda/Cloud 渲染完成时调用 Webhook 通知业务方:

ts
import { renderMediaOnLambda } from '@remotion/lambda';

await renderMediaOnLambda({
  composition, serveUrl, functionName, region,
  webhook: { url: 'https://api.myapp.com/hook', secret: 'my-secret' },
});

Webhook 收到 POST,验证签名后即可在数据库中更新视频状态、触发推送通知等。

Chapter 08

Studio 自部署

把 Remotion Studio 部署到 VPS 供团队内部预览。Studio 服务端基于 Express:

bash
# 项目启用 Studio
npx remotion add @remotion/studio
# 生产启动
NODE_ENV=production npx remotion studio --port 3000 --host 0.0.0.0

# 配合 systemd 守护
[Unit]
Description=Remotion Studio
[Service]
ExecStart=/usr/bin/node node_modules/@remotion/studio/cli.js --port 3000
Restart=always
[Install]
WantedBy=multi-user.target

Nginx 反代 + HTTPS + Basic Auth 即可暴露公网给团队预览。
