Chapter 02

benchmark 性能基准

v4.0.5+ 测单 Composition 渲染时间,优化前后对比:

bash
# 完整基准(单次)
npx remotion benchmark MyComp out.mp4

# 多次平均(--runs 关闭 trial 提示)
npx remotion benchmark MyComp out.mp4 --runs=5

# 测不同参数组合
npx remotion benchmark MyComp out.mp4 --concurrency=1
npx remotion benchmark MyComp out.mp4 --concurrency=4
npx remotion benchmark MyComp out.mp4 --concurrency=8

输出 FPS / 总耗时 / 单帧平均,助你选最佳并发。

Chapter 05

新组件(4.0.455+)

用 HTML2Canvas 风格的方案,把 DOM 内容直接绘入 canvas,比 `` 路径更轻量:

tsx
import { HtmlInCanvas, AbsoluteFill } from 'remotion';

<AbsoluteFill>
  <HtmlInCanvas>
    <div style={{ color: 'white' }}>
      可任意写 React,会被画到 canvas
    </div>
  </HtmlInCanvas>
</AbsoluteFill>

适合:复杂 CSS 动画(伪元素、阴影)、Canvas 不便实现的 UI。

Chapter 06

图像特效

把图片绘到 canvas,可施加任意像素级效果:

tsx
import { CanvasImage } from 'remotion';

<CanvasImage
  src={staticFile('photo.jpg')}
  onMount={(canvas) => {
    const ctx = canvas.getContext('2d')!;
    const data = ctx.getImageData(0, 0, canvas.width, canvas.height);
    // 应用灰度滤镜
    for (let i = 0; i < data.data.length; i += 4) {
      const avg = (data.data[i] + data.data[i+1] + data.data[i+2]) / 3;
      data.data[i] = data.data[i+1] = data.data[i+2] = avg;
    }
    ctx.putImageData(data, 0, 0);
  }}
/>

使用场景:滤镜、边缘检测、马赛克、合成图。
