Chapter 01

目标与流程

我们要做一个 3 分钟的代码讲解视频,完整流程:

  1. 写好代码讲解文稿(纯文本)
  2. 用 Edge TTS 合成中文配音 MP3
  3. 用 Whisper 对配音做时间戳对齐
  4. 写 Remotion 组件:代码块滚动 + 字幕 + 配音
  5. 渲染输出 MP4
Chapter 02

Step 1:合成配音

用 Microsoft Edge 免费 TTS 合成中文语音:

npm i -g edge-tts
edge-tts --voice zh-CN-XiaoxiaoNeural \
  --text "今天我们讲 React Hooks" \
  --write-media voiceover.mp3

也可以用 Python:

import edge_tts, asyncio

async def synth():
    comm = edge_tts.Communicate(
        script_text, voice="zh-CN-XiaoxiaoNeural"
    )
    await comm.save("voiceover.mp3")

asyncio.run(synth())
Chapter 03

Step 2:字幕时间戳

用 Whisper 对 MP3 做 ASR 得到逐句时间戳:

pip install openai-whisper
whisper voiceover.mp3 --language Chinese \
  --output_format json --output_dir ./

输出 voiceover.json 包含 segments[].start / end / text。

Chapter 04

Step 3:Remotion 组件

把 JSON 注入 Composition 作为 Props:

import { AbsoluteFill, Audio, Sequence, useCurrentFrame } from 'remotion';
import { staticFile } from 'remotion';

type Sub = { start: number; end: number; text: string };

const CodeVideo: React.FC<{ subs: Sub[]; code: string }> = ({ subs, code }) => (
  <AbsoluteFill style={{ background: '#0a1a2a' }}>
    <Audio src={staticFile('voiceover.mp3')} />
    <CodeBlock code={code} />
    {subs.map((s, i) => (
      <Sequence key={i} from={Math.floor(s.start * 30)} durationInFrames={Math.ceil((s.end - s.start) * 30)}>
        <Subtitle text={s.text} />
      </Sequence>
    ))}
  </AbsoluteFill>
);
Chapter 05

Step 4:滚动代码高亮

代码块跟随讲解滚动 + 当前行高亮:

const CodeBlock: React.FC<{ code: string }> = ({ code }) => {
  const frame = useCurrentFrame();
  const lineHeight = 32;
  const visibleLines = 12;
  const targetLine = Math.floor(frame / 30);  // 每秒滚动一行
  const offsetY = -targetLine * lineHeight;

  return (
    <pre style={{
      position: 'absolute', top: 200, left: 200, right: 200,
      fontFamily: 'monospace', color: '#e6edf3',
      transform: `translateY(${offsetY}px)`,
      transition: 'transform 0.3s',
    }}>
      {code.split('\n').map((line, i) => (
        <div key={i} style={{
          background: i === targetLine ? 'rgba(36,150,237,.2)' : 'transparent',
          height: lineHeight,
        }}>{line}</div>
      ))}
    </pre>
  );
};
Chapter 06

Step 5:渲染与发布

把代码拆分到 JSON Props,渲染:

npx remotion render CodeVideo out/tutorial.mp4 \
  --props='{"subs":[...],"code":"..."}' \
  --concurrency=4

输出 1080p MP4,上传到 Bilibili/YouTube/抖音即可。

完整工程可参考 remotion-dev/examples,包含 tts-walkthrough 示例。
