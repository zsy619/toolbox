A-01 数据驱动视频 A 进阶

Chapter 01

为什么需要数据驱动

硬编码的视频只适合 demo。真实场景中,视频内容来自:

  • 数据库:用户列表、商品信息、订单数据
  • API:实时股价、社交媒体、新闻
  • CSV/Excel:报告、数据可视化
  • 用户输入:网页表单提交的内容

Remotion 的 Props 机制让 React 组件接收外部数据,渲染时按数据生成画面。

Chapter 02

基础 Props

在 Composition 中通过 defaultProps 传入:

type MyProps = { title: string; subtitle: string };

const MyVideo: React.FC<MyProps> = ({ title, subtitle }) => (
  <AbsoluteFill>
    <h1>{title}</h1>
    <h2>{subtitle}</h2>
  </AbsoluteFill>
);

<Composition
  id="Video"
  component={MyVideo}
  durationInFrames={150}
  fps={30}
  width={1920}
  height={1080}
  defaultProps={{ title: 'Hello', subtitle: 'World' }}
/>
Chapter 03

getInputProps:CLI 注入数据

在组件外部(如 Root.tsx)用 getInputProps() 读取 CLI 传入的 JSON 数据:

// Root.tsx
import { Composition, getInputProps } from 'remotion';

const inputProps = getInputProps();  // 读取 CLI --props 参数

<Composition
  id="Video"
  component={MyVideo}
  defaultProps={inputProps}  // 注入到组件
  // ...
/>

渲染时:

npx remotion render Video out.mp4 --props='{"title":"2026 年度报告","subtitle":"Q1 增长 200%"}'
Chapter 04

calculateMetadata:动态时长

视频时长通常依赖数据量。Remotion 提供 calculateMetadata 在 bundle 阶段异步计算:

import { calculateMetadata, Composition } from 'remotion';

const calculate: CalculateMetadataFunction<MyProps> = async ({ props }) => {
  const data = await fetchData(props.dataUrl);  // 拉取数据
  return {
    durationInFrames: data.length * 30,        // 每条 30 帧
    fps: 30,
    width: 1920,
    height: 1080,
  };
};

<Composition
  id="Video"
  component={MyVideo}
  calculateMetadata={calculate}
  defaultProps={{ dataUrl: 'https://api.example.com/items' }}
/>
Chapter 05

Zod schema 类型安全

从 Remotion 4.0 起,Props 校验交给 Zod:

import { z } from 'zod';

export const mySchema = z.object({
  title: z.string().min(1).max(50),
  subtitle: z.string().optional(),
  tags: z.array(z.string()).max(10),
  darkMode: z.boolean().default(false),
});

<Composition
  id="Video"
  component={MyVideo}
  schema={mySchema}              // 校验 defaultProps
  defaultProps={{ title: 'Hello', tags: ['demo'], darkMode: true }}
/>
🔒

Zod 校验失败会阻止渲染,避免拼写错误等小问题在后期才暴露。

Chapter 06

实战:CSV 驱动的产品介绍

用 PapaParse 读 CSV → Series 渲染每个产品:

type Product = { name: string; price: number; image: string };
const [products, setProducts] = useState<Product[]>([]);

useEffect(() => {
  Papa.parse('/products.csv', { header: true, complete: r => setProducts(r.data) });
}, []);

return (
  <Series>
    {products.map(p => (
      <Series.Sequence key={p.name} durationInFrames={90}>
        <ProductCard product={p} />
      </Series.Sequence>
    ))}
  </Series>
);

Chapter 07

数据获取 + useDelayRender

真实业务中 props 常需从 API 动态加载,使用 useDelayRender 阻塞渲染直到数据就绪:

tsx
import { useState, useEffect } from 'react';
import { useDelayRender } from 'remotion';

export const DataDriven: React.FC = () => {
  const [data, setData] = useState(null);
  const { delayRender, continueRender } = useDelayRender();
  const [h] = useState(() => delayRender());

  useEffect(() => {
    fetch('/api/data')
      .then(r => r.json())
      .then(d => { setData(d); continueRender(h); });
  }, []);

  if (!data) return null;
  return <MyVideo items={data} />;  // 把 API 数据当 props 传入
};
Chapter 08

calculateMetadata 动态元数据

v2.0+ 引入,Composition 接受 calculateMetadata 函数,返回动态覆盖项(durationInFrames / width / height / fps / props):

tsx
import { CalculateMetadataFunction } from 'remotion';
import { getMediaMetadata } from '@/lib/mediabunny-utils';

const calculateMetadata: CalculateMetadataFunction<Props> = async ({
  props, abortSignal,
}) => {
  const meta = await getMediaMetadata(props.videoSrc);
  return {
    durationInFrames: Math.ceil(meta.durationInSeconds * 30),
    width: meta.dimensions?.width ?? 1920,
    height: meta.dimensions?.height ?? 1080,
    defaultOutName: `clip-${props.id}`,
    props: { ...props, duration: meta.durationInSeconds },
  };
};

<Composition id="DynamicClip" component={Video} {...staticDefaults}
  calculateMetadata={calculateMetadata} />

典型场景:剪辑跟源视频长度;封面跟原图尺寸;多个视频合成总时长等。
