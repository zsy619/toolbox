A-02 Remotion 动画 API A 进阶

spring() / interpolate() / Easing —— 视频动效的三大基石。

阅读 ~ 11 分钟
前置 B-04 基础 Hooks
类型 进阶
Chapter 01

spring():物理弹簧动画

Remotion 模拟真实弹簧物理,推荐用于入场/出场动画:

import { spring, useCurrentFrame, useVideoConfig } from 'remotion';

const frame = useCurrentFrame();
const { fps } = useVideoConfig();

// 基础:从 0 弹到 1
const scale = spring({ frame, fps });

// 自定义配置
const bounce = spring({
  frame,
  fps,
  config: { damping: 8, stiffness: 100, mass: 1 },
});

常用 config 参数:

  • damping:阻尼(默认 10),越小越弹
  • stiffness:硬度(默认 100),越大越快
  • mass:质量(默认 1),越大越慢
Chapter 02

interpolate():线性插值

在两值之间根据帧号插值,适用所有线性场景:

import { interpolate, useCurrentFrame } from 'remotion';

const frame = useCurrentFrame();

const opacity = interpolate(frame, [0, 30], [0, 1], {
  extrapolateRight: 'clamp',  // 超出范围时钳制
  extrapolateLeft: 'clamp',
});

const x = interpolate(frame, [0, 60, 90], [0, 500, 1000]);
// 0-60 帧:0→500
// 60-90 帧:500→1000
Chapter 03

interpolateColors():颜色渐变

专用于颜色插值,自动在 RGB / HSL 空间过渡:

import { interpolateColors } from 'remotion';

const color = interpolateColors(frame, [0, 30, 60], ['#2496ED', '#d63031', '#00b894']);
Chapter 04

Easing 缓动函数

interpolate 支持 18 种内置缓动:

import { Easing } from 'remotion';

const value = interpolate(frame, [0, 30], [0, 1], {
  easing: Easing.bezier(0.25, 0.1, 0.25, 1),  // CSS ease
});

// 常用预设
Easing.in(Easing.cubic)      // 缓入
Easing.out(Easing.cubic)     // 缓出(最常用)
Easing.inOut(Easing.cubic)   // 缓入缓出
Easing.exp                  // 指数
Chapter 05

实战:弹跳小球

用 spring 实现一个落地弹跳的小球:

const frame = useCurrentFrame();
const { fps } = useVideoConfig();

const drop = spring({ frame, fps, config: { damping: 6 } });
const y = 500 - drop * 400;  // 从 y=500 弹到 y=100

<div style={{
  position: 'absolute', left: 800,
  top: y, width: 80, height: 80,
  borderRadius: '50%', background: '#2496ED',
}}/>
Chapter 06

spring vs interpolate 选型

场景推荐原因
入场动画(出现/淡入)spring自然弹性,更生动
进度条/百分比interpolate需要精确线性映射
鼠标跟随spring有惯性更自然
色值变化interpolateColors色彩空间插值
路径动画interpolate + Easing需控制曲线
Remotion 动画 API(2025)、CSS Easing Functions、Apple Spring 物理
Chapter 07

@remotion/motion-blur 运动模糊

为高速运动元素添加真实物理模糊,显著提升真实感。安装:

bash
npx remotion add @remotion/motion-blur

使用示例:

tsx
import { MotionBlur } from '@remotion/motion-blur';

<MotionBlur shutter={0.5}>
  <FastBall />  // 高速移动的元素
</MotionBlur>

关键参数 shutter 是快门角度(0.1-1),值越大越模糊。
