@remotion/media-utils 11 个 API

音视频元数据 + 频谱分析全套工具:

API作用
getAudioData(src)异步获取音频元数据 + 频谱
getAudioDurationInSeconds(src)仅获取时长(快)

getWaveformPortion({...})音频波形的某段

useWindowedAudioData({...})流式窗口加载,长录音优化
visualizeAudio({...})音乐频谱(返回每帧 32 段高度)
visualizeAudioWaveform({...})语音波形(返回浮点数组)
audioBufferToDataUrl(buffer)AudioBuffer → dataURL
createSmoothSvgPath(points)波形点 → 平滑 SVG path

@remotion/zod-types 完整 API

3 个核心类型 + 1 个 v3 兼容包:

tsx
import { zColor, zTextarea, zMatrix } from '@remotion/zod-types';
import { z } from 'zod';

const Schema = z.object({
  brand: zColor(),                  // 颜色选择器
  description: zTextarea(),         // 多行文本
  position: zMatrix(),              // 2D 变换矩阵
  title: z.string(),
});

Studio 自动渲染对应可视化控件。

类型Studio 控件返回值
zColor()拾色器string(hex/rgba)
zTextarea()多行文本框string(保留 )
zMatrix()2D 矩阵编辑器number[6] (matrix2d)

Zod v3 用户:用 @remotion/zod-types-v3(同 API,Zod 3.22.3 输出)。

Chapter 07

完整工作流:动态视频编辑器

tsx
// 用户上传视频 → 自动剪到 30s → 抽音轨 → 加字幕 → 渲染
import { getVideoMetadata } from '@remotion/media-utils';
import { extractAudio } from '@remotion/renderer';
import { transcribe } from '@remotion/openai-whisper';

async function processVideo(src: string) {
  // 1. 元数据
  const meta = await getVideoMetadata(src);
  // 2. 抽音轨(给 Whisper)
  await extractAudio({ videoSource: src, audioOutput: 'tmp.aac' });
  // 3. Whisper 转录
  const captions = await transcribe({ audio: 'tmp.aac', language: 'en' });
  // 4. 用 calculateMetadata 动态调整时长
  return { duration: meta.durationInSeconds, captions };
}
