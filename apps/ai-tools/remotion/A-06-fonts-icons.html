A-06 字体与图标系统 A 进阶

Google Fonts / Iconify / 中文字体子集化 —— 视觉系统的基石。

Chapter 01

@remotion/google-fonts 自动加载

Remotion 官方提供的字体包,Studio 内自动注入 @import:

import { loadFont } from '@remotion/google-fonts/Inter';

const { fontFamily, waitUntilDone } = loadFont();

const MyComp = () => {
  waitUntilDone();  // 阻塞渲染直到字体就绪
  return <h1 style={{ fontFamily: fontFamily || 'sans-serif' }}>Hello</h1>;
};
💡

在 Studio 中即时下载字体,但在 Lambda 渲染时需要预先 bundle 进静态资源,详见官方包文档。

Chapter 02

本地字体:CSS @font-face

自托管字体时,放在 public/fonts/:

/* public/fonts/fonts.css */
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter-Bold.woff2') format('woff2');
  font-weight: 700;
  font-display: block;
}

Root.tsx 中引入:

import './styles/fonts.css';
Chapter 03

中文字体子集化

中文字体动辄 5-10MB,需用 fonttools 提取子集:

from fontTools.subset import Subsetter
from fontTools.ttLib import TTFont

font = TTFont('SourceHanSans.otf')
sub = Subsetter()
sub.populate(text='只提取这些字')
sub.subset(font)
font.save('SourceHan-subset.woff2')

这样 8MB 字体可压缩到 50KB。

Chapter 04

Iconify 海量图标

Iconify 提供 20 万+ 图标,直接 import 使用:

import { Icon } from '@iconify/react';

<Icon icon="mdi:rocket" style={{ fontSize: 96, color: '#2496ED' }} />
💡

Iconify 会把用过的图标单独打包,体积仅 10-30KB。远胜于一次性打包 FontAwesome 全集(>1MB)。

Chapter 05

动态字体切换

用 Props 让用户选字体:

import { loadFont as loadInter } from '@remotion/google-fonts/Inter';
import { loadFont as loadNoto } from '@remotion/google-fonts/NotoSansSC';

const Video: React.FC<{ font: 'inter' | 'noto' }> = ({ font }) => {
  const inter = loadInter();
  const noto = loadNoto();
  const family = font === 'inter' ? inter.fontFamily : noto.fontFamily;
  return <h1 style={{ fontFamily: family || 'sans-serif' }}>Hi</h1>;
};
Chapter 06

字体加载失败的回退

⚠️

症状:Lambda 渲染中字体未加载完成,报 delayRender timeout。

解决:在 loadFont() 后调用 waitUntilDone() 阻塞渲染:

const { fontFamily, waitUntilDone } = loadFont();

const Component = () => {
  waitUntilDone();  // 阻塞到字体就绪
  return <div style={{ fontFamily: fontFamily || 'sans-serif' }} />;
};
@remotion/google-fonts、Iconify 文档、fonttools 子集化
Chapter 07

Tailwind CSS 集成

Remotion 完全兼容 Tailwind,初始化项目时勾选 TailwindCSS 即可:

bash
# 已经初始化过项目,后续添加
npx remotion add @remotion/tailwind

使用示例:

tsx
// tsconfig.json 加 "types": ["@remotion/tailwind"]
// 注意:需要任意值语法 (brackets)
<div className="w-[1920px] h-[1080px] bg-blue-500 text-[80px]">
  Tailwind
</div>
⚠️

Remotion 渲染时 1920×1080 实际生效,浏览器中通常缩小展示,因此需要 任意值语法而非响应式断点(sm/md)。

Chapter 08

CSS 变量与主题切换

Remotion 支持 CSS 变量,可动态切换主题色而无需重渲染:

css
/* styles.css */
:root {
  --primary: #2496ED;
  --bg: #0a1a2a;
  --text: #ffffff;
}
.theme-red {
  --primary: #e94560;
}
tsx
// 父级加 className 即可切换整组颜色
<AbsoluteFill className="theme-red" style={{
  background: 'var(--bg)', color: 'var(--text)',
}}>
  <h1 style={{ color: 'var(--primary)' }}>Title</h1>
</AbsoluteFill>
Chapter 09

@remotion/google-fonts 动态加载

官方包支持 1400+ Google Fonts,动态加载避免 Bundle 膨胀:

ts
import { getAvailableFonts, loadFont } from '@remotion/google-fonts/Inter';

const { fontFamily, waitUntilDone } = loadFont();
await waitUntilDone();  // 阻塞渲染直到字体就绪

// 动态切换:用户选择
const fonts = getAvailableFonts();
const font = await fonts[idx].load();
const { fontFamily } = font.loadFont();

注意:必须 ES 模块导入,CJS 模式会报错。
