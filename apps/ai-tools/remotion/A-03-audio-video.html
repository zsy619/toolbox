Chapter 01

OffthreadVideo:抽帧视频

原生 <video> 在渲染时存在性能问题(requestVideoFrameCallback 缺失),用 OffthreadVideo 替代:

import { OffthreadVideo, staticFile } from 'remotion';

<OffthreadVideo
  src={staticFile('bg.mp4')}
  style={{ width: '100%', height: '100%', objectFit: 'cover' }}
  startFrom={30}        // 从第 30 帧开始
  endAt={150}           // 到第 150 帧结束
  muted={false}
  volume={(f) => Math.max(0, 1 - f / 60)}  // 音量包络
/>
⚡

OffthreadVideo 在 ffmpeg 阶段抽帧(而非浏览器),避免视频卡顿或音画不同步。

  <>
    {subs.map((s, i) => (
      <Sequence key={i} from={s.from} durationInFrames={s.durationInFrames}>

          position: 'absolute', bottom: 80, left: 0, right: 0,
          textAlign: 'center', color: '#fff',
          fontSize: 48, textShadow: '0 2px 8px #000',
        }}>{s.text}</div>
      </Sequence>
    ))}
  </>
);
Chapter 04

视频裁剪与变换

用 CSS transform 配合 useCurrentFrame 实现推拉摇移:

Chapter 05

ffmpeg 自定义滤镜

在 remotion.config.ts 中可自定义合流参数:

Config.setFfmpegOverrideFunction(({ args }) => {
  return [...args, '-vf', 'eq=brightness=0.05:saturation=1.2', '-c:a', 'aac', '-b:a', '192k'];
});

高级场景:多视频拼接、水印、转场滤镜。

Chapter 07

@remotion/media 新一代 <Video>

v4.0.445+ 引入 WebCodecs 版的 <Video>,底层用 Mediabunny 抽帧,支持 HLS 流媒体与原生缓冲:

tsx
import { Video } from '@remotion/media';

// 本地视频
<Video src={staticFile('hero.webm')} />

// HLS 流
<Video src="https://stream.example.com/video.m3u8" />

// 远端 URL
<Video src="https://remotion.media/BigBuckBunny.mp4" />
⚡

新版 <Video> 在 Player 中自动暂停缓冲、缓冲完后自动恢复,大幅改善播放体验。

Chapter 09

音频频谱可视化

使用 @remotion/media-utils 的 visualizeAudio() 实时分析音频频谱,做音乐可视化、播客片头声波图:

tsx
import { useAudioData, visualizeAudio } from '@remotion/media-utils';

export const Bars: React.FC = () => {
  const frame = useCurrentFrame();
  const { fps, width } = useVideoConfig();
  const audio = useAudioData(staticFile('music.mp3'));
  if (!audio) return null;

  const bars = visualizeAudio({
    fps, frame, audioData: audio,
    numberOfSamples: 32,
    optimizeFor: 'speed',  // 4.0.83+ 加速 FFT
  });

  return (
    <AbsoluteFill style={{ display: 'flex', alignItems: 'end' }}>
      {bars.map((v, i) => (
        <div key={i} style={{ width: width/32, height: 1000 * v, background: 'cyan' }} />
      ))}
    </AbsoluteFill>
  );
};

对于波形图用 visualizeAudioWaveform()。大文件改用 useWindowedAudioData() 窗口化加载(仅 .wav 格式)。

Chapter 10

Mediabunny 完整指南

2026-02 起 @remotion/media-parser 已弃用,官方推荐 Mediabunny(Vanilagy 出品,MPL-2.0 许可):

bash
npm i mediabunny
ts
import { Input, ALL_FORMATS, UrlSource } from 'mediabunny';

export const getMediaMetadata = async (src: string) => {
  const input = new Input({
    formats: ALL_FORMATS,
    source: new UrlSource(src, { getRetryDelay: () => null }),
  });
  const durationInSeconds = await input.computeDuration();
  const track = await input.getPrimaryVideoTrack();
  const dimensions = track
    ? { width: await track.getDisplayWidth(),
        height: await track.getDisplayHeight() }
    : null;
  const stats = await track?.computePacketStats(50);
  return { durationInSeconds, dimensions, fps: stats?.averagePacketRate ?? null };
};

优势:零依赖、跨浏览器/Node/Bun,无需 video 标签即可读取 codec/帧率等元数据。

Chapter 12

音频高级:速度 / 音调 / 音效

tsx
<Html5Audio
  src={staticFile('speech.mp3')}

  toneFrequency={1.2}       // 升调 20%(只渲染时生效)
  preservePitch={false}     // 速度变时不保持音调
  muted={frame < 30}        // 动态静音
  name="vo-track-1"         // Studio 时间轴显示名

/>

Chapter 13

透明视频(alpha 通道)

两种编码支持 alpha:

格式codecprofilepixel-format用途
WebM (浏览器)vp8 / vp9—yuva420pChrome/Firefox 网页
ProRes (剪辑)prores4444 / 4444-xqyuva444p10leFinal Cut/Premiere/DaVinci
bash
# WebM 透明
npx remotion render MyComp out.webm \
  --image-format=png --pixel-format=yuva420p --codec=vp8

# ProRes 4444
npx remotion render MyComp out.mov \
  --image-format=png --pixel-format=yuva444p10le \
  --codec=prores --prores-profile=4444

OffthreadVideo 加 transparent 属性(略微降低性能)。

Chapter 14

媒体片段语法

用 URL hash 控制时间偏移,无需截取物理文件:

tsx
// 从第 30 秒起播
<OffthreadVideo src="video.mp4#t=30" />

// 30s 到 60s
<OffthreadVideo src="video.mp4#t=30,60" />

// 多个片段拼接
<Sequence from={0} durationInFrames={90}>
  <OffthreadVideo src="clip.mp4#t=0,3" />
</Sequence>
