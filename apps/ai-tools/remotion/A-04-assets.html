A-04 静态资源 A 进阶

staticFile() / prefetch() / watchStaticFile() —— 资源管理三件套。

阅读 ~ 8 分钟
前置 B-04 基础 Hooks
类型 进阶
Chapter 01

public 目录

Remotion 默认从项目根的 public/ 目录读取静态资源:

my-video/
├── public/             ← 静态资源
│   ├── logo.png
│   ├── bg.mp4
│   ├── fonts/
│   │   └── Inter-Bold.woff2
│   └── data.json
├── src/
└── package.json

打包后这些文件会被复制到 build/public/。

Chapter 02

staticFile():路径解析

推荐用 staticFile() 而非硬编码路径,便于开发与生产一致:

import { staticFile, Img } from 'remotion';

// 引用 public/logo.png → /logo.png
<Img src={staticFile('logo.png')} />

// 子目录
<Img src={staticFile('images/hero.jpg')} />
💡

用 staticFile 可以在 remotion.config.ts 中通过 setPublicDir 改变根目录,无需改组件代码。

Chapter 03

prefetch():预加载远程资源

对远程 URL(CDN / API)用 prefetch 提前加载,避免首帧空白:

import { prefetch } from 'remotion';
import { useEffect } from 'react';

useEffect(() => {
  prefetch('https://cdn.example.com/hero.jpg');
  prefetch('https://fonts.googleapis.com/css2?family=Inter');
}, []);
Chapter 04

watchStaticFile():文件热更新

替换静态资源后,Studio 自动重新加载:

import { watchStaticFile } from 'remotion';
import { useEffect, useState } from 'react';

const [version, setVersion] = useState(0);
useEffect(() => {
  return watchStaticFile('logo.png', () => setVersion(v => v + 1));
}, []);
Chapter 05

字体加载最佳实践

用 @remotion/google-fonts 自动加载 Google Fonts:

import { loadFont } from '@remotion/google-fonts/Inter';

const { fontFamily } = loadFont();
const fontLoaded = fontFamily;  // 'Inter' 或 null(加载中)

<h1 style={{ fontFamily: fontLoaded || 'sans-serif' }}>Hello</h1>

或本地字体放在 public/fonts/ + CSS @font-face。

Chapter 06

CDN 资源 vs 本地资源

方式优点缺点
public/ 本地无网络依赖,确定性强git 仓库大
CDN URL无仓库膨胀,版本化依赖网络,首帧慢
API 动态加载实时数据必须 prefetch

生产推荐:本地放核心资源(字体、Logo),动态数据走 API + prefetch。

Remotion 静态资源(2025)、@remotion/google-fonts 文档、HTTP 缓存策略
Chapter 07

@remotion/preload

Remotion 4 提供的官方资源预加载包,统一管理 fetch/视频/图片预热:

bash
npx remotion add @remotion/preload

在 Root.tsx 顶层预加载:

tsx
import { Preload } from '@remotion/preload';

<Preload>
  <Composition ... />
</Preload>
