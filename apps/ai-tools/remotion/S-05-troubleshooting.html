Chapter 01

Bundle 失败

⚠️

症状:Cannot find module 'xxx' 或 Module not found。

排查步骤:

  1. 删除 build/ 目录重新打包
  2. 删除 node_modules/ 和 package-lock.json 重新 npm install
  3. 检查 Node.js 版本是否 >= 18
  4. 检查 tsconfig.json 是否正确
Chapter 02

字体加载失败

⚠️

症状:渲染时文字显示为系统默认字体。

解决:

// ✅ 用 @remotion/google-fonts
import { loadFont } from '@remotion/google-fonts/Inter';
const { fontFamily } = loadFont();
<div style={{ fontFamily: fontFamily || 'sans-serif' }}>Hello</div>

本地字体需用 CSS @font-face 显式声明 + 放在 public/fonts/。

Chapter 03

Chrome 崩溃 / 内存不足

⚠️

症状:Page crashed 或 OOM Killer 杀掉进程。

解决:

  1. 降低 --concurrency
  2. 使用 OffthreadVideo 而非原生 <video>
  3. 大图片用 prefetch 后转 base64 一次性加载
  4. Linux 服务器加 --disable-dev-shm-usage
Chapter 04

视频音画不同步

⚠️

症状:视频画面与音频偏移,或音频先结束。

解决:

  • 改用 <OffthreadVideo> 而非 <video>
  • 检查 Composition 的 durationInFrames 是否匹配视频长度(durationInFrames = 视频秒数 × fps)
  • 音频用 endAt 显式控制结束点
Chapter 05

delayRender 永久卡住

⚠️

症状:30 秒后报 delayRender timeout 错误。

解决:

// ✅ 必须在组件顶层调用
const handle = delayRender('Loading data');
useEffect(() => {
  fetchData().then(() => continueRender(handle));
  return () => continueRender(handle);  // 清理
}, []);

注意:不能在事件回调中调用 delayRender,必须在 useEffect 顶层或渲染期间调用。

Chapter 06

暗色主题闪烁

⚠️

症状:Studio 切换主题时画面闪一下。

解决:在 useEffect 同步主题,避免初始值不一致:

// scripts.js
const stored = localStorage.getItem('theme');
if (stored === 'dark') document.documentElement.setAttribute('data-theme', 'dark');
// 应在 body 渲染前就设置好
Chapter 07

Lambda 超时

⚠️

症状:Task timed out after 900.00 seconds。

解决:Lambda 最大 15 分钟,长视频需拆:

# 减小每任务帧数
npx remotion lambda render Video out.mp4 --frames-per-lambda=30
# 提高单任务内存
npx remotion lambda functions deploy --memory=3009
Chapter 08

Props 未生效

⚠️

症状:CLI 传 --props='{...}' 但组件仍用 defaultProps。

解决:必须用 getInputProps() 在 Root.tsx 读取:

// Root.tsx
import { getInputProps } from 'remotion';
const inputProps = getInputProps();
<Composition component={MyVideo} defaultProps={inputProps} ... />

Chapter 10

CORS 跨域错误

⚠️

症状:fetch 远程 API 报 CORS policy。

解决:用 prefetch() 让 Remotion 在 Node.js 端拉取,绕过浏览器 CORS:

import { prefetch } from 'remotion';
prefetch('https://api.example.com/data.json');  // 走 Node 端 fetch
FAQ

常见问题

Q: 渲染时间和 Studio 不一致?

A: 检查 durationInFrames 是否被 calculateMetadata 动态覆盖。

Q: 中文乱码?

A: 终端执行 export LANG=en_US.UTF-8 或用 PNG 帧(无字符编码问题)。

Q: Audio 重复播放?

A: Audio 必须包在 Sequence 内,且 Sequence 的 from 早于其他 Sequence 起始。

Chapter 14

<Artifact> 调试输出

渲染时收集任意数据(JSON/字符串)到输出目录,用于调试/审计:

tsx
import { Artifact } from 'remotion';

<Artifact filename="render-report.json">
  {JSON.stringify({ frames, duration, props }, null, 2)}
</Artifact>

// 渲染后会输出到 out/ 目录
Chapter 15

@remotion/webcodecs

直接用 WebCodecs API 解码/编码视频帧,做高阶特效:

ts
import { extractFrames, makeVideo } from '@remotion/webcodecs';

// 从视频抽帧为 VideoFrame[]
const frames = await extractFrames({ src: 'video.mp4', timestamps: [0, 0.5, 1] });

// VideoFrame[] 重新编码为视频
const blob = await makeVideo({ frames, fps: 30, codec: 'h264' });
Chapter 16

Chromium Flags 调试选项

支持传入 3 类标志:

Flag作用
--disable-web-security禁用 CORS(允许跨域 fetch)
--ignore-certificate-errors忽略无效 SSL 证书
--disable-headless5.0 移除(改用 Chrome Headless Shell)

3 种设置方式:

ts
// 1) Node API
await renderMedia({ chromiumOptions: { disableWebSecurity: true } });

// 2) CLI
npx remotion render MyComp out.mp4 --disable-web-security

// 3) remotion.config.ts
Config.setChromiumDisableWebSecurity(true);
Config.setChromiumIgnoreCertificateErrors(true);

Studio 部署到 VPS

bash

npx remotion bundle src/index.ts --out-dir=build

npx remotion studio --host 0.0.0.0 --port 3000

}
