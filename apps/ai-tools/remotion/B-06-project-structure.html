Chapter 01

标准 monorepo 布局

生产级 Remotion 项目通常用 monorepo 管理多视频:

my-video-suite/
├── packages/
│   ├── shared/             # 共享组件库
│   │   ├── Logo.tsx
│   │   └── theme.ts
│   ├── video-tutorial/     # 教程视频
│   │   ├── src/
│   │   └── package.json
│   └── video-ad/           # 广告视频
│       ├── src/
│       └── package.json
├── tooling/
│   ├── eslint-config/
│   └── tsconfig/
├── package.json            # workspace root
└── pnpm-workspace.yaml
Chapter 02

TypeScript 路径别名

用 workspace 包引用避免相对路径混乱:

// packages/video-tutorial/tsconfig.json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@shared/*": ["../shared/src/*"],
      "@/*": ["./src/*"]
    }
  }
}

组件内直接:

import { Logo } from '@shared/Logo';
Chapter 03

remotion.config.ts 全部配置

import { Config } from '@remotion/cli/config';
import path from 'path';

Config.setVideoImageFormat('jpeg');                 // 帧图格式
Config.setConcurrency(4);                            // 并发
Config.setEntryPoint('src/index.ts');                 // 入口
Config.setCachingEnabled(true);                       // bundle 缓存
Config.setPort(3000);                                 // Studio 端口
Config.setWebpackOverride((c) => {
  c.resolve.alias = {
    ...c.resolve.alias,
    '@': path.resolve(__dirname, 'src'),
  };
  return c;
});

Config.setFfmpegOverrideFunction(({ args }) => {
  return [...args, '-c:v', 'libx264', '-preset', 'fast'];
});
Chapter 04

环境变量管理

用 dotenv + 校验避免 CI 失败:

# .env.local
REMOTION_AWS_REGION=us-east-1
REMOTION_BUCKET=remotion-prod
# 不要把 .env.local 入 git

运行时读取:

const region = process.env.REMOTION_AWS_REGION;
if (!region) throw new Error('Set REMOTION_AWS_REGION');
Chapter 05

ESLint 规范

基于 react + remotion 规则的最小配置:

// .eslintrc.json
{
  "extends": ["@remotion/eslint-config"],
  "rules": {
    "react/prop-types": "off",
    "@typescript-eslint/no-unused-vars": "error"
  }
}
Chapter 06

多 Composition 组织

大型项目把 Composition 分文件管理:

// Root.tsx
<>
  <Composition {...compositions.intro} />
  <Composition {...compositions.main} />
  <Composition {...compositions.outro} />
</>

每个 Composition 单独 schema + defaultProps 集中在 compositions/ 目录,便于团队 review。

Chapter 07

Studio 高级定制

Studio 不止是开发工具,还能通过 saveBeforeRemux、getStaticFiles、getRenderProgress 钩子深度定制:

tsx
// remotion.config.ts
Config.setVideoImageFormat('jpeg');
Config.setOverwriteOutput(true);
Config.setConcurrency(4);  // 4 并行渲染

// 启用 Remotion Studio
Config.setStudioEnabled(true);

Studio 内部支持 Watch 模式(保存源文件自动重载)与 Premounting(提前挂载,大幅减少切换卡顿)。
