Chapter 01

时间容器组件

组件作用关键 props
<Composition>注册可渲染视频id, component, durationInFrames, fps, width, height, defaultProps, calculateMetadata
<Sequence>子组件时间偏移from, durationInFrames, name, layout
<Series>顺序播放子 Sequence(无,内部用 Sequence)
<Loop>循环 N 帧durationInFrames, times
<Freeze>冻结某一帧frame
<Still>单帧图,无 durationid, component, width, height
<Folder>Studio 侧边栏分组title
Chapter 02

媒体组件

组件作用
<OffthreadVideo>Rust 解码,帧精确(SSR 首选)
<Html5Video>HTML5 video 标签(预览好)
<Video> @remotion/mediaWebCodecs 版,新项目推荐
<Html5Audio>音频播放
<Audio> @remotion/mediaWebCodecs 音频
<Img>图片(用 staticFile/URL)
<AnimatedImage>动画图片(APNG/GIF)
<IFrame>嵌入外部网页
<Artifact>渲染时输出文件
Chapter 03

Hooks

Hook作用
useCurrentFrame()当前帧(0 索引,Sequence 内是相对值)
useVideoConfig(){ fps, width, height, durationInFrames, id }
useDelayRender()异步数据加载(替代全局 delayRender)
useBufferState()资源缓冲状态
useCurrentScale()Player 实际缩放比
useRemotionEnvironment(){ isStudio, isRendering, isPlayer, ... }
Chapter 04

异步控制

ts
import {
  delayRender, continueRender, cancelRender,
} from 'remotion';

// 阻塞渲染
const handle = delayRender('Loading data');

try {
  const data = await fetchData();
  setData(data);
  continueRender(handle);  // 解除阻塞
} catch (e) {
  cancelRender(e);  // 出错终止
}
Chapter 05

数学/动画工具

ts
// 线性插值
interpolate(frame, [0, 100], [0, 1], { extrapolateLeft: 'clamp' });

// 颜色插值(支持 sRGB / sRGB-linear / OKLCH)
interpolateColors(frame, [0, 30], ['#fff', '#000']);

// 弹簧(物理)
spring({ frame, fps, config: { damping: 200, mass: 1, stiffness: 100 } });

// 预计算弹簧总帧数
measureSpring({ fps, config: {...} });  // → 帧数

// 缓动
Easing.bezier(0.25, 0.1, 0.25, 1);
Easing.in(Easing.cubic);
Easing.out(Easing.exp);

// 随机(种子化)
random('particle-0');  // 0~1,同 name 跨帧同值
Chapter 06

资源 API

ts
// 解析 public/ 内文件 URL
staticFile('video.mp4');  // → /video.mp4

// 预加载
prefetch(staticFile('big.png'));

// 监听文件变化触发重渲染
watchStaticFile(staticFile('data.json'));

// 列出所有静态文件(SSR)
getStaticFiles();  // [{ name, fullPath, size }]
