Chapter 01

典型 CI/CD 流水线

text
git push → GitHub Actions 触发
  ├─ Checkout 代码
  ├─ 装依赖 + 锁文件缓存
  ├─ ESLint + TypeScript 类型检查
  ├─ 单元测试 (vitest/jest)
  ├─ Bundle 测试 (npx remotion compositions)
  ├─ 部署到 S3 (serveUrl)
  └─ 触发 Lambda 渲染 (webhook)
Chapter 02

完整 GitHub Actions 配置

yaml
name: Remotion CI/CD
on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint && pnpm typecheck
      - run: pnpm test
      - run: npx remotion compositions

  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: npx remotion deploy --entry=src/index.ts
        env:
          REMOTION_AWS_REGION: ${{ secrets.AWS_REGION }}
          REMOTION_AWS_ACCESS_KEY_ID: ${{ secrets.AWS_KEY }}
          REMOTION_AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET }}
Chapter 03

Lambda 自动渲染触发

ts
// API 路由 - 用户提交数据时触发渲染
import { renderMediaOnLambda } from '@remotion/lambda';

app.post('/render', async (req, res) => {
  const { id, data } = req.body;
  const { url } = await renderMediaOnLambda({
    composition: 'MyVideo',
    serveUrl: process.env.SERVE_URL!,
    functionName: 'remotion-render',
    region: 'us-east-1',
    inputProps: data,
    webhook: { url: `${process.env.API}/webhook/${id}`, secret: 'my-secret' },
  });
  await db.update(id, { status: 'rendering', renderId: url });
  res.json({ ok: true });
});
Chapter 04

Webhook + 钉钉/飞书通知

渲染完成后通过 Webhook 通知业务系统 + 群机器人:

ts
app.post('/webhook/:id', async (req, res) => {
  const { type, renders } = req.body;
  await db.update(req.params.id, { status: type });
  await fetch(process.env.DINGTING_WEBHOOK!, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      msgtype: 'markdown',
      markdown: { title: '视频渲染', text: `任务 ${req.params.id} ${type} → ${renders[0].output}` },
    }),
  });
  res.json({ ok: true });
});

Chapter 08

Express Render Server 完整搭建

官方 render-server 模板提供开箱即用的 Express 渲染 API:

ts
// server.ts
import express from 'express';
import { bundle } from '@remotion/bundler';
import { renderMedia, selectComposition } from '@remotion/renderer';

const app = express();
app.use(express.json());

app.post('/render', async (req, res) => {
  const { compId, inputProps } = req.body;
  const bundleLocation = await bundle({ entryPoint: './src/index.ts' });
  const comp = await selectComposition({ serveUrl: bundleLocation, id: compId, inputProps });
  const output = `out/${compId}-${Date.now()}.mp4`;
  await renderMedia({ composition: comp, serveUrl: bundleLocation, codec: 'h264', outputLocation: output, inputProps });
  res.json({ url: `/${output}` });
});

app.listen(3001, () => console.log('Render API on :3001'));
