Chapter 02

CSV 数据读取

用 PapaParse 解析 CSV:

import Papa from 'papaparse';
import { useEffect, useState } from 'react';

type Row = { month: string; revenue: number };
const [data, setData] = useState<Row[]>([]);

useEffect(() => {
  fetch('/sales-2026.csv').then(r => r.text()).then(csv => {
    Papa.parse<Row>(csv, {
      header: true,
      dynamicTyping: true,
      skipEmptyLines: true,
      complete: r => setData(r.data),
    });
  });
}, []);
Chapter 03

动态时长:calculateMetadata

Composition 时长根据数据行数决定:

const calculate: CalculateMetadataFunction = async () => {
  const r = await fetch('/sales-2026.csv');
  const csv = await r.text();
  const parsed = Papa.parse(csv, { header: true });
  // 每行数据 1.5 秒
  return { durationInFrames: parsed.data.length * 45, fps: 30 };
};
Chapter 04

柱状图动画

高度逐帧增长:

import { useCurrentFrame, interpolate } from 'remotion';

const Bar: React.FC<{ value: number; max: number; delay: number }> = ({ value, max, delay }) => {
  const frame = useCurrentFrame();
  const h = interpolate(frame - delay, [0, 30], [0, (value / max) * 500], {
    extrapolateLeft: 'clamp', extrapolateRight: 'clamp',
  });
  return <div style={{ width: 60, height: h, background: '#2496ED', marginRight: 10 }} />;
};
Chapter 05

数字飞入动画

关键指标从 0 滚动到目标值:

const CountUp: React.FC<{ target: number; duration: number }> = ({ target, duration }) => {
  const frame = useCurrentFrame();
  const v = Math.floor(interpolate(frame, [0, duration], [0, target], { extrapolateRight: 'clamp' }));
  return <span style={{ fontSize: 96, fontWeight: 800, color: '#2496ED' }}>{v.toLocaleString()}</span>;
};

Chapter 07

D3.js / Recharts 数据可视化

Remotion 与 D3 完美兼容,D3 负责计算 path,Remotion 负责时间动画:

tsx
import { line, curveMonotoneX } from 'd3-shape';
import { scaleLinear } from 'd3-scale';

const data = [{x:0,y:0}, {x:1,y:5}, {x:2,y:3}];
const xScale = scaleLinear().domain([0, 2]).range([0, 800]);
const yScale = scaleLinear().domain([0, 5]).range([400, 0]);
const lineGen = line().x(d => xScale(d.x)).y(d => yScale(d.y)).curve(curveMonotoneX);

<svg width={800} height={400}>
  <path d={lineGen(data)} stroke="white" fill="none" />
</svg>

搭配 useCurrentFrame 做 path 描边动画(类似 Chart.js 风格的入场效果)。

Chapter 08

Recharts 完整图表动画

用 Recharts 做柱状图/折线图,搭配 spring 平滑入场:

tsx
import { BarChart, Bar, XAxis, YAxis } from 'recharts';

const data = [{n:'一',v:10},{n:'二',v:30},{n:'三',v:20}];

<BarChart width={800} height={400} data={data}>
  <XAxis dataKey="n" />
  <YAxis />
  <Bar dataKey="v" fill="cyan"
    isAnimationActive={true} animationDuration={2000} />
</BarChart>
⚠️

Recharts 默认开启动画,在 Studio 中实时可见但 Lambda 渲染时需禁用或显式控制时长(配合帧数)。
