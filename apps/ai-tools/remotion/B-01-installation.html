B-01 安装与环境配置 B 基础

Node.js、npm、FFmpeg、Remotion CLI 完整安装流程,项目初始化与目录结构解读。

阅读 ~ 8 分钟
前置 无
类型 入门
Chapter 01

环境要求

Remotion 是一个 React 视频框架,运行依赖以下三件套:

  • Node.js 18+:JavaScript 运行时,推荐使用 LTS 版本
  • npm/pnpm/yarn:包管理器,任选其一
  • FFmpeg:视频编码工具,Remotion 用它做最终合流
💡

macOS 用户推荐用 brew install node ffmpeg 一次性装好两个核心依赖。Windows 需手动下载 FFmpeg.exe 并加入 PATH。

Chapter 02

检查环境

在终端运行以下命令,确认版本符合要求:

node --version    # 应当 >= v18.0.0
npm --version     # 应当 >= 9.0.0
ffmpeg -version   # 应当 >= 4.0

任一命令报错都意味着该依赖未正确安装或未加入 PATH,需先修复再继续。

Chapter 03

初始化项目

Remotion 提供了官方脚手架,一条命令即可创建项目:

npx create-video@latest my-video
cd my-video
npm install
npm start

脚手架会询问 4 个选项:视频名称、模板(Blank / Hello World / Recorder 等)、React 版本、是否启用 TypeScript。本教程选 Blank + TypeScript。

Chapter 04

项目结构

初始化完成后会看到如下目录:

路径作用
src/Root.tsxComposition 注册中心,所有视频元数据在此声明
src/Composition.tsx具体视频组件,放置所有 React 节点与逻辑
src/index.ts浏览器入口,挂载 React 到 DOM
remotion.config.tsRemotion 全局配置(分辨率、并发、bundle 行为)
public/静态资源目录,放字体、图片、视频原文件
out/渲染输出目录,生成的 MP4 会出现在此
Chapter 05

常用命令

npm start           # 启动 Studio(交互式预览,默认 http://localhost:3000)
npm run build       # 打包成可部署的网站
npx remotion render # 渲染为 MP4
npx remotion still  # 渲染为单帧 PNG/JPG
npx remotion compositions # 列出所有已注册的 Composition
🎬

Studio 是 Remotion 最强大的特性——它会在浏览器中实时渲染视频每一帧,改代码后秒级热更新,极大提升开发效率。

Chapter 06

常见问题

⚠️

Q: 提示 "ffmpeg: command not found"?
A: macOS 用 brew install ffmpeg;Ubuntu 用 sudo apt install ffmpeg;Windows 需手动下载 ffmpeg.exe 并加入系统 PATH。

⚠️

Q: npm start 报 ENOSPC?
A: Linux 需调大 inotify 限制:echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf && sudo sysctl -p

Remotion 官方文档(2025)、create-video 脚手架、Remotion CLI 命令参考
Chapter 07

Remotion 全局 CLI

Remotion 提供全局 CLI,可在任意位置使用:

bash
npm i -g @remotion/cli
# 升级到最新版
npm i -g @remotion/cli@latest

# 创建新项目
npx create-video@latest

常用命令:

命令说明
npx remotion versions查看已安装版本
npx remotion upgrade升级到最新稳定版
npx remotion upgrade [pkg]升级指定包
npx remotion add <pkg>添加官方插件
npx remotion <studio|render|still|compositions|lambda>子命令
Chapter 08

CLI Flags 完整速查

Remotion 4.x 全部 render/still CLI 标志:

Flag作用
--props=JSON输入 props JSON 字符串
--concurrency=N并行帧数(默认 CPU 核数 / 2)
--frame-range=A-B只渲染 A 到 B 帧
--output=out.mp4输出文件
--codec=h264|h265|vp8|vp9|prores视频编码
--crf=N恒定质量因子(0-51,越小越好)
--pixel-format=yuv420p像素格式
--image-format=jpeg|png单帧图片格式
--jpeg-quality=80JPEG 质量 0-100
--audio-codec=aac|mp3|opus音频编码
--audio-bitrate=320k音频比特率
--muted去除音频
--video-bitrate=2M视频比特率
--gl=angle|swiftshader|swangle|eglWebGL 后端
--browser-executable=/pathChrome 路径
--user-agent=UA浏览器 UA
--height=1080输出缩放高度
--scale=0.5分辨率缩放
--log=verbose|info|warn|error日志级别
--overwrite覆盖已存在输出
--enforce-audio-codec强制音频编码
⚡

完整参数列表见 npx remotion render --help。Lambda API 镜像相同字段名。
