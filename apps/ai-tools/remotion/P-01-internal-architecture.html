Chapter 01

包边界

Remotion 4.x 是 monorepo,主要 npm 包及其职责:

包职责
remotion运行时 API (Composition/Sequence/spring/Hooks)
@remotion/cli命令行工具 (studio/render/still)
@remotion/rendererNode.js 端渲染引擎
@remotion/bundlerWebpack 打包用户代码
@remotion/lambdaAWS Lambda 云渲染
@remotion/media-utilsffmpeg 辅助 (getVideoMetadata 等)
Chapter 02

整体数据流

┌─ 用户 React 代码 (src/Root.tsx) ────┐
│        ↓ Webpack 打包                │
│   build/ (静态资源 + JS Bundle)      │
│        ↓ Puppeteer 启动              │
│  Chrome (打开 index.html)            │
│        ↓ 注入 currentFrame           │
│  React 渲染该帧 DOM                  │
│        ↓ Chrome 截图                 │
│   raw PNG/JPEG (每帧)                │
│        ↓ FFmpeg 合并                 │
│   out.mp4 (最终视频)                 │
└──────────────────────────────────────┘
Chapter 03

Bundle 机制

@remotion/bundler 基于 Webpack 5,核心配置:

// remotion.config.ts
Config.setWebpackOverride((config) => {
  config.resolve.alias['@'] = path.resolve(__dirname, 'src');
  return config;
});

支持 --public-url 自定义 bundle 输出目录,便于 CDN 部署。

Chapter 04

浏览器调度:Puppeteer

每个并发实例是一个独立 Chrome 进程,通过 Chrome DevTools Protocol (CDP) 与 Node.js 通信:

  • Page.navigate:加载 bundle URL
  • Runtime.evaluate:注入 window.remotion_setFrame(frame)
  • Page.captureScreenshot:截图该帧
  • Page.close:释放资源
💡

Remotion 不使用 Puppeteer 自身的 screenshot 截整个页面,而是截特定 DOM 容器,避免头部 URL 栏等干扰。

Chapter 05

React 渲染细节

每帧切换时,Remotion 用全局变量传递 frame:

// @remotion/renderer 内部(简化)
await page.evaluate((frame) => {
  (window as any).__remotion_setCurrentFrame(frame);
}, targetFrame);

Remotion 在 Root 顶层拦截 useCurrentFrame,直接返回该全局值,避免每帧重建 React 树。

Chapter 06

FFmpeg 桥接

Node.js 端通过 child_process.spawn('ffmpeg', args) 调用:

// 内部命令(简化)
const args = [
  '-framerate', String(fps),
  '-i', 'frame-%05d.jpeg',
  '-i', 'audio.mp3',
  '-c:v', 'libx264', '-pix_fmt', 'yuv420p',
  '-c:a', 'aac', outputFile,
];

每个 Composition 一次合流,临时文件自动清理。

Chapter 07

浏览器与 Puppeteer

Remotion 渲染实际是 控制 Chrome 无头浏览器 截屏:用 Puppeteer 打开本地 URL,逐帧截屏,最后用 FFmpeg 合成视频。

ts
import { renderMedia, openBrowser } from '@remotion/renderer';

// 显式复用浏览器(适合批量渲染)
const browser = await openBrowser('chrome');
for (const composition of compositions) {
  await renderMedia({ browser, composition, ... });
}
await browser.close({ graceful: true });

Remotion 4.0.455+ 预编译了特殊 Chrome(开启 HTML-in-canvas 标志),默认优于标准 Chrome。WebGL 默认使用 --gl=angle(ANGLE 后端),可用 Config.setChromiumOpenGlRenderer('egl') 切换。

Chapter 08

serveUrl 缓存与 CDN

每个 Lambda 调用都会传 serveUrl(项目打包后的 URL)。生产最佳实践:

ts
// 1) 启动时打包一次
import { bundle } from '@remotion/bundler';
import { deploySite, getSites } from '@remotion/lambda';

const bundleLocation = await bundle({ entryPoint: 'src/index.ts' });
const { serveUrl } = await deploySite({
  bundleLocation, region, entryPointName: 'index', siteName: 'video-app',
});

// 2) 后续渲染复用(避免重复打包)
for (const data of jobs) {
  await renderMediaOnLambda({ serveUrl, composition, inputProps: data });
}
